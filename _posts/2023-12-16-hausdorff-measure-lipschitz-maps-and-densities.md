<p>Length and area can be defined for sets that have no smooth parametrization. Hausdorff measure does this by covering a set with small pieces and adding powers of their diameters. The exponent specifies the dimension being measured.</p>

<p>We develop this construction, examine its behaviour under Lipschitz maps, and prove almost-everywhere differentiability of those maps. Density estimates then describe how the measure of a set is distributed near a typical point. These are the tools needed for area, coarea, and rectifiability.</p>

<h3 data-note-section="1" id="hausdorff-measure-and-lipschitz-functions">1. Hausdorff Measure and Lipschitz Functions</h3>
<p>Lipschitz functions constitute a larger class of functions than the class of smooth functions (defined on {% raw %}<span class="math inline">\(\mathscr C^\infty\)</span>{% endraw %} manifolds) considered so far. Their uniform control on distances is enough for several of the measure-theoretic conclusions used below. We begin with defining the Hausdorff dimension of sets, and extend that to Hausdorff measures on {% raw %}<span class="math inline">\(\mathbb R^d\)</span>{% endraw %}. For starters, we define the Hausdorff measure.</p>

<div id="def:hausdorff-set" class="definition" data-note-number="1" data-note-kind="Definition">
<p><strong>Definition 1.</strong> Put {% raw %}<span class="math inline">\(c_s=\omega_s2^{-s}\)</span>{% endraw %}, where {% raw %}<span class="math inline">\(\omega_s=\pi^{s/2}/\Gamma(1+s/2)\)</span>{% endraw %}. For {% raw %}<span class="math inline">\(0\leq s&lt;\infty\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\delta&gt;0\)</span>{% endraw %}, define </p>
{% raw %}<div class="math display">\[\mathcal H_\delta^s(A)=\inf\left\{\sum_jc_s(\operatorname{diam}C_j)^s:A\subseteq\bigcup_j C_j,\ \operatorname{diam}C_j\leq\delta\right\}.\]</div>{% endraw %}
<p> For {% raw %}<span class="math inline">\(s=0\)</span>{% endraw %}, every nonempty covering set costs one, including a singleton; empty sets can be discarded. The empty cover gives zero to the empty set.</p>
</div>
<div id="def:hausdorff-measure" class="definition" data-note-number="2" data-note-kind="Definition">
<p><strong>Definition 2.</strong> The {% raw %}<span class="math inline">\(s\)</span>{% endraw %}-dimensional Hausdorff outer measure is </p>
{% raw %}<div class="math display">\[\mathcal H^s(A)=\lim_{\delta\downarrow0}\mathcal H_\delta^s(A)=\sup_{\delta&gt;0}\mathcal H_\delta^s(A).\]</div>{% endraw %}
<p> The limit exists because imposing a smaller diameter bound can only increase the infimum. The variable tending to zero is the covering scale {% raw %}<span class="math inline">\(\delta\)</span>{% endraw %}; the dimension {% raw %}<span class="math inline">\(s\)</span>{% endraw %} stays fixed.</p>
</div>
<div id="result-3" class="remark" data-note-number="3" data-note-kind="Remark">
<p><strong>Remark 3.</strong> The normalization gives {% raw %}<span class="math inline">\(\lambda_d(B_r(x))=\omega_dr^d\)</span>{% endraw %}. We use the standard normalization theorem {% raw %}<span class="math inline">\(\mathcal H^d=\lambda_d\)</span>{% endraw %} on {% raw %}<span class="math inline">\(\mathbb R^d\)</span>{% endraw %}, including outer measures. One direction follows from the isodiametric inequality {% raw %}<span class="math inline">\(\lambda_d^*(C)\leq c_d(\operatorname{diam}C)^d\)</span>{% endraw %} applied to every cover. The opposite direction is the Euclidean covering theorem; an exact statement and proof are in <a href="https://web.stanford.edu/class/math285/ts-gmt.pdf">Simon, Chapter 1, §2</a>. The linear area calculations below use this normalization.</p>
</div>
<div id="result-4" class="proposition" data-note-number="4" data-note-kind="Proposition">
<p><strong>Proposition 4.</strong> {% raw %}<span class="math inline">\(\mathcal H^s\)</span>{% endraw %} is a metric outer measure, hence all Borel sets are Carathéodory measurable. It is Borel regular: every set {% raw %}<span class="math inline">\(A\)</span>{% endraw %} has a Borel superset {% raw %}<span class="math inline">\(B\)</span>{% endraw %} with {% raw %}<span class="math inline">\(\mathcal H^s(B)=\mathcal H^s(A)\)</span>{% endraw %}. Its restriction to measurable sets is a complete measure.</p>
</div>
<p><strong>Proof.</strong> Empty-set and monotonicity properties follow directly from covers. For countable subadditivity, choose a cover of each {% raw %}<span class="math inline">\(A_k\)</span>{% endraw %} within {% raw %}<span class="math inline">\(\varepsilon2^{-k}\)</span>{% endraw %} of its infimum at scale {% raw %}<span class="math inline">\(\delta\)</span>{% endraw %}. Their union covers {% raw %}<span class="math inline">\(\bigcup_kA_k\)</span>{% endraw %}, so </p>
{% raw %}<div class="math display">\[\mathcal H_\delta^s\Bigl(\bigcup_kA_k\Bigr)\leq\sum_k\mathcal H_\delta^s(A_k)\leq\sum_k\mathcal H^s(A_k).\]</div>{% endraw %}
<p> Let {% raw %}<span class="math inline">\(\varepsilon\downarrow0\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\delta\downarrow0\)</span>{% endraw %}. These are outer-measure assertions; {% raw %}<span class="math inline">\(\mathcal H_\delta^s\)</span>{% endraw %} need not be additive on Borel sets at a fixed positive scale.</p>
<p>If {% raw %}<span class="math inline">\(\operatorname{dist}(A,B)&gt;\delta\)</span>{% endraw %}, no covering set of diameter at most {% raw %}<span class="math inline">\(\delta\)</span>{% endraw %} meets both {% raw %}<span class="math inline">\(A\)</span>{% endraw %} and {% raw %}<span class="math inline">\(B\)</span>{% endraw %}. Splitting a cover into the two subfamilies therefore gives </p>
{% raw %}<div class="math display">\[\mathcal H_\delta^s(A\cup B)\geq\mathcal H_\delta^s(A)+\mathcal H_\delta^s(B).\]</div>{% endraw %}
<p> Letting {% raw %}<span class="math inline">\(\delta\downarrow0\)</span>{% endraw %} proves metric additivity; the metric outer-measure criterion then makes every Borel set measurable.</p>
<p>For Borel regularity assume {% raw %}<span class="math inline">\(\mathcal H^s(A)&lt;\infty\)</span>{% endraw %}. Closing each covering set preserves its diameter. Choose closed {% raw %}<span class="math inline">\(C_j^k\)</span>{% endraw %} covering {% raw %}<span class="math inline">\(A\)</span>{% endraw %}, of diameter at most {% raw %}<span class="math inline">\(1/k\)</span>{% endraw %}, whose total cost is at most {% raw %}<span class="math inline">\(\mathcal H^s_{1/k}(A)+1/k\)</span>{% endraw %}. Set {% raw %}<span class="math inline">\(B=\bigcap_k\bigcup_jC_j^k\)</span>{% endraw %}. Then {% raw %}<span class="math inline">\(A\subseteq B\subseteq\bigcup_jC_j^k\)</span>{% endraw %} for every {% raw %}<span class="math inline">\(k\)</span>{% endraw %}, and </p>
{% raw %}<div class="math display">\[\mathcal H^s_{1/k}(B)\leq\mathcal H^s_{1/k}(A)+1/k.\]</div>{% endraw %}
<p> Take {% raw %}<span class="math inline">\(k\to\infty\)</span>{% endraw %} and use monotonicity for the reverse inequality. If {% raw %}<span class="math inline">\(\mathcal H^s(A)=\infty\)</span>{% endraw %}, take {% raw %}<span class="math inline">\(B=\mathbb R^d\)</span>{% endraw %}. Finally, {% raw %}<span class="math inline">\(s&lt;d\)</span>{% endraw %} gives infinite measure to every nonempty open ball, so this measure is not locally finite on {% raw %}<span class="math inline">\(\mathbb R^d\)</span>{% endraw %} in that regime. ◻</p>
<div id="prop:properties-hausdorff-measure" class="proposition" data-note-number="5" data-note-kind="Proposition">
<p><strong>Proposition 5.</strong> {% raw %}<span class="math inline">\(\mathcal H^0\)</span>{% endraw %} is counting measure; {% raw %}<span class="math inline">\(\mathcal H^1=\lambda_1\)</span>{% endraw %} on {% raw %}<span class="math inline">\(\mathbb R\)</span>{% endraw %}; {% raw %}<span class="math inline">\(\mathcal H^s=0\)</span>{% endraw %} on {% raw %}<span class="math inline">\(\mathbb R^d\)</span>{% endraw %} for {% raw %}<span class="math inline">\(s&gt;d\)</span>{% endraw %}; and </p>
{% raw %}<div class="math display">\[\mathcal H^s(aA)=a^s\mathcal H^s(A)\quad(a&gt;0),\qquad \mathcal H^s(U(A))=\mathcal H^s(A)\]</div>{% endraw %}
<p> for every affine isometry {% raw %}<span class="math inline">\(U\)</span>{% endraw %}.</p>
</div>
<p><strong>Proof.</strong> A sufficiently small scale separates any fixed finite collection of distinct points; thus the zero-dimensional cost is at least its cardinality. Singleton covers give the reverse inequality. On a line, replacing a set by its interval hull preserves diameter, yielding the usual interval-cover definition of Lebesgue outer measure. A bounded cube in {% raw %}<span class="math inline">\(\mathbb R^d\)</span>{% endraw %} can be covered by {% raw %}<span class="math inline">\(O(\delta^{-d})\)</span>{% endraw %} cubes of diameter at most {% raw %}<span class="math inline">\(\delta\)</span>{% endraw %}, at total {% raw %}<span class="math inline">\(s\)</span>{% endraw %}-cost {% raw %}<span class="math inline">\(O(\delta^{s-d})\)</span>{% endraw %}; exhaust space by bounded cubes. Scaling or applying an isometry to every cover, then applying the inverse map, proves the two equalities. ◻</p>
<div id="result-6" class="proposition" data-note-number="6" data-note-kind="Proposition">
<p><strong>Proposition 6.</strong> For a finite dimension parameter {% raw %}<span class="math inline">\(s\geq0\)</span>{% endraw %}, if {% raw %}<span class="math inline">\(\mathcal H_\delta^s(A)=0\)</span>{% endraw %} at one positive scale, then {% raw %}<span class="math inline">\(\mathcal H^s(A)=0\)</span>{% endraw %}.</p>
</div>
<p><strong>Proof.</strong> For {% raw %}<span class="math inline">\(s=0\)</span>{% endraw %}, zero cost implies {% raw %}<span class="math inline">\(A=\varnothing\)</span>{% endraw %}. For {% raw %}<span class="math inline">\(s&gt;0\)</span>{% endraw %}, a cover of total cost at most {% raw %}<span class="math inline">\(\varepsilon\)</span>{% endraw %} has each diameter at most {% raw %}<span class="math inline">\((\varepsilon/c_s)^{1/s}\)</span>{% endraw %}. Hence the same cover works at that smaller scale. Given any fixed {% raw %}<span class="math inline">\(\eta&gt;0\)</span>{% endraw %}, let {% raw %}<span class="math inline">\(\varepsilon\downarrow0\)</span>{% endraw %} with {% raw %}<span class="math inline">\((\varepsilon/c_s)^{1/s}&lt;\eta\)</span>{% endraw %}; then {% raw %}<span class="math inline">\(\mathcal H_\eta^s(A)=0\)</span>{% endraw %}. Take {% raw %}<span class="math inline">\(\eta\downarrow0\)</span>{% endraw %}. ◻</p>
<div id="result-7" class="lemma" data-note-number="7" data-note-kind="Lemma">
<p><strong>Lemma 7.</strong> For {% raw %}<span class="math inline">\(0\leq s&lt;t&lt;\infty\)</span>{% endraw %}, finite {% raw %}<span class="math inline">\(\mathcal H^s(A)\)</span>{% endraw %} implies {% raw %}<span class="math inline">\(\mathcal H^t(A)=0\)</span>{% endraw %}; equivalently, positive {% raw %}<span class="math inline">\(\mathcal H^t(A)\)</span>{% endraw %} implies infinite {% raw %}<span class="math inline">\(\mathcal H^s(A)\)</span>{% endraw %}.</p>
</div>
<p><strong>Proof.</strong> Every scale-{% raw %}<span class="math inline">\(\delta\)</span>{% endraw %} cover gives </p>
{% raw %}<div class="math display">\[\mathcal H_\delta^t(A)\leq(c_t/c_s)\delta^{t-s}\mathcal H_\delta^s(A)\leq(c_t/c_s)\delta^{t-s}\mathcal H^s(A).\]</div>{% endraw %}
<p> Send {% raw %}<span class="math inline">\(\delta\downarrow0\)</span>{% endraw %}. The zero-dimensional convention makes the same comparison valid when {% raw %}<span class="math inline">\(s=0\)</span>{% endraw %}. ◻</p>
<div id="result-8" class="definition" data-note-number="8" data-note-kind="Definition">
<p><strong>Definition 8.</strong> {% raw %}<span class="math inline">\(\dim_H A=\inf\{s\geq0:\mathcal H^s(A)=0\}\)</span>{% endraw %}. Proposition 5 gives {% raw %}<span class="math inline">\(\dim_H A\leq d\)</span>{% endraw %} for subsets of {% raw %}<span class="math inline">\(\mathbb R^d\)</span>{% endraw %}.</p>
</div>
<div id="result-9" class="proposition" data-note-number="9" data-note-kind="Proposition">
<p><strong>Proposition 9.</strong> If {% raw %}<span class="math inline">\(f:A\subseteq\mathbb R^d\to\mathbb R^q\)</span>{% endraw %} is {% raw %}<span class="math inline">\(L\)</span>{% endraw %}-Lipschitz and {% raw %}<span class="math inline">\(s&gt;0\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(\mathcal H^s(f(A))\leq L^s\mathcal H^s(A)\)</span>{% endraw %}. For {% raw %}<span class="math inline">\(s=0\)</span>{% endraw %}, the assertion is simply that a map cannot increase cardinality.</p>
</div>
<p><strong>Proof.</strong> For {% raw %}<span class="math inline">\(L&gt;0\)</span>{% endraw %}, intersect a scale-{% raw %}<span class="math inline">\(\delta\)</span>{% endraw %} cover with {% raw %}<span class="math inline">\(A\)</span>{% endraw %} and apply {% raw %}<span class="math inline">\(f\)</span>{% endraw %}. Image diameters are at most {% raw %}<span class="math inline">\(L\)</span>{% endraw %} times the original diameters, so {% raw %}<span class="math inline">\(\mathcal H_{L\delta}^s(f(A))\leq L^s\mathcal H_\delta^s(A)\)</span>{% endraw %}. Let {% raw %}<span class="math inline">\(\delta\downarrow0\)</span>{% endraw %}. A constant map has image at most one point and has zero positive-dimensional Hausdorff measure. In particular Lipschitz maps carry {% raw %}<span class="math inline">\(\mathcal H^s\)</span>{% endraw %}-null sets to null sets. ◻</p>
<div id="result-10" class="proposition" data-note-number="10" data-note-kind="Proposition">
<p><strong>Proposition 10.</strong> For {% raw %}<span class="math inline">\(f\in L^1_{\mathrm{loc}}(\mathbb R^d)\)</span>{% endraw %} and {% raw %}<span class="math inline">\(0\leq s&lt;d\)</span>{% endraw %}, the exceptional set </p>
{% raw %}<div class="math display">\[\Lambda_s=\left\{x:\limsup_{r\downarrow0}r^{-s}\int_{B_r(x)}|f(y)|\,dy&gt;0\right\}\]</div>{% endraw %}
<p> has {% raw %}<span class="math inline">\(\mathcal H^s\)</span>{% endraw %} measure zero. The factor {% raw %}<span class="math inline">\(r^{-s}\)</span>{% endraw %} is part of the assertion.</p>
</div>
<p><strong>Proof.</strong> At Lebesgue points of {% raw %}<span class="math inline">\(|f|\)</span>{% endraw %}, the displayed quantity is {% raw %}<span class="math inline">\(\omega_dr^{d-s}\)</span>{% endraw %} times a convergent average, so it tends to zero. Work on a bounded ball and truncate {% raw %}<span class="math inline">\(f\)</span>{% endraw %} outside a larger ball; this reduces the covering argument to an integrable function. For {% raw %}<span class="math inline">\(\varepsilon&gt;0\)</span>{% endraw %}, the set {% raw %}<span class="math inline">\(E\)</span>{% endraw %} where the limsup exceeds {% raw %}<span class="math inline">\(\varepsilon\)</span>{% endraw %} is Lebesgue null. Choose an open {% raw %}<span class="math inline">\(U\supseteq E\)</span>{% endraw %} with {% raw %}<span class="math inline">\(\int_U|f|&lt;\sigma\)</span>{% endraw %}. For every {% raw %}<span class="math inline">\(x\in E\)</span>{% endraw %} there are arbitrarily small closed balls {% raw %}<span class="math inline">\(B_r(x)\subset U\)</span>{% endraw %} satisfying {% raw %}<span class="math inline">\(\int_{B_r(x)}|f|&gt;\varepsilon r^s\)</span>{% endraw %}.</p>
<p>Select disjoint such balls {% raw %}<span class="math inline">\(B_{r_i}(x_i)\)</span>{% endraw %} with {% raw %}<span class="math inline">\(r_i&lt;\delta\)</span>{% endraw %} whose fivefold enlargements cover {% raw %}<span class="math inline">\(E\)</span>{% endraw %}, by Lemma 22 below. Countability follows from disjoint positive-radius balls in Euclidean space. Then </p>
{% raw %}<div class="math display">\[\mathcal H^s_{10\delta}(E)\leq\omega_s5^s\sum_i r_i^s\leq\frac{\omega_s5^s}{\varepsilon}\int_U|f|&lt;\frac{\omega_s5^s\sigma}{\varepsilon}.\]</div>{% endraw %}
<p> Let {% raw %}<span class="math inline">\(\delta\downarrow0\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(\sigma\downarrow0\)</span>{% endraw %}, and take the countable union over bounded balls and {% raw %}<span class="math inline">\(\varepsilon=1/j\)</span>{% endraw %}. For {% raw %}<span class="math inline">\(s=0\)</span>{% endraw %} absolute continuity of the integral also shows directly that {% raw %}<span class="math inline">\(E\)</span>{% endraw %} is empty. The selected balls themselves need not cover {% raw %}<span class="math inline">\(E\)</span>{% endraw %}; their enlargements do. ◻</p>
<p>The following proof supplies the derivative used in the area and coarea formulas.</p>

<div id="thm:rademacher" class="theorem" data-note-number="11" data-note-kind="Theorem">
<p><strong>Theorem 11</strong> (Rademacher).  Let {% raw %}<span class="math inline">\(f : \mathbb R^n \to \mathbb R^m\)</span>{% endraw %} be a locally Lipschitz function. Then, {% raw %}<span class="math inline">\(f\)</span>{% endraw %} is differentiable {% raw %}<span class="math inline">\(\lambda_n\)</span>{% endraw %}-a.e.</p>

</div>
<div class="proof">
<p><em>Proof.</em> It suffices to prove the scalar case on an open ball {% raw %}<span class="math inline">\(B\)</span>{% endraw %} where {% raw %}<span class="math inline">\(f\)</span>{% endraw %} has a Lipschitz constant {% raw %}<span class="math inline">\(L\)</span>{% endraw %}. A locally Lipschitz map admits a countable cover by such balls, and the vector-valued result follows by intersecting the full-measure sets for its finitely many components.</p>
<p>Fix a unit vector {% raw %}<span class="math inline">\(v\)</span>{% endraw %}. The restriction of {% raw %}<span class="math inline">\(f\)</span>{% endraw %} to every line parallel to {% raw %}<span class="math inline">\(v\)</span>{% endraw %}, on its intersection with {% raw %}<span class="math inline">\(B\)</span>{% endraw %}, is Lipschitz and hence absolutely continuous. The one-dimensional differentiation theorem and Fubini imply that</p>
{% raw %}<div class="math display">\[D_vf(x)=\lim_{t\to0}\frac{f(x+tv)-f(x)}t\]</div>{% endraw %}
<p>exists for almost every {% raw %}<span class="math inline">\(x\in B\)</span>{% endraw %}, with {% raw %}<span class="math inline">\(|D_vf|\le L\)</span>{% endraw %}. The exceptional set is measurable: the upper and lower limits can be taken through rational nonzero {% raw %}<span class="math inline">\(t\)</span>{% endraw %}, giving countable suprema and infima of continuous difference quotients. This is an almost-everywhere statement for each fixed direction, not a claim about all points.</p>
<p>Let {% raw %}<span class="math inline">\(g_i=D_{e_i}f\)</span>{% endraw %}, choosing arbitrary values on their null exceptional sets, and put {% raw %}<span class="math inline">\(g=(g_1,\ldots,g_n)\)</span>{% endraw %}. For {% raw %}<span class="math inline">\(\zeta\in C_c^\infty(B)\)</span>{% endraw %} and sufficiently small {% raw %}<span class="math inline">\(t\)</span>{% endraw %}, translation of the integration variable gives</p>
{% raw %}<div class="math display">\[\int \frac{f(x+tv)-f(x)}t\zeta(x)\,dx
 =\int f(x)\frac{\zeta(x-tv)-\zeta(x)}t\,dx.\]</div>{% endraw %}
<p>All integrations occur in a fixed compact subset of {% raw %}<span class="math inline">\(B\)</span>{% endraw %}. Dominated convergence on the left, and smoothness of {% raw %}<span class="math inline">\(\zeta\)</span>{% endraw %} on the right, give</p>
{% raw %}<div class="math display">\[\int D_vf\,\zeta=-\int f\,v\cdot\nabla\zeta
 =\sum_{i=1}^n v_i\int g_i\zeta.\]</div>{% endraw %}
<p>The last equality follows from the same identity in coordinate directions. Uniqueness of locally integrable distributions implies {% raw %}<span class="math inline">\(D_vf=v\cdot g\)</span>{% endraw %} almost everywhere.</p>
<p>Choose a countable dense set {% raw %}<span class="math inline">\(D\)</span>{% endraw %} in the unit sphere, containing the coordinate vectors. Intersect the full-measure sets just obtained for {% raw %}<span class="math inline">\(v\in D\)</span>{% endraw %}. At every point {% raw %}<span class="math inline">\(x\)</span>{% endraw %} of the resulting set, all these directional derivatives exist and equal {% raw %}<span class="math inline">\(v\cdot g(x)\)</span>{% endraw %}. We show that {% raw %}<span class="math inline">\(h\mapsto g(x)\cdot h\)</span>{% endraw %} is the full derivative.</p>
<p>For small nonzero {% raw %}<span class="math inline">\(t\)</span>{% endraw %}, put</p>
{% raw %}<div class="math display">\[Q_t(v)=\frac{f(x+tv)-f(x)}t-g(x)\cdot v.\]</div>{% endraw %}
<p>Uniformly over unit vectors {% raw %}<span class="math inline">\(v,w\)</span>{% endraw %}, the Lipschitz bound gives {% raw %}<span class="math inline">\(|Q_t(v)-Q_t(w)|\le(L+|g(x)|)|v-w|\)</span>{% endraw %}. Given {% raw %}<span class="math inline">\(\varepsilon&gt;0\)</span>{% endraw %}, choose a finite set {% raw %}<span class="math inline">\(v_1,\ldots,v_N\in D\)</span>{% endraw %} whose balls of radius {% raw %}<span class="math inline">\(\varepsilon/[2(L+|g(x)|+1)]\)</span>{% endraw %} cover the sphere. For sufficiently small {% raw %}<span class="math inline">\(|t|\)</span>{% endraw %}, all {% raw %}<span class="math inline">\(|Q_t(v_j)|&lt;\varepsilon/2\)</span>{% endraw %}. The preceding Lipschitz estimate then gives {% raw %}<span class="math inline">\(\sup_{|v|=1}|Q_t(v)|&lt;\varepsilon\)</span>{% endraw %}. Setting {% raw %}<span class="math inline">\(t=|h|\)</span>{% endraw %} and {% raw %}<span class="math inline">\(v=h/|h|\)</span>{% endraw %} proves</p>
{% raw %}<div class="math display">\[\lim_{h\to0}\frac{|f(x+h)-f(x)-g(x)\cdot h|}{|h|}=0.\]</div>{% endraw %}
<p>This proves differentiability at every point of a full-measure set. The union of the null exceptional sets over the countable ball cover and the finitely many output components is still null. This completes the proof. ◻</p>

</div>
<p>The following linear estimates and decompositions prepare for the area and coarea formulas. They relate the Jacobian to the measure of images and fibres.</p>

<div id="lem:high-dim-pythagorean" class="lemma" data-note-number="12" data-note-kind="Lemma">
<p><strong>Lemma 12.</strong> For a linear map {% raw %}<span class="math inline">\(L:\mathbb R^n\to\mathbb R^m\)</span>{% endraw %} with {% raw %}<span class="math inline">\(n\leq m\)</span>{% endraw %}, </p>
{% raw %}<div class="math display">\[\mathcal H^n(L(A))=J_nL\,\lambda_n^*(A),\qquad J_nL=\sqrt{\det(L^*L)}.\]</div>{% endraw %}
<p> This holds for every {% raw %}<span class="math inline">\(A\)</span>{% endraw %}, with {% raw %}<span class="math inline">\(0\cdot\infty=0\)</span>{% endraw %} when the rank is deficient.</p>
</div>
<p><strong>Proof.</strong> If {% raw %}<span class="math inline">\(L\)</span>{% endraw %} is injective, write {% raw %}<span class="math inline">\(L=OT\)</span>{% endraw %} with {% raw %}<span class="math inline">\(O\)</span>{% endraw %} an isometry onto its range and {% raw %}<span class="math inline">\(T=(L^*L)^{1/2}\)</span>{% endraw %} positive definite. Isometry invariance, {% raw %}<span class="math inline">\(\mathcal H^n=\lambda_n\)</span>{% endraw %} on an {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-plane, and linear change of variables give the formula. If the rank is below {% raw %}<span class="math inline">\(n\)</span>{% endraw %}, the image is contained in a lower-dimensional linear space, whose {% raw %}<span class="math inline">\(\mathcal H^n\)</span>{% endraw %} measure is zero by a cube covering. ◻</p>
<div id="lem:mble-lipschitz-image" class="lemma" data-note-number="13" data-note-kind="Lemma">
<p><strong>Lemma 13.</strong> Let {% raw %}<span class="math inline">\(f:\mathbb R^n\to\mathbb R^m\)</span>{% endraw %} be Lipschitz, {% raw %}<span class="math inline">\(n\leq m\)</span>{% endraw %}, and let {% raw %}<span class="math inline">\(A\)</span>{% endraw %} be Lebesgue measurable. Then {% raw %}<span class="math inline">\(f(A)\)</span>{% endraw %} and the multiplicity {% raw %}<span class="math inline">\(N(f,A,y)=\mathcal H^0(A\cap f^{-1}(y))\)</span>{% endraw %} are {% raw %}<span class="math inline">\(\mathcal H^n\)</span>{% endraw %}-measurable, and </p>
{% raw %}<div class="math display">\[\int N(f,A,y)\,d\mathcal H^n(y)\leq\operatorname{Lip}(f)^n\lambda_n(A).\]</div>{% endraw %}

</div>
<p><strong>Proof.</strong> Write {% raw %}<span class="math inline">\(A\)</span>{% endraw %} as a countable union of compact sets together with a null remainder. The compact images are compact, and the remaining image is {% raw %}<span class="math inline">\(\mathcal H^n\)</span>{% endraw %}-null by Proposition 9. This proves image measurability, also for {% raw %}<span class="math inline">\(A\)</span>{% endraw %} intersected with any dyadic cube. Partition all of {% raw %}<span class="math inline">\(\mathbb R^n\)</span>{% endraw %} into half-open dyadic cubes of side {% raw %}<span class="math inline">\(2^{-k}\)</span>{% endraw %} and set </p>
{% raw %}<div class="math display">\[N_k(y)=\sum_Q\mathbb1_{f(A\cap Q)}(y).\]</div>{% endraw %}
<p> These measurable counts increase under refinement. Any finite collection of distinct preimages is separated by sufficiently small cubes, so {% raw %}<span class="math inline">\(N_k\uparrow N\)</span>{% endraw %}, including infinite multiplicities. Finally, </p>
{% raw %}<div class="math display">\[\int N_k\,d\mathcal H^n=\sum_Q\mathcal H^n(f(A\cap Q))\leq L^n\sum_Q\lambda_n(A\cap Q)=L^n\lambda_n(A).\]</div>{% endraw %}
<p> Monotone convergence completes the proof. ◻</p>
<div id="lem:lipschitz-gradient-borel-bound" class="lemma" data-note-number="14" data-note-kind="Lemma">
<p><strong>Lemma 14.</strong> Let {% raw %}<span class="math inline">\(f:\mathbb R^n\to\mathbb R^m\)</span>{% endraw %} be Lipschitz, {% raw %}<span class="math inline">\(n\leq m\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(t&gt;1\)</span>{% endraw %}. The differentiability set {% raw %}<span class="math inline">\(B=\{x:J_nf(x)&gt;0\}\)</span>{% endraw %} has a countable Borel partition into sets {% raw %}<span class="math inline">\(E_k\)</span>{% endraw %} on which {% raw %}<span class="math inline">\(f\)</span>{% endraw %} is injective. There are positive definite symmetric {% raw %}<span class="math inline">\(T_k:\mathbb R^n\to\mathbb R^n\)</span>{% endraw %} such that </p>
{% raw %}<div class="math display">\[\operatorname{Lip}(f|_{E_k}\circ T_k^{-1})\leq t,\quad \operatorname{Lip}(T_k\circ(f|_{E_k})^{-1})\leq t,\quad t^{-n}\det T_k\leq J_nf(x)\leq t^n\det T_k\quad(x\in E_k).\]</div>{% endraw %}
<p> The maps and inverses here have their natural restricted domains and images.</p>
</div>
<p><strong>Proof.</strong> Choose {% raw %}<span class="math inline">\(\eta&gt;0\)</span>{% endraw %} with {% raw %}<span class="math inline">\(1+\eta\leq t\)</span>{% endraw %} and {% raw %}<span class="math inline">\((1-\eta)^{-1}\leq t\)</span>{% endraw %}. Approximate {% raw %}<span class="math inline">\(Df(x)\)</span>{% endraw %} by a full-rank matrix {% raw %}<span class="math inline">\(A\)</span>{% endraw %} from a countable dense family. Put {% raw %}<span class="math inline">\(T=(A^*A)^{1/2}\)</span>{% endraw %}. Group points for which </p>
{% raw %}<div class="math display">\[\|(Df(x)-A)T^{-1}\|&lt;\eta/2,\]</div>{% endraw %}
<p> and for which the differentiability remainder, uniformly for {% raw %}<span class="math inline">\(0&lt;|h|&lt;1/j\)</span>{% endraw %}, is at most {% raw %}<span class="math inline">\((\eta/2)\,\sigma_{\min}(T)|h|\)</span>{% endraw %}. Subdivide each group into Borel pieces of diameter less than {% raw %}<span class="math inline">\(1/j\)</span>{% endraw %}. Differentiability and the measurability of the derivative make these a countable Borel cover of {% raw %}<span class="math inline">\(B\)</span>{% endraw %}; rational {% raw %}<span class="math inline">\(h\)</span>{% endraw %} suffice to express the uniform condition because {% raw %}<span class="math inline">\(f\)</span>{% endraw %} is continuous. Disjointize the cover.</p>
<p>For {% raw %}<span class="math inline">\(x,y\)</span>{% endraw %} in one piece the two errors give </p>
{% raw %}<div class="math display">\[|f(y)-f(x)-A(y-x)|\leq\eta|T(y-x)|.\]</div>{% endraw %}
<p> Since {% raw %}<span class="math inline">\(|Av|=|Tv|\)</span>{% endraw %}, the image distance lies between {% raw %}<span class="math inline">\((1-\eta)|T(y-x)|\)</span>{% endraw %} and {% raw %}<span class="math inline">\((1+\eta)|T(y-x)|\)</span>{% endraw %}. This proves injectivity and the two Lipschitz bounds. Every singular value of {% raw %}<span class="math inline">\(Df(x)T^{-1}\)</span>{% endraw %} lies between {% raw %}<span class="math inline">\(1-\eta\)</span>{% endraw %} and {% raw %}<span class="math inline">\(1+\eta\)</span>{% endraw %}, so its {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-Jacobian is between their {% raw %}<span class="math inline">\(n\)</span>{% endraw %}th powers. Multiplication by {% raw %}<span class="math inline">\(\det T\)</span>{% endraw %} proves the last bounds. ◻</p>
<div id="lem:hausdorff-upwards-dimension" class="lemma" data-note-number="15" data-note-kind="Lemma">
<p><strong>Lemma 15.</strong> For linear {% raw %}<span class="math inline">\(L:\mathbb R^n\to\mathbb R^m\)</span>{% endraw %}, {% raw %}<span class="math inline">\(n\geq m\)</span>{% endraw %}, and Lebesgue measurable {% raw %}<span class="math inline">\(A\)</span>{% endraw %}, </p>
{% raw %}<div class="math display">\[\int_{\mathbb R^m}\mathcal H^{n-m}(A\cap L^{-1}(y))\,dy=J_mL\,\lambda_n(A),\qquad J_mL=\sqrt{\det(LL^*)}.\]</div>{% endraw %}
<p> Slice measurability and the integral are understood for almost every {% raw %}<span class="math inline">\(y\)</span>{% endraw %}, with completed measures.</p>
</div>
<p><strong>Proof.</strong> If {% raw %}<span class="math inline">\(L\)</span>{% endraw %} has full rank, orthogonal changes of coordinates put it into the form {% raw %}<span class="math inline">\(L(z,w)=Dz\)</span>{% endraw %}, with {% raw %}<span class="math inline">\(D\)</span>{% endraw %} invertible, {% raw %}<span class="math inline">\(z\in\mathbb R^m\)</span>{% endraw %} and {% raw %}<span class="math inline">\(w\in\mathbb R^{n-m}\)</span>{% endraw %}. Fibres are isometric copies of the {% raw %}<span class="math inline">\(w\)</span>{% endraw %}-space. Fubini followed by {% raw %}<span class="math inline">\(y=Dz\)</span>{% endraw %} gives the formula and almost-everywhere measurability. A null change in {% raw %}<span class="math inline">\(A\)</span>{% endraw %} changes almost no slice. If the rank is below {% raw %}<span class="math inline">\(m\)</span>{% endraw %}, the image lies in a Lebesgue-null subspace; all fibres outside it are empty, and both sides are zero. ◻</p>
<div id="lem:mble-lipschitz-image-upwards-dimension" class="lemma" data-note-number="16" data-note-kind="Lemma">
<p><strong>Lemma 16.</strong> The covering inequality needed for coarea is the following: if {% raw %}<span class="math inline">\(E\subset\mathbb R^N\)</span>{% endraw %} is {% raw %}<span class="math inline">\(\mathcal H^q\)</span>{% endraw %}-measurable with finite measure and {% raw %}<span class="math inline">\(f:\mathbb R^N\to\mathbb R^m\)</span>{% endraw %} is {% raw %}<span class="math inline">\(L\)</span>{% endraw %}-Lipschitz, with integers {% raw %}<span class="math inline">\(q\geq m\geq1\)</span>{% endraw %}, then </p>
{% raw %}<div class="math display">\[\int_{\mathbb R^m}\mathcal H^{q-m}(E\cap f^{-1}(y))\,dy\leq\frac{\omega_{q-m}\omega_m}{\omega_q}L^m\mathcal H^q(E).\]</div>{% endraw %}
<p> When the right side is finite, the fibres are measurable for almost every {% raw %}<span class="math inline">\(y\)</span>{% endraw %}, and their measure has a measurable representative. In particular this applies to {% raw %}<span class="math inline">\(q=N=n\)</span>{% endraw %}. No measurability of {% raw %}<span class="math inline">\(f(E)\)</span>{% endraw %} is asserted in this dimension regime.</p>
</div>
<p><strong>Covering argument.</strong> At scale {% raw %}<span class="math inline">\(\delta\)</span>{% endraw %}, cover {% raw %}<span class="math inline">\(E\)</span>{% endraw %} by closed bounded sets {% raw %}<span class="math inline">\(C_i\)</span>{% endraw %} of near-minimal total {% raw %}<span class="math inline">\(q\)</span>{% endraw %}-cost. For each {% raw %}<span class="math inline">\(y\)</span>{% endraw %}, their intersections with {% raw %}<span class="math inline">\(f^{-1}(y)\)</span>{% endraw %} cover the slice. Thus its {% raw %}<span class="math inline">\((q-m)\)</span>{% endraw %}-dimensional content is at most </p>
{% raw %}<div class="math display">\[\sum_i c_{q-m}(\operatorname{diam}C_i)^{q-m}\mathbb1_{f(C_i)}(y).\]</div>{% endraw %}
<p> The images are compact, and the isodiametric inequality bounds their Lebesgue measures by {% raw %}<span class="math inline">\(c_mL^m(\operatorname{diam}C_i)^m\)</span>{% endraw %}. Use upper integrals until slice measurability is established, let {% raw %}<span class="math inline">\(\delta\downarrow0\)</span>{% endraw %} using Fatou, and let the covering costs decrease to {% raw %}<span class="math inline">\(\mathcal H^q(E)\)</span>{% endraw %}. The constant is {% raw %}<span class="math inline">\(c_{q-m}c_m/c_q=\omega_{q-m}\omega_m/\omega_q\)</span>{% endraw %}. For null {% raw %}<span class="math inline">\(E\)</span>{% endraw %} this argument gives zero outer measure on almost every fibre, even if {% raw %}<span class="math inline">\(E\)</span>{% endraw %} is not Borel. For finite positive measure choose a Borel hull differing by a null set; the measurable-section theorem for Hausdorff measures supplies measurability for the Borel part. These standard section-measurability details are included in the coarea framework in <a href="https://web.stanford.edu/class/math285/ts-gmt.pdf">Simon, Chapter 2, Theorems 1.8–1.9, pp.44–46</a>. The coarea inequality extends to sigma-finite {% raw %}<span class="math inline">\(E\)</span>{% endraw %} by a disjoint finite-measure decomposition and Tonelli.</p>
<p>The image of a Lebesgue measurable set under a Lipschitz map need not be Lebesgue measurable: a nonmeasurable subset {% raw %}<span class="math inline">\(V\subset\mathbb R\)</span>{% endraw %} gives a Lebesgue measurable null subset {% raw %}<span class="math inline">\(V\times\{0\}\)</span>{% endraw %} of {% raw %}<span class="math inline">\(\mathbb R^2\)</span>{% endraw %}, whose coordinate projection is {% raw %}<span class="math inline">\(V\)</span>{% endraw %}.</p>
<div id="lem:lipschitz-gradient-borel-bound-upwards-dimension" class="lemma" data-note-number="17" data-note-kind="Lemma">
<p><strong>Lemma 17.</strong> For a Lipschitz map {% raw %}<span class="math inline">\(h:\mathbb R^n\to\mathbb R^n\)</span>{% endraw %} and {% raw %}<span class="math inline">\(t&gt;1\)</span>{% endraw %}, the set where {% raw %}<span class="math inline">\(Dh\)</span>{% endraw %} exists and is invertible has a countable Borel partition {% raw %}<span class="math inline">\(D_k\)</span>{% endraw %}. For invertible linear maps {% raw %}<span class="math inline">\(S_k\)</span>{% endraw %}, the map {% raw %}<span class="math inline">\(F_k=S_k^{-1}\circ h|_{D_k}\)</span>{% endraw %} and its inverse are {% raw %}<span class="math inline">\(t\)</span>{% endraw %}-Lipschitz; moreover every singular value of {% raw %}<span class="math inline">\(S_k^{-1}Dh(x)\)</span>{% endraw %} is in {% raw %}<span class="math inline">\([t^{-1},t]\)</span>{% endraw %} for {% raw %}<span class="math inline">\(x\in D_k\)</span>{% endraw %}.</p>
</div>
<p><strong>Proof.</strong> Use the construction of Lemma 14 with a countable dense family of invertible square matrices {% raw %}<span class="math inline">\(S\)</span>{% endraw %}, but apply the error bound after multiplication by {% raw %}<span class="math inline">\(S^{-1}\)</span>{% endraw %}. On sufficiently small pieces, </p>
{% raw %}<div class="math display">\[|S^{-1}(h(y)-h(x))-(y-x)|\leq\eta|y-x|,\qquad\|S^{-1}Dh(x)-I\|\leq\eta.\]</div>{% endraw %}
<p> The same choices of {% raw %}<span class="math inline">\(\eta\)</span>{% endraw %} give the claimed bounds. No symmetry of {% raw %}<span class="math inline">\(S\)</span>{% endraw %} is needed. A dimension-reducing map {% raw %}<span class="math inline">\(f:\mathbb R^n\to\mathbb R^m\)</span>{% endraw %} with {% raw %}<span class="math inline">\(n&gt;m\)</span>{% endraw %} cannot itself have the asserted local inverse; coarea applies this lemma to the square augmented map {% raw %}<span class="math inline">\(h=(f,P)\)</span>{% endraw %} instead. ◻</p>
<div id="result-18" class="remark" data-note-number="18" data-note-kind="Remark">
<p><strong>Remark 18.</strong> The two Jacobians use different Gram matrices: {% raw %}<span class="math inline">\(J_nL=\sqrt{\det(L^*L)}\)</span>{% endraw %} for {% raw %}<span class="math inline">\(n\leq m\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(J_mL=\sqrt{\det(LL^*)}\)</span>{% endraw %} for {% raw %}<span class="math inline">\(n\geq m\)</span>{% endraw %}. A rectangular map itself has no determinant.</p>
</div>

<h3 data-note-section="2" id="densities">2. Densities</h3>
<p>Let {% raw %}<span class="math inline">\((X,d)\)</span>{% endraw %} be a metric space, let {% raw %}<span class="math inline">\(\mu\)</span>{% endraw %} be an outer measure, let {% raw %}<span class="math inline">\(A\subset X\)</span>{% endraw %} be {% raw %}<span class="math inline">\(\mu\)</span>{% endraw %}-measurable, and let {% raw %}<span class="math inline">\(x\in X\)</span>{% endraw %}.</p>

<div id="result-19" class="definition" data-note-number="19" data-note-kind="Definition">
<p><strong>Definition 19.</strong> For a Borel regular measure {% raw %}<span class="math inline">\(\mu\)</span>{% endraw %} on a metric space and a measurable set {% raw %}<span class="math inline">\(A\)</span>{% endraw %}, define </p>
{% raw %}<div class="math display">\[\Theta^{*n}(\mu,A,x)=\limsup_{r\downarrow0}\frac{\mu(A\cap\overline B_r(x))}{\omega_nr^n},\qquad \Theta_*^n(\mu,A,x)=\liminf_{r\downarrow0}\frac{\mu(A\cap\overline B_r(x))}{\omega_nr^n}.\]</div>{% endraw %}
<p> Here {% raw %}<span class="math inline">\(n\geq1\)</span>{% endraw %} and balls have their specified centres and radii.</p>
</div>
<div id="result-20" class="remark" data-note-number="20" data-note-kind="Remark">
<p><strong>Remark 20.</strong> If the restriction {% raw %}<span class="math inline">\(\mu\mathbin{\restriction}A\)</span>{% endraw %} is finite on a slightly larger ball around {% raw %}<span class="math inline">\(x\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(z\mapsto\mu(A\cap\overline B_r(z))\)</span>{% endraw %} is upper semicontinuous at {% raw %}<span class="math inline">\(x\)</span>{% endraw %}. Indeed, for {% raw %}<span class="math inline">\(z\)</span>{% endraw %} near {% raw %}<span class="math inline">\(x\)</span>{% endraw %} it is at most {% raw %}<span class="math inline">\(\mu(A\cap\overline B_{r+\varepsilon}(x))\)</span>{% endraw %}; continuity from above as {% raw %}<span class="math inline">\(\varepsilon\downarrow0\)</span>{% endraw %} proves the assertion. Local finiteness supplies this hypothesis in Euclidean space. The function need not be bounded on the whole space.</p>
</div>
<div id="thm:upper-density-comparison" class="theorem" data-note-number="21" data-note-kind="Theorem">
<p><strong>Theorem 21.</strong> Let {% raw %}<span class="math inline">\(\mu\)</span>{% endraw %} be a Borel regular measure, let {% raw %}<span class="math inline">\(A_2\)</span>{% endraw %} be measurable, and {% raw %}<span class="math inline">\(A_1\subseteq A_2\)</span>{% endraw %}. If {% raw %}<span class="math inline">\(\Theta^{*n}(\mu,A_2,x)\geq t\)</span>{% endraw %} for every {% raw %}<span class="math inline">\(x\in A_1\)</span>{% endraw %}, then </p>
{% raw %}<div class="math display">\[t\mathcal H^n(A_1)\leq\mu(A_2).\]</div>{% endraw %}
<p> For {% raw %}<span class="math inline">\(t=0\)</span>{% endraw %} the assertion means only nonnegativity.</p>
</div>
<div id="lem:5-times-covering" class="lemma" data-note-number="22" data-note-kind="Lemma">
<p><strong>Lemma 22.</strong> A family of closed balls with positive radii bounded above by {% raw %}<span class="math inline">\(R&lt;\infty\)</span>{% endraw %} has a pairwise disjoint subfamily such that every original ball meets a selected ball of radius at least half its radius, and is contained in that selected ball’s fivefold enlargement. In a separable metric space the selected family is countable.</p>
</div>
<p><strong>Proof.</strong> Group radii into {% raw %}<span class="math inline">\((R2^{-j-1},R2^{-j}]\)</span>{% endraw %}, {% raw %}<span class="math inline">\(j=0,1,\ldots\)</span>{% endraw %}. At each level choose a maximal disjoint subfamily among balls disjoint from all earlier selections. Maximality follows from Zorn’s lemma, since unions of chains of disjoint families remain disjoint. Every rejected ball meets a selection at its own or an earlier level, whose radius {% raw %}<span class="math inline">\(r&#39;\)</span>{% endraw %} satisfies {% raw %}<span class="math inline">\(r\leq2r&#39;\)</span>{% endraw %}. For any {% raw %}<span class="math inline">\(z\)</span>{% endraw %} in the rejected ball, the intersecting-ball triangle inequality gives {% raw %}<span class="math inline">\(d(z,x&#39;)\leq2r+r&#39;\leq5r&#39;\)</span>{% endraw %}. Separability makes a disjoint family of positive-radius balls countable, by assigning distinct points of a fixed countable dense set in their interiors. In a general metric space the family may be uncountable, but positive measure inside each selected ball and finite total measure also give countability. ◻</p>
<p><strong>Proof of Theorem 21.</strong> We may assume {% raw %}<span class="math inline">\(t&gt;0\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\mu(A_2)&lt;\infty\)</span>{% endraw %}. Fix {% raw %}<span class="math inline">\(0&lt;\tau&lt;t\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\delta&gt;0\)</span>{% endraw %}. Take every closed ball centred at {% raw %}<span class="math inline">\(x\in A_1\)</span>{% endraw %}, of radius {% raw %}<span class="math inline">\(0&lt;r&lt;\delta/10\)</span>{% endraw %}, for which {% raw %}<span class="math inline">\(\mu(A_2\cap B_r(x))&gt;\tau\omega_nr^n\)</span>{% endraw %}. There are arbitrarily small such balls at every {% raw %}<span class="math inline">\(x\)</span>{% endraw %}. Lemma 22 gives disjoint selections {% raw %}<span class="math inline">\(B_i=B_{r_i}(x_i)\)</span>{% endraw %}, which are countable since each has positive {% raw %}<span class="math inline">\(\mu\mathbin{\restriction}A_2\)</span>{% endraw %} measure. They satisfy </p>
{% raw %}<div class="math display">\[\tau\sum_i\omega_nr_i^n\leq\mu(A_2).\]</div>{% endraw %}
<p> For every {% raw %}<span class="math inline">\(N\)</span>{% endraw %}, </p>
{% raw %}<div class="math display">\[A_1\setminus\bigcup_{i\leq N}B_i\subseteq\bigcup_{i&gt;N}5B_i.\]</div>{% endraw %}
<p> To justify this stronger tail assertion, a point outside the first finitely many closed balls has a positive distance from their union. Choose a sufficiently small eligible ball centred there, disjoint from those balls. The selection property forces it to meet a selected ball with index greater than {% raw %}<span class="math inline">\(N\)</span>{% endraw %}, whose enlargement contains the point.</p>
<p>The first {% raw %}<span class="math inline">\(N\)</span>{% endraw %} original balls and the enlarged tail therefore cover {% raw %}<span class="math inline">\(A_1\)</span>{% endraw %}, all at diameter at most {% raw %}<span class="math inline">\(\delta\)</span>{% endraw %}. Hence </p>
{% raw %}<div class="math display">\[\mathcal H_\delta^n(A_1)\leq\sum_{i\leq N}\omega_nr_i^n+5^n\sum_{i&gt;N}\omega_nr_i^n.\]</div>{% endraw %}
<p> The series is finite; let {% raw %}<span class="math inline">\(N\to\infty\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(\delta\downarrow0\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(\tau\uparrow t\)</span>{% endraw %}. The covering argument with an enlarged tail proves the density-comparison bound with sharp constant one. Merely using the enlarged balls throughout would give the weaker constant {% raw %}<span class="math inline">\(5^n\)</span>{% endraw %}. ◻</p>
<div id="thm:upper-density" class="theorem" data-note-number="23" data-note-kind="Theorem">
<p><strong>Theorem 23.</strong> If {% raw %}<span class="math inline">\(\mu\)</span>{% endraw %} is Borel regular on a metric space and {% raw %}<span class="math inline">\(A\)</span>{% endraw %} is measurable with {% raw %}<span class="math inline">\(\mu(A)&lt;\infty\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(\Theta^{*n}(\mu,A,x)=0\)</span>{% endraw %} for {% raw %}<span class="math inline">\(\mathcal H^n\)</span>{% endraw %}-almost every {% raw %}<span class="math inline">\(x\notin A\)</span>{% endraw %}.</p>
</div>
<p><strong>Proof.</strong> Put {% raw %}<span class="math inline">\(\nu=\mu\mathbin{\restriction}A\)</span>{% endraw %}, a finite Borel regular measure. Its metric regularity gives closed {% raw %}<span class="math inline">\(C_j\subset A\)</span>{% endraw %} with {% raw %}<span class="math inline">\(\mu(A\setminus C_j)\to0\)</span>{% endraw %} (in Euclidean space this is the usual compact approximation). Set {% raw %}<span class="math inline">\(S_t=\{x\notin A:\Theta^{*n}(\mu,A,x)\geq t\}\)</span>{% endraw %}. For {% raw %}<span class="math inline">\(x\in S_t\)</span>{% endraw %}, sufficiently small balls miss {% raw %}<span class="math inline">\(C_j\)</span>{% endraw %}, so </p>
{% raw %}<div class="math display">\[\Theta^{*n}(\nu,X\setminus C_j,x)=\Theta^{*n}(\mu,A,x)\geq t.\]</div>{% endraw %}
<p> Apply Theorem 21 to {% raw %}<span class="math inline">\(\nu\)</span>{% endraw %}, {% raw %}<span class="math inline">\(A_1=S_t\)</span>{% endraw %}, {% raw %}<span class="math inline">\(A_2=X\setminus C_j\)</span>{% endraw %}. This gives {% raw %}<span class="math inline">\(t\mathcal H^n(S_t)\leq\mu(A\setminus C_j)\)</span>{% endraw %}. Let {% raw %}<span class="math inline">\(j\to\infty\)</span>{% endraw %}, then take the union over {% raw %}<span class="math inline">\(t=1/k\)</span>{% endraw %}. For locally finite restrictions, the same conclusion holds locally by a countable exhaustion. ◻</p>
<p>The density comparison and regularity inputs are also stated in <a href="https://web.stanford.edu/class/math285/ts-gmt.pdf">Simon, Chapter 1, Theorems 3.3 and 3.6</a>; the selection and tail-cover steps above give the argument used here.</p>
