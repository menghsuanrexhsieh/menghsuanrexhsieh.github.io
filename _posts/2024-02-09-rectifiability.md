<div id="rectifiability" data-note-section="title">

</div>
<p>We take the rectifiable dimension {% raw %}<span class="math inline">\(n\geq1\)</span>{% endraw %}. Rectifiability describes sets that can be covered, apart from a set of Hausdorff measure zero, by countably many Lipschitz images of Euclidean sets. It retains enough of the structure of a smooth submanifold to support tangent planes and area calculations.</p>

<p>We compare this parametrized description with the existence of approximate tangent planes almost everywhere. The converse direction is the main task: concentration near planes must be turned into Lipschitz graph pieces. We then discuss the part of a set that admits no rectifiable piece of positive measure.</p>

<div id="def:countably-n-rectifiable" class="definition" data-note-number="1" data-note-kind="Definition">
<p><strong>Definition 1</strong>.  Let {% raw %}<span class="math inline">\(M \subset \mathbb R^{n+m}\)</span>{% endraw %}. {% raw %}<span class="math inline">\(M\)</span>{% endraw %} is <strong>countably {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-rectifiable</strong> if </p>

{% raw %}<div class="math display">\[\begin{aligned}
        M \subset M_0 \cup \bigcup_{j \geq 1} F_j (\mathbb R^n) ~,
    
\end{aligned}\]</div>{% endraw %}
<p> where {% raw %}<span class="math inline">\(\mathcal H^n (M_0) = 0\)</span>{% endraw %} and {% raw %}<span class="math inline">\(F_j : \mathbb R^n \to \mathbb R^{n+m}\)</span>{% endraw %} are Lipschitz functions for all {% raw %}<span class="math inline">\(j\)</span>{% endraw %}. In the view of the extension theorems, this amounts to saying that for some {% raw %}<span class="math inline">\(A_j \subset \mathbb R^n\)</span>{% endraw %}, </p>

{% raw %}<div class="math display">\[\begin{aligned}
        M \subset M_0 \cup \bigcup_{j \geq 1} F_j (A_j) ~,
    
\end{aligned}\]</div>{% endraw %}
<p> under the identical conditions as stated above.</p>

</div>
<div id="prop:characterization-countably-n-rectifiable" class="proposition" data-note-number="2" data-note-kind="Proposition">
<p><strong>Proposition 2.</strong> A set {% raw %}<span class="math inline">\(M\subset\mathbb R^{n+m}\)</span>{% endraw %} is countably {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-rectifiable if and only if it is contained in a null set together with countably many embedded {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-dimensional {% raw %}<span class="math inline">\(C^1\)</span>{% endraw %} submanifolds.</p>
</div>
<p><strong>Proof.</strong> A {% raw %}<span class="math inline">\(C^1\)</span>{% endraw %} parametrization is Lipschitz on each closed ball compactly contained in its coordinate domain. Second countability and a countable exhaustion of each chart give a countable Lipschitz cover. Each restricted map extends componentwise to the whole {% raw %}<span class="math inline">\(\mathbb R^n\)</span>{% endraw %}, so this proves one direction.</p>
<p>Conversely, consider a Lipschitz map {% raw %}<span class="math inline">\(F:\mathbb R^n\to\mathbb R^{n+m}\)</span>{% endraw %}. The {% raw %}<span class="math inline">\(C^1\)</span>{% endraw %} approximation theorem supplies maps {% raw %}<span class="math inline">\(G_i:\mathbb R^n\to\mathbb R^{n+m}\)</span>{% endraw %} for which </p>
{% raw %}<div class="math display">\[\lambda_n\{x:F(x)\ne G_i(x)\text{ or }DF(x)\ne DG_i(x)\}&lt;1/i.\]</div>{% endraw %}
<p> Apply the scalar theorem to each output component with error {% raw %}<span class="math inline">\(1/[i(n+m)]\)</span>{% endraw %} and take their union. The exact input is <a href="https://web.stanford.edu/class/math285/ts-gmt.pdf">Simon, Chapter 2, Theorem 1.5</a>, which follows from Whitney extension after selecting sets with continuous derivative and uniform differentiability remainder. The common exceptional set {% raw %}<span class="math inline">\(Z=\mathbb R^n\setminus\bigcup_i\{F=G_i,DF=DG_i\}\)</span>{% endraw %} is null, since it has measure at most {% raw %}<span class="math inline">\(1/i\)</span>{% endraw %} for every {% raw %}<span class="math inline">\(i\)</span>{% endraw %}. Its Lipschitz image is {% raw %}<span class="math inline">\(\mathcal H^n\)</span>{% endraw %}-null.</p>
<p>For each {% raw %}<span class="math inline">\(G_i\)</span>{% endraw %}, the area formula on bounded coordinate balls shows </p>
{% raw %}<div class="math display">\[\mathcal H^n\bigl(G_i(\{J_nG_i=0\})\bigr)=0.\]</div>{% endraw %}
<p> It is the <strong>image</strong> of the critical set that is null; the critical set in the domain need not be null. At a regular point, one coordinate {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-minor of {% raw %}<span class="math inline">\(DG_i\)</span>{% endraw %} is nonzero. The inverse function theorem for that coordinate projection writes the nearby image of {% raw %}<span class="math inline">\(G_i\)</span>{% endraw %} as an embedded {% raw %}<span class="math inline">\(C^1\)</span>{% endraw %} graph. Countably many such neighbourhoods cover all regular points. Therefore {% raw %}<span class="math inline">\(F(\mathbb R^n)\)</span>{% endraw %} is covered by countably many embedded submanifolds and a null set. Repeat this for the countably many parametrizations of {% raw %}<span class="math inline">\(M\)</span>{% endraw %}. ◻</p>
<div id="result-3" class="remark" data-note-number="3" data-note-kind="Remark">
<p><strong>Remark 3.</strong> If {% raw %}<span class="math inline">\(M\)</span>{% endraw %} is measurable, disjointize the cover by {% raw %}<span class="math inline">\(M_0=M\cap N_0\)</span>{% endraw %} and {% raw %}<span class="math inline">\(M_j=M\cap(N_j\setminus\bigcup_{i&lt;j}N_i)\)</span>{% endraw %}. The manifold patches can be chosen with finite area in precompact graph charts. This makes the local measure estimates below applicable without assuming that a whole nonproper embedded manifold has finite area in every ambient compact set.</p>
</div>

<div id="def:approx-tangent-space" class="definition" data-note-number="4" data-note-kind="Definition">
<p><strong>Definition 4</strong>.  Let {% raw %}<span class="math inline">\(M\)</span>{% endraw %} be a {% raw %}<span class="math inline">\(\mathcal H^n\)</span>{% endraw %}-measurable subset of {% raw %}<span class="math inline">\(\mathbb R^{n+m}\)</span>{% endraw %}, with {% raw %}<span class="math inline">\(\mathcal H^n(M \cap K) &lt; \infty\)</span>{% endraw %} for all compact sets {% raw %}<span class="math inline">\(K\)</span>{% endraw %}. A {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-dimensional subspace {% raw %}<span class="math inline">\(P \subset \mathbb R^{n+m}\)</span>{% endraw %} is called the <strong>approximate tangent space for {% raw %}<span class="math inline">\(M\)</span>{% endraw %} at {% raw %}<span class="math inline">\(x \in \mathbb R^{n+m}\)</span>{% endraw %}</strong> if </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \lim\limits_{c \to 0} \int_{\eta_{x,c}(M)} f(y) \dif \mathcal H^n(y) = \int_P f(y) \dif \mathcal H^n(y) \quad \forall f \in \mathscr C_c(\mathbb R^{n+m}) ~.
    
\end{aligned}\]</div>{% endraw %}
<p> Here, {% raw %}<span class="math inline">\(\eta_{x,c}(y) \triangleq \frac1c (y-x)\)</span>{% endraw %} for all {% raw %}<span class="math inline">\(c &gt; 0\)</span>{% endraw %} and {% raw %}<span class="math inline">\(x,y \in \mathbb R^{n+m}\)</span>{% endraw %}.</p>

</div>
<p>The next characterization connects countably {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-rectifiability with approximate tangent spaces.</p>

<div id="thm:countably-n-rectifiable-approx-tangent" class="theorem" data-note-number="5" data-note-kind="Theorem">
<p><strong>Theorem 5</strong>.  Suppose {% raw %}<span class="math inline">\(M\)</span>{% endraw %} is {% raw %}<span class="math inline">\(\mathcal H^n\)</span>{% endraw %}-measurable with {% raw %}<span class="math inline">\(\mathcal H^n(M \cap K) &lt; \infty\)</span>{% endraw %} for each compact subset {% raw %}<span class="math inline">\(K \subset \mathbb R^{n+m}\)</span>{% endraw %}. Then, {% raw %}<span class="math inline">\(M\)</span>{% endraw %} is countably {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-rectifiable if and only if the approximate tangent space {% raw %}<span class="math inline">\(T_x M\)</span>{% endraw %} exists for {% raw %}<span class="math inline">\(\mathcal H^n\)</span>{% endraw %}-a.e. {% raw %}<span class="math inline">\(x \in M\)</span>{% endraw %}.</p>

</div>
<p><strong>Proof, rectifiability implies tangents.</strong> Use the disjoint pieces {% raw %}<span class="math inline">\(M_j\subset N_j\)</span>{% endraw %} from Remark 3. A {% raw %}<span class="math inline">\(C^1\)</span>{% endraw %} graph, rescaled at {% raw %}<span class="math inline">\(x\)</span>{% endraw %}, converges to its tangent plane: in graph coordinates the scaled graph function converges uniformly on bounded sets to its derivative, and the area Jacobian converges uniformly to the linear one. The area formula and dominated convergence then give </p>
{% raw %}<div class="math display">\[\int_{\eta_{x,c}(N_j)}f\,d\mathcal H^n\longrightarrow\int_{T_xN_j}f\,d\mathcal H^n.\]</div>{% endraw %}
<p> For {% raw %}<span class="math inline">\(f\)</span>{% endraw %} supported in {% raw %}<span class="math inline">\(B_R(0)\)</span>{% endraw %}, write the exact identity </p>
{% raw %}<div class="math display">\[\int_{\eta_{x,c}(M)}f=\int_{\eta_{x,c}(N_j)}f-\int_{\eta_{x,c}(N_j\setminus M_j)}f+\int_{\eta_{x,c}(M\setminus M_j)}f.\]</div>{% endraw %}
<p> The missing part of {% raw %}<span class="math inline">\(N_j\)</span>{% endraw %} is subtracted. By the upper-density theorem applied locally to the last two sets, for almost every {% raw %}<span class="math inline">\(x\in M_j\)</span>{% endraw %} each error in absolute value is at most </p>
{% raw %}<div class="math display">\[\|f\|_\infty c^{-n}\mathcal H^n(E\cap B_{cR}(x))\longrightarrow0.\]</div>{% endraw %}
<p> The balls are centred at {% raw %}<span class="math inline">\(x\)</span>{% endraw %}. Thus the approximate tangent is {% raw %}<span class="math inline">\(T_xN_j\)</span>{% endraw %} at almost every point of {% raw %}<span class="math inline">\(M_j\)</span>{% endraw %}, and the countable union proves this direction.</p>
<p><strong>Conversely, tangents imply rectifiability.</strong> Write {% raw %}<span class="math inline">\(\mu=\mathcal H^n\mathbin{\restriction}M\)</span>{% endraw %}. It is locally finite. Work in a fixed bounded ball, and discard the null set where the tangent does not exist. At each remaining point {% raw %}<span class="math inline">\(x\)</span>{% endraw %}, let {% raw %}<span class="math inline">\(P_x\)</span>{% endraw %} be its {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-plane tangent and {% raw %}<span class="math inline">\(\Pi_x=P_x^\perp\)</span>{% endraw %} its {% raw %}<span class="math inline">\(m\)</span>{% endraw %}-dimensional normal plane. If {% raw %}<span class="math inline">\(q_\Pi\)</span>{% endraw %} denotes projection onto {% raw %}<span class="math inline">\(\Pi^\perp\)</span>{% endraw %}, define the cone around the normal plane by </p>
{% raw %}<div class="math display">\[X_\alpha(\Pi,x)=\{z:|q_\Pi(z-x)|\leq\alpha|z-x|\}.\]</div>{% endraw %}
<p> The assumed weak convergence of rescaled measures gives </p>
{% raw %}<div class="math display">\[\frac{\mu(B_r(x))}{\omega_nr^n}\to1,\qquad\frac{\mu(X_{1/2}(\Pi_x,x)\cap B_r(x))}{\omega_nr^n}\to0.\]</div>{% endraw %}
<p> Indeed the unit sphere has zero {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-measure in {% raw %}<span class="math inline">\(P_x\)</span>{% endraw %}, while the closed normal cone meets {% raw %}<span class="math inline">\(P_x\)</span>{% endraw %} only at the origin; continuous upper/lower approximations to these sets justify the two limits.</p>
Fix {% raw %}<span class="math inline">\(\varepsilon=(4\cdot16^n)^{-1}\)</span>{% endraw %}. For each integer {% raw %}<span class="math inline">\(k\)</span>{% endraw %}, collect the points where, for every {% raw %}<span class="math inline">\(0&lt;r&lt;1/k\)</span>{% endraw %},
<div id="eq:egorov-iff-thm-condition">

</div>
{% raw %}<div class="math display">\[\mu(B_r(x))\geq(1-\varepsilon)\omega_nr^n,\qquad\mu(X_{1/2}(\Pi_x,x)\cap B_r(x))\leq\varepsilon\omega_nr^n.\tag{1}\]</div>{% endraw %}
<p> Their union contains all the remaining points. This countable uniform-scale decomposition supplies the uniform estimates that replace the Egorov step of the classical proof.</p>
<p>The normal-plane Grassmannian is compact in projection-matrix norm. Choose finitely many {% raw %}<span class="math inline">\(m\)</span>{% endraw %}-planes {% raw %}<span class="math inline">\(\Pi_j\)</span>{% endraw %} so every {% raw %}<span class="math inline">\(\Pi_x\)</span>{% endraw %} has {% raw %}<span class="math inline">\(\|q_{\Pi_x}-q_{\Pi_j}\|&lt;1/16\)</span>{% endraw %} for some {% raw %}<span class="math inline">\(j\)</span>{% endraw %}. Let {% raw %}<span class="math inline">\(E_{k,j}\)</span>{% endraw %} be the points satisfying (1) and that plane bound. We claim that distinct {% raw %}<span class="math inline">\(x,y\in E_{k,j}\)</span>{% endraw %} with {% raw %}<span class="math inline">\(r=|y-x|&lt;1/(2k)\)</span>{% endraw %} obey </p>
{% raw %}<div class="math display">\[|q_{\Pi_j}(y-x)|&gt;r/4.\]</div>{% endraw %}
<p> Otherwise, for {% raw %}<span class="math inline">\(z\in B_{r/8}(y)\)</span>{% endraw %}, </p>
{% raw %}<div class="math display">\[|q_{\Pi_x}(z-x)|\leq(r/4+r/16)+r/8=7r/16\leq\frac12|z-x|,\]</div>{% endraw %}
<p> since {% raw %}<span class="math inline">\(|z-x|\geq7r/8\)</span>{% endraw %}. Also {% raw %}<span class="math inline">\(|z-x|&lt;2r\)</span>{% endraw %}. Thus {% raw %}<span class="math inline">\(B_{r/8}(y)\subseteq X_{1/2}(\Pi_x,x)\cap B_{2r}(x)\)</span>{% endraw %}. Applying (1) at {% raw %}<span class="math inline">\(y\)</span>{% endraw %} and {% raw %}<span class="math inline">\(x\)</span>{% endraw %} gives </p>
{% raw %}<div class="math display">\[(1-\varepsilon)\omega_n(r/8)^n\leq\varepsilon\omega_n(2r)^n,\]</div>{% endraw %}
<p> or {% raw %}<span class="math inline">\(1-\varepsilon\leq16^n\varepsilon\)</span>{% endraw %}, contrary to our choice of {% raw %}<span class="math inline">\(\varepsilon\)</span>{% endraw %}. The lower-density factor {% raw %}<span class="math inline">\(1-\varepsilon\)</span>{% endraw %} and the change of reference plane are both needed.</p>
<p>Intersect {% raw %}<span class="math inline">\(E_{k,j}\)</span>{% endraw %} with a countable cover by balls of diameter below {% raw %}<span class="math inline">\(1/(2k)\)</span>{% endraw %}. On each piece projection onto {% raw %}<span class="math inline">\(\Pi_j^\perp\)</span>{% endraw %} is injective, and its inverse has Lipschitz constant at most four. After an orthogonal coordinate change the piece is a graph over a subset of {% raw %}<span class="math inline">\(\mathbb R^n\)</span>{% endraw %}; its normal-coordinate function has Lipschitz constant at most {% raw %}<span class="math inline">\(\sqrt{15}\)</span>{% endraw %}. Extend each component to all of {% raw %}<span class="math inline">\(\mathbb R^n\)</span>{% endraw %} using the formula </p>
{% raw %}<div class="math display">\[\widetilde u(a)=\inf_{b\in D}\{u(b)+L|a-b|\},\]</div>{% endraw %}
<p> which is {% raw %}<span class="math inline">\(L\)</span>{% endraw %}-Lipschitz and equals {% raw %}<span class="math inline">\(u\)</span>{% endraw %} on its original domain {% raw %}<span class="math inline">\(D\)</span>{% endraw %}. The resulting vector map is Lipschitz, so its graph is a Lipschitz image of {% raw %}<span class="math inline">\(\mathbb R^n\)</span>{% endraw %}. There are only countably many pieces over all {% raw %}<span class="math inline">\(k,j\)</span>{% endraw %} and covering balls. Exhaust ambient space by bounded balls and add the discarded null set. This proves countable rectifiability. ◻</p>

<p>The following construction generalizes {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-rectifiability, by permitting an index function to each point of a set {% raw %}<span class="math inline">\(M\)</span>{% endraw %}.</p>

<div id="def:general-n-rectifiability" class="definition" data-note-number="6" data-note-kind="Definition">
<p><strong>Definition 6.</strong> Let {% raw %}<span class="math inline">\(M\)</span>{% endraw %} be {% raw %}<span class="math inline">\(\mathcal H^n\)</span>{% endraw %}-measurable and let {% raw %}<span class="math inline">\(0&lt;\theta&lt;\infty\)</span>{% endraw %} almost everywhere on {% raw %}<span class="math inline">\(M\)</span>{% endraw %}, with {% raw %}<span class="math inline">\(\int_{M\cap K}\theta\,d\mathcal H^n&lt;\infty\)</span>{% endraw %} for every compact {% raw %}<span class="math inline">\(K\)</span>{% endraw %}. A plane {% raw %}<span class="math inline">\(P_x\)</span>{% endraw %} is an approximate tangent with multiplicity {% raw %}<span class="math inline">\(\theta(x)\)</span>{% endraw %} at a point {% raw %}<span class="math inline">\(x\in M\)</span>{% endraw %} where {% raw %}<span class="math inline">\(0&lt;\theta(x)&lt;\infty\)</span>{% endraw %} if </p>
{% raw %}<div class="math display">\[\lim_{c\downarrow0}\int_{\eta_{x,c}(M)}f(y)\theta(x+cy)\,d\mathcal H^n(y)=\theta(x)\int_{P_x}f\,d\mathcal H^n\quad(f\in C_c(\mathbb R^{n+m})).\]</div>{% endraw %}

</div>
<div id="result-7" class="remark" data-note-number="7" data-note-kind="Remark">
<p><strong>Remark 7.</strong> To apply Lusin’s theorem, first restrict to {% raw %}<span class="math inline">\(M\cap\overline B_j(0)\cap\{1/j\leq\theta\leq j\}\)</span>{% endraw %}. Its {% raw %}<span class="math inline">\(\mathcal H^n\)</span>{% endraw %} measure is at most {% raw %}<span class="math inline">\(j\int_{M\cap\overline B_j}\theta\,d\mathcal H^n&lt;\infty\)</span>{% endraw %}. Compact approximation and Lusin then give countably many compact subsets covering {% raw %}<span class="math inline">\(M\)</span>{% endraw %} up to a null set, on each of which {% raw %}<span class="math inline">\(\theta\)</span>{% endraw %} is continuous. Positivity on a compact piece gives a positive minimum, so finite weighted measure implies finite unweighted measure there. Continuity without positivity or this localization would not suffice.</p>
</div>

<div id="def:purely-unrectifiable" class="definition" data-note-number="8" data-note-kind="Definition">
<p><strong>Definition 8</strong>.  {% raw %}<span class="math inline">\(P \subset \mathbb R^{n+m}\)</span>{% endraw %} is <strong>purely {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-unrectifiable</strong> if it contains no countably {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-rectifiable subset of positive {% raw %}<span class="math inline">\(\mathcal H^n\)</span>{% endraw %} measure.</p>

</div>
<div id="lem:decomp-rec-unrec" class="lemma" data-note-number="9" data-note-kind="Lemma">
<p><strong>Lemma 9.</strong> Every {% raw %}<span class="math inline">\(\mathcal H^n\)</span>{% endraw %}-sigma-finite set {% raw %}<span class="math inline">\(A\subset\mathbb R^{n+m}\)</span>{% endraw %} admits a disjoint decomposition {% raw %}<span class="math inline">\(A=R\sqcup P\)</span>{% endraw %}, where {% raw %}<span class="math inline">\(R\)</span>{% endraw %} is countably {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-rectifiable and {% raw %}<span class="math inline">\(P\)</span>{% endraw %} is purely {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-unrectifiable. Here sigma-finite means that {% raw %}<span class="math inline">\(A\)</span>{% endraw %} is covered by countably many sets of finite {% raw %}<span class="math inline">\(\mathcal H^n\)</span>{% endraw %} outer measure; measurability is not assumed. If {% raw %}<span class="math inline">\(A\)</span>{% endraw %} is measurable, {% raw %}<span class="math inline">\(R\)</span>{% endraw %} may be chosen Borel.</p>
</div>
<p><strong>Proof.</strong> First suppose that the set is measurable. Write {% raw %}<span class="math inline">\(A=\bigcup_jA_j\)</span>{% endraw %} with each {% raw %}<span class="math inline">\(A_j\)</span>{% endraw %} measurable of finite measure, and put </p>
{% raw %}<div class="math display">\[\alpha_j=\sup\{\mathcal H^n(S):S\subseteq A_j,\ S\text{ measurable and countably }n\text{-rectifiable}\}.\]</div>{% endraw %}
<p> Choose such sets approaching {% raw %}<span class="math inline">\(\alpha_j\)</span>{% endraw %}, and then compact subsets {% raw %}<span class="math inline">\(K_{ij}\)</span>{% endraw %} with {% raw %}<span class="math inline">\(\mathcal H^n(K_{ij})&gt;\alpha_j-1/i\)</span>{% endraw %} whenever {% raw %}<span class="math inline">\(\alpha_j&gt;0\)</span>{% endraw %}; take the empty set when {% raw %}<span class="math inline">\(\alpha_j=0\)</span>{% endraw %}. Compact approximation is available for each finite restricted Hausdorff measure in Euclidean space, and a subset of a rectifiable set is rectifiable. Set {% raw %}<span class="math inline">\(R=\bigcup_{i,j}K_{ij}\)</span>{% endraw %}. This is Borel and rectifiable, and {% raw %}<span class="math inline">\(\mathcal H^n(R\cap A_j)=\alpha_j\)</span>{% endraw %}: it is at least the supremum limit and at most {% raw %}<span class="math inline">\(\alpha_j\)</span>{% endraw %} by definition.</p>
<p>If {% raw %}<span class="math inline">\(P=A\setminus R\)</span>{% endraw %} had a measurable rectifiable subset {% raw %}<span class="math inline">\(S\)</span>{% endraw %} of positive measure, then {% raw %}<span class="math inline">\(\mathcal H^n(S\cap A_j)&gt;0\)</span>{% endraw %} for some {% raw %}<span class="math inline">\(j\)</span>{% endraw %}. The disjoint union {% raw %}<span class="math inline">\((R\cap A_j)\cup(S\cap A_j)\)</span>{% endraw %} would be a rectifiable subset of {% raw %}<span class="math inline">\(A_j\)</span>{% endraw %} with measure greater than {% raw %}<span class="math inline">\(\alpha_j\)</span>{% endraw %}, a contradiction. For a possibly nonmeasurable rectifiable subset of {% raw %}<span class="math inline">\(P\)</span>{% endraw %}, cover it by a Borel rectifiable carrier using Proposition 2; its measurable intersection with {% raw %}<span class="math inline">\(P\)</span>{% endraw %} contains the subset and has at least its outer measure. This reduces to the same contradiction. Thus {% raw %}<span class="math inline">\(P\)</span>{% endraw %} is purely unrectifiable.</p>
<p>For an arbitrary sigma-finite {% raw %}<span class="math inline">\(A\)</span>{% endraw %}, write {% raw %}<span class="math inline">\(A=\bigcup_j A_j\)</span>{% endraw %} with {% raw %}<span class="math inline">\(\mathcal H^n(A_j)&lt;\infty\)</span>{% endraw %}. By Borel regularity of Hausdorff measure, choose Borel sets {% raw %}<span class="math inline">\(B_j\supseteq A_j\)</span>{% endraw %} with {% raw %}<span class="math inline">\(\mathcal H^n(B_j)=\mathcal H^n(A_j)\)</span>{% endraw %}. The set {% raw %}<span class="math inline">\(B=\bigcup_jB_j\)</span>{% endraw %} is Borel and sigma-finite. The measurable case gives {% raw %}<span class="math inline">\(B=R_B\sqcup P_B\)</span>{% endraw %}. Set</p>
{% raw %}<div class="math display">\[R=A\cap R_B,\qquad P=A\cap P_B.\]</div>{% endraw %}
<p>A subset of a countably rectifiable set is countably rectifiable, and a subset of a purely unrectifiable set is purely unrectifiable. Thus these sets give the required decomposition of {% raw %}<span class="math inline">\(A\)</span>{% endraw %}. They need not be measurable when {% raw %}<span class="math inline">\(A\)</span>{% endraw %} is not measurable. ◻</p>
<div id="lem:unrectifiable-sufficiency" class="lemma" data-note-number="10" data-note-kind="Lemma">
<p><strong>Lemma 10.</strong> If every coordinate projection of {% raw %}<span class="math inline">\(S\subset\mathbb R^{n+m}\)</span>{% endraw %} onto an {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-dimensional coordinate plane has zero {% raw %}<span class="math inline">\(\mathcal H^n\)</span>{% endraw %} outer measure, then {% raw %}<span class="math inline">\(S\)</span>{% endraw %} is purely {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-unrectifiable.</p>
</div>
<p><strong>Proof.</strong> Suppose {% raw %}<span class="math inline">\(S\)</span>{% endraw %} contained a rectifiable set of positive measure. Proposition 2 gives an embedded {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-manifold patch {% raw %}<span class="math inline">\(N\)</span>{% endraw %} for which {% raw %}<span class="math inline">\(N\cap S\)</span>{% endraw %} has positive outer measure. At every {% raw %}<span class="math inline">\(x\in N\)</span>{% endraw %}, a basis matrix for {% raw %}<span class="math inline">\(T_xN\)</span>{% endraw %} has rank {% raw %}<span class="math inline">\(n\)</span>{% endraw %}, hence some coordinate {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-minor is nonzero. The corresponding projection restricted to {% raw %}<span class="math inline">\(N\)</span>{% endraw %} is a local {% raw %}<span class="math inline">\(C^1\)</span>{% endraw %} diffeomorphism. Shrink to precompact coordinate patches so that its inverse is Lipschitz. A countable collection of these patches covers {% raw %}<span class="math inline">\(N\)</span>{% endraw %}, and one has intersection with {% raw %}<span class="math inline">\(S\)</span>{% endraw %} of positive outer measure. The Lipschitz inverse inequality then forces its projection to have positive measure, contradicting the hypothesis. We need a positive-measure subset of a manifold, not an entire manifold contained in {% raw %}<span class="math inline">\(S\)</span>{% endraw %}. ◻</p>

<div id="result-11" class="example" data-note-number="11" data-note-kind="Example">
<p><strong>Example 11</strong>.  Let {% raw %}<span class="math inline">\(C_0 = [0,1] \times [0,1]\)</span>{% endraw %}. Let {% raw %}<span class="math inline">\(C_1\)</span>{% endraw %} be the union of 4 sub-squares of {% raw %}<span class="math inline">\(C_0\)</span>{% endraw %} such that one of each squares’ corners is a corner of {% raw %}<span class="math inline">\(C_0\)</span>{% endraw %}. Consider the line {% raw %}<span class="math inline">\(y=\frac12 x\)</span>{% endraw %}. We can explicitly calculate the projection of each sub-square onto the line. For instance, the top sub-square has coordinates {% raw %}<span class="math inline">\(\{(0,\frac34),(0,1),(\frac14,\frac34),(\frac14,1)\}\)</span>{% endraw %}; call these points {% raw %}<span class="math inline">\(\{i,ii,iii,iv\}\)</span>{% endraw %} respectively. The orthogonal projections are </p>

{% raw %}<div class="math display">\[\begin{aligned}
        P_{y=\frac12x}(i) &amp;= \frac{(1,\frac12) \cdot (0,\frac34)}{(1,\frac12) \cdot (1,\frac12)} \begin{pmatrix} 1 \\ \frac12 \end{pmatrix} = \frac{\frac38}{\frac54} \begin{pmatrix} 1 \\ \frac12 \end{pmatrix} = \frac{3}{10} \begin{pmatrix} 1 \\ \frac12 \end{pmatrix}  \\
        
        P_{y=\frac12x}(ii) &amp;= \frac{(1,\frac12) \cdot (0,1)}{(1,\frac12) \cdot (1,\frac12)} \begin{pmatrix} 1 \\ \frac12 \end{pmatrix} = \frac{\frac12}{\frac54} \begin{pmatrix} 1 \\ \frac12 \end{pmatrix} = \frac{2}{5} \begin{pmatrix} 1 \\ \frac12 \end{pmatrix} \\
        
        P_{y=\frac12x}(iii) &amp;= \frac{(1,\frac12) \cdot (\frac14,\frac34)}{(1,\frac12) \cdot (1,\frac12)} \begin{pmatrix} 1 \\ \frac12 \end{pmatrix} = \frac{\frac14 + \frac38}{\frac54} \begin{pmatrix} 1 \\ \frac12 \end{pmatrix} = \frac12 \begin{pmatrix} 1 \\ \frac12 \end{pmatrix} \\
        
        P_{y=\frac12x}(iv) &amp;= \frac{(1,\frac12) \cdot (\frac14,1)}{(1,\frac12) \cdot (1,\frac12)} \begin{pmatrix} 1 \\ \frac12 \end{pmatrix} = \frac{\frac14 + \frac12}{\frac54} \begin{pmatrix} 1 \\ \frac12 \end{pmatrix} = \frac{3}{5} \begin{pmatrix} 1 \\ \frac12 \end{pmatrix} 
    
\end{aligned}\]</div>{% endraw %}
<p> and doing calculations for all sub-squares gives the furthest orthogonal projection along the line is the point </p>

{% raw %}<div class="math display">\[\begin{aligned}
        =\frac{(1,\frac12) \cdot (1,1)}{(1,\frac12) \cdot (1,\frac12)} \begin{pmatrix} 1 \\ \frac12 \end{pmatrix} = \frac{\frac32}{\frac54} \begin{pmatrix} 1 \\ \frac12 \end{pmatrix} = \frac65 \begin{pmatrix} 1 \\ \frac12 \end{pmatrix} ~.
    
\end{aligned}\]</div>{% endraw %}
<p>Thus the projection of {% raw %}<span class="math inline">\(C_1\)</span>{% endraw %} onto the line has length {% raw %}<span class="math inline">\(3/\sqrt5\)</span>{% endraw %}. Define {% raw %}<span class="math inline">\(C_k\)</span>{% endraw %} by retaining the four corner squares of relative side {% raw %}<span class="math inline">\(1/4\)</span>{% endraw %} at every step. Then {% raw %}<span class="math inline">\(C_{k+1}\subseteq C_k\)</span>{% endraw %}, each {% raw %}<span class="math inline">\(C_k\)</span>{% endraw %} consists of {% raw %}<span class="math inline">\(4^k\)</span>{% endraw %} squares of side {% raw %}<span class="math inline">\(4^{-k}\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(C=\bigcap_kC_k\)</span>{% endraw %} is compact.</p>
<p>To verify that the oblique projection has no gaps even in the limit, write {% raw %}<span class="math inline">\(C=K\times K\)</span>{% endraw %}, where {% raw %}<span class="math inline">\(K=\{\sum_{j\geq1}a_j4^{-j}:a_j\in\{0,3\}\}\)</span>{% endraw %}. Projection distance along the unit vector {% raw %}<span class="math inline">\((2,1)/\sqrt5\)</span>{% endraw %} is {% raw %}<span class="math inline">\((2x+y)/\sqrt5\)</span>{% endraw %}. Its possible digits are {% raw %}<span class="math inline">\(2a_j+b_j\in\{0,3,6,9\}\)</span>{% endraw %}. Every number in {% raw %}<span class="math inline">\([0,3]\)</span>{% endraw %} has an expansion {% raw %}<span class="math inline">\(\sum_{j\geq1}3d_j4^{-j}\)</span>{% endraw %} with {% raw %}<span class="math inline">\(d_j\in\{0,1,2,3\}\)</span>{% endraw %}, and each digit {% raw %}<span class="math inline">\(3d_j\)</span>{% endraw %} is realized by one pair {% raw %}<span class="math inline">\((a_j,b_j)\)</span>{% endraw %}. Therefore the projection of {% raw %}<span class="math inline">\(C\)</span>{% endraw %} is exactly an interval of length {% raw %}<span class="math inline">\(3/\sqrt5\)</span>{% endraw %}.</p>
<p>The Lipschitz projection bound and the level-{% raw %}<span class="math inline">\(k\)</span>{% endraw %} square cover give </p>
{% raw %}<div class="math display">\[\frac3{\sqrt5}\leq\mathcal H^1(C)\leq\lim_{k\to\infty}4^k(\sqrt2\,4^{-k})=\sqrt2.\]</div>{% endraw %}
<p> Meanwhile, either coordinate projection is covered by {% raw %}<span class="math inline">\(2^k\)</span>{% endraw %} intervals of length {% raw %}<span class="math inline">\(4^{-k}\)</span>{% endraw %}, so its one-dimensional Lebesgue measure is at most {% raw %}<span class="math inline">\(2^{-k}\)</span>{% endraw %} for every {% raw %}<span class="math inline">\(k\)</span>{% endraw %}, hence zero. These are unions of intervals, not one full interval. On each coordinate line {% raw %}<span class="math inline">\(\mathcal H^1=\lambda_1\)</span>{% endraw %}, and Lemma 10 proves that {% raw %}<span class="math inline">\(C\)</span>{% endraw %} is purely 1-unrectifiable. Positive projection in one exceptional direction is consistent with the almost-everywhere theorem below.</p>

</div>
<div id="result-12" class="theorem" data-note-number="12" data-note-kind="Theorem">
<p><strong>Theorem 12.</strong> Let {% raw %}<span class="math inline">\(Q\subset\mathbb R^{n+m}\)</span>{% endraw %} be measurable, purely {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-unrectifiable and {% raw %}<span class="math inline">\(\mathcal H^n\)</span>{% endraw %}-sigma-finite. For almost every {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-plane {% raw %}<span class="math inline">\(V\)</span>{% endraw %} under the rotation-invariant probability measure on the Grassmannian {% raw %}<span class="math inline">\(G(n+m,n)\)</span>{% endraw %}, </p>
{% raw %}<div class="math display">\[\mathcal H^n(P_VQ)=0.\]</div>{% endraw %}
<p> This is the Besicovitch–Federer projection theorem. The measure is the pushforward of Haar probability on the orthogonal group; the collection of projections is not itself a group.</p>
</div>
<p>This theorem is an external input: <a href="https://web.stanford.edu/class/math285/ts-gmt.pdf">Simon, Chapter 3, Theorem 3.6, p.80</a>, states the exact sigma-finite projection result. Sigma-finiteness is a hypothesis, not a consequence of pure unrectifiability. Its finite-measure form extends to the stated form by a countable union of exceptional sets of directions.</p>
<div id="thm:rectifiability-thm" class="theorem" data-note-number="13" data-note-kind="Theorem">
<p><strong>Theorem 13.</strong> Let {% raw %}<span class="math inline">\(A\)</span>{% endraw %} be measurable and {% raw %}<span class="math inline">\(\mathcal H^n\)</span>{% endraw %}-sigma-finite. Suppose every measurable {% raw %}<span class="math inline">\(B\subseteq A\)</span>{% endraw %} of positive {% raw %}<span class="math inline">\(\mathcal H^n\)</span>{% endraw %} measure has {% raw %}<span class="math inline">\(\mathcal H^n(P_VB)&gt;0\)</span>{% endraw %} on a positive-measure set of directions {% raw %}<span class="math inline">\(V\in G(n+m,n)\)</span>{% endraw %}. Then {% raw %}<span class="math inline">\(A\)</span>{% endraw %} is countably {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-rectifiable.</p>
</div>
<p><strong>Proof.</strong> Decompose {% raw %}<span class="math inline">\(A=R\sqcup P\)</span>{% endraw %} by Lemma 9. If {% raw %}<span class="math inline">\(\mathcal H^n(P)&gt;0\)</span>{% endraw %}, take {% raw %}<span class="math inline">\(B=P\)</span>{% endraw %} in the hypothesis. Theorem 12 says its projection is null for almost every direction, a contradiction. Thus {% raw %}<span class="math inline">\(P\)</span>{% endraw %} is null, and a rectifiable set together with a null set is rectifiable. ◻</p>
<div id="result-14" class="remark" data-note-number="14" data-note-kind="Remark">
<p><strong>Remark 14.</strong> The hypothesis tests every positive-measure subset, because a set can contain both rectifiable and purely unrectifiable parts. Testing only {% raw %}<span class="math inline">\(A\)</span>{% endraw %} would miss a positive unrectifiable part hidden beside a rectifiable one.</p>
</div>

<h4 data-note-section="1" id="a-class-of-rectifiable-sets-locally-finite-perimeter">1. A Class of Rectifiable Sets: Locally Finite Perimeter</h4>
<p>Perimeter is a codimension-one notion. Work now in an open {% raw %}<span class="math inline">\(U\subset\mathbb R^{n+1}\)</span>{% endraw %}, with a Lebesgue measurable set {% raw %}<span class="math inline">\(S\)</span>{% endraw %}. By the <a href="{% post_url 2024-06-24-sobolev-spaces-embeddings-and-bounded-variation %}#def:finite-perimeter">bounded-variation definition</a>, locally finite perimeter means that {% raw %}<span class="math inline">\(D\mathbb1_S\)</span>{% endraw %} is a vector Radon measure. Write its polar decomposition as {% raw %}<span class="math inline">\(D\mathbb1_S=\nu\mu_S\)</span>{% endraw %}, where {% raw %}<span class="math inline">\(\mu_S=|D\mathbb1_S|\)</span>{% endraw %} and {% raw %}<span class="math inline">\(|\nu|=1\)</span>{% endraw %} almost everywhere for {% raw %}<span class="math inline">\(\mu_S\)</span>{% endraw %}. Thus </p>
{% raw %}<div class="math display">\[\int_S\operatorname{div}\varphi\,dx=-\int_U\varphi\cdot\nu\,d\mu_S\qquad(\varphi\in C_c^1(U;\mathbb R^{n+1})).\]</div>{% endraw %}
<p> For a smooth boundary the divergence theorem identifies {% raw %}<span class="math inline">\(\mu_S=\mathcal H^n\mathbin{\restriction}\partial S\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\nu\)</span>{% endraw %} as the inward normal, because the usual outward-normal formula has the opposite sign.</p>
<p>Define the reduced boundary by </p>
{% raw %}<div class="math display">\[\partial^*S=\left\{x\in U\cap\operatorname{spt}\mu_S:\lim_{r\downarrow0}\frac{1}{\mu_S(B_r(x))}\int_{B_r(x)}\nu\,d\mu_S\text{ exists and has norm }1\right\}.\]</div>{% endraw %}
<p> The support condition ensures positive denominators for sufficiently small balls contained in {% raw %}<span class="math inline">\(U\)</span>{% endraw %}. Denote the limit by {% raw %}<span class="math inline">\(\nu_S(x)\)</span>{% endraw %}.</p>
<div id="result-15" class="theorem" data-note-number="15" data-note-kind="Theorem">
<p><strong>Theorem 15.</strong> For a set of locally finite perimeter in {% raw %}<span class="math inline">\(U\subset\mathbb R^{n+1}\)</span>{% endraw %}, the reduced boundary is countably {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-rectifiable and </p>
{% raw %}<div class="math display">\[\mu_S=\mathcal H^n\mathbin{\restriction}\partial^*S.\]</div>{% endraw %}
<p> At every {% raw %}<span class="math inline">\(x\in\partial^*S\)</span>{% endraw %}, the rescaled perimeter measures converge with multiplicity one to {% raw %}<span class="math inline">\(\mathcal H^n\)</span>{% endraw %} on the plane {% raw %}<span class="math inline">\(T_x=\{z:z\cdot\nu_S(x)=0\}\)</span>{% endraw %}, and </p>
{% raw %}<div class="math display">\[\mathbb1_{(S-x)/r}\longrightarrow\mathbb1_{\{z:z\cdot\nu_S(x)&gt;0\}}\quad\text{in }L^1_{\mathrm{loc}}(\mathbb R^{n+1})\quad(r\downarrow0).\]</div>{% endraw %}

</div>
<p>This is De Giorgi’s structure theorem, used here as a named theorem rather than inferred from the definition alone. The exact form, including the every-reduced-boundary-point blow-up, is <a href="https://web.stanford.edu/class/math285/ts-gmt.pdf">Simon, Chapter 3, Theorem 4.3, pp.81–84</a>. In ambient dimension {% raw %}<span class="math inline">\(d\)</span>{% endraw %}, the same statement has boundary dimension {% raw %}<span class="math inline">\(d-1\)</span>{% endraw %}; it is not an arbitrary-codimension {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-dimensional conclusion in {% raw %}<span class="math inline">\(\mathbb R^{n+m}\)</span>{% endraw %}. The convergence is of characteristic functions, and the sign of the limiting half-space matches the inward normal in the integration-by-parts identity.</p>
