<p>If people choose their neighbors, an observed link reflects incentives as well as a possible channel for spillovers. The formation equation must then be studied together with the outcome equation. These notes compare estimated equilibrium beliefs in <span class="citation" data-cites="leung_two-step_2015"><a href="#ref-leung_two-step_2015" role="doc-biblioref">Leung (2015)</a></span>, joint link and activity choices in <span class="citation" data-cites="battaglini_endogenous_2022"><a href="#ref-battaglini_endogenous_2022" role="doc-biblioref">Battaglini, Patacchini, and Rainone (2022)</a></span>, and repeated risk sharing in <span class="citation" data-cites="bramoulle_risk_2007"><a href="#ref-bramoulle_risk_2007" role="doc-biblioref">Bramoullé and Kranton (2007)</a></span>. The calculations distinguish responses on a fixed network from responses that also change the network.</p>

<h3 data-note-section="1" id="10-447-estimate-equilibrium-beliefs-before-preferences">1. Estimate equilibrium beliefs before preferences</h3>
<p>In an incomplete-information link-formation game, an agent chooses links using private payoff shocks and beliefs about others’ choices. Equilibrium requires those beliefs to agree with the choice probabilities generated by the model.</p>

<p>An equilibrium supplies choice probabilities that can be estimated from network and covariate patterns. The two-step method uses those estimates as beliefs in a payoff index, then estimates preferences. Its computational advantage is that each candidate preference parameter does not require solving the entire equilibrium again.</p>

<p>The main consistency result relies on the paper’s symmetry, distributional, identification, and regularity restrictions. It does not follow simply because there are order {% raw %}<span class="math inline">\(n^2\)</span>{% endraw %} possible dyads. Dyads sharing an agent can be dependent, and the first-step estimation error enters the second-step distribution.</p>

<h3 data-note-section="2" id="10-447-an-equilibrium-calculation">2. An equilibrium calculation</h3>
<p>A related model links a vector of outcomes or activities {% raw %}<span class="math inline">\(E\)</span>{% endraw %} to the network through</p>

{% raw %}<div class="math display">\[
E=\delta GE+\epsilon.
\]</div>{% endraw %}
<p>For a fixed {% raw %}<span class="math inline">\(G\)</span>{% endraw %}, if the spectral radius of {% raw %}<span class="math inline">\(\delta G\)</span>{% endraw %} is below one,</p>

{% raw %}<div class="math display">\[
E=(I-\delta G)^{-1}\epsilon
=\sum_{r=0}^\infty\delta^rG^r\epsilon.
\]</div>{% endraw %}
<p>Each successive term transmits the initial disturbances along longer walks through the network. Here {% raw %}<span class="math inline">\(G\)</span>{% endraw %} is fixed. If links are chosen, the same outcome equation remains necessary, but the link choices must also satisfy their own optimality conditions.</p>

<p>For a link payoff {% raw %}<span class="math inline">\(\alpha\delta E_jg_{ij}\)</span>{% endraw %} and convex cost</p>

{% raw %}<div class="math display">\[
\frac{g_{ij}^{1+1/\lambda}}{(1+1/\lambda)\theta_{ij}^{(1+\lambda)/\lambda}},
\]</div>{% endraw %}
<p>the interior first-order condition gives</p>

{% raw %}<div class="math display">\[
g_{ij}=\theta_{ij}^{1+\lambda}(\alpha\delta E_j)^\lambda.
\]</div>{% endraw %}
<p>An upper capacity {% raw %}<span class="math inline">\(\overline g\)</span>{% endraw %} caps the optimal link at {% raw %}<span class="math inline">\(\overline g\)</span>{% endraw %}, subject to the sign and concavity conditions. These best responses must be solved together with the outcome equation. Replacing that equation by an unweighted degree sum would discard both the neighbors’ activity levels and the exogenous term.</p>

<h3 data-note-section="3" id="10-447-repeated-sharing-is-another-mechanism">3. Repeated sharing is another mechanism</h3>
<p>To see the repeated-sharing intuition, consider {% raw %}<span class="math inline">\(x^{(t+1)}=Px^{(t)}\)</span>{% endraw %} on a connected component. If {% raw %}<span class="math inline">\(P\)</span>{% endraw %} is a primitive doubly stochastic matrix, then</p>

{% raw %}<div class="math display">\[
P^t\to\mathbf1\mathbf1&#x27;/m,
\]</div>{% endraw %}
<p>The limit sends each initial vector to its component average. Two conditions explain the equal sharing: double stochasticity preserves the total, and primitivity ensures convergence. Connectivity alone gives neither conclusion; periodic exchange can oscillate, and a row-stochastic matrix can converge to unequal weights. Stochastic sharing models require their corresponding assumptions.</p>

<h3 data-note-section="4" id="10-447-what-these-models-imply-for-empirical-work">4. What these models imply for empirical work</h3>
<p>The formation model also matters for identification. People with similar unobserved characteristics may choose each other, so conditioning on adjacency does not remove selection. If some links are unobserved, an observation model is needed as well. The <a href="{% post_url 2025-05-08-missing-network-links-and-spillover-bias %}">missing-link note</a> derives the resulting mixture over latent exposures.</p>

<h3 data-note-section="5" id="10-447-differentiate-the-link-choice-and-check-the-corners">5. Differentiate the link choice and check the corners</h3>
<p>Holding the relevant activity {% raw %}<span class="math inline">\(E_j\)</span>{% endraw %} fixed in the link payoff, let {% raw %}<span class="math inline">\(b=\alpha\delta E_j\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\theta=\theta_{ij}&gt;0\)</span>{% endraw %}. The derivative of the cost is</p>

{% raw %}<div class="math display">\[
\frac{d}{dg}\frac{g^{1+1/\lambda}}
 {(1+1/\lambda)\theta^{(1+\lambda)/\lambda}}
=\frac{g^{1/\lambda}}{\theta^{(1+\lambda)/\lambda}},\qquad\lambda&gt;0.
\]</div>{% endraw %}
<p>For {% raw %}<span class="math inline">\(b&gt;0\)</span>{% endraw %}, equating marginal benefit and marginal cost gives {% raw %}<span class="math inline">\(g=\theta^{1+\lambda}b^\lambda\)</span>{% endraw %}. The cost is strictly convex on the positive interior, so this is the unique interior optimum. With {% raw %}<span class="math inline">\(0\leq g\leq\overline g\)</span>{% endraw %}, the best response is zero when {% raw %}<span class="math inline">\(b\leq0\)</span>{% endraw %}, the interior value when it lies below capacity, and {% raw %}<span class="math inline">\(\overline g\)</span>{% endraw %} otherwise.</p>

<p>Strict convexity settles the link choice for a given activity. It leaves open whether the network and activities have a unique joint solution, since higher activity may increase links, which in turn raise activity. That feedback is a separate fixed-point problem.</p>

<h3 data-note-section="6" id="10-447-the-resolvent-separates-paths-from-feedback">6. The resolvent separates paths from feedback</h3>
<p>For comparison, hold the network fixed. The spectral-radius condition makes repeated substitution converge to the Neumann series</p>

{% raw %}<div class="math display">\[
(I-\delta G)^{-1}=I+\delta G+\delta^2G^2+\cdots.
\]</div>{% endraw %}
<p>The {% raw %}<span class="math inline">\((i,j)\)</span>{% endraw %} entry of {% raw %}<span class="math inline">\(G^r\)</span>{% endraw %} sums products of link weights along all length-{% raw %}<span class="math inline">\(r\)</span>{% endraw %} walks from {% raw %}<span class="math inline">\(i\)</span>{% endraw %} to {% raw %}<span class="math inline">\(j\)</span>{% endraw %}. Walks can revisit vertices. The effect of a primitive disturbance on {% raw %}<span class="math inline">\(E_i\)</span>{% endraw %} includes each such route, discounted by {% raw %}<span class="math inline">\(\delta^r\)</span>{% endraw %}.</p>

<p>A differential calculation makes the amplification explicit. From {% raw %}<span class="math inline">\((I-\delta G)E=\epsilon\)</span>{% endraw %}, a fixed-{% raw %}<span class="math inline">\(\delta\)</span>{% endraw %} perturbation gives</p>

{% raw %}<div class="math display">\[
(I-\delta G)\,dE=\delta(dG)E+d\epsilon,
\]</div>{% endraw %}
<p>so</p>

{% raw %}<div class="math display">\[
dE=(I-\delta G)^{-1}(\delta(dG)E+d\epsilon).
\]</div>{% endraw %}
<p>For a change in one link {% raw %}<span class="math inline">\(g_{ab}\)</span>{% endraw %} with exogenous {% raw %}<span class="math inline">\(\epsilon\)</span>{% endraw %}, the derivative is {% raw %}<span class="math inline">\(\delta E_b(I-\delta G)^{-1}e_a\)</span>{% endraw %}. The link first changes activity at its origin through the destination’s activity, then that change propagates through the resolvent. If {% raw %}<span class="math inline">\(G\)</span>{% endraw %} itself responds to {% raw %}<span class="math inline">\(E\)</span>{% endraw %}, its differential must also satisfy the link first-order conditions; treating {% raw %}<span class="math inline">\(dG\)</span>{% endraw %} as externally fixed would omit that endogenous feedback.</p>

<p>A symmetric two-person special case shows how much this distinction can matter. Suppose both activities equal {% raw %}<span class="math inline">\(E\)</span>{% endraw %}, both chosen links equal {% raw %}<span class="math inline">\(g(E)=cE^\lambda\)</span>{% endraw %}, and both primitive shocks equal {% raw %}<span class="math inline">\(\epsilon\)</span>{% endraw %}. The simultaneous equilibrium equation reduces to</p>

{% raw %}<div class="math display">\[
E-\delta cE^{\lambda+1}=\epsilon.
\]</div>{% endraw %}
<p>At a positive interior equilibrium where {% raw %}<span class="math inline">\(1-(\lambda+1)\delta cE^\lambda\ne0\)</span>{% endraw %}, implicit differentiation gives</p>

{% raw %}<div class="math display">\[
\frac{dE}{d\epsilon}
=\frac1{1-(\lambda+1)\delta g(E)}.
\]</div>{% endraw %}
<p>Holding the network fixed would instead give {% raw %}<span class="math inline">\(1/(1-\delta g)\)</span>{% endraw %}. The additional {% raw %}<span class="math inline">\(\lambda\delta g\)</span>{% endraw %} in the equilibrium derivative comes from the response of link intensity to activity. Indeed, {% raw %}<span class="math inline">\(d(gE)=g\,dE+E\,dg=(1+\lambda)g\,dE\)</span>{% endraw %}.</p>

<p>For nonnegative parameters, the fixed-network condition {% raw %}<span class="math inline">\(\delta g&lt;1\)</span>{% endraw %} therefore does not by itself establish local stability of the joint activity-link iteration. The stronger derivative bound {% raw %}<span class="math inline">\((\lambda+1)\delta g&lt;1\)</span>{% endraw %} does so in this scalar iteration. This calculation is an illustration of feedback within the displayed model, not a claim about global equilibrium uniqueness. It explains the empirical role of the formation equation: an exogenous link change and a policy that induces new links generally have different multipliers.</p>

<h3 data-note-section="7" id="10-447-why-two-step-estimation-has-a-first-stage-term">7. Why two-step estimation has a first-stage term</h3>
<p>Let {% raw %}<span class="math inline">\(p\)</span>{% endraw %} collect equilibrium choice probabilities and let the second-step population moment be {% raw %}<span class="math inline">\(M(\theta,p)\)</span>{% endraw %}, with {% raw %}<span class="math inline">\(M(\theta_0,p_0)=0\)</span>{% endraw %}. If {% raw %}<span class="math inline">\(A=\partial_\theta M(\theta_0,p_0)\)</span>{% endraw %} is nonsingular, a local expansion gives</p>

{% raw %}<div class="math display">\[
\widehat\theta-\theta_0
\approx-A^{-1}(\widehat M(\theta_0,p_0)
+\partial_pM(\theta_0,p_0)[\widehat p-p_0]).
\]</div>{% endraw %}
<p>The derivative in brackets is a directional linear map if {% raw %}<span class="math inline">\(p\)</span>{% endraw %} is a function rather than a finite vector. The first term is sampling noise with beliefs fixed; the second carries estimated-belief error into preference estimates. The sampling-noise and estimated-belief terms can be correlated because the same network informs both stages.</p>

<p>The first-stage term disappears only if the moment has the required orthogonality property. Substituting estimates into a likelihood does not create that property. Identification and regularity assumptions must determine both which beliefs are estimable and how their estimation errors enter the second step.</p>

<p>For a finite-dimensional first stage with an asymptotic linear representation, this expansion also identifies the variance correction. For a common normalization {% raw %}<span class="math inline">\(r_n\)</span>{% endraw %}, suppose {% raw %}<span class="math inline">\(r_n\widehat M(\theta_0,p_0)\)</span>{% endraw %} and {% raw %}<span class="math inline">\(r_n(\widehat p-p_0)\)</span>{% endraw %} have joint limits {% raw %}<span class="math inline">\((Z_M,Z_p)\)</span>{% endraw %}, and write {% raw %}<span class="math inline">\(B=\partial_pM\)</span>{% endraw %}. The second-step limit is {% raw %}<span class="math inline">\(-A^{-1}(Z_M+BZ_p)\)</span>{% endraw %}, with covariance</p>

{% raw %}<div class="math display">\[
A^{-1}\left(\Omega_{MM}+B\Omega_{pp}B&#x27;
+\Omega_{Mp}B&#x27;+B\Omega_{pM}\right)A^{-T}.
\]</div>{% endraw %}
<p>The variance must therefore include first-stage uncertainty and its covariance with the second-step score. A second-step Hessian generally misses both. Avoiding repeated equilibrium solutions simplifies computation, but does not justify treating estimated beliefs as known.</p>

<h3 data-note-section="8" id="10-447-counting-dyads-does-not-count-independent-observations">8. Counting dyads does not count independent observations</h3>
<p>For an undirected network, consider a simple dyadic variable {% raw %}<span class="math inline">\(H_{ij}=U_i+U_j+e_{ij}\)</span>{% endraw %} for {% raw %}<span class="math inline">\(i&lt;j\)</span>{% endraw %}, with independent centered node shocks of variance {% raw %}<span class="math inline">\(\sigma_U^2\)</span>{% endraw %} and independent edge shocks of variance {% raw %}<span class="math inline">\(\sigma_e^2\)</span>{% endraw %}. Its average over {% raw %}<span class="math inline">\(m=n(n-1)/2\)</span>{% endraw %} dyads is</p>

{% raw %}<div class="math display">\[
\overline H=\frac2n\sum_iU_i+\frac1m\sum_{i&lt;j}e_{ij}.
\]</div>{% endraw %}
<p>Thus</p>

{% raw %}<div class="math display">\[
\operatorname{Var}(\overline H)
=\frac{4\sigma_U^2}{n}+\frac{2\sigma_e^2}{n(n-1)}.
\]</div>{% endraw %}
<p>There are order {% raw %}<span class="math inline">\(n^2\)</span>{% endraw %} dyads, but shared node shocks produce order {% raw %}<span class="math inline">\(n^{-1}\)</span>{% endraw %} variance. This example does not describe every formation model; it explains why a dyad count alone cannot justify a root-number-of-dyads rate.</p>

<h3 data-note-section="9" id="10-447-equal-sharing-needs-both-conservation-and-convergence">9. Equal sharing needs both conservation and convergence</h3>
<p>For {% raw %}<span class="math inline">\(x^{(t+1)}=Px^{(t)}\)</span>{% endraw %}, row stochasticity preserves constant vectors: {% raw %}<span class="math inline">\(P\mathbf1=\mathbf1\)</span>{% endraw %}. Column stochasticity preserves total holdings: {% raw %}<span class="math inline">\(\mathbf1&#x27;P=\mathbf1&#x27;\)</span>{% endraw %}. If {% raw %}<span class="math inline">\(P\)</span>{% endraw %} is primitive, its powers converge to {% raw %}<span class="math inline">\(\mathbf1\pi&#x27;\)</span>{% endraw %}, where {% raw %}<span class="math inline">\(\pi\)</span>{% endraw %} is the stationary left eigenvector. Double stochasticity makes {% raw %}<span class="math inline">\(\pi=\mathbf1/m\)</span>{% endraw %}, giving equal sharing.</p>

<p>Without aperiodicity, the swap matrix on two vertices alternates holdings forever. Without column stochasticity, the matrix with rows {% raw %}<span class="math inline">\((0.9,0.1)\)</span>{% endraw %} and {% raw %}<span class="math inline">\((0.2,0.8)\)</span>{% endraw %} converges to the weighted average with weights {% raw %}<span class="math inline">\((2/3,1/3)\)</span>{% endraw %}, not the arithmetic mean. These checks identify what connectivity alone leaves unresolved.</p>

<p>If initial holdings contain independent shocks of common variance {% raw %}<span class="math inline">\(\sigma^2\)</span>{% endraw %}, equal sharing reduces each final shock variance to {% raw %}<span class="math inline">\(\sigma^2/m\)</span>{% endraw %}. Weighted sharing instead gives {% raw %}<span class="math inline">\(\sigma^2\sum_i\pi_i^2\)</span>{% endraw %}, minimized by equal weights. This elementary calculation connects the averaging mechanism to risk reduction while keeping its stochastic and graph assumptions explicit.</p>

<h3 id="10-447-an-elementary-convergence-proof-for-repeated-sharing">An elementary convergence proof for repeated sharing</h3>
<p>For a primitive row-stochastic {% raw %}<span class="math inline">\(P\)</span>{% endraw %}, some power {% raw %}<span class="math inline">\(P^r\)</span>{% endraw %} has every entry at least {% raw %}<span class="math inline">\(\epsilon&gt;0\)</span>{% endraw %}. Put {% raw %}<span class="math inline">\(\eta=m\epsilon\le1\)</span>{% endraw %} and {% raw %}<span class="math inline">\(J=\mathbf1\mathbf1&#39;/m\)</span>{% endraw %}. If {% raw %}<span class="math inline">\(\eta&lt;1\)</span>{% endraw %}, write {% raw %}<span class="math inline">\(P^r=\eta J+(1-\eta)R\)</span>{% endraw %} for another row-stochastic matrix {% raw %}<span class="math inline">\(R\)</span>{% endraw %}. Any stochastic average lies between the smallest and largest coordinates, so, for {% raw %}<span class="math inline">\(\operatorname{osc}(x)=\max_i x_i-\min_i x_i\)</span>{% endraw %},</p>
{% raw %}<div class="math display">\[\operatorname{osc}(P^r x)\le(1-\eta)\operatorname{osc}(x).\]</div>{% endraw %}
<p>Iterating makes the oscillation tend to zero geometrically. The case {% raw %}<span class="math inline">\(\eta=1\)</span>{% endraw %} gives exact averaging after {% raw %}<span class="math inline">\(r\)</span>{% endraw %} steps. When {% raw %}<span class="math inline">\(P\)</span>{% endraw %} is also column-stochastic, every iterate has the same arithmetic mean as {% raw %}<span class="math inline">\(x\)</span>{% endraw %}, so all its coordinates converge to that mean. The finitely many intermediate powers preserve the shrinking coordinate interval, which proves {% raw %}<span class="math inline">\(P^t x\to Jx\)</span>{% endraw %} for the full sequence, and hence {% raw %}<span class="math inline">\(P^t\to J\)</span>{% endraw %}. This supplies the convergence step in the sharing example without mistaking connectivity for primitivity.</p>
