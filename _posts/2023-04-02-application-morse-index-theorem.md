<div class="note-content" markdown="0">

<p>Let {% raw %}<span class="math inline">\((M,g)\)</span>{% endraw %} be a smooth Riemannian manifold, with Levi–Civita connection {% raw %}<span class="math inline">\(\nabla\)</span>{% endraw %}. For an immersed submanifold, the tangent and normal parts of {% raw %}<span class="math inline">\(\nabla\)</span>{% endraw %} give the induced connection and second fundamental form. See the <a href="{% post_url 2022-05-11-connections-lie-brackets-and-curvature %}">connection notes</a> for the notation.</p>

<div id="application-morse-index-theorem" data-note-section="title">

</div>
<p>The Morse index theorem relates the second variation along a geodesic to its conjugate points. It states that the index of every geodesic is finite, and is equal to the number of its interior conjugate points, counted with multiplicity. The index measures the number of independent directions in which a geodesic {% raw %}<span class="math inline">\(\gamma\)</span>{% endraw %} can be deformed to decrease its length.</p>

<div id="def:index-of-index-form" class="definition" data-note-number="1" data-note-kind="Definition">
<p><strong>Definition 1</strong>.  For the index form {% raw %}<span class="math inline">\(I\)</span>{% endraw %}, its <em>index</em> is the maximal dimension of all subspaces such that {% raw %}<span class="math inline">\(I(X,X) &lt; 0\)</span>{% endraw %} (i.e. negative definite). The <em>nullity</em> of {% raw %}<span class="math inline">\(I\)</span>{% endraw %} is the dimension of the subspace formed by {% raw %}<span class="math inline">\(V\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(I(V,W)=0\)</span>{% endraw %} for all {% raw %}<span class="math inline">\(W\)</span>{% endraw %}. Finally, {% raw %}<span class="math inline">\(I\)</span>{% endraw %} is said to be <em>degenerate</em> if its nullity is strictly positive.</p>

<p>Here negative definite means {% raw %}<span class="math inline">\(I(X,X)&lt;0\)</span>{% endraw %} for every <em>nonzero</em> vector of the subspace. We work along a smooth geodesic on a compact interval {% raw %}<span class="math inline">\([a,b]\)</span>{% endraw %}, {% raw %}<span class="math inline">\(a&lt;b\)</span>{% endraw %}, with fields vanishing at both endpoints. The index is initially the supremum of the possible dimensions; the finiteness proof below makes it an attained finite maximum. The null space means the radical {% raw %}<span class="math inline">\(\{X:I(X,Y)=0\text{ for all }Y\}\)</span>{% endraw %}, not the larger cone {% raw %}<span class="math inline">\(\{X:I(X,X)=0\}\)</span>{% endraw %}.</p>
</div>
<div id="thm:morse-index" class="theorem" data-note-number="2" data-note-kind="Theorem">
<p><strong>Theorem 2</strong> (Morse Index Theorem).  The index of the form {% raw %}<span class="math inline">\(I(X,X)\)</span>{% endraw %} is finite. Moreover, this is given by the number of points {% raw %}<span class="math inline">\(\gamma(t)\)</span>{% endraw %} conjugate to {% raw %}<span class="math inline">\(\gamma(a)\)</span>{% endraw %}, where {% raw %}<span class="math inline">\(a &lt; t &lt; b\)</span>{% endraw %}, each counted with multiplicity.</p>

<p>The form here acts on endpoint-vanishing fields on a compact geodesic interval {% raw %}<span class="math inline">\([a,b]\)</span>{% endraw %}, {% raw %}<span class="math inline">\(a&lt;b\)</span>{% endraw %}. The full proof, including its Sobolev completion and the endpoint-nullity distinction, is Theorem 10 below. Conjugate <em>parameter times</em> are counted, even if the geodesic revisits the same point of the manifold.</p>
</div>
<p>First identify the null space of the index form. Integration by parts shows why the Jacobi equation appears: it is the differential equation left after testing against all fields that vanish at the endpoints.</p>

<div id="prop:nullity-index-jacobi" class="proposition" data-note-number="3" data-note-kind="Proposition">
<p><strong>Proposition 3</strong>.  A proper normal vector field {% raw %}<span class="math inline">\(V\)</span>{% endraw %} belongs to the null space of {% raw %}<span class="math inline">\(I\)</span>{% endraw %} if and only if {% raw %}<span class="math inline">\(V\)</span>{% endraw %} is a Jacobi field along {% raw %}<span class="math inline">\(\gamma\)</span>{% endraw %}.</p>

</div>
<div class="proof">
<p><em>Proof.</em> Write {% raw %}<span class="math inline">\(T=\gamma'\)</span>{% endraw %}, and use the convention {% raw %}<span class="math inline">\(I(V,W)=\int(\langle V',W'\rangle-\langle R(T,V)T,W\rangle)dt\)</span>{% endraw %}. For continuous piecewise smooth {% raw %}<span class="math inline">\(V\)</span>{% endraw %}, integration on each smooth piece gives</p>
<p> {% raw %}<div class="math display">\[I(V,W)=-\int_a^b\langle V''+R(T,V)T,W\rangle dt-\sum_j\langle V'(t_j^+)-V'(t_j^-),W(t_j)\rangle,\]</div>{% endraw %}</p>
<p> where the endpoint terms vanish because {% raw %}<span class="math inline">\(W(a)=W(b)=0\)</span>{% endraw %}. If {% raw %}<span class="math inline">\(V\)</span>{% endraw %} is Jacobi, the integrand and jumps vanish. Conversely choose a nonnegative bump supported in the interior of one piece and set {% raw %}<span class="math inline">\(W=f(V''+R(T,V)T)\)</span>{% endraw %}. The expression in parentheses is normal, so this is an allowed test field; the integral of its squared norm is zero and the Jacobi equation holds on that piece. Then test at each junction with a normal field whose value is its derivative jump and whose values at all other junctions vanish. The formula forces every jump to vanish. Matching values and derivatives let ODE uniqueness join the pieces into one smooth Jacobi field. The jump step is essential: being Jacobi separately on pieces alone does not give a global Jacobi field. ◻</p>
</div>
<p>We pass to the completion of the space of vector fields in a Sobolev norm. This gives a setting in which bounded sequences have the compactness properties needed to prove finiteness of the index.</p>

<div id="result-4" class="definition" data-note-number="4" data-note-kind="Definition">
<p><strong>Definition 4.</strong> Let {% raw %}<span class="math inline">\(\mathcal E_0(\gamma)\)</span>{% endraw %} be the space of smooth vector fields along {% raw %}<span class="math inline">\(\gamma\)</span>{% endraw %} with {% raw %}<span class="math inline">\(X(a)=X(b)=0\)</span>{% endraw %}. Define</p>
<p> {% raw %}<div class="math display">\[\|X\|_{H^1}^2=\int_a^b(|D_tX|^2+|X|^2)dt.\]</div>{% endraw %}</p>
<p> Its completion is denoted {% raw %}<span class="math inline">\(\mathscr H_\gamma^1\)</span>{% endraw %}. We use {% raw %}<span class="math inline">\(\mathcal E\)</span>{% endraw %} here to distinguish arbitrary fields from the Jacobi-field spaces {% raw %}<span class="math inline">\(\mathscr J^t\)</span>{% endraw %} below.</p>
</div>
<div id="result-5" class="remark" data-note-number="5" data-note-kind="Remark">
<p><strong>Remark 5.</strong> In a parallel orthonormal frame along {% raw %}<span class="math inline">\(\gamma\)</span>{% endraw %}, write {% raw %}<span class="math inline">\(X=x^iE_i\)</span>{% endraw %}, so {% raw %}<span class="math inline">\(D_tX=(x^i)'E_i\)</span>{% endraw %}. This identifies {% raw %}<span class="math inline">\(\mathscr H_\gamma^1\)</span>{% endraw %} with {% raw %}<span class="math inline">\(H_0^1((a,b);\mathbb R^d)\)</span>{% endraw %}, whose fields have continuous representatives and zero endpoint traces. Put</p>
<p> {% raw %}<div class="math display">\[A(t)u=R(\gamma'(t),u)\gamma'(t),\qquad I(X,Y)=\int_a^b(\langle X',Y'\rangle-\langle A(t)X,Y\rangle)dt.\]</div>{% endraw %}</p>
<p> The operator {% raw %}<span class="math inline">\(A(t)\)</span>{% endraw %} is smooth and self-adjoint, and {% raw %}<span class="math inline">\(\|A(t)\|\leq C\)</span>{% endraw %} on the compact interval. Hence {% raw %}<span class="math inline">\(|I(X,Y)|\leq(1+C)\|X\|_{H^1}\|Y\|_{H^1}\)</span>{% endraw %}, so the form extends continuously to the completion.</p>
<p>For a nonconstant geodesic, split {% raw %}<span class="math inline">\(X=fT/|T|+X^\perp\)</span>{% endraw %}. Parallelness of {% raw %}<span class="math inline">\(T\)</span>{% endraw %} and the curvature symmetries give {% raw %}<span class="math inline">\(I(X,X)=\int|f'|^2+I(X^\perp,X^\perp)\)</span>{% endraw %}. Thus tangent components contribute neither negative directions nor nullity with zero endpoints. We may use all fields or only normal fields with the same index and nullity. A constant geodesic has {% raw %}<span class="math inline">\(A=0\)</span>{% endraw %} and zero index and nullity.</p>
<p>Passing to the {% raw %}<span class="math inline">\(H^1_0\)</span>{% endraw %} completion does not change the index. Smooth endpoint-zero fields are dense in {% raw %}<span class="math inline">\(H^1_0\)</span>{% endraw %}, and the index form is continuous in that norm. A finite-dimensional negative subspace has a uniform strictly negative bound on its unit sphere; approximating a basis by smooth fields preserves linear independence and that bound. The reverse inequality follows by inclusion. The radical is the space of smooth endpoint-zero Jacobi fields, as proved below, so the corresponding extended index agrees as well.</p>
</div>
<div id="def:index-geodesic" class="definition" data-note-number="6" data-note-kind="Definition">
<p><strong>Definition 6</strong>.  The <em>index of {% raw %}<span class="math inline">\(\gamma\)</span>{% endraw %}</em>, denoted {% raw %}<span class="math inline">\(\operatorname{Ind}(\gamma)\)</span>{% endraw %}, is the dimension of the maximal subspace of {% raw %}<span class="math inline">\(\mathscr H_\gamma^1\)</span>{% endraw %} on which the index form is <em>negative definite</em>. The <em>extended index of {% raw %}<span class="math inline">\(\gamma\)</span>{% endraw %}</em>, denoted {% raw %}<span class="math inline">\(\operatorname{Ind}_0 (\gamma)\)</span>{% endraw %}, is the dimension of the maximal subspace of {% raw %}<span class="math inline">\(\mathscr H_\gamma^1\)</span>{% endraw %} on which the index form is <em>negative semidefinite</em>. The <em>nullity of {% raw %}<span class="math inline">\(\gamma\)</span>{% endraw %}</em> is defined as {% raw %}<span class="math inline">\(N(\gamma) \triangleq \operatorname{Ind}_0(\gamma) - \operatorname{Ind}(\gamma)\)</span>{% endraw %}.</p>

</div>
<div id="lem:finite-index-and-nullity" class="lemma" data-note-number="7" data-note-kind="Lemma">
<p><strong>Lemma 7</strong>.  {% raw %}<span class="math inline">\(\operatorname{Ind}(\gamma)\)</span>{% endraw %} and {% raw %}<span class="math inline">\(N(\gamma)\)</span>{% endraw %} are finite.</p>

</div>
<div class="proof">
<p><em>Proof.</em> In a nonpositive subspace, every {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %}-unit field satisfies</p>
<p> {% raw %}<div class="math display">\[\int_a^b|X'|^2dt\leq\int_a^b\langle AX,X\rangle dt\leq C.\]</div>{% endraw %}</p>
<p> Thus all such unit fields, from all possible nonpositive subspaces, lie in one bounded {% raw %}<span class="math inline">\(H_0^1\)</span>{% endraw %} set. On an interval this set is precompact in {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %}. Indeed Cauchy–Schwarz gives {% raw %}<span class="math inline">\(|X(t)-X(s)|\leq\|X'\|_{L^2}|t-s|^{1/2}\)</span>{% endraw %}, and the zero endpoint gives a uniform sup norm bound; Arzelà–Ascoli produces uniform, hence {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %}, convergence of a subsequence. This is the interval version of Rellich compactness.</p>
<p>A precompact metric set has a finite cover by balls of radius less than {% raw %}<span class="math inline">\(\sqrt2/2\)</span>{% endraw %}. An {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %}-orthonormal family has pairwise distance {% raw %}<span class="math inline">\(\sqrt2\)</span>{% endraw %}, so contains at most one point in each such ball. Applying Gram–Schmidt within any finite-dimensional nonpositive subspace gives a uniform bound on its dimension. This proves {% raw %}<span class="math inline">\(\operatorname{Ind}_0&lt;\infty\)</span>{% endraw %}, and hence finiteness of the index and its difference {% raw %}<span class="math inline">\(N\)</span>{% endraw %}. The uniform bound also rules out arbitrarily large finite-dimensional subspaces, without assuming in advance that they lie in one infinite-dimensional nonpositive subspace. ◻</p>
</div>
<div id="result-8" class="definition" data-note-number="8" data-note-kind="Definition">
<p><strong>Definition 8</strong>.  For each {% raw %}<span class="math inline">\(t \in (a,b]\)</span>{% endraw %}, let {% raw %}<span class="math inline">\(\mathscr J^t (\gamma)\)</span>{% endraw %} denote the space of Jacobi fields along {% raw %}<span class="math inline">\(\gamma : [a,b] \to M\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(X(a) = 0\)</span>{% endraw %} and {% raw %}<span class="math inline">\(X(t) = 0\)</span>{% endraw %}.</p>

</div>
<div id="lem:nullity-finite" class="lemma" data-note-number="9" data-note-kind="Lemma">
<p><strong>Lemma 9</strong>.  On {% raw %}<span class="math inline">\(\mathscr H_\gamma^1\)</span>{% endraw %}, {% raw %}<span class="math inline">\(N(\gamma) = \dim \mathscr J^b (\gamma)\)</span>{% endraw %}.</p>

</div>
<div class="proof">
<p><em>Proof.</em> First justify that the difference of the two indices equals the dimension of the radical. Choose a maximal negative-definite subspace {% raw %}<span class="math inline">\(E\)</span>{% endraw %}, finite-dimensional by Lemma 7. Nondegeneracy of {% raw %}<span class="math inline">\(I|_E\)</span>{% endraw %} gives the algebraic decomposition {% raw %}<span class="math inline">\(\mathscr H_\gamma^1=E\oplus E^{\perp_I}\)</span>{% endraw %}. On {% raw %}<span class="math inline">\(W=E^{\perp_I}\)</span>{% endraw %}, the form is nonnegative, since a vector with negative square would enlarge {% raw %}<span class="math inline">\(E\)</span>{% endraw %}. For a nonnegative bilinear form, {% raw %}<span class="math inline">\(I(w,w)=0\)</span>{% endraw %} implies {% raw %}<span class="math inline">\(I(w,z)=0\)</span>{% endraw %} for all {% raw %}<span class="math inline">\(z\)</span>{% endraw %}, by considering {% raw %}<span class="math inline">\(I(w+tz,w+tz)\)</span>{% endraw %} as a quadratic polynomial. Thus the null vectors of {% raw %}<span class="math inline">\(I|_W\)</span>{% endraw %} are precisely the full radical {% raw %}<span class="math inline">\(K\)</span>{% endraw %}.</p>
<p>For any nonpositive subspace {% raw %}<span class="math inline">\(L\)</span>{% endraw %}, the kernel of its projection to {% raw %}<span class="math inline">\(E\)</span>{% endraw %} is contained in {% raw %}<span class="math inline">\(K\)</span>{% endraw %}, because it lies in {% raw %}<span class="math inline">\(W\)</span>{% endraw %}. Hence {% raw %}<span class="math inline">\(\dim L\leq\dim E+\dim K\)</span>{% endraw %}. Equality is attained by {% raw %}<span class="math inline">\(E\oplus K\)</span>{% endraw %}, giving {% raw %}<span class="math inline">\(N=\dim K\)</span>{% endraw %}.</p>
<p>In parallel coordinates, an {% raw %}<span class="math inline">\(H_0^1\)</span>{% endraw %} field in {% raw %}<span class="math inline">\(K\)</span>{% endraw %} satisfies {% raw %}<span class="math inline">\(x''+A(t)x=0\)</span>{% endraw %} distributionally, by testing against compactly supported smooth fields. Its continuous representative makes {% raw %}<span class="math inline">\(Ax\)</span>{% endraw %} continuous; integrating twice shows {% raw %}<span class="math inline">\(x\)</span>{% endraw %} is {% raw %}<span class="math inline">\(C^2\)</span>{% endraw %}, and the smooth coefficients bootstrap it to smoothness. It is therefore a Jacobi field with the endpoint conditions. Conversely integration by parts shows any such Jacobi field lies in {% raw %}<span class="math inline">\(K\)</span>{% endraw %}, first against smooth fields and then against all {% raw %}<span class="math inline">\(H_0^1\)</span>{% endraw %} fields by density. Consequently {% raw %}<span class="math inline">\(K=\mathscr J^b\)</span>{% endraw %}, proving the assertion. ◻</p>
</div>
<div id="thm:morse-index-complete" class="theorem" data-note-number="10" data-note-kind="Theorem">
<p><strong>Theorem 10</strong> (Morse Index Theorem).  Let {% raw %}<span class="math inline">\(\gamma: [a,b] \to M\)</span>{% endraw %} be a geodesic. There are at most finitely many points conjugate to {% raw %}<span class="math inline">\(\gamma(a)\)</span>{% endraw %} along {% raw %}<span class="math inline">\(\gamma\)</span>{% endraw %}, and </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \operatorname{Ind} (\gamma) &amp;= \sum_{t \in (a,b)} \dim \mathscr J^t (\gamma) ~, \\
        \operatorname{Ind}_0 (\gamma) &amp;= \sum_{t \in (a,b]} \dim \mathscr J^t (\gamma) ~.
    
\end{aligned}\]</div>{% endraw %}
</div>
<div class="proof">
<p><em>Proof.</em> Translate the parameter so that {% raw %}<span class="math inline">\(a=0\)</span>{% endraw %}. All rescalings below are of coefficient functions in a fixed parallel frame, so vectors in different tangent spaces are compared correctly.</p>
<p><strong>Finitely many conjugate times.</strong> For any finite list {% raw %}<span class="math inline">\(0&lt;t_1&lt;\cdots&lt;t_k\leq b\)</span>{% endraw %}, choose a basis {% raw %}<span class="math inline">\(J_{i,r}\)</span>{% endraw %} of each {% raw %}<span class="math inline">\(\mathscr J^{t_i}\)</span>{% endraw %} and truncate it to zero after {% raw %}<span class="math inline">\(t_i\)</span>{% endraw %}, obtaining continuous {% raw %}<span class="math inline">\(H_0^1\)</span>{% endraw %} fields {% raw %}<span class="math inline">\(Y_{i,r}\)</span>{% endraw %}. These fields span a totally isotropic subspace: for {% raw %}<span class="math inline">\(t_i\leq t_j\)</span>{% endraw %}, integrate using the Jacobi equation of {% raw %}<span class="math inline">\(J_{j,s}\)</span>{% endraw %} on {% raw %}<span class="math inline">\([0,t_i]\)</span>{% endraw %}, obtaining</p>
<p> {% raw %}<div class="math display">\[I(Y_{i,r},Y_{j,s})=[\langle J_{i,r},J_{j,s}'\rangle]_0^{t_i}=0.\]</div>{% endraw %}</p>
<p> The fields are independent. On the last interval {% raw %}<span class="math inline">\((t_{k-1},t_k)\)</span>{% endraw %}, any linear relation involves only the last group of Jacobi fields; ODE uniqueness forces that group's coefficients to vanish. Continue backwards. Thus {% raw %}<span class="math inline">\(\sum_i\dim\mathscr J^{t_i}\leq\operatorname{Ind}_0(\gamma)\)</span>{% endraw %}. Lemma 7 bounds this sum for every finite list, proving finiteness of the conjugate times, with their multiplicities. Merely having individual zero squares would not suffice; the cross terms above matter.</p>
<p><strong>Moving the endpoint.</strong> Set {% raw %}<span class="math inline">\(m(\tau)=\operatorname{Ind}(\gamma|_{[0,\tau]})\)</span>{% endraw %} and {% raw %}<span class="math inline">\(m_0(\tau)=\operatorname{Ind}_0(\gamma|_{[0,\tau]})\)</span>{% endraw %}. Extension by zero embeds the form on a shorter interval into that on a longer interval, so both functions are nondecreasing. After rescaling to {% raw %}<span class="math inline">\([0,1]\)</span>{% endraw %}, the form is</p>
<p> {% raw %}<div class="math display">\[Q_\tau(x)=\frac1\tau\int_0^1|x'|^2du-\tau\int_0^1\langle A(\tau u)x,x\rangle du.\]</div>{% endraw %}</p>
<p> It depends continuously on {% raw %}<span class="math inline">\(\tau&gt;0\)</span>{% endraw %} in the norm of bilinear forms on {% raw %}<span class="math inline">\(H_0^1\)</span>{% endraw %}. On the unit sphere of a fixed finite-dimensional negative subspace, negativity is uniform, so it persists for {% raw %}<span class="math inline">\(\sigma\)</span>{% endraw %} sufficiently close to {% raw %}<span class="math inline">\(\tau\)</span>{% endraw %}. Combined with monotonicity this proves {% raw %}<span class="math inline">\(m(\tau^-)=m(\tau)\)</span>{% endraw %}.</p>
<p>To prove {% raw %}<span class="math inline">\(m_0(\tau^+)=m_0(\tau)\)</span>{% endraw %}, suppose instead that a sequence {% raw %}<span class="math inline">\(\tau_n\downarrow\tau\)</span>{% endraw %} has nonpositive subspaces of dimension {% raw %}<span class="math inline">\(r=m_0(\tau)+1\)</span>{% endraw %}. Choose {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %}-orthonormal bases {% raw %}<span class="math inline">\(X_{n,1},\ldots,X_{n,r}\)</span>{% endraw %} and extend them by zero to {% raw %}<span class="math inline">\([0,b]\)</span>{% endraw %}. Nonpositivity bounds each derivative norm by {% raw %}<span class="math inline">\(C\)</span>{% endraw %}. Pass to a common subsequence converging weakly in {% raw %}<span class="math inline">\(H_0^1\)</span>{% endraw %} and strongly in {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %} to {% raw %}<span class="math inline">\(X_1,\ldots,X_r\)</span>{% endraw %}. The limits remain {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %}-orthonormal and vanish on {% raw %}<span class="math inline">\((\tau,b]\)</span>{% endraw %}; continuity gives zero trace at {% raw %}<span class="math inline">\(\tau\)</span>{% endraw %}. For every coefficient vector {% raw %}<span class="math inline">\(c\)</span>{% endraw %}, weak lower semicontinuity of the derivative norm and strong convergence of the curvature term give</p>
<p> {% raw %}<div class="math display">\[I_\tau\left(\sum c_jX_j,\sum c_jX_j\right)\leq\liminf_n I_{\tau_n}\left(\sum c_jX_{n,j},\sum c_jX_{n,j}\right)\leq0.\]</div>{% endraw %}</p>
<p> This constructs an {% raw %}<span class="math inline">\(r\)</span>{% endraw %}-dimensional nonpositive subspace on {% raw %}<span class="math inline">\([0,\tau]\)</span>{% endraw %}, a contradiction. Passing a whole orthonormal basis to the limit, rather than one vector, is what proves the dimension assertion.</p>
<p><strong>Counting jumps.</strong> On a sufficiently short interval, {% raw %}<span class="math inline">\(\int_0^\tau|X|^2\leq\tau^2\int_0^\tau|X'|^2/2\)</span>{% endraw %}, so {% raw %}<span class="math inline">\(I(X,X)\geq(1-C\tau^2/2)\int|X'|^2&gt;0\)</span>{% endraw %} for nonzero {% raw %}<span class="math inline">\(X\)</span>{% endraw %}. Thus {% raw %}<span class="math inline">\(m=m_0=0\)</span>{% endraw %} initially. Lemma 9 gives {% raw %}<span class="math inline">\(m_0(\tau)-m(\tau)=\dim\mathscr J^\tau\)</span>{% endraw %}. Away from the finitely many conjugate times this difference is zero, and the two one-sided continuity statements and monotonicity force the common integer value to be locally constant. At a conjugate time {% raw %}<span class="math inline">\(t_i\)</span>{% endraw %}, the value before it is {% raw %}<span class="math inline">\(m(t_i)\)</span>{% endraw %}, and the value after it is {% raw %}<span class="math inline">\(m_0(t_i)\)</span>{% endraw %}; their difference is exactly its multiplicity. Summing these jumps proves</p>
<p> {% raw %}<div class="math display">\[m(b)=\sum_{0&lt;t&lt;b}\dim\mathscr J^t,\qquad m_0(b)=\sum_{0&lt;t\leq b}\dim\mathscr J^t.\]</div>{% endraw %}</p>
<p> This includes the cases of no conjugate times and of an endpoint conjugate time. ◻</p>
</div>
<p>Finally, comparison of the curvature terms compares index forms after identifying parallel frames. The next lemma records the resulting inequality for indices.</p>

<div id="lem:index-comparison" class="lemma" data-note-number="11" data-note-kind="Lemma">
<p><strong>Lemma 11</strong>.  Let {% raw %}<span class="math inline">\(M\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\widetilde M\)</span>{% endraw %} be differentiable manifolds of the same dimension, such that their section curvatures {% raw %}<span class="math inline">\(K\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\widetilde K\)</span>{% endraw %} satisfy {% raw %}<span class="math inline">\(\sup \widetilde K \leq \inf K\)</span>{% endraw %}, where the supremum and infimum are taken over all 2-planes of {% raw %}<span class="math inline">\(TM\)</span>{% endraw %} and {% raw %}<span class="math inline">\(T \widetilde M\)</span>{% endraw %}. Let {% raw %}<span class="math inline">\(\sigma : [0,b] \to M\)</span>{% endraw %} be a geodesic such that {% raw %}<span class="math inline">\(\sigma(0) = p\)</span>{% endraw %}, and fix {% raw %}<span class="math inline">\(\widetilde p \in \widetilde M\)</span>{% endraw %}. Let {% raw %}<span class="math inline">\(i : T_p M \to T_{\widetilde p} \widetilde M\)</span>{% endraw %} be a linear isometry, and {% raw %}<span class="math inline">\(\widetilde \sigma : [0,b] \to \widetilde M\)</span>{% endraw %} be given by {% raw %}<span class="math inline">\(\widetilde \sigma (t) = \exp_{\widetilde p} (t i(\sigma&#x27;(0)))\)</span>{% endraw %}. Then, {% raw %}<span class="math inline">\(\operatorname{Ind}(\sigma) \geq \operatorname{Ind}(\widetilde \sigma)\)</span>{% endraw %}.</p>

<p>It is assumed that the target geodesic exists for all {% raw %}<span class="math inline">\(0\leq t\leq b\)</span>{% endraw %}, for example if {% raw %}<span class="math inline">\(\widetilde M\)</span>{% endraw %} is complete. The two velocities have equal lengths. The proof applies to the endpoint-vanishing Sobolev spaces as well as smooth fields by density.</p>
</div>
<div class="proof">
<p><em>Proof.</em> Define {% raw %}<span class="math inline">\(B_t=P_t i^{-1}\widetilde P_t^{-1}\)</span>{% endraw %}, which sends the target velocity to the source velocity and commutes with covariant differentiation. Thus {% raw %}<span class="math inline">\(W=B_t\widetilde W\)</span>{% endraw %} has the same norm, derivative norm, endpoints and tangential component. The squared area {% raw %}<span class="math inline">\(|\sigma'|^2|W|^2-\langle\sigma',W\rangle^2\)</span>{% endraw %} is preserved. Multiplying the sectional-curvature bound by this nonnegative quantity gives</p>
<p> {% raw %}<div class="math display">\[\langle R(\sigma',W)\sigma',W\rangle\geq\langle\widetilde R(\widetilde\sigma',\widetilde W)\widetilde\sigma',\widetilde W\rangle.\]</div>{% endraw %}</p>
<p> For a zero area both sides vanish by curvature antisymmetry. Therefore {% raw %}<span class="math inline">\(I(W,W)\leq\widetilde I(\widetilde W,\widetilde W)\)</span>{% endraw %}. The map {% raw %}<span class="math inline">\(\widetilde W\mapsto W\)</span>{% endraw %} is a linear bijection of field spaces, so it takes every negative-definite subspace for {% raw %}<span class="math inline">\(\widetilde I\)</span>{% endraw %} to a negative-definite subspace of the same dimension for {% raw %}<span class="math inline">\(I\)</span>{% endraw %}. Taking maximum dimensions proves the comparison. ◻</p>
</div>
