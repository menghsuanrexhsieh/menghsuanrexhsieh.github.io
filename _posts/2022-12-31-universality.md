<div id="universality"></div>
<p>The semicircle law describes the limiting empirical distribution of eigenvalues of a normalized Wigner matrix. The limit depends on the entry variance, rather than the full entry distribution. We give two proofs for bounded entries, then remove boundedness by truncation. The first proof counts trace moments; the second derives an equation for the Stieltjes transform.</p>
<p>Let {% raw %}<span class="math inline">\(\{\xi_{ij}:i&lt;j\}\)</span>{% endraw %} be iid complex random variables with {% raw %}<span class="math inline">\(\mathbb{E}\xi_{12}=0\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\mathbb{E}|\xi_{12}|^2=1\)</span>{% endraw %}. Set {% raw %}<span class="math inline">\(\xi_{ji}=\overline{\xi_{ij}}\)</span>{% endraw %}. Independently, let the diagonal entries be iid real variables with finite second moment. Write {% raw %}<span class="math inline">\(M_n=(\xi_{ij})_{i,j\le n}\)</span>{% endraw %}, {% raw %}<span class="math inline">\(H_n=M_n/\sqrt n\)</span>{% endraw %}, and</p>
{% raw %}<div class="math display">\[\mu_n=\frac1n\sum_{i=1}^n\delta_{\lambda_i(H_n)}.\]</div>{% endraw %}
<p>This is a random probability measure. Its expectation is the deterministic probability measure defined by {% raw %}<span class="math inline">\((\mathbb{E}\mu_n)(B)=\mathbb{E}[\mu_n(B)]\)</span>{% endraw %}, or equivalently by integration of bounded measurable test functions.</p>
<div id="thm:semicircular-law" class="theorem" data-note-number="1" data-note-kind="Theorem"><p><strong>Theorem 1 (Semicircle law).</strong> Under these hypotheses, {% raw %}<span class="math inline">\(\mu_n\)</span>{% endraw %} converges weakly almost surely to</p>
{% raw %}<div class="math display">\[d\mu_{\rm sc}(x)=\frac1{2\pi}\sqrt{(4-x^2)_+}\,dx.\]</div>{% endraw %}
<p>Precisely, on one event of probability one, {% raw %}<span class="math inline">\(\int f\,d\mu_n\to\int f\,d\mu_{\rm sc}\)</span>{% endraw %} for every bounded continuous function {% raw %}<span class="math inline">\(f:\mathbb R\to\mathbb R\)</span>{% endraw %}.</p></div>
<div id="result-2" class="remark" data-note-number="2" data-note-kind="Remark"><p><strong>Remark 2 (Geometric subsequences).</strong> Write {% raw %}<span class="math inline">\(F_n(x)=\mu_n(( -\infty,x])\)</span>{% endraw %}. Cauchy interlacing, with all eigenvalues put at the same unnormalized threshold, gives for {% raw %}<span class="math inline">\(m&lt;n\)</span>{% endraw %},</p>
{% raw %}<div class="math display">\[\frac n m F_n(x\sqrt{m/n})-\frac{n-m}m\le F_m(x)\le\frac n m F_n(x\sqrt{m/n}).\]</div>{% endraw %}
<p>It suffices to prove almost-sure weak convergence along every sequence {% raw %}<span class="math inline">\(n_j=\lfloor(1+\epsilon)^j\rfloor\)</span>{% endraw %}, for a countable collection {% raw %}<span class="math inline">\(\epsilon\downarrow0\)</span>{% endraw %}. Indeed, for {% raw %}<span class="math inline">\(m\)</span>{% endraw %} between consecutive sizes, the displayed inequalities bound its cdf by the larger matrix's cdf, with a threshold perturbation of order {% raw %}<span class="math inline">\(|x|\epsilon\)</span>{% endraw %}, a multiplicative error of order {% raw %}<span class="math inline">\(\epsilon\)</span>{% endraw %}, and an additive error of order {% raw %}<span class="math inline">\(\epsilon\)</span>{% endraw %}. Along each sequence the limiting cdf is continuous. First let {% raw %}<span class="math inline">\(j\to\infty\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(\epsilon\downarrow0\)</span>{% endraw %}. Taking rational {% raw %}<span class="math inline">\(x\)</span>{% endraw %} first puts all these conclusions on one probability-one event. Convergence on one fixed geometric sequence alone would not suffice.</p></div>
<p>The interlacing assertion itself follows from Courant–Fischer. For an {% raw %}<span class="math inline">\(m\)</span>{% endraw %}-dimensional coordinate subspace {% raw %}<span class="math inline">\(V\subset\mathbb C^n\)</span>{% endraw %}, the Rayleigh quotient of the principal minor is the restriction of the full quotient to {% raw %}<span class="math inline">\(V\)</span>{% endraw %}. Restricting the maximizing subspaces gives {% raw %}<span class="math inline">\(\lambda_i(M_n)\ge\lambda_i(M_m)\)</span>{% endraw %}; restricting the minimizing subspaces gives {% raw %}<span class="math inline">\(\lambda_i(M_m)\ge\lambda_{i+n-m}(M_n)\)</span>{% endraw %}, in descending order. At a common unnormalized threshold the two eigenvalue counts therefore differ by a number between zero and {% raw %}<span class="math inline">\(n-m\)</span>{% endraw %}. This is precisely the cdf comparison in Remark 2, after dividing by the appropriate matrix dimensions.</p>
<div id="result-3" class="remark" data-note-number="3" data-note-kind="Remark"><p><strong>Remark 3 (Perturbations).</strong> For Hermitian matrices with ordered eigenvalues, the Hoffman–Wielandt inequality is</p>
{% raw %}<div class="math display">\[\sum_{i=1}^n|\lambda_i(A+B)-\lambda_i(A)|^2\le\|B\|_F^2.\]</div>{% endraw %}
<p>For completeness, diagonalize {% raw %}<span class="math inline">\(A\)</span>{% endraw %} and {% raw %}<span class="math inline">\(C=A+B\)</span>{% endraw %}, with descending eigenvalues {% raw %}<span class="math inline">\(\alpha_i,\gamma_i\)</span>{% endraw %} and unit eigenvectors {% raw %}<span class="math inline">\(u_i,v_i\)</span>{% endraw %}. The matrix {% raw %}<span class="math inline">\(p_{ij}=|u_i^*v_j|^2\)</span>{% endraw %} has nonnegative entries and all row and column sums one. Set {% raw %}<span class="math inline">\(q_i=\sum_jp_{ij}\gamma_j\)</span>{% endraw %}. For every {% raw %}<span class="math inline">\(k\)</span>{% endraw %}, the weights {% raw %}<span class="math inline">\(w_j=\sum_{i\le k}p_{ij}\)</span>{% endraw %} lie in {% raw %}<span class="math inline">\([0,1]\)</span>{% endraw %} and sum to {% raw %}<span class="math inline">\(k\)</span>{% endraw %}; therefore {% raw %}<span class="math inline">\(\sum_{i\le k}q_i=\sum_jw_j\gamma_j\le\sum_{j\le k}\gamma_j\)</span>{% endraw %}. Equality holds at {% raw %}<span class="math inline">\(k=n\)</span>{% endraw %}. Summation by parts, with {% raw %}<span class="math inline">\(\alpha_k-\alpha_{k+1}\ge0\)</span>{% endraw %}, now gives</p>

{% raw %}<div class="math display">\[\operatorname{Tr}(AC)=\sum_i\alpha_iq_i\le\sum_i\alpha_i\gamma_i.\]</div>{% endraw %}

<p>Consequently {% raw %}<span class="math inline">\(\|A-C\|_F^2=\operatorname{Tr}A^2+\operatorname{Tr}C^2-2\operatorname{Tr}(AC)\ge\sum_i(\alpha_i-\gamma_i)^2\)</span>{% endraw %}, proving the inequality. The square on the Frobenius norm is essential.</p>

<p>At most {% raw %}<span class="math inline">\(\|B\|_F^2/(n\epsilon^2)\)</span>{% endraw %} eigenvalues move by more than {% raw %}<span class="math inline">\(\epsilon\sqrt n\)</span>{% endraw %}. Dividing this count by {% raw %}<span class="math inline">\(n\)</span>{% endraw %} gives</p>
{% raw %}<div class="math display">\[F_{A/\sqrt n}(x-\epsilon)-\frac{\|B\|_F^2}{n^2\epsilon^2}\le F_{(A+B)/\sqrt n}(x)\le F_{A/\sqrt n}(x+\epsilon)+\frac{\|B\|_F^2}{n^2\epsilon^2}.\]</div>{% endraw %}
<p>This estimate will transfer the law from bounded entries to entries having only a second moment.</p></div>
<div class="proof"><p><em>First proof for bounded entries: moments.</em> For each fixed integer {% raw %}<span class="math inline">\(k\ge0\)</span>{% endraw %},</p><span id="eq:duality-formula-sc"></span>
{% raw %}<div class="math display">\[m_k^{(n)}:=\int x^k\,d\mu_n(x)=n^{-1-k/2}\sum_{i_1,\ldots,i_k}\xi_{i_1i_2}\cdots\xi_{i_ki_1}.\]</div>{% endraw %}
<p>For this part of the proof, assume a fixed finite bound on both the off-diagonal and diagonal entries. Constants in the moment estimates may depend on that bound and on the fixed degree {% raw %}<span class="math inline">\(k\)</span>{% endraw %}, but not on {% raw %}<span class="math inline">\(n\)</span>{% endraw %}. The case {% raw %}<span class="math inline">\(k=0\)</span>{% endraw %} is the identity {% raw %}<span class="math inline">\(m_0^{(n)}=1\)</span>{% endraw %}.</p>
<p>View an index sequence as a closed walk on its distinct vertices, with an unordered edge for each matrix entry. An off-diagonal edge used exactly once makes the expectation zero, by independence and centering. If the walk uses {% raw %}<span class="math inline">\(v\)</span>{% endraw %} vertices, at least {% raw %}<span class="math inline">\(v-1\)</span>{% endraw %} distinct non-loop edges are needed, each at least twice in a surviving term. Thus {% raw %}<span class="math inline">\(v\le1+k/2\)</span>{% endraw %}. For fixed {% raw %}<span class="math inline">\(k\)</span>{% endraw %}, there are finitely many walk patterns, each contributing {% raw %}<span class="math inline">\(O_k(n^v)\)</span>{% endraw %} index choices and a bounded expectation.</p>
<p>If {% raw %}<span class="math inline">\(k=2r\)</span>{% endraw %}, the only patterns with {% raw %}<span class="math inline">\(v=r+1\)</span>{% endraw %} are trees traversed exactly twice along each edge. A closed walk on a tree traverses each edge once in each direction, so its expectation is one, also for complex entries. The successive distances from the starting vertex form a Dyck path of length {% raw %}<span class="math inline">\(2r\)</span>{% endraw %}, and conversely each such path gives one walk with vertices labeled in order of first appearance. There are {% raw %}<span class="math inline">\(C_r=(r+1)^{-1}\binom{2r}{r}\)</span>{% endraw %} such paths, by the reflection principle. Each has {% raw %}<span class="math inline">\(n(n-1)\cdots(n-r)\)</span>{% endraw %} labelings. All remaining patterns have at most {% raw %}<span class="math inline">\(r\)</span>{% endraw %} vertices. Consequently,</p>
{% raw %}<div class="math display">\[\mathbb{E}m_{2r}^{(n)}=C_r+O_r(n^{-1}),\qquad \mathbb{E}m_{2r+1}^{(n)}=O_r(n^{-1/2}).\]</div>{% endraw %}
<p>The Dyck-path count can be checked directly. Among all {% raw %}<span class="math inline">\(\binom{2r}{r}\)</span>{% endraw %} sequences of {% raw %}<span class="math inline">\(r\)</span>{% endraw %} upward and {% raw %}<span class="math inline">\(r\)</span>{% endraw %} downward steps, reflect the initial segment through the first visit to height {% raw %}<span class="math inline">\(-1\)</span>{% endraw %} for each path that goes below zero. This gives a bijection with paths having {% raw %}<span class="math inline">\(r+1\)</span>{% endraw %} upward and {% raw %}<span class="math inline">\(r-1\)</span>{% endraw %} downward steps. Hence the number that stay nonnegative is</p>

{% raw %}<div class="math display">\[\binom{2r}{r}-\binom{2r}{r-1}=\frac1{r+1}\binom{2r}{r}.\]</div>{% endraw %}

<p>In the tree walk, an upward step visits a new vertex; a downward step returns to its parent. An edge cannot be revisited after that return, because its two allowed traversals are already used. Thus the path determines the entire walk pattern, not just its sequence of distances.</p>
<p>The variance is {% raw %}<span class="math inline">\(O_k(n^{-1})\)</span>{% endraw %}. To see this, expand it as a sum of covariances of two closed walks. Walks using disjoint unordered edges have zero covariance. If they share an edge, their union is connected. A nonzero covariance requires each non-loop edge in the union to occur at least twice in the combined {% raw %}<span class="math inline">\(2k\)</span>{% endraw %} steps, so the union has at most {% raw %}<span class="math inline">\(k+1\)</span>{% endraw %} vertices. Its contribution, after the normalization {% raw %}<span class="math inline">\(n^{-k-2}\)</span>{% endraw %}, is {% raw %}<span class="math inline">\(O_k(n^{-1})\)</span>{% endraw %}. This argument also permits diagonal entries, including nonzero diagonal means.</p>
<p>Chebyshev and Borel–Cantelli now give convergence of every moment along each geometric subsequence, simultaneously for all integer {% raw %}<span class="math inline">\(k\)</span>{% endraw %}. On that event, the second moments are bounded, hence the spectral measures are tight. Along any weakly convergent further subsequence, bounded higher even moments make each lower power uniformly integrable, so its limiting moments are the values just computed.</p>
<p>The semicircle moments are zero in odd degree. In even degree, substituting {% raw %}<span class="math inline">\(x=2\sqrt u\)</span>{% endraw %} gives</p>
{% raw %}<div class="math display">\[\frac1\pi\int_0^2x^{2r}\sqrt{4-x^2}\,dx=\frac{2^{2r+1}}\pi B(r+1/2,3/2)=C_r.\]</div>{% endraw %}
<p>These moments determine the measure. Indeed, {% raw %}<span class="math inline">\(C_r\le4^r\)</span>{% endraw %}, so any measure with these moments assigns at most {% raw %}<span class="math inline">\((4/R^2)^r\)</span>{% endraw %} mass to {% raw %}<span class="math inline">\(\{|x|&gt;R\}\)</span>{% endraw %}. Letting {% raw %}<span class="math inline">\(r\to\infty\)</span>{% endraw %} for {% raw %}<span class="math inline">\(R&gt;2\)</span>{% endraw %} shows it is supported on {% raw %}<span class="math inline">\([-2,2]\)</span>{% endraw %}. Polynomial approximation on that compact interval then gives uniqueness. Every subsequential limit is therefore {% raw %}<span class="math inline">\(\mu_{\rm sc}\)</span>{% endraw %}, and Remark 2 extends the result to all sizes. ◻</p></div>
<div class="proof"><p><em>Second proof for bounded entries: resolvents.</em> For {% raw %}<span class="math inline">\(z=a+ib\)</span>{% endraw %} with {% raw %}<span class="math inline">\(b&gt;0\)</span>{% endraw %}, set</p>
{% raw %}<div class="math display">\[s_n(z)=\int\frac{d\mu_n(x)}{x-z}=\frac1n\operatorname{Tr}(H_n-zI)^{-1}.\]</div>{% endraw %}
<p>Every such transform has positive imaginary part, absolute value at most {% raw %}<span class="math inline">\(1/b\)</span>{% endraw %}, and derivative bounded by {% raw %}<span class="math inline">\(1/b^2\)</span>{% endraw %}. Its imaginary part is {% raw %}<span class="math inline">\(\pi\)</span>{% endraw %} times convolution with the Poisson kernel {% raw %}<span class="math inline">\(P_b(x)=b/[\pi(x^2+b^2)]\)</span>{% endraw %}.</p>
<p>Let {% raw %}<span class="math inline">\(H_n^{(i)}\)</span>{% endraw %} be the principal minor obtained by deleting row and column {% raw %}<span class="math inline">\(i\)</span>{% endraw %}, retaining the normalization {% raw %}<span class="math inline">\(1/\sqrt n\)</span>{% endraw %}, and let {% raw %}<span class="math inline">\(R_i=(H_n^{(i)}-zI)^{-1}\)</span>{% endraw %}. Interlacing and integration by parts against {% raw %}<span class="math inline">\(g(x)=(x-z)^{-1}\)</span>{% endraw %} imply</p><span id="eq:alternating-sign-sum"></span>
{% raw %}<div class="math display">\[\left|\operatorname{Tr}(H_n-zI)^{-1}-\operatorname{Tr}R_i\right|\le\int_{\mathbb R}|g'(x)|\,dx=\frac\pi b.\]</div>{% endraw %}
<p>The bound applies to the full complex transform. No change from {% raw %}<span class="math inline">\(\sqrt n\)</span>{% endraw %} to {% raw %}<span class="math inline">\(\sqrt{n-1}\)</span>{% endraw %} is made inside this comparison.</p>
<p>Here are the counting details behind the trace estimate and its rank-perturbation version. Write {% raw %}<span class="math inline">\(N_A(x)=\#\{i:\lambda_i(A)\le x\}\)</span>{% endraw %}. For a principal minor, interlacing gives {% raw %}<span class="math inline">\(0\le N_A(x)-N_{A^{(i)}}(x)\le1\)</span>{% endraw %}. Integration by parts against {% raw %}<span class="math inline">\(g\)</span>{% endraw %}, whose limits at both infinities vanish, yields</p>

{% raw %}<div class="math display">\[\operatorname{Tr}g(A)-\operatorname{Tr}g(A^{(i)})=-\int_{\mathbb R}g'(x)[N_A(x)-N_{A^{(i)}}(x)]\,dx.\]</div>{% endraw %}

<p>For two matrices of the same size with {% raw %}<span class="math inline">\(\operatorname{rank}(A-C)\le r\)</span>{% endraw %}, one has {% raw %}<span class="math inline">\(|N_A-N_C|\le r\)</span>{% endraw %}. Indeed, intersect the spectral subspace of {% raw %}<span class="math inline">\(A\)</span>{% endraw %} for eigenvalues at most {% raw %}<span class="math inline">\(x\)</span>{% endraw %} with {% raw %}<span class="math inline">\(\ker(A-C)\)</span>{% endraw %}; it loses at most {% raw %}<span class="math inline">\(r\)</span>{% endraw %} dimensions and the quotient of {% raw %}<span class="math inline">\(C\)</span>{% endraw %} there is also at most {% raw %}<span class="math inline">\(x\)</span>{% endraw %}. Courant–Fischer gives {% raw %}<span class="math inline">\(N_C(x)\ge N_A(x)-r\)</span>{% endraw %}; interchange the matrices for the other inequality. The same integral identity then bounds the trace difference by {% raw %}<span class="math inline">\(r\int|g'|\)</span>{% endraw %}. Finally {% raw %}<span class="math inline">\(\int_{\mathbb R}|(x-a-ib)^{-2}|dx=\pi/b\)</span>{% endraw %}.</p>
<p>Group the independent upper-triangular entries by their row index. Replacing one group changes the Hermitian matrix by rank at most two. The same cdf integration argument bounds the resulting change in {% raw %}<span class="math inline">\(s_n(z)\)</span>{% endraw %} by {% raw %}<span class="math inline">\(2\pi/(nb)\)</span>{% endraw %}. Applying <a href="{% post_url 2022-09-13-concentration-inequalities %}#lem:mcdiarmid">bounded differences</a> to the real and imaginary parts yields, for fixed {% raw %}<span class="math inline">\(z\)</span>{% endraw %},</p>
{% raw %}<div class="math display">\[P(|s_n(z)-\mathbb{E}s_n(z)|&gt;t)\le4e^{-cnb^2t^2}.\]</div>{% endraw %}
<p>Thus {% raw %}<span class="math inline">\(s_n(z)-\mathbb{E}s_n(z)\to0\)</span>{% endraw %} almost surely, initially on a countable dense set of {% raw %}<span class="math inline">\(z\)</span>{% endraw %}'s. The derivative bound extends the conclusion to every point of the upper half-plane on the same event.</p>
<p>Write {% raw %}<span class="math inline">\(X_i\)</span>{% endraw %} for the unnormalized off-diagonal column removed with index {% raw %}<span class="math inline">\(i\)</span>{% endraw %}. It is independent of {% raw %}<span class="math inline">\(R_i\)</span>{% endraw %}, its entries are centered and independent, and {% raw %}<span class="math inline">\(\mathbb{E}X_iX_i^*=I\)</span>{% endraw %}. Schur complementation gives</p>
{% raw %}<div class="math display">\[((H_n-zI)^{-1})_{ii}=-\left(z-\xi_{ii}/\sqrt n+n^{-1}X_i^*R_iX_i\right)^{-1}.\]</div>{% endraw %}
<p>Bounded entries have uniformly bounded fourth moments. Expanding the quadratic form and pairing its centered terms gives, conditionally on {% raw %}<span class="math inline">\(R_i\)</span>{% endraw %},</p>
{% raw %}<div class="math display">\[\mathbb{E}(X_i^*R_iX_i\mid R_i)=\operatorname{Tr}R_i,\qquad \mathbb{E}(|X_i^*R_iX_i-\operatorname{Tr}R_i|^2\mid R_i)\le C\operatorname{Tr}(R_iR_i^*)\le Cn/b^2.\]</div>{% endraw %}
<p>For the inequality, diagonal terms contribute at most a constant times {% raw %}<span class="math inline">\(\sum_j|R_{jj}|^2\)</span>{% endraw %}; among off-diagonal terms, independence leaves only the identical or reversed index pairs, bounded by a constant times {% raw %}<span class="math inline">\(\sum_{j,k}|R_{jk}|^2\)</span>{% endraw %}. This avoids any unwarranted concentration claim for a general resolvent quadratic form.</p>
<p>More explicitly, write the centered quadratic form as</p>

{% raw %}<div class="math display">\[\sum_j R_{jj}(|X_j|^2-1)+\sum_{j\ne k}\overline{X_j}R_{jk}X_k.\]</div>{% endraw %}

<p>The first sum has second moment bounded by {% raw %}<span class="math inline">\(C\sum_j|R_{jj}|^2\)</span>{% endraw %}, since its summands are independent and the fourth moments are uniformly bounded. Its cross terms with the second sum vanish by centering. In the squared modulus of the second sum, only identical or reversed pairs of indices survive. The first contribution is {% raw %}<span class="math inline">\(\sum_{j\ne k}|R_{jk}|^2\)</span>{% endraw %}, while the absolute value of the second is at most {% raw %}<span class="math inline">\(\sum_{j\ne k}|R_{jk}R_{kj}|\le\sum_{j\ne k}|R_{jk}|^2\)</span>{% endraw %}, using {% raw %}<span class="math inline">\(|\mathbb EX_j^2|\le1\)</span>{% endraw %}. This proves the stated bound without requiring circularly symmetric complex entries. The resolvent spectral decomposition gives {% raw %}<span class="math inline">\(\operatorname{Tr}(RR^*)\le(n-1)/b^2\)</span>{% endraw %}.</p>
<p>Set {% raw %}<span class="math inline">\(m_n(z)=\mathbb{E}s_n(z)\)</span>{% endraw %}. The quadratic-form bound, interlacing, concentration, and the diagonal term show, uniformly in {% raw %}<span class="math inline">\(i\)</span>{% endraw %}, that</p>
{% raw %}<div class="math display">\[\mathbb{E}\left|n^{-1}X_i^*R_iX_i-\xi_{ii}/\sqrt n-m_n(z)\right|\longrightarrow0.\]</div>{% endraw %}
<p>For example, the four terms in this replacement can be bounded in {% raw %}<span class="math inline">\(L^1\)</span>{% endraw %} by</p>

{% raw %}<div class="math display">\[\frac{C}{\sqrt n\,b}+\frac{\pi}{nb}+\mathbb E|s_n(z)-m_n(z)|+\frac{\mathbb E|\xi_{ii}|}{\sqrt n}.\]</div>{% endraw %}

<p>The third term is {% raw %}<span class="math inline">\(O(1/(\sqrt n\,b))\)</span>{% endraw %} by integrating the bounded-differences tail. All bounds are uniform in the deleted index {% raw %}<span class="math inline">\(i\)</span>{% endraw %}; row/column exchangeability is unnecessary. Also {% raw %}<span class="math inline">\(\Im R_i=bR_iR_i^*\)</span>{% endraw %} is positive semidefinite, so {% raw %}<span class="math inline">\(\Im(X_i^*R_iX_i)\ge0\)</span>{% endraw %}. Since {% raw %}<span class="math inline">\(\xi_{ii}\)</span>{% endraw %} is real, the exact Schur denominator has imaginary part at least {% raw %}<span class="math inline">\(b\)</span>{% endraw %}. This justifies the inverse comparison even on rare events where a quadratic form is large.</p>
<p>Both denominators in the Schur formula and in {% raw %}<span class="math inline">\((z+m_n)^{-1}\)</span>{% endraw %} have imaginary part at least {% raw %}<span class="math inline">\(b\)</span>{% endraw %}. The inverse map is therefore {% raw %}<span class="math inline">\(b^{-2}\)</span>{% endraw %}-Lipschitz on these values. Averaging the diagonal resolvent entries proves</p>
{% raw %}<div class="math display">\[m_n(z)=-\frac1{z+m_n(z)}+o(1).\]</div>{% endraw %}
<p>Every convergent subsequence of these bounded complex numbers has a limit satisfying {% raw %}<span class="math inline">\(m=-1/(z+m)\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\Im m\ge0\)</span>{% endraw %}; the equation forces {% raw %}<span class="math inline">\(\Im m&gt;0\)</span>{% endraw %}. There is only one such root. Indeed, imaginary parts give {% raw %}<span class="math inline">\(|m|^2=\Im m/(b+\Im m)&lt;1\)</span>{% endraw %}, while two distinct roots of {% raw %}<span class="math inline">\(m^2+zm+1=0\)</span>{% endraw %} have product one. Hence</p>
{% raw %}<div class="math display">\[m_n(z)\longrightarrow m(z)=\frac{-z+\sqrt{z^2-4}}2,\]</div>{% endraw %}
<p>with the square-root branch chosen so that {% raw %}<span class="math inline">\(m(z)\sim-1/z\)</span>{% endraw %} at imaginary infinity. To identify this root with the semicircle transform without making an assumption about boundary inversion, use the deterministic density moments calculated above. For {% raw %}<span class="math inline">\(|z|&gt;2\)</span>{% endraw %} in the upper half-plane, the uniformly convergent geometric expansion on {% raw %}<span class="math inline">\([-2,2]\)</span>{% endraw %} gives</p>

{% raw %}<div class="math display">\[s_{\mu_{\rm sc}}(z)=-\frac1z\sum_{r\ge0}C_r z^{-2r}.\]</div>{% endraw %}

<p>A nonempty Dyck path has a unique first-return decomposition into an initial up step, a Dyck path, a down step, and another Dyck path. Consequently {% raw %}<span class="math inline">\(C_r=\sum_{j=0}^{r-1}C_jC_{r-1-j}\)</span>{% endraw %} and {% raw %}<span class="math inline">\(C_0=1\)</span>{% endraw %}. The convergent generating function {% raw %}<span class="math inline">\(C(w)=\sum_r C_rw^r\)</span>{% endraw %} satisfies {% raw %}<span class="math inline">\(C=1+wC^2\)</span>{% endraw %}. Thus this transform satisfies the same quadratic equation and has positive imaginary part, so it equals the unique root above. Analytic continuation extends equality throughout the upper half-plane. Lemma 4 below turns the almost-sure transform convergence into weak convergence. ◻</p>
</div>
<p><strong>Removing boundedness.</strong> For large integers {% raw %}<span class="math inline">\(K\)</span>{% endraw %}, let</p>
{% raw %}<div class="math display">\[\xi^{(K)}=\frac{\xi\mathbf1\{|\xi|\le K\}-\mathbb{E}[\xi\mathbf1\{|\xi|\le K\}]}{\sqrt{\operatorname{Var}(\xi\mathbf1\{|\xi|\le K\})}},\]</div>{% endraw %}
<p>where complex variance means {% raw %}<span class="math inline">\(\mathbb{E}|Z-\mathbb{E}Z|^2\)</span>{% endraw %}. Its denominator tends to one and is positive for all sufficiently large {% raw %}<span class="math inline">\(K\)</span>{% endraw %}. Use these variables above the diagonal and zero diagonal entries to form {% raw %}<span class="math inline">\(M_n^{(K)}\)</span>{% endraw %}. The bounded-entry law applies to each {% raw %}<span class="math inline">\(K\)</span>{% endraw %}. Moreover, by the strong law applied to an enumeration of the iid upper-triangular entries,</p>
{% raw %}<div class="math display">\[\frac1{n^2}\|M_n-M_n^{(K)}\|_F^2\longrightarrow \mathbb{E}|\xi-\xi^{(K)}|^2\quad\hbox{almost surely}.\]</div>{% endraw %}
<p>The diagonal contributes zero to this limit because {% raw %}<span class="math inline">\(n^{-1}\sum_{i\le n}\xi_{ii}^2\)</span>{% endraw %} converges to a finite mean. The right side tends to zero as {% raw %}<span class="math inline">\(K\to\infty\)</span>{% endraw %}, by {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %} truncation and normalization. Remark 3, first with {% raw %}<span class="math inline">\(n\to\infty\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(K\to\infty\)</span>{% endraw %}, and finally {% raw %}<span class="math inline">\(\epsilon\downarrow0\)</span>{% endraw %}, proves Theorem 1 under the stated second-moment assumptions. Countably many truncation levels and rational thresholds again give a single probability-one event.</p>
<p>The strong-law enumeration can be made explicit: list the upper-triangular variables column by column, so that all {% raw %}<span class="math inline">\(i&lt;j\le n\)</span>{% endraw %} form the first {% raw %}<span class="math inline">\(n(n-1)/2\)</span>{% endraw %} terms. Their squared differences are iid integrable. The off-diagonal part of the normalized squared Frobenius norm equals</p>

{% raw %}<div class="math display">\[\frac{2}{n^2}\sum_{1\le i&lt;j\le n}|\xi_{ij}-\xi_{ij}^{(K)}|^2\longrightarrow\mathbb E|\xi-\xi^{(K)}|^2.\]</div>{% endraw %}

<p>This identifies the normalization exactly. For any fixed {% raw %}<span class="math inline">\(\epsilon&gt;0\)</span>{% endraw %}, the limiting perturbation error in the cdf bound is at most {% raw %}<span class="math inline">\(\epsilon^{-2}\mathbb E|\xi-\xi^{(K)}|^2\)</span>{% endraw %}. Send {% raw %}<span class="math inline">\(K\to\infty\)</span>{% endraw %} before sending {% raw %}<span class="math inline">\(\epsilon\to0\)</span>{% endraw %}; continuity of the semicircle cdf then gives both limiting inequalities.</p>
<div id="lem:stieltjes-cvg-pointwise" class="lemma" data-note-number="4" data-note-kind="Lemma"><p><strong>Lemma 4.</strong> For probability measures {% raw %}<span class="math inline">\(\mu_n,\mu\)</span>{% endraw %} on {% raw %}<span class="math inline">\(\mathbb R\)</span>{% endraw %}, weak convergence {% raw %}<span class="math inline">\(\mu_n\Rightarrow\mu\)</span>{% endraw %} is equivalent to {% raw %}<span class="math inline">\(s_{\mu_n}(z)\to s_\mu(z)\)</span>{% endraw %} for every {% raw %}<span class="math inline">\(\Im z&gt;0\)</span>{% endraw %}.</p></div>
<div class="proof"><p><em>Proof.</em> The forward implication uses the bounded continuous test function {% raw %}<span class="math inline">\((x-z)^{-1}\)</span>{% endraw %}. For the converse, first prove tightness; it is not automatic from Helly selection. For {% raw %}<span class="math inline">\(y&gt;0\)</span>{% endraw %},</p>
{% raw %}<div class="math display">\[y\Im s_{\mu_n}(iy)=\int\frac{y^2}{x^2+y^2}\,d\mu_n(x),\qquad \mu_n(|x|&gt;y)\le2[1-y\Im s_{\mu_n}(iy)].\]</div>{% endraw %}
<p>The corresponding integral for the probability measure {% raw %}<span class="math inline">\(\mu\)</span>{% endraw %} tends to one as {% raw %}<span class="math inline">\(y\to\infty\)</span>{% endraw %}. Transform convergence therefore controls the tails of all sufficiently large {% raw %}<span class="math inline">\(n\)</span>{% endraw %}; enlarging the compact interval handles the finitely many remaining measures. Thus the sequence is tight, and every subsequence has a weakly convergent further subsequence with a probability limit {% raw %}<span class="math inline">\(\nu\)</span>{% endraw %}.</p>
<p>That limit has {% raw %}<span class="math inline">\(s_\nu=s_\mu\)</span>{% endraw %}. Taking imaginary parts gives {% raw %}<span class="math inline">\(\nu*P_b=\mu*P_b\)</span>{% endraw %} for every {% raw %}<span class="math inline">\(b&gt;0\)</span>{% endraw %}. Integrating against a compactly supported continuous function and sending {% raw %}<span class="math inline">\(b\downarrow0\)</span>{% endraw %}, using the Poisson approximate identity, shows {% raw %}<span class="math inline">\(\nu=\mu\)</span>{% endraw %}. All subsequential limits coincide, proving weak convergence. The assumption that the limiting transform belongs to a probability measure is what prevents loss of mass at infinity. ◻</p></div>
<p>To justify the Poisson approximate identity used in Lemma 4, extend a compactly supported continuous test function {% raw %}<span class="math inline">\(\varphi\)</span>{% endraw %} to its bounded uniformly continuous function on {% raw %}<span class="math inline">\(\mathbb R\)</span>{% endraw %}. For each {% raw %}<span class="math inline">\(\delta&gt;0\)</span>{% endraw %},</p>

{% raw %}<div class="math display">\[\sup_x|(P_b*\varphi)(x)-\varphi(x)|\le\omega_\varphi(\delta)+2\|\varphi\|_\infty\int_{|u|&gt;\delta}P_b(u)\,du\le\omega_\varphi(\delta)+C\|\varphi\|_\infty b/\delta.\]</div>{% endraw %}

<p>First let {% raw %}<span class="math inline">\(b\downarrow0\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(\delta\downarrow0\)</span>{% endraw %}. Fubini's theorem identifies integration against {% raw %}<span class="math inline">\(\nu*P_b\)</span>{% endraw %} with integration of {% raw %}<span class="math inline">\(P_b*\varphi\)</span>{% endraw %} against {% raw %}<span class="math inline">\(\nu\)</span>{% endraw %}, so the uniform bound proves equality of the two measures on all such test functions.</p>
<p>A primary reference for the precise second-moment theorem is <a href="https://terrytao.wordpress.com/2010/02/02/254a-notes-4-the-semi-circular-law/">Terence Tao, 254A Notes 4, Theorem 1</a>. Both proofs above are supplied in full; in particular, the resolvent argument uses the explicit conditional second-moment calculation given here.</p>
