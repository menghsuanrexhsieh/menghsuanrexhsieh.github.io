<p>A subgroup of a Lie group need not be an embedded submanifold: its topology may interact poorly with the ambient topology. Cartan’s closed subgroup theorem gives a useful criterion. A subgroup that is closed as a subset automatically has an embedded Lie group structure.</p>

<p>We reach this theorem through the exponential map. One-parameter subgroups connect tangent vectors at the identity to curves in the group, allowing us to detect the tangent directions of a closed subgroup before we know that it is a manifold.</p>

<div id="result-1" class="definition" data-note-number="1" data-note-kind="Definition">
<p><strong>Definition 1</strong>.  Let {% raw %}<span class="math inline">\(G\)</span>{% endraw %} and {% raw %}<span class="math inline">\(H\)</span>{% endraw %} be Lie groups. A <em>Lie group homomorphism</em> from {% raw %}<span class="math inline">\(G\)</span>{% endraw %} to {% raw %}<span class="math inline">\(H\)</span>{% endraw %} is a smooth map {% raw %}<span class="math inline">\(F : G \to H\)</span>{% endraw %} that is also a group homomorphism. Such a map {% raw %}<span class="math inline">\(F\)</span>{% endraw %} is called a <em>Lie group isomorphism</em> if it is also a diffeomorphism; in this case, we say {% raw %}<span class="math inline">\(G\)</span>{% endraw %} and {% raw %}<span class="math inline">\(H\)</span>{% endraw %} are isomorphic Lie groups.</p>

</div>
<div id="result-2" class="example" data-note-number="2" data-note-kind="Example">
<p><strong>Example 2</strong> (Examples of Lie group homomorphisms).  The determinant function {% raw %}<span class="math inline">\(\det : \operatorname{GL}_n (\mathbb R) \to \mathbb R \setminus \{0\}\)</span>{% endraw %} is smooth because {% raw %}<span class="math inline">\(\det A\)</span>{% endraw %} is a polynomial in the matrix entries of {% raw %}<span class="math inline">\(A \in \operatorname{GL}_n (\mathbb R)\)</span>{% endraw %}. It is a Lie group homomorphism, because {% raw %}<span class="math inline">\(\det (AB) = (\det A) (\det B)\)</span>{% endraw %}.</p>

<p>Here is an important example of a Lie group homomorphism. Let {% raw %}<span class="math inline">\(G\)</span>{% endraw %} be a Lie group, and let {% raw %}<span class="math inline">\(g \in G\)</span>{% endraw %}. Define the <em>conjugation map by {% raw %}<span class="math inline">\(g\)</span>{% endraw %}</em> as {% raw %}<span class="math inline">\(C_g : G \to G : x \mapsto g x g^{-1}\)</span>{% endraw %}. With the notation introduced above, {% raw %}<span class="math inline">\(C_g (x) = (L_g \circ R_{g^{-1}}) (x)\)</span>{% endraw %}. Note that {% raw %}<span class="math inline">\(C_g\)</span>{% endraw %} is smooth as the composition of smooth maps, and for all {% raw %}<span class="math inline">\(x,y \in G\)</span>{% endraw %}, {% raw %}<span class="math inline">\(C_g (xy) = g (xy) g^{-1} = g(xg^{-1}g y)g^{-1} = (gxg^{-1})(gyg^{-1}) = C_g (x) C_g (y)\)</span>{% endraw %}; therefore, {% raw %}<span class="math inline">\(C_g\)</span>{% endraw %} is a homomorphism. Furthermore, because {% raw %}<span class="math inline">\(C_{g^{-1}}\)</span>{% endraw %} exists, it follows that {% raw %}<span class="math inline">\(C_g\)</span>{% endraw %} is a Lie group isomorphism.</p>

</div>
<div id="result-3" class="definition" data-note-number="3" data-note-kind="Definition">
<p><strong>Definition 3</strong>.  Let {% raw %}<span class="math inline">\(H \subset G\)</span>{% endraw %} be a subgroup of a Lie group {% raw %}<span class="math inline">\(G\)</span>{% endraw %}. {% raw %}<span class="math inline">\(H\)</span>{% endraw %} is <em>normal</em> if {% raw %}<span class="math inline">\(C_g (H) = H\)</span>{% endraw %} for every {% raw %}<span class="math inline">\(g \in G\)</span>{% endraw %}.</p>

</div>
<div id="thm:lie-group-homomorphism-constant-rank" class="theorem" data-note-number="4" data-note-kind="Theorem">
<p><strong>Theorem 4</strong>.  Every Lie group homomorphism has constant rank.</p>

</div>
<div class="proof">
<p><em>Proof.</em> Let {% raw %}<span class="math inline">\(F : G \to H\)</span>{% endraw %} be a Lie group homomorphism, and let {% raw %}<span class="math inline">\(e\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\widetilde e\)</span>{% endraw %} denote the identity elements of {% raw %}<span class="math inline">\(G\)</span>{% endraw %} and {% raw %}<span class="math inline">\(H\)</span>{% endraw %}, respectively. Take any {% raw %}<span class="math inline">\(g_0 \in G\)</span>{% endraw %}. We <em>claim</em> {% raw %}<span class="math inline">\((\dif F)_e\)</span>{% endraw %} and {% raw %}<span class="math inline">\((\dif F)_{g_0}\)</span>{% endraw %} have the same rank. Since {% raw %}<span class="math inline">\(F\)</span>{% endraw %} is a homomorphism, it follows from direct calculations that </p>

{% raw %}<div class="math display">\[\begin{aligned}
        F(L_{g_0} (g)) = F(g_0 g) = F(g_0) F(g) = L_{F(g_0)} (F(g)) ~,
    
\end{aligned}\]</div>{% endraw %}
<p> or {% raw %}<span class="math inline">\(F \circ L_{g_0} = L_{F(g_0)} \circ F\)</span>{% endraw %}. By the chain rule, </p>

{% raw %}<div class="math display">\[\begin{aligned}
        (\dif F)_{g_0} \circ (\dif L_{g_0})_{e} = (\dif L_{F(g_0)})_{\widetilde e} \circ (\dif F)_e ~.
    
\end{aligned}\]</div>{% endraw %}
<p> Clearly, both {% raw %}<span class="math inline">\((\dif L_{g_0})_{e}\)</span>{% endraw %} and {% raw %}<span class="math inline">\((\dif L_{F(g_0)})_{\widetilde e}\)</span>{% endraw %} are isomorphisms, because the left multiplication map is a diffeomorphism. Composition of a map with an isomorphism does not change the rank of the original map. Therefore, {% raw %}<span class="math inline">\((\dif F)_e\)</span>{% endraw %} and {% raw %}<span class="math inline">\((\dif F)_{g_0}\)</span>{% endraw %} must have the same rank. ◻</p>

</div>
<p>Theorem <a href="#thm:lie-group-homomorphism-constant-rank" data-reference-type="ref" data-reference="thm:lie-group-homomorphism-constant-rank">4</a> allows us to apply constant-rank arguments to Lie group homomorphisms. Here are two consequences.</p>

<div id="cor:lie-group-homomorphism-bijective-isom" class="corollary" data-note-number="5" data-note-kind="Corollary">
<p><strong>Corollary 5</strong>.  A Lie group homomorphism is a Lie group isomorphism if and only if it is bijective.</p>

<p><em>Proof.</em> Suppose {% raw %}<span class="math inline">\(F\)</span>{% endraw %} is bijective. By constant rank and injectivity, its rank is {% raw %}<span class="math inline">\(\dim G\)</span>{% endraw %}: otherwise a positive-dimensional coordinate fiber would contain distinct points with the same image. If this rank were less than {% raw %}<span class="math inline">\(\dim H\)</span>{% endraw %}, cover {% raw %}<span class="math inline">\(G\)</span>{% endraw %} by countably many compact coordinate pieces on which the constant-rank form holds. Each image is compact with empty interior in {% raw %}<span class="math inline">\(H\)</span>{% endraw %}, since locally it lies in a lower-dimensional slice. Surjectivity would express the locally compact Hausdorff manifold {% raw %}<span class="math inline">\(H\)</span>{% endraw %} as a countable union of closed nowhere-dense sets, contradicting the Baire theorem. Thus the differential is bijective. The inverse function theorem gives smooth local inverses, which agree with the global inverse. The converse follows from the definition. ◻</p>
</div>
<div id="prop:lie-subgroup-characterization-embedded-submanifold" class="proposition" data-note-number="6" data-note-kind="Proposition">
<p><strong>Proposition 6</strong>.  Let {% raw %}<span class="math inline">\(G\)</span>{% endraw %} be a Lie group, and suppose {% raw %}<span class="math inline">\(H \subset G\)</span>{% endraw %} is a subgroup that is also an embedded submanifold. Then H is a Lie subgroup.</p>

<p><em>Proof.</em> Restrict multiplication to {% raw %}<span class="math inline">\(H\times H\)</span>{% endraw %} and inversion to {% raw %}<span class="math inline">\(H\)</span>{% endraw %}. These maps are smooth as maps into {% raw %}<span class="math inline">\(G\)</span>{% endraw %}, and their values lie in {% raw %}<span class="math inline">\(H\)</span>{% endraw %}. In a slice chart for an embedded submanifold, a smooth map into {% raw %}<span class="math inline">\(G\)</span>{% endraw %} with image in {% raw %}<span class="math inline">\(H\)</span>{% endraw %} has its last coordinates identically zero; its first coordinates prove smoothness as a map into {% raw %}<span class="math inline">\(H\)</span>{% endraw %}. This establishes the Lie group operations in the submanifold structure. ◻</p>
</div>
<p>For the definition of Lie subgroup, see Definition <a href="{% post_url 2022-10-07-lie-groups-and-their-lie-algebras %}#def:lie-subgroup" data-reference-type="ref" data-reference="def:lie-subgroup">4</a>. The simplest example of embedded Lie subgroups are the open subgroups. Their cosets are open as well, which forces an open subgroup to be closed.</p>

<div id="result-7" class="proposition" data-note-number="7" data-note-kind="Proposition">
<p><strong>Proposition 7</strong>.  Let {% raw %}<span class="math inline">\(G\)</span>{% endraw %} be a Lie group, and {% raw %}<span class="math inline">\(H \subset G\)</span>{% endraw %} be an open subgroup. Then, {% raw %}<span class="math inline">\(H\)</span>{% endraw %} is an embedded Lie subgroup. Furthermore, {% raw %}<span class="math inline">\(H\)</span>{% endraw %} is closed, so it is a union of connected components of {% raw %}<span class="math inline">\(G\)</span>{% endraw %}.</p>

</div>
<div class="proof">
<p><em>Proof.</em> Embeddedness follows from standard results. In addition, every left coset {% raw %}<span class="math inline">\(gH = \{gh : h \in H\}\)</span>{% endraw %} is open in {% raw %}<span class="math inline">\(G\)</span>{% endraw %}, as the image of {% raw %}<span class="math inline">\(H\)</span>{% endraw %} under the diffeomorphism {% raw %}<span class="math inline">\(L_g\)</span>{% endraw %}. {% raw %}<span class="math inline">\(G \setminus H\)</span>{% endraw %} is open as the union of the cosets of {% raw %}<span class="math inline">\(H\)</span>{% endraw %} other than {% raw %}<span class="math inline">\(H\)</span>{% endraw %} itself, hence {% raw %}<span class="math inline">\(H\)</span>{% endraw %} must be closed in {% raw %}<span class="math inline">\(G\)</span>{% endraw %}. The second desired conclusion then follows. ◻</p>

</div>
<div id="result-8" class="definition" data-note-number="8" data-note-kind="Definition">
<p><strong>Definition 8.</strong> For any subset {% raw %}<span class="math inline">\(E\)</span>{% endraw %} of a group {% raw %}<span class="math inline">\(G\)</span>{% endraw %}, the subgroup {% raw %}<span class="math inline">\(\langle E\rangle\)</span>{% endraw %} generated by {% raw %}<span class="math inline">\(E\)</span>{% endraw %} is the intersection of all subgroups containing {% raw %}<span class="math inline">\(E\)</span>{% endraw %}. Equivalently it consists of finite products of elements of {% raw %}<span class="math inline">\(E\cup E^{-1}\)</span>{% endraw %}, including the empty product {% raw %}<span class="math inline">\(e\)</span>{% endraw %}.</p>
</div>
<div id="prop:open-subgroup-characterizations" class="proposition" data-note-number="9" data-note-kind="Proposition">
<p><strong>Proposition 9</strong>.  Let {% raw %}<span class="math inline">\(G\)</span>{% endraw %} be a Lie group, and let {% raw %}<span class="math inline">\(W \subset G\)</span>{% endraw %} be any neighbourhood of the identity. Then, the following are true:</p>

<ol>
<li><p>{% raw %}<span class="math inline">\(W\)</span>{% endraw %} generates an open subgroup of {% raw %}<span class="math inline">\(G\)</span>{% endraw %}.</p></li>
<li><p>If {% raw %}<span class="math inline">\(W\)</span>{% endraw %} is connected, it generates a connected open subgroup of {% raw %}<span class="math inline">\(G\)</span>{% endraw %}.</p></li>
<li><p>If {% raw %}<span class="math inline">\(G\)</span>{% endraw %} is connected, then {% raw %}<span class="math inline">\(W\)</span>{% endraw %} generates {% raw %}<span class="math inline">\(G\)</span>{% endraw %}.</p></li>
</ol>
<p><em>Proof.</em> Let {% raw %}<span class="math inline">\(S=W\cup W^{-1}\)</span>{% endraw %}, so {% raw %}<span class="math inline">\(e\in S\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\langle W\rangle=\bigcup_{n\geq1}S^n\)</span>{% endraw %}. It contains an open identity neighborhood {% raw %}<span class="math inline">\(U\subset W\)</span>{% endraw %}; translating {% raw %}<span class="math inline">\(U\)</span>{% endraw %} by each subgroup element shows that the subgroup is open. If {% raw %}<span class="math inline">\(W\)</span>{% endraw %} is connected, {% raw %}<span class="math inline">\(S\)</span>{% endraw %} is connected because its two connected pieces meet at {% raw %}<span class="math inline">\(e\)</span>{% endraw %}. Each {% raw %}<span class="math inline">\(S^n\)</span>{% endraw %} is a continuous image of a connected product, and these sets are increasing, so their union is connected. Finally every open subgroup is also closed by Proposition 7; a nonempty clopen subset of connected {% raw %}<span class="math inline">\(G\)</span>{% endraw %} is all of {% raw %}<span class="math inline">\(G\)</span>{% endraw %}. ◻</p>
</div>
<p>For any Lie group {% raw %}<span class="math inline">\(G\)</span>{% endraw %}, the connected component of {% raw %}<span class="math inline">\(G\)</span>{% endraw %} containing the identity is called the <em>identity component of {% raw %}<span class="math inline">\(G\)</span>{% endraw %}</em>. This turns out to make further rigid the open subgroups of a Lie group {% raw %}<span class="math inline">\(G\)</span>{% endraw %}.</p>

<div id="result-10" class="lemma" data-note-number="10" data-note-kind="Lemma">
<p><strong>Lemma 10</strong>.  Let {% raw %}<span class="math inline">\(G\)</span>{% endraw %} be a Lie group and let {% raw %}<span class="math inline">\(G_0\)</span>{% endraw %} be its identity component. Then, {% raw %}<span class="math inline">\(G_0\)</span>{% endraw %} is a normal subgroup of {% raw %}<span class="math inline">\(G\)</span>{% endraw %}, and is the <em>only</em> connected open subgroup. Every connected component of {% raw %}<span class="math inline">\(G\)</span>{% endraw %} is diffeomorphic to {% raw %}<span class="math inline">\(G_0\)</span>{% endraw %}.</p>

<p><em>Proof.</em> Manifolds are locally path connected, so connected components are open. The image of connected {% raw %}<span class="math inline">\(G_0\times G_0\)</span>{% endraw %} under {% raw %}<span class="math inline">\((a,b)\mapsto ab^{-1}\)</span>{% endraw %} is connected and contains {% raw %}<span class="math inline">\(e\)</span>{% endraw %}, hence lies in {% raw %}<span class="math inline">\(G_0\)</span>{% endraw %}; thus {% raw %}<span class="math inline">\(G_0\)</span>{% endraw %} is a subgroup. Conjugation is a homeomorphism fixing {% raw %}<span class="math inline">\(e\)</span>{% endraw %}, so it preserves the identity component, proving normality. A connected open subgroup lies in {% raw %}<span class="math inline">\(G_0\)</span>{% endraw %}; being also closed, it must fill the connected space {% raw %}<span class="math inline">\(G_0\)</span>{% endraw %}. Left translation maps the component of {% raw %}<span class="math inline">\(e\)</span>{% endraw %} to the component of any {% raw %}<span class="math inline">\(g\)</span>{% endraw %}, giving the claimed diffeomorphisms. ◻</p>
</div>
<p>For more general Lie groups, the following result shows how to produce many more examples of <em>embedded</em> Lie subgroups.</p>

<div id="prop:lie-subgroup-general-embedded-characterization" class="proposition" data-note-number="11" data-note-kind="Proposition">
<p><strong>Proposition 11</strong>.  </p>

<ol>
<li><p>Let {% raw %}<span class="math inline">\(F : G \to H\)</span>{% endraw %} be a Lie group homomorphism. The kernel of {% raw %}<span class="math inline">\(F\)</span>{% endraw %} is a properly embedded Lie subgroup of {% raw %}<span class="math inline">\(G\)</span>{% endraw %}, whose codimension is equal to the rank of {% raw %}<span class="math inline">\(F\)</span>{% endraw %}.</p></li>
<li><p>Let {% raw %}<span class="math inline">\(F : G \to H\)</span>{% endraw %} be an injective Lie group homomorphism. The image of {% raw %}<span class="math inline">\(F\)</span>{% endraw %} has a unique smooth manifold structure such that {% raw %}<span class="math inline">\(F(G)\)</span>{% endraw %} is a Lie subgroup of {% raw %}<span class="math inline">\(H\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(F:G \to F(G)\)</span>{% endraw %} is a Lie group <em>isomorphism</em>.</p></li>
</ol>
</div>
<div class="proof">
<p><em>Proof.</em> Write {% raw %}<span class="math inline">\(r=\operatorname{rank}F\)</span>{% endraw %}, constant by Theorem 4. Constant-rank coordinates make the fiber {% raw %}<span class="math inline">\(F^{-1}(e_H)\)</span>{% endraw %} a slice of codimension {% raw %}<span class="math inline">\(r\)</span>{% endraw %}. It is closed by continuity and the Hausdorff property of {% raw %}<span class="math inline">\(H\)</span>{% endraw %}. Its inclusion is proper: intersecting the closed fiber with a compact subset of {% raw %}<span class="math inline">\(G\)</span>{% endraw %} remains compact. Proposition 6 supplies the group structure.</p>
<p>If {% raw %}<span class="math inline">\(F\)</span>{% endraw %} is injective, the constant-rank form cannot have a positive-dimensional fiber, so {% raw %}<span class="math inline">\(r=\dim G\)</span>{% endraw %}. Transport the topology and all charts of {% raw %}<span class="math inline">\(G\)</span>{% endraw %} across the bijection {% raw %}<span class="math inline">\(F:G\to F(G)\)</span>{% endraw %}. This makes it a diffeomorphism by construction, the inclusion into {% raw %}<span class="math inline">\(H\)</span>{% endraw %} is an injective immersion, and the transported operations are smooth because {% raw %}<span class="math inline">\(F\)</span>{% endraw %} is a homomorphism. Uniqueness refers to the structure making {% raw %}<span class="math inline">\(F\)</span>{% endraw %} a diffeomorphism; it does not assert that the image has the ambient subspace topology. ◻</p>
</div>
<p>We first examine subgroups already equipped with an immersed Lie group structure. In this setting, closedness and embeddedness are equivalent.</p>

<div id="thm:closed-lie-subgroup-iff-embedded" class="theorem" data-note-number="12" data-note-kind="Theorem">
<p><strong>Theorem 12</strong>.  Let {% raw %}<span class="math inline">\(G\)</span>{% endraw %} be a Lie group, and let {% raw %}<span class="math inline">\(H \subset G\)</span>{% endraw %} be a Lie subgroup. Then {% raw %}<span class="math inline">\(H\)</span>{% endraw %} is closed in {% raw %}<span class="math inline">\(G\)</span>{% endraw %} if and only if {% raw %}<span class="math inline">\(H\)</span>{% endraw %} is embedded.</p>

</div>
<div id="result-13" class="remark" data-note-number="13" data-note-kind="Remark">
<p><strong>Remark 13</strong>.  In general, smooth submanifolds can be closed without being embedded, or embedded without being closed (as is the open unit ball in {% raw %}<span class="math inline">\(\mathbb R^n\)</span>{% endraw %}). Theorem <a href="#thm:closed-lie-subgroup-iff-embedded" data-reference-type="ref" data-reference="thm:closed-lie-subgroup-iff-embedded">12</a> uses the fact that translations tie the local topology at every point of a Lie subgroup to that at the identity. The closed subgroup theorem goes further: every subgroup of a Lie group that is topologically a closed subset (without assuming it is a submanifold) is automatically a properly embedded Lie subgroup.</p>

</div>
<div class="proof">
<p><em>Proof.</em> Suppose first that {% raw %}<span class="math inline">\(H\)</span>{% endraw %} is embedded. A slice chart {% raw %}<span class="math inline">\(U\)</span>{% endraw %} about {% raw %}<span class="math inline">\(e\)</span>{% endraw %} makes {% raw %}<span class="math inline">\(H\cap U\)</span>{% endraw %} closed in {% raw %}<span class="math inline">\(U\)</span>{% endraw %}. Choose identity neighborhoods {% raw %}<span class="math inline">\(W,V\)</span>{% endraw %} with {% raw %}<span class="math inline">\(\overline W\subset U\)</span>{% endraw %} and {% raw %}<span class="math inline">\(VV^{-1}\subset W\)</span>{% endraw %}. For {% raw %}<span class="math inline">\(h_i\in H\)</span>{% endraw %} converging to {% raw %}<span class="math inline">\(g\)</span>{% endraw %}, discard finitely many terms so that {% raw %}<span class="math inline">\(h_i g^{-1}\in V\)</span>{% endraw %}. Then {% raw %}<span class="math inline">\(h_i h_j^{-1}\in W\)</span>{% endraw %}. Fix {% raw %}<span class="math inline">\(j\)</span>{% endraw %} and take the limit: {% raw %}<span class="math inline">\(g h_j^{-1}\in\overline W\subset U\)</span>{% endraw %}, and relative closedness gives {% raw %}<span class="math inline">\(g h_j^{-1}\in H\)</span>{% endraw %}, hence {% raw %}<span class="math inline">\(g\in H\)</span>{% endraw %}.</p>
<p>For the converse we record carefully the difference between the two topologies. The inclusion of the Lie subgroup is an immersion, so an intrinsic identity neighborhood {% raw %}<span class="math inline">\(V\subset H\)</span>{% endraw %} is embedded. Choose a transverse submanifold {% raw %}<span class="math inline">\(P\)</span>{% endraw %} through {% raw %}<span class="math inline">\(e\)</span>{% endraw %} with {% raw %}<span class="math inline">\(T_eG=T_eH\oplus T_eP\)</span>{% endraw %}. Multiplication {% raw %}<span class="math inline">\(\psi(v,p)=vp\)</span>{% endraw %} has derivative {% raw %}<span class="math inline">\((X,Y)\mapsto X+Y\)</span>{% endraw %} at {% raw %}<span class="math inline">\((e,e)\)</span>{% endraw %}, so, after shrinking, it is a diffeomorphism from {% raw %}<span class="math inline">\(V_0\times P_0\)</span>{% endraw %} to an ambient open neighborhood {% raw %}<span class="math inline">\(U_0\)</span>{% endraw %}. Put {% raw %}<span class="math inline">\(K=P_0\cap H\)</span>{% endraw %}. The subgroup law gives</p>
{% raw %}<div class="math display">\[\psi^{-1}(H\cap U_0)=V_0\times K.\]</div>{% endraw %}
<p> For each {% raw %}<span class="math inline">\(h\in K\)</span>{% endraw %}, the intrinsic open set {% raw %}<span class="math inline">\(V_0h\subset H\)</span>{% endraw %} intersects {% raw %}<span class="math inline">\(K\)</span>{% endraw %} only in {% raw %}<span class="math inline">\(h\)</span>{% endraw %}, by injectivity of {% raw %}<span class="math inline">\(\psi\)</span>{% endraw %}. Thus {% raw %}<span class="math inline">\(K\)</span>{% endraw %} is discrete in the intrinsic topology of {% raw %}<span class="math inline">\(H\)</span>{% endraw %}, and is countable: choose a distinct basis element from a countable basis of {% raw %}<span class="math inline">\(H\)</span>{% endraw %} isolating each of its points.</p>
<p>Closedness of {% raw %}<span class="math inline">\(H\)</span>{% endraw %} now makes {% raw %}<span class="math inline">\(K\)</span>{% endraw %} closed in the manifold {% raw %}<span class="math inline">\(P_0\)</span>{% endraw %}, and hence locally compact Hausdorff. If this nonempty countable space had no isolated point, its singleton subsets would be closed and nowhere dense; their countable union would contradict Baire's theorem. Thus some {% raw %}<span class="math inline">\(h_1\in K\)</span>{% endraw %} is isolated in the ambient transverse topology. Choose open {% raw %}<span class="math inline">\(P_1\subset P_0\)</span>{% endraw %} with {% raw %}<span class="math inline">\(P_1\cap H=\{h_1\}\)</span>{% endraw %}. Then</p>
{% raw %}<div class="math display">\[H\cap\psi(V_0\times P_1)=\psi(V_0\times\{h_1\})\]</div>{% endraw %}
<p> is a single slice, with the given intrinsic smooth structure. Left translation by {% raw %}<span class="math inline">\(h h_1^{-1}\)</span>{% endraw %} carries this slice neighborhood to a slice neighborhood of any {% raw %}<span class="math inline">\(h\in H\)</span>{% endraw %}. These charts show that the existing immersed subgroup is embedded. ◻</p>
</div>
<div id="result-14" class="remark" data-note-number="14" data-note-kind="Remark">
<p><strong>Remark 14.</strong> Without closedness, the countable transverse set {% raw %}<span class="math inline">\(K\)</span>{% endraw %} need not have an isolated point in its ambient topology. For the irrational line {% raw %}<span class="math inline">\(t\mapsto(e^{it},e^{i\alpha t})\)</span>{% endraw %} in the two-torus, {% raw %}<span class="math inline">\(\alpha\notin\mathbb Q\)</span>{% endraw %}, the subgroup is dense and the transverse intersections are countable and dense. Intrinsic discreteness of {% raw %}<span class="math inline">\(K\)</span>{% endraw %} does not imply ambient discreteness; closedness was used precisely at the Baire step.</p>
</div>
<h3 data-note-section="1" id="exponential-map">1. Exponential Map</h3>
<p>Let {% raw %}<span class="math inline">\(G\)</span>{% endraw %} be a Lie group. Since left-invariant vector fields are naturally defined in terms of the group structure of {% raw %}<span class="math inline">\(G\)</span>{% endraw %}, one might reasonably expect to find some relationship between the group law for the <em>flow</em> of a left-invariant vector field, and the group multiplication in {% raw %}<span class="math inline">\(G\)</span>{% endraw %}. The definition of a one-parameter subgroup makes this relationship precise.</p>

<div id="result-15" class="definition" data-note-number="15" data-note-kind="Definition">
<p><strong>Definition 15</strong>.  A <em>one-parameter subgroup of {% raw %}<span class="math inline">\(G\)</span>{% endraw %}</em> is a Lie group homomorphism {% raw %}<span class="math inline">\(\gamma : \mathbb R \to G\)</span>{% endraw %}, with {% raw %}<span class="math inline">\(\mathbb R\)</span>{% endraw %} considered as a Lie group under addition.</p>

</div>
<p>A one-parameter subgroup here is the <em>map</em> {% raw %}<span class="math inline">\(\gamma:\mathbb R\to G\)</span>{% endraw %}, not just its image, and it need not be onto {% raw %}<span class="math inline">\(G\)</span>{% endraw %}. Its image may be a periodic circle, an injectively immersed line, or the identity alone. We identify these maps by their initial velocities.</p>

<div id="thm:characterization-one-parameter-subgroups" class="theorem" data-note-number="16" data-note-kind="Theorem">
<p><strong>Theorem 16</strong>.  Let {% raw %}<span class="math inline">\(G\)</span>{% endraw %} be a Lie group. The one-parameter subgroups of {% raw %}<span class="math inline">\(G\)</span>{% endraw %} are the maximal integral curves of left-invariant vector fields starting at the identity element of {% raw %}<span class="math inline">\(G\)</span>{% endraw %}.</p>

</div>
<div class="proof">
<p><em>Proof of Theorem <a href="#thm:characterization-one-parameter-subgroups" data-reference-type="ref" data-reference="thm:characterization-one-parameter-subgroups">16</a>.</em> Differentiate the homomorphism identity to obtain one direction. For the converse, uniqueness of integral curves gives the homomorphism identity locally, and translation extends the curve to all time.</p>

<ol>
<li><p>First, let {% raw %}<span class="math inline">\(\gamma : \mathbb R \to G\)</span>{% endraw %} be a one-parameter subgroup. By definition, {% raw %}<span class="math inline">\(\gamma\)</span>{% endraw %} is a group homomorphism, meaning {% raw %}<span class="math inline">\(\gamma(s+t) = \gamma(s)\gamma(t)\)</span>{% endraw %} for all {% raw %}<span class="math inline">\(s,t \in \mathbb R\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(\gamma(0) = e\)</span>{% endraw %}. Let {% raw %}<span class="math inline">\(X \in \mathfrak g\)</span>{% endraw %} be the unique left-invariant vector field on {% raw %}<span class="math inline">\(G\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(X_e = \dot \gamma(0)\)</span>{% endraw %}. We want to show that {% raw %}<span class="math inline">\(\gamma\)</span>{% endraw %} is an integral curve of {% raw %}<span class="math inline">\(X\)</span>{% endraw %}. Taking the derivative with respect to {% raw %}<span class="math inline">\(s\)</span>{% endraw %} at {% raw %}<span class="math inline">\(s=0\)</span>{% endraw %}, we have </p>

{% raw %}<div class="math display">\[\begin{aligned}
            \dot \gamma(t) &amp;= \left. \frac{\dif}{\dif s} \right|_{s=0} \gamma(t+s) \nonumber \\
            &amp;= \left. \frac{\dif}{\dif s} \right|_{s=0} \gamma(t)\gamma(s) \nonumber \\
            &amp;= \left. \frac{\dif}{\dif s} \right|_{s=0} L_{\gamma(t)} (\gamma(s)) \nonumber \\
            &amp;= (\dif L_{\gamma(t)})_e (\dot \gamma(0)) = (\dif L_{\gamma(t)})_e (X_e) = X_{\gamma(t)} ~.
        
\end{aligned}\]</div>{% endraw %}
<p> This implies {% raw %}<span class="math inline">\(\gamma\)</span>{% endraw %} is an integral curve of {% raw %}<span class="math inline">\(X\)</span>{% endraw %} starting at {% raw %}<span class="math inline">\(e\)</span>{% endraw %}. Since its domain is {% raw %}<span class="math inline">\(\mathbb R\)</span>{% endraw %}, it is a maximal integral curve.</p></li>
<li><p>Conversely, let {% raw %}<span class="math inline">\(X \in \mathfrak g\)</span>{% endraw %} be a left-invariant vector field on {% raw %}<span class="math inline">\(G\)</span>{% endraw %}, and let {% raw %}<span class="math inline">\(\gamma : I \to G\)</span>{% endraw %} be the maximal integral curve of {% raw %}<span class="math inline">\(X\)</span>{% endraw %} starting at {% raw %}<span class="math inline">\(\gamma(0) = e\)</span>{% endraw %}. We want to show that {% raw %}<span class="math inline">\(I = \mathbb R\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\gamma(s+t) = \gamma(s)\gamma(t)\)</span>{% endraw %}. Let {% raw %}<span class="math inline">\(s \in I\)</span>{% endraw %} be arbitrary, and consider the two curves {% raw %}<span class="math inline">\(\alpha(t) = \gamma(s+t)\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\beta(t) = L_{\gamma(s)} (\gamma(t)) = \gamma(s)\gamma(t)\)</span>{% endraw %}. They both satisfy the initial condition {% raw %}<span class="math inline">\(\alpha(0) = \gamma(s)\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\beta(0) = \gamma(s)e = \gamma(s)\)</span>{% endraw %}. Computing their derivatives, we get </p>

{% raw %}<div class="math display">\[\begin{aligned}
            \dot \alpha(t) &amp;= \dot \gamma(s+t) = X_{\gamma(s+t)} = X_{\alpha(t)} ~, \\
            \dot \beta(t) &amp;= \frac{\dif}{\dif t} L_{\gamma(s)}(\gamma(t)) = (\dif L_{\gamma(s)})_{\gamma(t)} (\dot \gamma(t)) = (\dif L_{\gamma(s)})_{\gamma(t)} (X_{\gamma(t)}) = X_{\beta(t)} ~,
        
\end{aligned}\]</div>{% endraw %}
<p> where the last equality follows from the fact that {% raw %}<span class="math inline">\(X\)</span>{% endraw %} is left-invariant. Therefore, both {% raw %}<span class="math inline">\(\alpha\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\beta\)</span>{% endraw %} are integral curves of {% raw %}<span class="math inline">\(X\)</span>{% endraw %}. By the fundamental uniqueness of integral curves, they must be equal wherever they are both defined, implying {% raw %}<span class="math inline">\(\gamma(s+t) = \gamma(s)\gamma(t)\)</span>{% endraw %}.</p></li>
<li><p>Finally choose {% raw %}<span class="math inline">\(\delta&gt;0\)</span>{% endraw %} with {% raw %}<span class="math inline">\((-\delta,\delta)\subset I\)</span>{% endraw %}. If the maximal right endpoint {% raw %}<span class="math inline">\(b\)</span>{% endraw %} were finite, choose {% raw %}<span class="math inline">\(s\in I\)</span>{% endraw %} with {% raw %}<span class="math inline">\(b-\delta/2&lt;s&lt;b\)</span>{% endraw %}. The curve {% raw %}<span class="math inline">\(t\mapsto\gamma(s)\gamma(t-s)\)</span>{% endraw %}, defined for {% raw %}<span class="math inline">\(|t-s|&lt;\delta\)</span>{% endraw %}, is an integral curve agreeing with {% raw %}<span class="math inline">\(\gamma(t)\)</span>{% endraw %} near {% raw %}<span class="math inline">\(s\)</span>{% endraw %}; uniqueness makes them agree throughout their overlapping intervals. It extends the curve past {% raw %}<span class="math inline">\(b\)</span>{% endraw %}, a contradiction. The same argument at the left endpoint proves {% raw %}<span class="math inline">\(I=\mathbb R\)</span>{% endraw %}. Now the identity {% raw %}<span class="math inline">\(\gamma(s+t)=\gamma(s)\gamma(t)\)</span>{% endraw %} holds for all real {% raw %}<span class="math inline">\(s,t\)</span>{% endraw %}. This uses smooth ODE uniqueness, not analytic continuation.</p></li>
</ol>
<p>This shows the desired statement. ◻</p>

</div>
<div id="result-17" class="remark" data-note-number="17" data-note-kind="Remark">
<p><strong>Remark 17</strong>.  Given {% raw %}<span class="math inline">\(X \in \mathfrak g\)</span>{% endraw %}, the one-parameter subgroup determined by {% raw %}<span class="math inline">\(X\)</span>{% endraw %} in this way is called the <em>one-parameter subgroup generated by {% raw %}<span class="math inline">\(X\)</span>{% endraw %}</em>. Because left-invariant vector fields are uniquely determined by their values at the identity, it follows that each one-parameter subgroup is uniquely determined by its initial velocity in {% raw %}<span class="math inline">\(T_e G\)</span>{% endraw %}, and thus there are one-to-one correspondences between the collection of one-parameter subgroups of {% raw %}<span class="math inline">\(G\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\mathfrak g\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(T_e G\)</span>{% endraw %}.</p>

</div>
<p>Theorem <a href="#thm:characterization-one-parameter-subgroups" data-reference-type="ref" data-reference="thm:characterization-one-parameter-subgroups">16</a> leads to the exponential map: evaluate the one-parameter subgroup at time one. Rescaling its initial velocity recovers every other time on that subgroup.</p>

<div id="result-18" class="definition" data-note-number="18" data-note-kind="Definition">
<p><strong>Definition 18</strong>.  Given a Lie group {% raw %}<span class="math inline">\(G\)</span>{% endraw %} with Lie algebra {% raw %}<span class="math inline">\(\mathfrak g\)</span>{% endraw %}, the <em>exponential map of {% raw %}<span class="math inline">\(G\)</span>{% endraw %}</em> is a map {% raw %}<span class="math inline">\(\exp : \mathfrak g \to G\)</span>{% endraw %} such that </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \exp (X) = \gamma(1) ~,
    
\end{aligned}\]</div>{% endraw %}
<p> where {% raw %}<span class="math inline">\(\gamma\)</span>{% endraw %} is the (maximal) integral curve of {% raw %}<span class="math inline">\(X\)</span>{% endraw %} starting at the identity.</p>

</div>
<div id="prop:exponential-map-rescaled-one-parameter-subgroup" class="proposition" data-note-number="19" data-note-kind="Proposition">
<p><strong>Proposition 19</strong>.  Let {% raw %}<span class="math inline">\(G\)</span>{% endraw %} be a Lie group. For any {% raw %}<span class="math inline">\(X \in \mathfrak g\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\gamma(s) = \exp (sX)\)</span>{% endraw %} is the one-parameter subgroup of {% raw %}<span class="math inline">\(G\)</span>{% endraw %} generated by {% raw %}<span class="math inline">\(X\)</span>{% endraw %}.</p>

</div>
<div class="proof">
<p><em>Proof.</em> Write {% raw %}<span class="math inline">\(c_X\)</span>{% endraw %} for the complete integral curve with initial velocity {% raw %}<span class="math inline">\(X\)</span>{% endraw %}. For each real {% raw %}<span class="math inline">\(s\)</span>{% endraw %}, differentiation shows {% raw %}<span class="math inline">\(t\mapsto c_X(st)\)</span>{% endraw %} solves the equation for {% raw %}<span class="math inline">\(sX\)</span>{% endraw %}, starts at {% raw %}<span class="math inline">\(e\)</span>{% endraw %}, and hence equals {% raw %}<span class="math inline">\(c_{sX}(t)\)</span>{% endraw %} by uniqueness. At {% raw %}<span class="math inline">\(t=1\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\exp(sX)=c_X(s)\)</span>{% endraw %}, which proves the claim, including {% raw %}<span class="math inline">\(s=0\)</span>{% endraw %} and negative {% raw %}<span class="math inline">\(s\)</span>{% endraw %}. ◻</p>
</div>
<div id="prop:properties-exponential-map-lie-group" class="proposition" data-note-number="20" data-note-kind="Proposition">
<p><strong>Proposition 20</strong>.  Let {% raw %}<span class="math inline">\(G\)</span>{% endraw %} be a Lie group and {% raw %}<span class="math inline">\(\mathfrak g\)</span>{% endraw %} be its Lie algebra. The following statements are true.</p>

<ol>
<li><p>The exponential map is a smooth map from {% raw %}<span class="math inline">\(\mathfrak g\)</span>{% endraw %} to {% raw %}<span class="math inline">\(G\)</span>{% endraw %}.</p></li>
<li><p>(Group law) For any {% raw %}<span class="math inline">\(X \in \mathfrak g\)</span>{% endraw %} and {% raw %}<span class="math inline">\(s,t \in \mathbb R\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\exp ((s+t)X) = \exp(sX) \exp(tX)\)</span>{% endraw %}.</p></li>
<li><p>For any {% raw %}<span class="math inline">\(X \in \mathfrak g\)</span>{% endraw %}, {% raw %}<span class="math inline">\((\exp X)^{-1} = \exp(-X)\)</span>{% endraw %}.</p></li>
<li><p>For any {% raw %}<span class="math inline">\(X \in \mathfrak g\)</span>{% endraw %} and {% raw %}<span class="math inline">\(n \in \mathbb N\)</span>{% endraw %}, {% raw %}<span class="math inline">\((\exp X)^n = \exp(nX)\)</span>{% endraw %}.</p></li>
<li><p>The differential {% raw %}<span class="math inline">\((\dif \exp)_0 : T_0 \mathfrak g \to T_e G\)</span>{% endraw %} is the identity map, once we identify both {% raw %}<span class="math inline">\(T_0 \mathfrak g\)</span>{% endraw %} and {% raw %}<span class="math inline">\(T_e G\)</span>{% endraw %} canonically with {% raw %}<span class="math inline">\(\mathfrak g\)</span>{% endraw %}.</p></li>
<li><p>The exponential map restricts to a diffeomorphism from some neighbourhood of {% raw %}<span class="math inline">\(0 \in \mathfrak g\)</span>{% endraw %} to a neighbourhood of {% raw %}<span class="math inline">\(e \in G\)</span>{% endraw %}.</p></li>
<li><p>Let {% raw %}<span class="math inline">\(H\)</span>{% endraw %} be another Lie group with Lie algebra {% raw %}<span class="math inline">\(\mathfrak h\)</span>{% endraw %}, and let {% raw %}<span class="math inline">\(F: G \to H\)</span>{% endraw %} be a Lie group homomorphism. Then the following diagram commutes:</p>

<figure class="note-diagram" id="diagram-lie-exponential-naturality" data-diagram="lie-exponential-naturality" style="--diagram-width: 164px; --diagram-min-width: 123px">
<div class="note-diagram__canvas" tabindex="0" role="region" aria-label="A Lie-group homomorphism commutes with the exponential maps and its differential at the identity."><a href="{{ '/assets/images/notes/tikz/lie-exponential-naturality.svg' | relative_url }}?v=269394ddb96e" title="Open diagram at full size"><img src="{{ '/assets/images/notes/tikz/lie-exponential-naturality.svg' | relative_url }}?v=269394ddb96e" alt="A Lie-group homomorphism commutes with the exponential maps and its differential at the identity." loading="lazy" decoding="async"></a></div>
<figcaption>A Lie-group homomorphism commutes with the exponential maps and its differential at the identity.</figcaption>
</figure></li>
<li><p>The flow of a left-invariant vector field {% raw %}<span class="math inline">\(X\)</span>{% endraw %} is given by {% raw %}<span class="math inline">\(\kappa_t = R_{\exp(tX)}\)</span>{% endraw %}, i.e. by right multiplication by {% raw %}<span class="math inline">\(\exp (tX)\)</span>{% endraw %}.</p></li>
</ol>
</div>
<div class="proof">
<p><em>Proof of Proposition <a href="#prop:properties-exponential-map-lie-group" data-reference-type="ref" data-reference="prop:properties-exponential-map-lie-group">20</a>.</em> We proceed by proving the statements sequentially.</p>

<ol>
<li><p>Define a vector field {% raw %}<span class="math inline">\(\Xi\)</span>{% endraw %} on the product manifold {% raw %}<span class="math inline">\(G \times \mathfrak g\)</span>{% endraw %} by {% raw %}<span class="math inline">\(\Xi_{(g,X)} = (X_g, 0)\)</span>{% endraw %}. Since the map {% raw %}<span class="math inline">\((g,X) \mapsto X_g = (\dif L_g)_e (X)\)</span>{% endraw %} is smooth (it depends smoothly on {% raw %}<span class="math inline">\(g\)</span>{% endraw %} and linearly on {% raw %}<span class="math inline">\(X\)</span>{% endraw %}), {% raw %}<span class="math inline">\(\Xi\)</span>{% endraw %} is a smooth vector field. The integral curve of {% raw %}<span class="math inline">\(\Xi\)</span>{% endraw %} starting at {% raw %}<span class="math inline">\((e,X)\)</span>{% endraw %} is given by {% raw %}<span class="math inline">\(t \mapsto (\gamma_X(t), X)\)</span>{% endraw %}, where {% raw %}<span class="math inline">\(\gamma_X\)</span>{% endraw %} is the maximal integral curve of {% raw %}<span class="math inline">\(X\)</span>{% endraw %} starting at {% raw %}<span class="math inline">\(e\)</span>{% endraw %}. Because left-invariant vector fields are complete, this flow is defined for all {% raw %}<span class="math inline">\(t \in \mathbb R\)</span>{% endraw %}. By the fundamental theorem on flows, the global flow map {% raw %}<span class="math inline">\(\Theta_t(g,X)\)</span>{% endraw %} depends smoothly on its initial conditions. In particular, evaluating at {% raw %}<span class="math inline">\(t=1\)</span>{% endraw %} and {% raw %}<span class="math inline">\(g=e\)</span>{% endraw %}, the map {% raw %}<span class="math inline">\(X \mapsto \pi_G (\Theta_1(e,X)) = \exp(X)\)</span>{% endraw %} is smooth, implying that {% raw %}<span class="math inline">\(\exp : \mathfrak g \to G\)</span>{% endraw %} is a smooth map.</p></li>
<li><p>By Proposition <a href="#prop:exponential-map-rescaled-one-parameter-subgroup" data-reference-type="ref" data-reference="prop:exponential-map-rescaled-one-parameter-subgroup">19</a>, the curve {% raw %}<span class="math inline">\(\gamma(s) = \exp(sX)\)</span>{% endraw %} is the one-parameter subgroup generated by {% raw %}<span class="math inline">\(X\)</span>{% endraw %}. Since it is a group homomorphism from {% raw %}<span class="math inline">\(\mathbb R\)</span>{% endraw %} to {% raw %}<span class="math inline">\(G\)</span>{% endraw %}, we have {% raw %}<span class="math inline">\(\exp((s+t)X) = \gamma(s+t) = \gamma(s)\gamma(t) = \exp(sX)\exp(tX)\)</span>{% endraw %}.</p></li>
<li><p>From (b), taking {% raw %}<span class="math inline">\(s=1\)</span>{% endraw %} and {% raw %}<span class="math inline">\(t=-1\)</span>{% endraw %} yields {% raw %}<span class="math inline">\(\exp(X)\exp(-X) = \exp(0X) = \exp(0)\)</span>{% endraw %}. The integral curve of the zero vector field is constantly {% raw %}<span class="math inline">\(e\)</span>{% endraw %}, so {% raw %}<span class="math inline">\(\exp(0) = e\)</span>{% endraw %}. Therefore, {% raw %}<span class="math inline">\((\exp X)^{-1} = \exp(-X)\)</span>{% endraw %}.</p></li>
<li><p>This follows directly from (b) by mathematical induction on {% raw %}<span class="math inline">\(n\)</span>{% endraw %}.</p></li>
<li><p>Let {% raw %}<span class="math inline">\(X \in \mathfrak g\)</span>{% endraw %}. Under the canonical identification of {% raw %}<span class="math inline">\(T_0 \mathfrak g\)</span>{% endraw %} with {% raw %}<span class="math inline">\(\mathfrak g\)</span>{% endraw %}, we can evaluate the differential {% raw %}<span class="math inline">\((\dif \exp)_0 (X)\)</span>{% endraw %} by considering the smooth curve {% raw %}<span class="math inline">\(c(t) = tX\)</span>{% endraw %} in {% raw %}<span class="math inline">\(\mathfrak g\)</span>{% endraw %}, which has {% raw %}<span class="math inline">\(c(0)=0\)</span>{% endraw %} and initial velocity {% raw %}<span class="math inline">\(X\)</span>{% endraw %}. Then, </p>

{% raw %}<div class="math display">\[\begin{aligned}
            (\dif \exp)_0 (X) = \left. \frac{\dif}{\dif t} \right|_{t=0} \exp(tX) ~.
        
\end{aligned}\]</div>{% endraw %}
<p> By definition, {% raw %}<span class="math inline">\(t \mapsto \exp(tX)\)</span>{% endraw %} is the integral curve of {% raw %}<span class="math inline">\(X\)</span>{% endraw %} starting at {% raw %}<span class="math inline">\(e\)</span>{% endraw %}, so its derivative at {% raw %}<span class="math inline">\(t=0\)</span>{% endraw %} is exactly {% raw %}<span class="math inline">\(X_e\)</span>{% endraw %}. Under the standard identification of {% raw %}<span class="math inline">\(T_e G\)</span>{% endraw %} with {% raw %}<span class="math inline">\(\mathfrak g\)</span>{% endraw %}, this is precisely {% raw %}<span class="math inline">\(X\)</span>{% endraw %}. Thus, {% raw %}<span class="math inline">\((\dif \exp)_0\)</span>{% endraw %} is the identity map.</p></li>
<li><p>Since {% raw %}<span class="math inline">\((\dif \exp)_0 : T_0 \mathfrak g \to T_e G\)</span>{% endraw %} is the identity map, it is a linear isomorphism. The inverse function theorem then implies that {% raw %}<span class="math inline">\(\exp\)</span>{% endraw %} restricts to a diffeomorphism from some open neighbourhood of {% raw %}<span class="math inline">\(0 \in \mathfrak g\)</span>{% endraw %} to an open neighbourhood of {% raw %}<span class="math inline">\(e \in G\)</span>{% endraw %}.</p></li>
<li><p>For any {% raw %}<span class="math inline">\(X \in \mathfrak g\)</span>{% endraw %}, the curve {% raw %}<span class="math inline">\(\alpha(t) = \exp_G(tX)\)</span>{% endraw %} is a one-parameter subgroup of {% raw %}<span class="math inline">\(G\)</span>{% endraw %}. Since {% raw %}<span class="math inline">\(F : G \to H\)</span>{% endraw %} is a Lie group homomorphism, the composition {% raw %}<span class="math inline">\(F \circ \alpha : \mathbb R \to H\)</span>{% endraw %} is also a Lie group homomorphism, and thus a one-parameter subgroup of {% raw %}<span class="math inline">\(H\)</span>{% endraw %}. Its initial velocity at {% raw %}<span class="math inline">\(t=0\)</span>{% endraw %} is </p>

{% raw %}<div class="math display">\[\begin{aligned}
            \left. \frac{\dif}{\dif t} \right|_{t=0} F(\exp_G(tX)) = (\dif F)_e (\dot \alpha(0)) = (\dif F)_e (X_e) = (F_* X)_e ~.
        
\end{aligned}\]</div>{% endraw %}
<p> Therefore, {% raw %}<span class="math inline">\(F \circ \alpha\)</span>{% endraw %} is the one-parameter subgroup of {% raw %}<span class="math inline">\(H\)</span>{% endraw %} generated by {% raw %}<span class="math inline">\(F_* X\)</span>{% endraw %}, meaning {% raw %}<span class="math inline">\(F(\exp_G(tX)) = \exp_H(t F_* X)\)</span>{% endraw %}. Evaluating at {% raw %}<span class="math inline">\(t=1\)</span>{% endraw %} gives {% raw %}<span class="math inline">\(F(\exp_G(X)) = \exp_H(F_* X)\)</span>{% endraw %}, which establishes that the diagram commutes.</p></li>
<li><p>Let {% raw %}<span class="math inline">\(X \in \mathfrak g\)</span>{% endraw %}. We want to find the flow {% raw %}<span class="math inline">\(\kappa_t\)</span>{% endraw %} of {% raw %}<span class="math inline">\(X\)</span>{% endraw %}. Fix {% raw %}<span class="math inline">\(g \in G\)</span>{% endraw %} and consider the curve {% raw %}<span class="math inline">\(\beta(t) = R_{\exp(tX)}(g) = g \exp(tX) = L_g(\exp(tX))\)</span>{% endraw %}. At {% raw %}<span class="math inline">\(t=0\)</span>{% endraw %}, we have {% raw %}<span class="math inline">\(\beta(0) = g e = g\)</span>{% endraw %}. The tangent vector to this curve at time {% raw %}<span class="math inline">\(t\)</span>{% endraw %} is </p>

{% raw %}<div class="math display">\[\begin{aligned}
            \dot \beta(t) &amp;= \frac{\dif}{\dif t} L_g(\exp(tX)) \nonumber \\
            &amp;= (\dif L_g)_{\exp(tX)} \left( \frac{\dif}{\dif t} \exp(tX) \right) \nonumber \\
            &amp;= (\dif L_g)_{\exp(tX)} (X_{\exp(tX)}) ~.
        
\end{aligned}\]</div>{% endraw %}
<p> Because {% raw %}<span class="math inline">\(X\)</span>{% endraw %} is a left-invariant vector field, {% raw %}<span class="math inline">\((\dif L_g)_h (X_h) = X_{gh}\)</span>{% endraw %} for all {% raw %}<span class="math inline">\(h \in G\)</span>{% endraw %}. Setting {% raw %}<span class="math inline">\(h = \exp(tX)\)</span>{% endraw %} yields {% raw %}<span class="math inline">\(\dot \beta(t) = X_{g \exp(tX)} = X_{\beta(t)}\)</span>{% endraw %}. Therefore, {% raw %}<span class="math inline">\(\beta\)</span>{% endraw %} is an integral curve of {% raw %}<span class="math inline">\(X\)</span>{% endraw %} starting at {% raw %}<span class="math inline">\(g\)</span>{% endraw %}. By the uniqueness of integral curves, it must be the flow of {% raw %}<span class="math inline">\(X\)</span>{% endraw %}, so {% raw %}<span class="math inline">\(\kappa_t(g) = R_{\exp(tX)}(g)\)</span>{% endraw %}.</p></li>
</ol>
<p>This concludes the proof. ◻</p>

<div id="result-21" class="remark" data-note-number="21" data-note-kind="Remark">
<p><strong>Remark 21.</strong> The Lie-group exponential and the Riemannian exponential both arise from ODEs, but are different constructions. The former uses complete invariant vector fields and is defined on all of {% raw %}<span class="math inline">\(\mathfrak g\)</span>{% endraw %}. The latter depends on a metric and its geodesics, and its domain can be smaller without completeness. They agree at the identity for a bi-invariant Riemannian metric, but no such metric has been assumed here.</p>
</div>
<div id="result-22" class="lemma" data-note-number="22" data-note-kind="Lemma">
<p><strong>Lemma 22</strong>.  Let {% raw %}<span class="math inline">\(G\)</span>{% endraw %} be a Lie group, and let {% raw %}<span class="math inline">\(H \subset G\)</span>{% endraw %} be a Lie subgroup. With {% raw %}<span class="math inline">\(\mathfrak h\)</span>{% endraw %} considered as a subalgebra of {% raw %}<span class="math inline">\(\mathfrak g\)</span>{% endraw %} in the usual way, by Theorem <a href="{% post_url 2022-10-07-lie-groups-and-their-lie-algebras %}#thm:lie-algebra-of-subgroup" data-reference-type="ref" data-reference="thm:lie-algebra-of-subgroup">18</a>, the exponential map of {% raw %}<span class="math inline">\(H\)</span>{% endraw %} is the restriction of the exponential map of {% raw %}<span class="math inline">\(G\)</span>{% endraw %} to {% raw %}<span class="math inline">\(\mathfrak h\)</span>{% endraw %}. Furthermore, {% raw %}<span class="math inline">\(\mathfrak h = \{X \in \mathfrak g : \exp (tX) \in H \text{ for all } t \in \mathbb R\}\)</span>{% endraw %}.</p>

</div>
<div class="proof">
<p><em>Proof.</em> Apply the exponential naturality in Proposition 20 to the smooth inclusion {% raw %}<span class="math inline">\(H\hookrightarrow G\)</span>{% endraw %}. It gives {% raw %}<span class="math inline">\(\exp_G(X)=\exp_H(X)\)</span>{% endraw %} for {% raw %}<span class="math inline">\(X\in\mathfrak h\)</span>{% endraw %}, proving both the first assertion and one inclusion in the second.</p>
<p>For the reverse inclusion suppose the smooth ambient curve {% raw %}<span class="math inline">\(c(t)=\exp_G(tX)\)</span>{% endraw %} lies in {% raw %}<span class="math inline">\(H\)</span>{% endraw %}. Use the product neighborhood {% raw %}<span class="math inline">\(\psi:V_0\times P_0\to U_0\)</span>{% endraw %} from the proof of Theorem 12; its construction and the countability of {% raw %}<span class="math inline">\(K=P_0\cap H\)</span>{% endraw %} did not use closedness. For {% raw %}<span class="math inline">\(t\)</span>{% endraw %} in a small interval about zero, the transverse component of {% raw %}<span class="math inline">\(\psi^{-1}(c(t))\)</span>{% endraw %} is a continuous map into countable {% raw %}<span class="math inline">\(K\)</span>{% endraw %}. A connected subset of a countable Euclidean set has only one point: if it had two, a separating coordinate projection would contain a nontrivial, uncountable interval. The transverse component is therefore constant, equal to {% raw %}<span class="math inline">\(e\)</span>{% endraw %}. Hence {% raw %}<span class="math inline">\(c\)</span>{% endraw %} lies in the single smooth plaque {% raw %}<span class="math inline">\(V_0\)</span>{% endraw %}, and is smooth as an {% raw %}<span class="math inline">\(H\)</span>{% endraw %}-valued curve there. Differentiating at zero gives {% raw %}<span class="math inline">\(X\in T_eH\)</span>{% endraw %}. This supplies the missing justification even when the subgroup is only immersed. ◻</p>
</div>
<h3 data-note-section="2" id="cartans-closed-subgroup-theorem">2. Cartan’s Closed Subgroup Theorem</h3>
<p>We showed in Theorem <a href="#thm:closed-lie-subgroup-iff-embedded" data-reference-type="ref" data-reference="thm:closed-lie-subgroup-iff-embedded">12</a> that a Lie subgroup is embedded if and only if it is closed. We now have all the tools needed to prove a much stronger statement: if a subgroup of a Lie group is topologically a closed subset, then it is automatically an embedded Lie subgroup. We proceed in a few steps.</p>

<div id="prop:first-order-group-multiplication-lie-group-exp" class="proposition" data-note-number="23" data-note-kind="Proposition">
<p><strong>Proposition 23</strong>.  Let {% raw %}<span class="math inline">\(G\)</span>{% endraw %} be a Lie group and let {% raw %}<span class="math inline">\(\mathfrak g\)</span>{% endraw %} be its Lie algebra. For any {% raw %}<span class="math inline">\(X,Y \in \mathfrak g\)</span>{% endraw %}, there exists a smooth function {% raw %}<span class="math inline">\(Z : (-\varepsilon,\varepsilon) \to \mathfrak g\)</span>{% endraw %} for some {% raw %}<span class="math inline">\(\varepsilon &gt; 0\)</span>{% endraw %} such that for all {% raw %}<span class="math inline">\(t \in (-\varepsilon,\varepsilon)\)</span>{% endraw %}, </p>

{% raw %}<div class="math display">\[\exp (tX) \exp(tY) = \exp(t(X+Y) + t^2 Z(t)) ~.\]</div>{% endraw %}
</div>
<div class="proof">
<p><em>Proof.</em> On a sufficiently small interval let {% raw %}<span class="math inline">\(\varphi(t)=\log(\exp(tX)\exp(tY))\)</span>{% endraw %}, using the local inverse of {% raw %}<span class="math inline">\(\exp\)</span>{% endraw %} at zero. It is smooth, {% raw %}<span class="math inline">\(\varphi(0)=0\)</span>{% endraw %}, and the product differential at {% raw %}<span class="math inline">\((e,e)\)</span>{% endraw %} together with {% raw %}<span class="math inline">\(d\exp_0=\mathrm{id}\)</span>{% endraw %} gives {% raw %}<span class="math inline">\(\varphi'(0)=X+Y\)</span>{% endraw %}. Taylor's formula with integral remainder gives the explicit smooth function</p>
{% raw %}<div class="math display">\[Z(t)=\int_0^1(1-u)\varphi''(ut)\,du,\qquad \varphi(t)=t(X+Y)+t^2Z(t).\]</div>{% endraw %}
<p> This includes {% raw %}<span class="math inline">\(t=0\)</span>{% endraw %} without division by zero and proves the asserted exponential identity. ◻</p>
</div>
<div id="result-24" class="remark" data-note-number="24" data-note-kind="Remark">
<p><strong>Remark 24 (Baker–Campbell–Hausdorff).</strong> The BCH expansion applies to {% raw %}<span class="math inline">\(\log(\exp(tX)\exp(tY))\)</span>{% endraw %}, not directly to the remainder {% raw %}<span class="math inline">\(Z\)</span>{% endraw %}. With the normalization of Proposition 23 it yields</p>
{% raw %}<div class="math display">\[Z(t)=\frac12[X,Y]+\frac{t}{12}\bigl([X,[X,Y]]+[Y,[Y,X]]\bigr)-\frac{t^2}{24}[Y,[X,[X,Y]]]+O(t^3).\]</div>{% endraw %}
<p> In particular {% raw %}<span class="math inline">\(Z(0)=\frac12[X,Y]\)</span>{% endraw %}; the terms {% raw %}<span class="math inline">\(X+Y\)</span>{% endraw %} have already been removed. The expansion is local in {% raw %}<span class="math inline">\(t\)</span>{% endraw %}. The first terms are recorded in <a href="https://math.mit.edu/~etingof/lnlg.pdf">Etingof, §7.6, Theorem 7.19 and Example 7.20, p. 46</a>. The following limit and closed subgroup proof need only the smooth remainder proved above, not convergence of an infinite BCH series.</p>
</div>
<div id="cor:first-order-lie-group-exp-expansion-limit" class="corollary" data-note-number="25" data-note-kind="Corollary">
<p><strong>Corollary 25</strong>.  Let {% raw %}<span class="math inline">\(G\)</span>{% endraw %} be a Lie group and let {% raw %}<span class="math inline">\(\mathfrak g\)</span>{% endraw %} be its Lie algebra. For any {% raw %}<span class="math inline">\(X,Y \in \mathfrak g\)</span>{% endraw %} and fixed {% raw %}<span class="math inline">\(t \in \mathbb R\)</span>{% endraw %}, </p>

{% raw %}<div class="math display">\[\lim\limits_{n\to\infty} \left( \exp \left( \frac{t}{n} X \right) \exp \left( \frac{t}{n} Y \right) \right)^n = \exp \left( t(X+Y) \right) ~.\]</div>{% endraw %}
<p>For completeness, for a fixed {% raw %}<span class="math inline">\(t\)</span>{% endraw %}, the arguments {% raw %}<span class="math inline">\(t/n\)</span>{% endraw %} eventually lie in a compact subinterval of the domain of {% raw %}<span class="math inline">\(Z\)</span>{% endraw %}. Continuity makes {% raw %}<span class="math inline">\(Z(t/n)\)</span>{% endraw %} bounded, so {% raw %}<span class="math inline">\(t^2Z(t/n)/n\to0\)</span>{% endraw %}. Continuity of {% raw %}<span class="math inline">\(\exp\)</span>{% endraw %} then justifies the limit in (1).</p>
</div>
<div class="proof">
<p><em>Proof.</em> It follows from Proposition <a href="#prop:first-order-group-multiplication-lie-group-exp" data-reference-type="ref" data-reference="prop:first-order-group-multiplication-lie-group-exp">23</a> that </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \exp \left( \frac{t}{n} X \right) \exp \left( \frac{t}{n} Y \right) = \exp \left( \frac{t}{n} (X+Y) + \frac{t^2}{n^2} Z \left( \frac{t}{n} \right) \right) ~.
    
\end{aligned}\]</div>{% endraw %}
<p> Furthermore, applying the property of exponential map gives us </p>

{% raw %}<span id="eq:cor-first-order-expansion-exp-lie-group"></span><div class="math display">\[\begin{aligned}
        \left( \exp \left( \frac{t}{n} X \right) \exp \left( \frac{t}{n} Y \right) \right)^n &amp;=  \left( \exp \left( \frac{t}{n} (X+Y) + \frac{t^2}{n^2} Z \left( \frac{t}{n} \right) \right) \right)^n \\
        &amp;= \exp \left( t (X+Y) + \frac{t^2}{n} Z \left( \frac{t}{n} \right) \right) ~. 
    
\end{aligned}\tag{1}\]</div>{% endraw %}
<p> For a fixed {% raw %}<span class="math inline">\(t \in \mathbb R\)</span>{% endraw %}, pass <a href="#eq:cor-first-order-expansion-exp-lie-group" data-reference-type="eqref" data-reference="eq:cor-first-order-expansion-exp-lie-group">(1)</a> to the limit and {% raw %}<span class="math inline">\(n\to \infty\)</span>{% endraw %} to conclude. ◻</p>

</div>
<div id="thm:closed-subgroup-theorem-cartan" class="theorem" data-note-number="26" data-note-kind="Theorem">
<p><strong>Theorem 26</strong> (Cartan’s Closed Subgroup Theorem).  Let {% raw %}<span class="math inline">\(G\)</span>{% endraw %} be a Lie group, and let {% raw %}<span class="math inline">\(H \subset G\)</span>{% endraw %} be a subgroup that is also a closed subset of {% raw %}<span class="math inline">\(G\)</span>{% endraw %}. Then, {% raw %}<span class="math inline">\(H\)</span>{% endraw %} is an embedded Lie subgroup.</p>

</div>
<div class="proof">
<p><em>Proof.</em> Define</p>
{% raw %}<div class="math display">\[\mathfrak H=\{X\in\mathfrak g:\exp(tX)\in H\text{ for every }t\in\mathbb R\}.\]</div>{% endraw %}
<p> It contains zero and is closed under real scalar multiplication. If {% raw %}<span class="math inline">\(X,Y\in\mathfrak H\)</span>{% endraw %}, every term {% raw %}<span class="math inline">\((\exp(tX/n)\exp(tY/n))^n\)</span>{% endraw %} belongs to the <em>group</em> {% raw %}<span class="math inline">\(H\)</span>{% endraw %}. The product limit and closedness put {% raw %}<span class="math inline">\(\exp(t(X+Y))\)</span>{% endraw %} in {% raw %}<span class="math inline">\(H\)</span>{% endraw %}, for every real {% raw %}<span class="math inline">\(t\)</span>{% endraw %}. Thus {% raw %}<span class="math inline">\(\mathfrak H\)</span>{% endraw %} is a vector subspace.</p>
<p>Choose a linear complement {% raw %}<span class="math inline">\(\mathfrak j\)</span>{% endraw %} and consider {% raw %}<span class="math inline">\(\Phi:\mathfrak H\times\mathfrak j\to G\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\Phi(X,Y)=\exp(X)\exp(Y)\)</span>{% endraw %}. Its differential at {% raw %}<span class="math inline">\((0,0)\)</span>{% endraw %} is {% raw %}<span class="math inline">\((X,Y)\mapsto X+Y\)</span>{% endraw %}, an isomorphism. On small product neighborhoods {% raw %}<span class="math inline">\(A\times B\)</span>{% endraw %} it is a diffeomorphism onto an ambient open set. We claim that {% raw %}<span class="math inline">\(B\)</span>{% endraw %} can be shrunk so that</p>
{% raw %}<div class="math display">\[Y\in B,\quad\exp(Y)\in H\quad\Longrightarrow\quad Y=0.\]</div>{% endraw %}
<p> If not, choose nonzero {% raw %}<span class="math inline">\(Y_i\in\mathfrak j\)</span>{% endraw %} tending to zero with {% raw %}<span class="math inline">\(\exp(Y_i)\in H\)</span>{% endraw %}. Set {% raw %}<span class="math inline">\(c_i=\|Y_i\|&gt;0\)</span>{% endraw %}, and pass to a subsequence with {% raw %}<span class="math inline">\(Y_i/c_i\to Y\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\|Y\|=1\)</span>{% endraw %}. For each fixed real {% raw %}<span class="math inline">\(t\)</span>{% endraw %}, choose the integer {% raw %}<span class="math inline">\(n_i=\lfloor t/c_i\rfloor\)</span>{% endraw %}, allowing negative integers. Then</p>
{% raw %}<div class="math display">\[|n_ic_i-t|\leq c_i\to0,\qquad n_iY_i=(n_ic_i)(Y_i/c_i)\to tY.\]</div>{% endraw %}
<p> Since {% raw %}<span class="math inline">\(\exp(n_iY_i)=\exp(Y_i)^{n_i}\in H\)</span>{% endraw %}, closedness implies {% raw %}<span class="math inline">\(\exp(tY)\in H\)</span>{% endraw %}. This holds for every {% raw %}<span class="math inline">\(t\)</span>{% endraw %}, so {% raw %}<span class="math inline">\(Y\in\mathfrak H\cap\mathfrak j=\{0\}\)</span>{% endraw %}, contradicting {% raw %}<span class="math inline">\(\|Y\|=1\)</span>{% endraw %}. The norm, not its square, is essential in this normalization.</p>
<p>Now for {% raw %}<span class="math inline">\((X,Y)\in A\times B\)</span>{% endraw %}, the element {% raw %}<span class="math inline">\(\exp(X)\)</span>{% endraw %} lies in {% raw %}<span class="math inline">\(H\)</span>{% endraw %}. Consequently {% raw %}<span class="math inline">\(\Phi(X,Y)\in H\)</span>{% endraw %} if and only if {% raw %}<span class="math inline">\(\exp(Y)\in H\)</span>{% endraw %}, which by the claim is equivalent to {% raw %}<span class="math inline">\(Y=0\)</span>{% endraw %}. The coordinates {% raw %}<span class="math inline">\(\Phi^{-1}\)</span>{% endraw %} therefore identify {% raw %}<span class="math inline">\(H\)</span>{% endraw %} near the identity with the slice {% raw %}<span class="math inline">\(A\times\{0\}\)</span>{% endraw %}. Left translation gives the same slice description near every point of {% raw %}<span class="math inline">\(H\)</span>{% endraw %}. Thus {% raw %}<span class="math inline">\(H\)</span>{% endraw %} is an embedded submanifold with its subspace topology, and Proposition 6 gives smooth group operations. It is properly embedded because it is closed. Its tangent space at the identity is exactly {% raw %}<span class="math inline">\(\mathfrak H\)</span>{% endraw %}; closure under Lie brackets follows from the already proved Lie-subgroup algebra theorem. ◻</p>
</div>
