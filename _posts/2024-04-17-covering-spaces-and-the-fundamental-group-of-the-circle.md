<p>A loop can wind around a hole even when every small neighbourhood looks Euclidean. The fundamental group records which loops can be deformed into one another while their base point stays fixed. Covering spaces help compute this group by replacing loops with paths upstairs.</p>

<p>For background, see <span class="citation" data-cites="hatcher_algebraic_2002">(<a href="#ref-hatcher_algebraic_2002" role="doc-biblioref">Hatcher 2002</a>)</span>. We develop path homotopy and lifting, then compute the fundamental group of the circle by recording the endpoint of a lifted loop. The same winding-number argument gives applications to the fundamental theorem of algebra and the two-dimensional Borsuk–Ulam theorem.</p>

<div id="def:homotopy" class="definition" data-note-number="1" data-note-kind="Definition">
<p><strong>Definition 1</strong> (Homotopy).  Let {% raw %}<span class="math inline">\(c_1 : [0,a_1] \to M\)</span>{% endraw %} and {% raw %}<span class="math inline">\(c_2 : [0,a_2] \to M\)</span>{% endraw %} be paths (continuous maps), with positive interval lengths, on a differentiable manifold {% raw %}<span class="math inline">\(M\)</span>{% endraw %}. {% raw %}<span class="math inline">\(c_1\)</span>{% endraw %} is said to be a <em>loop</em> if it is a path with {% raw %}<span class="math inline">\(c_1(0) = c_1(a_1)\)</span>{% endraw %}; {% raw %}<span class="math inline">\(c_1(0)\)</span>{% endraw %} is said to be the <em>base point</em> of the loop. {% raw %}<span class="math inline">\(c_1\)</span>{% endraw %} and {% raw %}<span class="math inline">\(c_2\)</span>{% endraw %} are said to be <em>homotopic</em> (as paths) if {% raw %}<span class="math inline">\(c_1(0)=c_2(0)\)</span>{% endraw %} and {% raw %}<span class="math inline">\(c_1(a_1)=c_2(a_2)\)</span>{% endraw %}, and there exists a continuous map {% raw %}<span class="math inline">\(H : [0,1]^2 \to M\)</span>{% endraw %} such that </p>

{% raw %}<div class="math display">\[\begin{aligned}
        H(0,t) = c_1(a_1t) &amp;~,~ H(1,t) = c_2(a_2t)  \text{ for all } t ~, \\
        H(s,0) = c_1(0) = c_2(0) &amp;~,~ H(s,1) = c_1 (a_1) = c_2 (a_2)  \text{ for all } s ~.
    
\end{aligned}\]</div>{% endraw %}
<p> We write {% raw %}<span class="math inline">\(c_1 \simeq c_2\)</span>{% endraw %} to mean {% raw %}<span class="math inline">\(c_1\)</span>{% endraw %} and {% raw %}<span class="math inline">\(c_2\)</span>{% endraw %} are homotopic (as paths).</p>

</div>
<p>It is clear from the definition of homotopy that {% raw %}<span class="math inline">\(H\)</span>{% endraw %} is a continuous deformation of path {% raw %}<span class="math inline">\(c_1\)</span>{% endraw %} into path {% raw %}<span class="math inline">\(c_2\)</span>{% endraw %} that keeps endpoints fixed. Formally, the functions {% raw %}<span class="math inline">\(H_s (t) = H(s,t)\)</span>{% endraw %} generated by the path homotopy {% raw %}<span class="math inline">\(H\)</span>{% endraw %} are paths from {% raw %}<span class="math inline">\(c_1(0)\)</span>{% endraw %} to {% raw %}<span class="math inline">\(c_2(a_2)\)</span>{% endraw %}. As a remark, distinctions are drawn between homotopy of continuous functions and homotopy of paths; here, we always mean homotopy of paths without explicit mention.</p>

<div id="lem:homotopy-is-equivalence-relation" class="lemma" data-note-number="2" data-note-kind="Lemma">
<p><strong>Lemma 2</strong>.  {% raw %}<span class="math inline">\(\simeq\)</span>{% endraw %} is an equivalence relation on the space of paths between fixed endpoints.</p>

</div>
<p>Transitivity requires joining two homotopies. The pasting lemma ensures that the joined map is continuous when the pieces agree along their common boundary.</p>

<div id="lem:pasting-lemma" class="lemma" data-note-number="3" data-note-kind="Lemma">
<p><strong>Lemma 3</strong> (Pasting Lemma).  Let {% raw %}<span class="math inline">\(f:X \to Y\)</span>{% endraw %} be a map between topological spaces {% raw %}<span class="math inline">\(X\)</span>{% endraw %} and {% raw %}<span class="math inline">\(Y\)</span>{% endraw %}. Let {% raw %}<span class="math inline">\(X = A \cup B\)</span>{% endraw %}, where {% raw %}<span class="math inline">\(A\)</span>{% endraw %} and {% raw %}<span class="math inline">\(B\)</span>{% endraw %} are both open or closed subsets of {% raw %}<span class="math inline">\(X\)</span>{% endraw %}. If {% raw %}<span class="math inline">\(f|_A\)</span>{% endraw %} and {% raw %}<span class="math inline">\(f|_B\)</span>{% endraw %} are both continuous maps, then {% raw %}<span class="math inline">\(f\)</span>{% endraw %} is a continuous map.</p>

</div>
<p><strong>Proof of the pasting lemma.</strong> If {% raw %}<span class="math inline">\(A,B\)</span>{% endraw %} are open, the inverse image of an open set is the union of two sets open in {% raw %}<span class="math inline">\(X\)</span>{% endraw %}. If {% raw %}<span class="math inline">\(A,B\)</span>{% endraw %} are closed, use a closed set {% raw %}<span class="math inline">\(C\subset Y\)</span>{% endraw %}: each {% raw %}<span class="math inline">\((f|_A)^{-1}(C)\)</span>{% endraw %} and {% raw %}<span class="math inline">\((f|_B)^{-1}(C)\)</span>{% endraw %} is closed in its closed domain and hence in {% raw %}<span class="math inline">\(X\)</span>{% endraw %}, and their finite union is {% raw %}<span class="math inline">\(f^{-1}(C)\)</span>{% endraw %}. In both cases {% raw %}<span class="math inline">\(f\)</span>{% endraw %} is continuous. The identity {% raw %}<span class="math inline">\((A\cap U_A)\cup(B\cap U_B)=(A\cup B)\cap(U_A\cup U_B)\)</span>{% endraw %} is not valid in general and is not needed. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>
<p><strong>Proof of Lemma 2.</strong> Normalize all paths to {% raw %}<span class="math inline">\(I=[0,1]\)</span>{% endraw %}. Reflexivity uses {% raw %}<span class="math inline">\(H(s,t)=c(t)\)</span>{% endraw %}; symmetry replaces {% raw %}<span class="math inline">\(s\)</span>{% endraw %} by {% raw %}<span class="math inline">\(1-s\)</span>{% endraw %}. If {% raw %}<span class="math inline">\(F\)</span>{% endraw %} deforms {% raw %}<span class="math inline">\(f\)</span>{% endraw %} to {% raw %}<span class="math inline">\(g\)</span>{% endraw %} and {% raw %}<span class="math inline">\(G\)</span>{% endraw %} deforms {% raw %}<span class="math inline">\(g\)</span>{% endraw %} to {% raw %}<span class="math inline">\(h\)</span>{% endraw %}, define</p>
{% raw %}<div class="math display">\[H(s,t)=\begin{cases}F(2s,t),&amp;0\le s\le\frac12,\\G(2s-1,t),&amp;\frac12\le s\le1.\end{cases}\]</div>{% endraw %}

<p>The two continuous pieces agree at {% raw %}<span class="math inline">\(s=1/2\)</span>{% endraw %}, where both equal {% raw %}<span class="math inline">\(g(t)\)</span>{% endraw %}, so the closed-set pasting lemma applies. The boundary values at {% raw %}<span class="math inline">\(t=0,1\)</span>{% endraw %} stay fixed. Thus {% raw %}<span class="math inline">\(f\simeq h\)</span>{% endraw %}. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>
<p>For a path {% raw %}<span class="math inline">\(c:[0,a]\to M\)</span>{% endraw %}, {% raw %}<span class="math inline">\(a&gt;0\)</span>{% endraw %}, the normalized path on {% raw %}<span class="math inline">\(I\)</span>{% endraw %} is {% raw %}<span class="math inline">\(\widetilde c(t)=c(at)\)</span>{% endraw %}. More generally, a continuous reparametrization {% raw %}<span class="math inline">\(\rho:I\to I\)</span>{% endraw %} fixing zero and one does not change a path class: {% raw %}<span class="math inline">\(c((1-s)t+s\rho(t))\)</span>{% endraw %} is an endpoint-fixing homotopy from {% raw %}<span class="math inline">\(c\)</span>{% endraw %} to {% raw %}<span class="math inline">\(c\circ\rho\)</span>{% endraw %}.</p>

<div id="def:fundamental-group" class="definition" data-note-number="4" data-note-kind="Definition">
<p><strong>Definition 4</strong>.  The homotopy classes of loops with a fixed base point {% raw %}<span class="math inline">\(p \in M\)</span>{% endraw %} is called the <em>fundamental group with base point {% raw %}<span class="math inline">\(p\)</span>{% endraw %}</em>, denoted {% raw %}<span class="math inline">\(\pi_1 (M,p)\)</span>{% endraw %}.</p>

</div>
<p>When two points lie in the same path component, their fundamental groups are isomorphic, but the isomorphism requires a chosen connecting path. We use the convention that {% raw %}<span class="math inline">\(f\star g\)</span>{% endraw %} traverses {% raw %}<span class="math inline">\(f\)</span>{% endraw %} first and then {% raw %}<span class="math inline">\(g\)</span>{% endraw %}. Thus, for paths {% raw %}<span class="math inline">\(f:x_0\to x_1\)</span>{% endraw %} and {% raw %}<span class="math inline">\(g:x_1\to x_2\)</span>{% endraw %}, define</p>

{% raw %}<div class="math display">\[\begin{aligned}
    f \star g = \begin{cases}
        f(2s) &amp; \text{ if } 0 \leq s \leq \frac12 ~, \\
        g(2s-1) &amp; \text{ if } \frac12 \leq s \leq 1 ~.
    \end{cases}
\end{aligned}\]</div>{% endraw %}
<p> Clearly, {% raw %}<span class="math inline">\(f \star g\)</span>{% endraw %} is continuous by the pasting lemma, so {% raw %}<span class="math inline">\(f \star g\)</span>{% endraw %} is a path from {% raw %}<span class="math inline">\(x_0\)</span>{% endraw %} to {% raw %}<span class="math inline">\(x_2\)</span>{% endraw %}. Applied to homotopy class, we write {% raw %}<span class="math inline">\([f] \star [g] = [f \star g]\)</span>{% endraw %}.</p>

<div id="result-5" class="proposition" data-note-number="5" data-note-kind="Proposition">
<p><strong>Proposition 5</strong>.  The operation {% raw %}<span class="math inline">\(\star\)</span>{% endraw %} between homotopy classes is well-defined.</p>

</div>
<p><strong>Proof of Proposition 5 and the group laws.</strong> Given endpoint-fixing homotopies {% raw %}<span class="math inline">\(F\)</span>{% endraw %} from {% raw %}<span class="math inline">\(f\)</span>{% endraw %} to {% raw %}<span class="math inline">\(\widetilde f\)</span>{% endraw %} and {% raw %}<span class="math inline">\(G\)</span>{% endraw %} from {% raw %}<span class="math inline">\(g\)</span>{% endraw %} to {% raw %}<span class="math inline">\(\widetilde g\)</span>{% endraw %}, use {% raw %}<span class="math inline">\(F(s,2t)\)</span>{% endraw %} for {% raw %}<span class="math inline">\(t\le1/2\)</span>{% endraw %} and {% raw %}<span class="math inline">\(G(s,2t-1)\)</span>{% endraw %} for {% raw %}<span class="math inline">\(t\ge1/2\)</span>{% endraw %}. They agree at the common endpoint, proving {% raw %}<span class="math inline">\(f\star g\simeq\widetilde f\star\widetilde g\)</span>{% endraw %}.</p>
<p>The paths {% raw %}<span class="math inline">\((f\star g)\star h\)</span>{% endraw %} and {% raw %}<span class="math inline">\(f\star(g\star h)\)</span>{% endraw %} traverse the same three paths, with breakpoints {% raw %}<span class="math inline">\((1/4,1/2)\)</span>{% endraw %} and {% raw %}<span class="math inline">\((1/2,3/4)\)</span>{% endraw %}. Interpolate these two breakpoints linearly and traverse each path at constant speed on its resulting subinterval. All three interval lengths stay positive; the formulas agree at moving boundaries, giving an endpoint-fixing homotopy and hence associativity of classes. A constant path is an identity by the reparametrization homotopy above. For the reverse {% raw %}<span class="math inline">\(f^*(t)=f(1-t)\)</span>{% endraw %}, put {% raw %}<span class="math inline">\(u(t)=2t\)</span>{% endraw %} on {% raw %}<span class="math inline">\([0,1/2]\)</span>{% endraw %} and {% raw %}<span class="math inline">\(u(t)=2-2t\)</span>{% endraw %} on {% raw %}<span class="math inline">\([1/2,1]\)</span>{% endraw %}. Then {% raw %}<span class="math inline">\(f((1-s)u(t))\)</span>{% endraw %} contracts {% raw %}<span class="math inline">\(f\star f^*\)</span>{% endraw %} to the constant at {% raw %}<span class="math inline">\(f(0)\)</span>{% endraw %} while fixing endpoints. Applying this to {% raw %}<span class="math inline">\(f^*\)</span>{% endraw %} proves the other inverse law. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>

<p>The operation {% raw %}<span class="math inline">\(\star\)</span>{% endraw %} makes homotopy classes of loops based at {% raw %}<span class="math inline">\(p_0\)</span>{% endraw %} into the group {% raw %}<span class="math inline">\(\pi_1(M,p_0)\)</span>{% endraw %}. Let {% raw %}<span class="math inline">\(p:[0,1]\to M\)</span>{% endraw %} be a chosen path from {% raw %}<span class="math inline">\(p_0\)</span>{% endraw %} to {% raw %}<span class="math inline">\(p_1\)</span>{% endraw %}. Its reverse is {% raw %}<span class="math inline">\(p^*(s)=p(1-s)\)</span>{% endraw %}. Change of base point is the map {% raw %}<span class="math inline">\(\widehat p:\pi_1(M,p_0)\to\pi_1(M,p_1)\)</span>{% endraw %} given by</p>

{% raw %}<div class="math display">\[\begin{aligned}
    \widehat p([f]) = [p^*] \star [f] \star [p] ~,
\end{aligned}\]</div>{% endraw %}
<p>If a loop changes by a homotopy fixing its endpoints, concatenate that homotopy with {% raw %}<span class="math inline">\(p^*\)</span>{% endraw %} and {% raw %}<span class="math inline">\(p\)</span>{% endraw %}. The resulting loops remain based at {% raw %}<span class="math inline">\(p_1\)</span>{% endraw %}, so {% raw %}<span class="math inline">\(\widehat p\)</span>{% endraw %} is well-defined. Concatenation is associative on homotopy classes, and {% raw %}<span class="math inline">\([p\star p^*]\)</span>{% endraw %} and {% raw %}<span class="math inline">\([p^*\star p]\)</span>{% endraw %} are the appropriate constant-loop classes.</p>

<div id="result-6" class="proposition" data-note-number="6" data-note-kind="Proposition">
<p><strong>Proposition 6</strong>.  {% raw %}<span class="math inline">\(\widehat p\)</span>{% endraw %} is an isomorphism.</p>

</div>
<div class="proof">
<p><em>Proof.</em> First, {% raw %}<span class="math inline">\(\widehat p\)</span>{% endraw %} is a homomorphism between groups. Let {% raw %}<span class="math inline">\([f], [g] \in \pi_1(M,p_0)\)</span>{% endraw %}. Then, by associativity of {% raw %}<span class="math inline">\(\star\)</span>{% endraw %}, </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \widehat p([f] \star [g]) &amp;= [p^*] \star [f] \star [g] \star [p] \\
        &amp;= [p^*] \star [f] \star ([e_{p_0}] \star [g]) \star [p] \\
        &amp;= [p^*] \star [f] \star ([p] \star [p^*] \star [g]) \star [p] \\
        &amp;= ([p^*] \star [f] \star [p]) \star ([p^*] \star [g]) \star [p] \\
        &amp;= \widehat p([f]) \star \widehat p([g]) ~.
    
\end{aligned}\]</div>{% endraw %}
<p> Then, note that if {% raw %}<span class="math inline">\(\widetilde g \in \pi_1(M,p_1)\)</span>{% endraw %}, we have that {% raw %}<span class="math inline">\([p] \star [\widetilde g] \star [p^*]\)</span>{% endraw %} is the homotopy class of a loop in {% raw %}<span class="math inline">\(M\)</span>{% endraw %} based at {% raw %}<span class="math inline">\(p_0\)</span>{% endraw %}. Then it follows </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \widehat p([p] \star [\widetilde g] \star [p^*]) = [p^*] \star ([p] \star [\widetilde g] \star [p^*]) \star [p] = [\widetilde g] ~.
    
\end{aligned}\]</div>{% endraw %}
<p> This shows the surjectivity of {% raw %}<span class="math inline">\(\widehat p\)</span>{% endraw %}. For the injectivity of {% raw %}<span class="math inline">\(\widehat p\)</span>{% endraw %}, suppose {% raw %}<span class="math inline">\(\widehat p([f]) = \widehat p([g])\)</span>{% endraw %}. It follows that </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \widehat p([f]) = [p^*] \star[f] \star [p] = [p^*] \star [g] \star [p] = \widehat p([g])
    
\end{aligned}\]</div>{% endraw %}
<p> implies </p>

{% raw %}<div class="math display">\[\begin{aligned}
       [p] \star ([p^*] \star[f] \star [p]) \star [p^*] &amp;= [p] \star ([p^*] \star [g] \star [p]) \star [p^*] \\
       ([p] \star [p^*]) \star[f] \star ([p] \star [p^*]) &amp;= ([p] \star [p^*]) \star [g] \star ([p] \star [p^*]) \\
       [f] &amp;= [g] ~.
    
\end{aligned}\]</div>{% endraw %}
<p> Therefore, {% raw %}<span class="math inline">\(\widehat p\)</span>{% endraw %} is injective, and this concludes the proof. ◻</p>

</div>
<p>For another path {% raw %}<span class="math inline">\(q:p_0\to p_1\)</span>{% endraw %}, let {% raw %}<span class="math inline">\(h=q^*\star p\)</span>{% endraw %}, a loop at {% raw %}<span class="math inline">\(p_1\)</span>{% endraw %}. Direct cancellation of reverse paths gives {% raw %}<span class="math inline">\(\widehat q([f])=[h]\star\widehat p([f])\star[h]^{-1}\)</span>{% endraw %}. The two identifications therefore differ by an inner automorphism. This is why omitting the base point records the group only up to isomorphism; in an abelian fundamental group the inner automorphism is trivial.</p>

<p>We can then conclude the following.</p>

<div id="result-7" class="corollary" data-note-number="7" data-note-kind="Corollary">
<p><strong>Corollary 7</strong>.  For {% raw %}<span class="math inline">\(p_0, p_1 \in M\)</span>{% endraw %}, if there exists a path connecting {% raw %}<span class="math inline">\(p_0\)</span>{% endraw %} and {% raw %}<span class="math inline">\(p_1\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(\pi_1(M,p_0)\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\pi_1(M,p_1)\)</span>{% endraw %} are isomorphic.</p>

</div>
<div id="def:simply-connected" class="definition" data-note-number="8" data-note-kind="Definition">
<p><strong>Definition 8</strong>. A manifold {% raw %}<span class="math inline">\(M\)</span>{% endraw %} is <em>simply connected</em> if it is path-connected and its fundamental group {% raw %}<span class="math inline">\(\pi_1(M,p)\)</span>{% endraw %} is trivial for one, equivalently every, base point {% raw %}<span class="math inline">\(p\)</span>{% endraw %}.</p>
</div>
<div id="result-9" class="remark" data-note-number="9" data-note-kind="Remark">
<p><strong>Remark 9</strong>. A continuous map {% raw %}<span class="math inline">\(f:M\to N\)</span>{% endraw %} induces a group homomorphism</p>
{% raw %}<div class="math display">\[f_\#: \pi_1(M,p)\longrightarrow\pi_1(N,f(p)),\qquad f_\#([c])=[f\circ c].\]</div>{% endraw %}
<p>Composing a path homotopy with {% raw %}<span class="math inline">\(f\)</span>{% endraw %} shows this is well-defined. Since {% raw %}<span class="math inline">\(f\circ(c\star d)=(f\circ c)\star(f\circ d)\)</span>{% endraw %}, it respects multiplication. It need not be injective or surjective: a constant map sends every loop class to the identity. A homeomorphism does induce an isomorphism, because its inverse induces the inverse homomorphism.</p>
<p>For a connected manifold {% raw %}<span class="math inline">\(M\)</span>{% endraw %}, the covering-space existence theorem states that each subgroup {% raw %}<span class="math inline">\(H\le\pi_1(M,p)\)</span>{% endraw %} is realized by a connected covering {% raw %}<span class="math inline">\(\pi:X\to M\)</span>{% endraw %} and a <em>chosen</em> point {% raw %}<span class="math inline">\(x\in\pi^{-1}(p)\)</span>{% endraw %} with {% raw %}<span class="math inline">\(\pi_\#\pi_1(X,x)=H\)</span>{% endraw %}. The manifold is locally path-connected and semilocally simply connected, as required by <a href="https://pi.math.cornell.edu/~hatcher/AT/ATch1.pdf">Hatcher, Proposition 1.36</a>. Other points of the fibre can give conjugate subgroups, so equality with {% raw %}<span class="math inline">\(H\)</span>{% endraw %} is not asserted at every lift. For {% raw %}<span class="math inline">\(H=\{1\}\)</span>{% endraw %}, the connected covering is simply connected and is called the universal covering.</p>
</div>
<p>We now turn to covering spaces. Once the starting point above a path is chosen, local inverse maps determine its lift; the same principle applies to homotopies.</p>

<div id="def:lift-of-path" class="definition" data-note-number="10" data-note-kind="Definition">
<p><strong>Definition 10</strong>.  Let {% raw %}<span class="math inline">\(\pi : X \to M\)</span>{% endraw %} be a covering of {% raw %}<span class="math inline">\(M\)</span>{% endraw %}, {% raw %}<span class="math inline">\(c : [0,1] \to M\)</span>{% endraw %} be a path, and {% raw %}<span class="math inline">\(x_0 \in \pi^{-1} (c(0))\)</span>{% endraw %}. Then, there exists a unique path {% raw %}<span class="math inline">\(\widetilde c: [0,1] \to X\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(\widetilde c(0) = x_0\)</span>{% endraw %} and {% raw %}<span class="math inline">\(c(t) = \pi(\widetilde c(t))\)</span>{% endraw %}. {% raw %}<span class="math inline">\(\widetilde c\)</span>{% endraw %} is called the <em>lift of {% raw %}<span class="math inline">\(c\)</span>{% endraw %} through {% raw %}<span class="math inline">\(x_0\)</span>{% endraw %}</em>.</p>

</div>
<div id="result-11" class="remark" data-note-number="11" data-note-kind="Remark">
<p><strong>Remark 11.</strong> (Lifting criterion.) Let {% raw %}<span class="math inline">\(M&#39;\)</span>{% endraw %} be a <strong>connected</strong> manifold, {% raw %}<span class="math inline">\(f:(M&#39;,y_0)\to(M,p_0)\)</span>{% endraw %} continuous, and {% raw %}<span class="math inline">\(\pi:(X,x_0)\to(M,p_0)\)</span>{% endraw %} a covering. A lift {% raw %}<span class="math inline">\(\widetilde f\)</span>{% endraw %} with {% raw %}<span class="math inline">\(\widetilde f(y_0)=x_0\)</span>{% endraw %} exists exactly when</p>
{% raw %}<div class="math display">\[f_\#\pi_1(M&#39;,y_0)\subset\pi_\#\pi_1(X,x_0).\]</div>{% endraw %}

<p>It is then unique. The group on the right belongs to the covering space {% raw %}<span class="math inline">\(X\)</span>{% endraw %}, not the base {% raw %}<span class="math inline">\(M\)</span>{% endraw %}.</p>
<p><strong>Proof, using the lifting lemma proved below.</strong> Necessity follows by applying fundamental groups to {% raw %}<span class="math inline">\(f=\pi\widetilde f\)</span>{% endraw %}. A loop at {% raw %}<span class="math inline">\(p_0\)</span>{% endraw %} lifts to a loop at {% raw %}<span class="math inline">\(x_0\)</span>{% endraw %} exactly when its class lies in {% raw %}<span class="math inline">\(\pi_\#\pi_1(X,x_0)\)</span>{% endraw %}: one implication follows by projection; the other follows by lifting an endpoint-fixing homotopy from a projected loop. Under the stated inclusion, choose a path {% raw %}<span class="math inline">\(a\)</span>{% endraw %} from {% raw %}<span class="math inline">\(y_0\)</span>{% endraw %} to {% raw %}<span class="math inline">\(y\)</span>{% endraw %} and define {% raw %}<span class="math inline">\(\widetilde f(y)\)</span>{% endraw %} as the endpoint of the lift of {% raw %}<span class="math inline">\(f\circ a\)</span>{% endraw %} from {% raw %}<span class="math inline">\(x_0\)</span>{% endraw %}. For two such paths {% raw %}<span class="math inline">\(a,b\)</span>{% endraw %}, the loop {% raw %}<span class="math inline">\(a\star b^*\)</span>{% endraw %} has image lifting to a loop, so the two endpoints agree. This defines {% raw %}<span class="math inline">\(\widetilde f\)</span>{% endraw %} independently of choices.</p>
<p>Near {% raw %}<span class="math inline">\(y\)</span>{% endraw %}, choose a path-connected neighbourhood {% raw %}<span class="math inline">\(W\)</span>{% endraw %} mapped by {% raw %}<span class="math inline">\(f\)</span>{% endraw %} into an evenly covered set {% raw %}<span class="math inline">\(U\)</span>{% endraw %}. Paths from {% raw %}<span class="math inline">\(y\)</span>{% endraw %} to points of {% raw %}<span class="math inline">\(W\)</span>{% endraw %} show that {% raw %}<span class="math inline">\(\widetilde f|_W=(\pi|_{\widetilde U})^{-1}\circ f\)</span>{% endraw %} for the sheet containing {% raw %}<span class="math inline">\(\widetilde f(y)\)</span>{% endraw %}, proving continuity. Any lift must have these same endpoints along paths from {% raw %}<span class="math inline">\(y_0\)</span>{% endraw %}, proving uniqueness. Connected manifolds are path-connected and locally path-connected, supplying exactly the properties used here. For disconnected domains one must specify data and check the criterion on each component. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>
<p>The same lifting argument proves that {% raw %}<span class="math inline">\(\pi_\#\)</span>{% endraw %} is injective: a loop upstairs whose projection is null-homotopic lifts that null-homotopy, so is itself null-homotopic.</p>
</div>

<div id="def:deck-transformation" class="definition" data-note-number="12" data-note-kind="Definition">
<p><strong>Definition 12</strong>.  Let {% raw %}<span class="math inline">\(\pi : \widetilde M \to M\)</span>{% endraw %} be the universal covering of {% raw %}<span class="math inline">\(M\)</span>{% endraw %}. A <em>deck transformation</em> is a homeomorphism {% raw %}<span class="math inline">\(\varphi : \widetilde M \to \widetilde M\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(\pi = \pi \circ \varphi\)</span>{% endraw %}.</p>

</div>
<p>For a connected universal cover and a chosen {% raw %}<span class="math inline">\(x_0\)</span>{% endraw %} above {% raw %}<span class="math inline">\(p_0\)</span>{% endraw %}, lifting gives a bijection between {% raw %}<span class="math inline">\(\pi_1(M,p_0)\)</span>{% endraw %} and the fibre {% raw %}<span class="math inline">\(\pi^{-1}(p_0)\)</span>{% endraw %}. Surjectivity follows by projecting a path upstairs from {% raw %}<span class="math inline">\(x_0\)</span>{% endraw %} to a chosen fibre point. Two projected paths give the same class exactly when their lifts have the same endpoint: in the converse direction, concatenate one lift with the reverse of the other and use simple connectedness upstairs.</p>
<p>The <strong>group of deck transformations</strong>, with composition, acts freely and transitively on this fibre. Indeed, the lifting criterion applied to the map {% raw %}<span class="math inline">\(\pi:\widetilde M\to M\)</span>{% endraw %} gives a unique lift {% raw %}<span class="math inline">\(T:\widetilde M\to\widetilde M\)</span>{% endraw %} taking {% raw %}<span class="math inline">\(x_0\)</span>{% endraw %} to any prescribed point {% raw %}<span class="math inline">\(x&#39;\)</span>{% endraw %} of the fibre. A lift in the reverse direction exists as well; uniqueness makes the two composites identities, so {% raw %}<span class="math inline">\(T\)</span>{% endraw %} is a homeomorphism. A deck map fixing {% raw %}<span class="math inline">\(x_0\)</span>{% endraw %} is the identity by uniqueness. Under the path model, the deck map associated with a loop {% raw %}<span class="math inline">\(a\)</span>{% endraw %} sends {% raw %}<span class="math inline">\([\gamma]\)</span>{% endraw %} to {% raw %}<span class="math inline">\([a\star\gamma]\)</span>{% endraw %}, so {% raw %}<span class="math inline">\(T_a\circ T_b=T_{a\star b}\)</span>{% endraw %} with our convention for path products. This identifies the deck group with {% raw %}<span class="math inline">\(\pi_1(M,p_0)\)</span>{% endraw %}. The fibre is a set on which this group acts freely and transitively; it has no distinguished identity until a lift {% raw %}<span class="math inline">\(x_0\)</span>{% endraw %} is chosen. A single deck transformation need not act transitively by itself.</p>

<div id="ex:fundamental-group" class="example" data-note-number="13" data-note-kind="Example">
<p><strong>Example 13</strong> (Fundamental groups).  Fundamental groups are notoriously difficult to determine. In simple spaces, we can explicitly determine them. For example, {% raw %}<span class="math inline">\(\pi_1(\mathbb R^n) = \{1\}\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\pi_1(\mathbb S^n) = \{1\}\)</span>{% endraw %} for {% raw %}<span class="math inline">\(n \geq 2\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\pi_1(\operatorname{SO}(n)) = \mathbb Z_2\)</span>{% endraw %} for {% raw %}<span class="math inline">\(n \geq 3\)</span>{% endraw %}. Perhaps the most interesting, {% raw %}<span class="math inline">\(\pi_1(\mathbb S^1) = \mathbb Z\)</span>{% endraw %}, and the generator is {% raw %}<span class="math inline">\(c(t) = (\cos 2\pi t, \sin 2\pi t)\)</span>{% endraw %}; the universal covering of {% raw %}<span class="math inline">\(\mathbb S^1\)</span>{% endraw %} is {% raw %}<span class="math inline">\(\mathbb R\)</span>{% endraw %}.</p>

</div>
<p>For {% raw %}<span class="math inline">\(\mathbb R^n\)</span>{% endraw %}, the straight-line homotopy {% raw %}<span class="math inline">\((1-s)c(t)+sc(0)\)</span>{% endraw %} contracts every based loop. For {% raw %}<span class="math inline">\(\mathbb S^n\)</span>{% endraw %}, {% raw %}<span class="math inline">\(n\ge2\)</span>{% endraw %}, subdivide a loop into pieces lying in small geodesically convex balls and homotope each piece, fixing its endpoints, to the short geodesic between them. The resulting finite union of arcs misses a point of the sphere. Stereographic projection from that point reduces its contraction to the Euclidean case, keeping the base point fixed.</p>
<p>For the additional example {% raw %}<span class="math inline">\(\operatorname{SO}(n)\)</span>{% endraw %}, {% raw %}<span class="math inline">\(n\ge3\)</span>{% endraw %}, a standard external input is its CW structure: the two-skeleton is {% raw %}<span class="math inline">\(\mathbb{RP}^2\)</span>{% endraw %}, and remaining cells have dimension at least three (<a href="https://pi.math.cornell.edu/~hatcher/AT/AT.pdf">Hatcher, Proposition 3D.1, pp. 295–296</a>). Thus its presentation has one generator and the relation that its square is the identity; higher-dimensional cells do not alter {% raw %}<span class="math inline">\(\pi_1\)</span>{% endraw %}. This gives {% raw %}<span class="math inline">\(\mathbb Z/2\mathbb Z\)</span>{% endraw %}.</p>

<h3 data-note-section="1" id="fundamental-group-of-mathbb-s1">1. Fundamental Group of {% raw %}<span class="math inline">\(\mathbb S^1\)</span>{% endraw %}</h3>
<p>Algorithmic statements require a specified finite input. The Adian–Rabin theorem implies that no algorithm decides whether the group specified by an arbitrary <strong>finite presentation</strong> is trivial; see <a href="https://arxiv.org/pdf/2208.08560">Adian’s papers in Nyberg-Brodda’s translation, theorem and example (iii), p. 3</a>. For each fixed dimension {% raw %}<span class="math inline">\(n\ge4\)</span>{% endraw %}, effective constructions realize such presentations as fundamental groups of closed triangulated {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-manifolds, so deciding simple connectedness in that class is also impossible. The construction uses a presentation two-complex and the boundary of a regular neighbourhood in {% raw %}<span class="math inline">\(\mathbb R^{n+1}\)</span>{% endraw %}; see <a href="https://cjhb.site/Files.php/HTML/Computational%20Topology/References/Computability%20Theory%20and%20Differential%20Geometry.pdf">Soare, §3.3, pp. 7–8 of the December 2003 manuscript</a>. This does not assert undecidability in every dimension or for every restricted family of manifolds. We now compute the circle’s group explicitly.</p>

<div id="thm:fundamental-group-S1" class="theorem" data-note-number="14" data-note-kind="Theorem">
<p><strong>Theorem 14</strong>.  {% raw %}<span class="math inline">\(\pi_1(\mathbb S^1)\)</span>{% endraw %} is an infinite cyclic group generated by homotopy class of the loop {% raw %}<span class="math inline">\(c(t) = (\cos 2\pi t, \sin 2\pi t)\)</span>{% endraw %} with base point {% raw %}<span class="math inline">\((1,0)\)</span>{% endraw %}.</p>

</div>
<p>With the ongoing notations, note that {% raw %}<span class="math inline">\([c]^n = [c_n] = [(\cos 2\pi nt, \sin 2\pi nt)]\)</span>{% endraw %} for all {% raw %}<span class="math inline">\(n \in \mathbb Z\)</span>{% endraw %}. Therefore, the statement of Theorem <a href="#thm:fundamental-group-S1" data-reference-type="ref" data-reference="thm:fundamental-group-S1">14</a> is equivalent to showing that <em>every</em> loop in {% raw %}<span class="math inline">\(\mathbb S^1\)</span>{% endraw %} based at {% raw %}<span class="math inline">\((1,0)\)</span>{% endraw %} is homotopic to {% raw %}<span class="math inline">\(c_n\)</span>{% endraw %} for some unique {% raw %}<span class="math inline">\(n \in \mathbb Z\)</span>{% endraw %}. The strategy of proving this equivalent statement is the following. Define {% raw %}<span class="math inline">\(\widetilde c_n(t) = nt\)</span>{% endraw %}, {% raw %}<span class="math inline">\(c_n = p \circ \widetilde c_n\)</span>{% endraw %}, where {% raw %}<span class="math inline">\(p\)</span>{% endraw %} is the projection of the embedding {% raw %}<span class="math inline">\(t \mapsto (\cos 2\pi t, \sin 2\pi t, t)\)</span>{% endraw %} onto the first two coordinates. Clearly, {% raw %}<span class="math inline">\(p\)</span>{% endraw %} is a covering map for {% raw %}<span class="math inline">\(\mathbb S^1\)</span>{% endraw %}. Then, we need to show the following properties of a covering map {% raw %}<span class="math inline">\(p : \widetilde M \to M\)</span>{% endraw %} (for any manifold {% raw %}<span class="math inline">\(M\)</span>{% endraw %}): for all paths {% raw %}<span class="math inline">\(f : I \to M\)</span>{% endraw %} starting at {% raw %}<span class="math inline">\(x_0 \in M\)</span>{% endraw %}, and for all {% raw %}<span class="math inline">\(\widetilde x_0 \in p^{-1}(x_0)\)</span>{% endraw %}, there exists a unique lift {% raw %}<span class="math inline">\(\widetilde f : I \to \widetilde M\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(\widetilde f\)</span>{% endraw %} starts at {% raw %}<span class="math inline">\(\widetilde x_0\)</span>{% endraw %}. Additionally, for all homotopy fixed at {% raw %}<span class="math inline">\(s\)</span>{% endraw %}, denoted {% raw %}<span class="math inline">\(H_s : I \to X : (s,t) \mapsto c_s(t)\)</span>{% endraw %}, where each curve in a homotopy class starts at {% raw %}<span class="math inline">\(x_0 \in X\)</span>{% endraw %}, for all {% raw %}<span class="math inline">\(\widetilde x_0 \in p^{-1}(x_0)\)</span>{% endraw %}, there exists a unique lifted homotopy {% raw %}<span class="math inline">\(\widetilde H_s\)</span>{% endraw %} of paths starting at {% raw %}<span class="math inline">\(\widetilde x_0\)</span>{% endraw %}. We deduce these facts from a more general claim.</p>

<div id="lem:extension-lifting-map" class="lemma" data-note-number="15" data-note-kind="Lemma">
<p><strong>Lemma 15.</strong> Let {% raw %}<span class="math inline">\(p:\widetilde M\to M\)</span>{% endraw %} be a covering, {% raw %}<span class="math inline">\(Y\)</span>{% endraw %} any topological space, and {% raw %}<span class="math inline">\(F:Y\times I\to M\)</span>{% endraw %} continuous. Given a <strong>continuous</strong> lift {% raw %}<span class="math inline">\(a:Y\to\widetilde M\)</span>{% endraw %} of {% raw %}<span class="math inline">\(F(\cdot,0)\)</span>{% endraw %}, there is a unique continuous {% raw %}<span class="math inline">\(\widetilde F:Y\times I\to\widetilde M\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(p\widetilde F=F\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\widetilde F(y,0)=a(y)\)</span>{% endraw %}.</p>
<p><strong>Proof.</strong> Fix {% raw %}<span class="math inline">\(y_0\)</span>{% endraw %}. By continuity and compactness of {% raw %}<span class="math inline">\(I\)</span>{% endraw %}, there are a neighbourhood {% raw %}<span class="math inline">\(N\)</span>{% endraw %} of {% raw %}<span class="math inline">\(y_0\)</span>{% endraw %} and a subdivision {% raw %}<span class="math inline">\(0=t_0&lt;\cdots&lt;t_m=1\)</span>{% endraw %} such that every {% raw %}<span class="math inline">\(F(N\times[t_i,t_{i+1}])\)</span>{% endraw %} lies in an evenly covered open set {% raw %}<span class="math inline">\(U_i\)</span>{% endraw %}. To obtain this subdivision, cover {% raw %}<span class="math inline">\(\{y_0\}\times I\)</span>{% endraw %} by finitely many product neighbourhoods with this property, use a Lebesgue number for their time intervals, and intersect their neighbourhoods in {% raw %}<span class="math inline">\(Y\)</span>{% endraw %}.</p>
<p>At {% raw %}<span class="math inline">\(t_0\)</span>{% endraw %}, choose the sheet {% raw %}<span class="math inline">\(\widetilde U_0\)</span>{% endraw %} containing {% raw %}<span class="math inline">\(a(y_0)\)</span>{% endraw %} and shrink {% raw %}<span class="math inline">\(N\)</span>{% endraw %} so that {% raw %}<span class="math inline">\(a(N)\subset\widetilde U_0\)</span>{% endraw %}. Define the lift on the first strip by {% raw %}<span class="math inline">\((p|_{\widetilde U_0})^{-1}\circ F\)</span>{% endraw %}. At step {% raw %}<span class="math inline">\(i\)</span>{% endraw %}, the already constructed boundary value {% raw %}<span class="math inline">\(y\mapsto\widetilde F(y,t_i)\)</span>{% endraw %} is continuous. Choose the sheet over {% raw %}<span class="math inline">\(U_i\)</span>{% endraw %} containing its value at {% raw %}<span class="math inline">\(y_0\)</span>{% endraw %} and shrink {% raw %}<span class="math inline">\(N\)</span>{% endraw %} so that all these boundary values lie in that sheet. Its inverse branch defines the next strip and agrees on the shared boundary. Finitely many shrinkings and the pasting lemma produce a continuous lift on {% raw %}<span class="math inline">\(N\times I\)</span>{% endraw %}.</p>
<p>For a single path, two lifts with the same start stay in the same sheet on each such subinterval: a connected path image contained in the disjoint union of sheets lies entirely in one sheet. Injectivity of {% raw %}<span class="math inline">\(p\)</span>{% endraw %} on that sheet gives equality, successively on all subintervals. Thus lifts are unique pointwise on each {% raw %}<span class="math inline">\(\{y\}\times I\)</span>{% endraw %}. Consequently the constructions for different neighbourhoods {% raw %}<span class="math inline">\(N\)</span>{% endraw %} agree on every overlap and glue to a continuous global lift. The same path uniqueness proves global uniqueness. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>
</div>
<div id="cor:to-lem:extension-lifting-map" class="corollary" data-note-number="16" data-note-kind="Corollary">
<p><strong>Corollary 16.</strong> Every path has a unique lift from a prescribed starting point. Every endpoint-fixing homotopy {% raw %}<span class="math inline">\(H(s,t)\)</span>{% endraw %} of paths has a unique lift whose paths start at a prescribed lift {% raw %}<span class="math inline">\(\widetilde x_0\)</span>{% endraw %} of the common initial point; the endpoints of the lifted paths are independent of {% raw %}<span class="math inline">\(s\)</span>{% endraw %}.</p>
<p><strong>Proof.</strong> The first assertion is Lemma 15 with {% raw %}<span class="math inline">\(Y\)</span>{% endraw %} a point. For the second, take {% raw %}<span class="math inline">\(Y=I\)</span>{% endraw %} with coordinate {% raw %}<span class="math inline">\(s\)</span>{% endraw %}, use {% raw %}<span class="math inline">\(t\)</span>{% endraw %} as the lifting time, and prescribe {% raw %}<span class="math inline">\(\widetilde H(s,0)=\widetilde x_0\)</span>{% endraw %}. The map {% raw %}<span class="math inline">\(s\mapsto\widetilde H(s,1)\)</span>{% endraw %} is continuous and lies in the discrete fibre above the common terminal point, so it is constant. The constant edges are {% raw %}<span class="math inline">\(I\times\{0\}\)</span>{% endraw %} and {% raw %}<span class="math inline">\(I\times\{1\}\)</span>{% endraw %}, not the two edges parametrizing the original paths. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>
</div>
<p><strong>Proof of Theorem 14.</strong> Write {% raw %}<span class="math inline">\(p(u)=e^{2\pi iu}\)</span>{% endraw %}. Short open arcs in the circle have inverse images consisting of disjoint translates of an interval of length less than one, on each of which {% raw %}<span class="math inline">\(p\)</span>{% endraw %} is a homeomorphism. Thus {% raw %}<span class="math inline">\(p:\mathbb R\to\mathbb S^1\)</span>{% endraw %} is a covering, and it is universal because {% raw %}<span class="math inline">\(\mathbb R\)</span>{% endraw %} is simply connected.</p>
<p>For a loop {% raw %}<span class="math inline">\(f\)</span>{% endraw %} based at {% raw %}<span class="math inline">\(1\)</span>{% endraw %}, let {% raw %}<span class="math inline">\(\widetilde f\)</span>{% endraw %} be its lift from zero. Its endpoint {% raw %}<span class="math inline">\(n=\widetilde f(1)\)</span>{% endraw %} is an integer. Define</p>
{% raw %}<div class="math display">\[H(s,t)=p\big((1-s)\widetilde f(t)+snt\big).\]</div>{% endraw %}

<p>This is a homotopy from {% raw %}<span class="math inline">\(f\)</span>{% endraw %} to {% raw %}<span class="math inline">\(c_n(t)=e^{2\pi int}\)</span>{% endraw %}, with {% raw %}<span class="math inline">\(H(s,0)=H(s,1)=1\)</span>{% endraw %}. If {% raw %}<span class="math inline">\(f\)</span>{% endraw %} and {% raw %}<span class="math inline">\(g\)</span>{% endraw %} are based-homotopic, Corollary 16 makes their lifted endpoints equal. Conversely, equal endpoints give the displayed linear homotopy. Hence the endpoint gives a bijection {% raw %}<span class="math inline">\(w:\pi_1(\mathbb S^1,1)\to\mathbb Z\)</span>{% endraw %}.</p>
<p>To check the group law explicitly, if {% raw %}<span class="math inline">\(w(f)=m\)</span>{% endraw %} and {% raw %}<span class="math inline">\(w(g)=n\)</span>{% endraw %}, a lift of {% raw %}<span class="math inline">\(f\star g\)</span>{% endraw %} is {% raw %}<span class="math inline">\(\widetilde f(2t)\)</span>{% endraw %} for {% raw %}<span class="math inline">\(t\le1/2\)</span>{% endraw %} and {% raw %}<span class="math inline">\(m+\widetilde g(2t-1)\)</span>{% endraw %} for {% raw %}<span class="math inline">\(t\ge1/2\)</span>{% endraw %}. Its endpoint is {% raw %}<span class="math inline">\(m+n\)</span>{% endraw %}, so {% raw %}<span class="math inline">\(w\)</span>{% endraw %} is an isomorphism. The once-around loop has endpoint one and generates the group. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>
<p>For loops at any other point of the circle, the same integer is the difference between terminal and initial lift values; multiplication by a fixed unit complex number reduces this to the base point {% raw %}<span class="math inline">\(1\)</span>{% endraw %}.</p>
<p>Theorem 14 has the following applications.</p>

<div id="thm:fundamental-thm-algebra" class="theorem" data-note-number="17" data-note-kind="Theorem">
<p><strong>Theorem 17</strong> (Fundamental theorem of algebra).  Every nonconstant polynomial with coefficients in {% raw %}<span class="math inline">\(\mathbb C\)</span>{% endraw %} has a root in {% raw %}<span class="math inline">\(\mathbb C\)</span>{% endraw %}.</p>

</div>
<p><strong>Proof.</strong> Divide by the leading coefficient and write {% raw %}<span class="math inline">\(p(z)=z^n+a_1z^{n-1}+\cdots+a_n\)</span>{% endraw %} with {% raw %}<span class="math inline">\(n\ge1\)</span>{% endraw %}. Suppose {% raw %}<span class="math inline">\(p\)</span>{% endraw %} never vanishes. For {% raw %}<span class="math inline">\(r\ge0\)</span>{% endraw %}, put</p>
{% raw %}<div class="math display">\[f_r(t)=\frac{p(re^{2\pi it})/p(r)}{|p(re^{2\pi it})/p(r)|}.\]</div>{% endraw %}

<p>The denominator is nonzero, and {% raw %}<span class="math inline">\(f_r(0)=f_r(1)=1\)</span>{% endraw %}. For fixed {% raw %}<span class="math inline">\(R\)</span>{% endraw %}, {% raw %}<span class="math inline">\((s,t)\mapsto f_{sR}(t)\)</span>{% endraw %} is a continuous based homotopy from the constant loop {% raw %}<span class="math inline">\(f_0\)</span>{% endraw %} to {% raw %}<span class="math inline">\(f_R\)</span>{% endraw %}, so {% raw %}<span class="math inline">\(w(f_R)=0\)</span>{% endraw %}.</p>
<p>Choose {% raw %}<span class="math inline">\(R&gt;\max\{1,\sum_j|a_j|\}\)</span>{% endraw %}. On {% raw %}<span class="math inline">\(|z|=R\)</span>{% endraw %},</p>
{% raw %}<div class="math display">\[\left|\sum_{j=1}^n a_jz^{n-j}\right|\le\sum_{j=1}^n|a_j|R^{n-j}\le R^{n-1}\sum_{j=1}^n|a_j|&lt;R^n.\]</div>{% endraw %}

<p>Thus {% raw %}<span class="math inline">\(p_s(z)=z^n+s\sum_j a_jz^{n-j}\)</span>{% endraw %} never vanishes on this circle for {% raw %}<span class="math inline">\(0\le s\le1\)</span>{% endraw %}, including at {% raw %}<span class="math inline">\(z=R\)</span>{% endraw %}. Replacing {% raw %}<span class="math inline">\(p\)</span>{% endraw %} by {% raw %}<span class="math inline">\(p_s\)</span>{% endraw %} in the formula for {% raw %}<span class="math inline">\(f_R\)</span>{% endraw %} therefore gives a based homotopy from {% raw %}<span class="math inline">\(c_n\)</span>{% endraw %} at {% raw %}<span class="math inline">\(s=0\)</span>{% endraw %} to {% raw %}<span class="math inline">\(f_R\)</span>{% endraw %} at {% raw %}<span class="math inline">\(s=1\)</span>{% endraw %}. This is a homotopy of loops, not a deformation retraction. It gives {% raw %}<span class="math inline">\(n=w(c_n)=w(f_R)=0\)</span>{% endraw %}, contradicting {% raw %}<span class="math inline">\(n\ge1\)</span>{% endraw %}. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>

<div id="thm:borsuk-ulam" class="theorem" data-note-number="18" data-note-kind="Theorem">
<p><strong>Theorem 18</strong> (Borsuk-Ulam; dimension {% raw %}<span class="math inline">\(2\)</span>{% endraw %}).  For every continuous map {% raw %}<span class="math inline">\(f : \mathbb S^2 \to \mathbb R^2\)</span>{% endraw %}, there exists a pair of antipodal points {% raw %}<span class="math inline">\(x\)</span>{% endraw %} and {% raw %}<span class="math inline">\(-x\)</span>{% endraw %} in {% raw %}<span class="math inline">\(\mathbb S^2\)</span>{% endraw %} with {% raw %}<span class="math inline">\(f(x)=f(-x)\)</span>{% endraw %}.</p>

</div>
<div id="result-19" class="remark" data-note-number="19" data-note-kind="Remark">
<p><strong>Remark 19</strong>.  The general Borsuk–Ulam theorem (an external result; see <a href="https://pi.math.cornell.edu/~hatcher/AT/AT.pdf">Hatcher, Corollary 2B.7, p. 176</a>) is true for any dimension {% raw %}<span class="math inline">\(n \geq 1\)</span>{% endraw %}. In dimension {% raw %}<span class="math inline">\(1\)</span>{% endraw %}, the statement is straightforward to verify, since the difference {% raw %}<span class="math inline">\(f(x)- f(-x)\)</span>{% endraw %} changes sign as {% raw %}<span class="math inline">\(x\)</span>{% endraw %} goes halfway around the circle, hence this difference must be zero for some {% raw %}<span class="math inline">\(x\)</span>{% endraw %} by the intermediate value theorem. For {% raw %}<span class="math inline">\(n \geq 2\)</span>{% endraw %}, the theorem is certainly less obvious. The theorem also says in particular that there is no one-to-one continuous map from {% raw %}<span class="math inline">\(\mathbb S^2\)</span>{% endraw %} to {% raw %}<span class="math inline">\(\mathbb R^2\)</span>{% endraw %}, so {% raw %}<span class="math inline">\(\mathbb S^2\)</span>{% endraw %} is not homeomorphic to a subspace of {% raw %}<span class="math inline">\(\mathbb R^2\)</span>{% endraw %}. While heuristically true, this is hard to verify directly.</p>

</div>
<p><strong>Proof of Theorem 18.</strong> If {% raw %}<span class="math inline">\(f(x)\ne f(-x)\)</span>{% endraw %} everywhere, then</p>
{% raw %}<div class="math display">\[g(x)=\frac{f(x)-f(-x)}{|f(x)-f(-x)|}\]</div>{% endraw %}

<p>is a continuous map {% raw %}<span class="math inline">\(\mathbb S^2\to\mathbb S^1\)</span>{% endraw %} satisfying {% raw %}<span class="math inline">\(g(-x)=-g(x)\)</span>{% endraw %}. Restrict to the equator {% raw %}<span class="math inline">\(e(t)=(\cos2\pi t,\sin2\pi t,0)\)</span>{% endraw %} and put {% raw %}<span class="math inline">\(h=g\circ e\)</span>{% endraw %}. Then {% raw %}<span class="math inline">\(h(t+1/2)=-h(t)\)</span>{% endraw %} for {% raw %}<span class="math inline">\(0\le t\le1/2\)</span>{% endraw %}. Lift {% raw %}<span class="math inline">\(h\)</span>{% endraw %} to {% raw %}<span class="math inline">\(\widetilde h:I\to\mathbb R\)</span>{% endraw %}. Since {% raw %}<span class="math inline">\(p(u+1/2)=-p(u)\)</span>{% endraw %},</p>
{% raw %}<div class="math display">\[\widetilde h(t+1/2)-\widetilde h(t)\in\frac12+\mathbb Z.\]</div>{% endraw %}

<p>This difference is continuous on a connected interval and takes values in a discrete set, so it is a constant {% raw %}<span class="math inline">\(r/2\)</span>{% endraw %} with {% raw %}<span class="math inline">\(r\)</span>{% endraw %} odd. Applying it at {% raw %}<span class="math inline">\(t=0\)</span>{% endraw %} and {% raw %}<span class="math inline">\(t=1/2\)</span>{% endraw %} gives {% raw %}<span class="math inline">\(\widetilde h(1)-\widetilde h(0)=r\)</span>{% endraw %}. Thus {% raw %}<span class="math inline">\(h\)</span>{% endraw %} has nonzero winding number.</p>
<p>On the other hand, the equator bounds the upper hemisphere, a disk. Its boundary loop contracts in that disk while fixing its base point: identify the hemisphere with the closed unit disk and use the linear homotopy from the boundary loop to its initial boundary point. Composing this homotopy with {% raw %}<span class="math inline">\(g\)</span>{% endraw %} makes {% raw %}<span class="math inline">\(h\)</span>{% endraw %} based null-homotopic, so its winding number is zero. This contradiction proves the claim. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>

<div id="result-20" class="proposition" data-note-number="20" data-note-kind="Proposition">
<p><strong>Proposition 20</strong>.  {% raw %}<span class="math inline">\(\pi_1(X \times Y)\)</span>{% endraw %} is isomorphic to {% raw %}<span class="math inline">\(\pi_1(X) \times \pi_1(Y)\)</span>{% endraw %} if {% raw %}<span class="math inline">\(X\)</span>{% endraw %} and {% raw %}<span class="math inline">\(Y\)</span>{% endraw %} are path-connected.</p>

</div>
<div class="proof">
<p><em>Proof.</em> This is the consequence of a fact about product topology: a map {% raw %}<span class="math inline">\(f: Z \to X \times Y\)</span>{% endraw %}, defined by {% raw %}<span class="math inline">\(f(z) = (g(z), h(z))\)</span>{% endraw %}, is continuous if and only if the maps {% raw %}<span class="math inline">\(g: Z \to X\)</span>{% endraw %} and {% raw %}<span class="math inline">\(h: Z \to Y\)</span>{% endraw %} are both continuous. Therefore, a loop {% raw %}<span class="math inline">\(f\)</span>{% endraw %} in {% raw %}<span class="math inline">\(X \times Y\)</span>{% endraw %} based at {% raw %}<span class="math inline">\((x_0, y_0)\)</span>{% endraw %} is equivalent to a pair of loops {% raw %}<span class="math inline">\(g\)</span>{% endraw %} in {% raw %}<span class="math inline">\(X\)</span>{% endraw %} and {% raw %}<span class="math inline">\(h\)</span>{% endraw %} in {% raw %}<span class="math inline">\(Y\)</span>{% endraw %} based at {% raw %}<span class="math inline">\(x_0\)</span>{% endraw %} and {% raw %}<span class="math inline">\(y_0\)</span>{% endraw %}, respectively.</p>

<p>Similarly, a homotopy {% raw %}<span class="math inline">\(f_s\)</span>{% endraw %} of a loop in {% raw %}<span class="math inline">\(X \times Y\)</span>{% endraw %} is equivalent to a pair of homotopies {% raw %}<span class="math inline">\(g_t\)</span>{% endraw %} and {% raw %}<span class="math inline">\(h_t\)</span>{% endraw %} of the corresponding loops {% raw %}<span class="math inline">\(g\)</span>{% endraw %} and {% raw %}<span class="math inline">\(h\)</span>{% endraw %} in {% raw %}<span class="math inline">\(X\)</span>{% endraw %} and {% raw %}<span class="math inline">\(Y\)</span>{% endraw %}, respectively. Therefore, we have a bijection that maps {% raw %}<span class="math inline">\([f]\)</span>{% endraw %} to {% raw %}<span class="math inline">\(([g],[h])\)</span>{% endraw %}. The inverse sends a pair of loop classes to the class of their pointwise pair. Endpoint-fixing homotopies pair in the same way, so both maps are well-defined. Concatenation is coordinatewise, which proves that the bijection is a group homomorphism. ◻</p>
