<div class="note-content" markdown="0">

<p>Conditioning on an event of positive probability gives a ratio of probabilities. Conditioning on a continuously distributed observation cannot generally be defined by a ratio at a single observed value, because that event may have probability zero. Conditional expectation avoids this division: it is specified by the information it can depend on and the integrals it must preserve.</p>

<div id="conditioning" data-note-section="title">

</div>

<div id="result-1" class="remark" data-note-number="1" data-note-kind="Remark">
<p><strong>Remark 1</strong>. For any event {% raw %}<span class="math inline">\(\{X\in A\}\)</span>{% endraw %} of positive probability, the function</p>

</div>
{% raw %}<div class="math display">\[F(y\mid X\in A)=\frac{P(X\in A,Y\leq y)}{P(X\in A)}\]</div>{% endraw %}<p>is a valid distribution function, whether or not {% raw %}<span class="math inline">\(X,Y\)</span>{% endraw %} are independent. The difficulty arises when conditioning on a single value {% raw %}<span class="math inline">\(X=x\)</span>{% endraw %} of probability zero. For real random variables, a regular conditional distribution {% raw %}<span class="math inline">\(K(x,\cdot)\)</span>{% endraw %} gives the precise replacement:</p>

{% raw %}<div class="math display">\[P(X\in A,Y\leq y)=\int_AK(x,(-\infty,y])\,P_X(dx).\]</div>{% endraw %}<p>The kernel is determined only for {% raw %}<span class="math inline">\(P_X\)</span>{% endraw %}-almost every {% raw %}<span class="math inline">\(x\)</span>{% endraw %}. Independence allows a version constant in {% raw %}<span class="math inline">\(x\)</span>{% endraw %}; it is not needed for the integral identity.</p>

<p>The information available after an observation is described by a sigma-field. Rather than beginning with the joint distribution of random variables {% raw %}<span class="math inline">\(X\)</span>{% endraw %} and {% raw %}<span class="math inline">\(Y\)</span>{% endraw %} directly, we can represent our limited knowledge of the distribution of {% raw %}<span class="math inline">\(Y\)</span>{% endraw %} by specifying a {% raw %}<span class="math inline">\(\sigma\)</span>{% endraw %}-field of events {% raw %}<span class="math inline">\(\mathscr G \subset \mathscr F\)</span>{% endraw %} such that, for all {% raw %}<span class="math inline">\(G \in \mathscr G\)</span>{% endraw %}, we know whether the outcome belongs to {% raw %}<span class="math inline">\(G\)</span>{% endraw %}. To make this concrete, we need to know about subfields, and what it means for a random variable to be measurable with respect to a subfield.</p>

<p>Recall that a random variable {% raw %}<span class="math inline">\(X\)</span>{% endraw %} is measurable with respect to a {% raw %}<span class="math inline">\(\sigma\)</span>{% endraw %}-field {% raw %}<span class="math inline">\(\mathscr G \subset \mathscr F\)</span>{% endraw %} if {% raw %}<span class="math inline">\(X^{-1} (B) = \{ \omega : X(\omega) \in B \} \in \mathscr G\)</span>{% endraw %} for all Borel measurable {% raw %}<span class="math inline">\(B\)</span>{% endraw %}. For a random variable {% raw %}<span class="math inline">\(X\)</span>{% endraw %}, there is a “smallest {% raw %}<span class="math inline">\(\sigma\)</span>{% endraw %}-field” with respect to which {% raw %}<span class="math inline">\(X\)</span>{% endraw %} is measurable; formally, that is the intersection of all {% raw %}<span class="math inline">\(\sigma\)</span>{% endraw %}-fields with respect to which {% raw %}<span class="math inline">\(X\)</span>{% endraw %} is measurable. Denote this “smallest” {% raw %}<span class="math inline">\(\sigma\)</span>{% endraw %}-field using {% raw %}<span class="math inline">\(\sigma(X)\)</span>{% endraw %}. The next result concerns how this information changes when a measurable function is applied to an observation.</p>


<div id="result-2" class="theorem" data-note-number="2" data-note-kind="Theorem">
<p><strong>Theorem 2</strong>. Let {% raw %}<span class="math inline">\(X\)</span>{% endraw %} be real valued, let {% raw %}<span class="math inline">\(g:\mathbb R\to\mathbb R\)</span>{% endraw %} be Borel, and put {% raw %}<span class="math inline">\(Y=g(X)\)</span>{% endraw %}. Then {% raw %}<span class="math inline">\(\sigma(Y)\subseteq\sigma(X)\)</span>{% endraw %}. Equality holds if and only if there is a Borel {% raw %}<span class="math inline">\(h:\mathbb R\to\mathbb R\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(X=h(Y)\)</span>{% endraw %} everywhere. After adjoining all ambient probability-zero sets to both sigma-fields, the analogous statement holds modulo null sets, with the representation required almost surely.</p>

</div>
<div class="proof">
<p><em>Proof.</em> Measurability of composition gives the inclusion. If the sigma-fields agree, the measurable-factorisation result for real random variables gives {% raw %}<span class="math inline">\(X=h(Y)\)</span>{% endraw %}. Conversely, this representation gives {% raw %}<span class="math inline">\(\sigma(X)\subseteq\sigma(Y)\)</span>{% endraw %}. A global Borel isomorphism is sufficient but unnecessary: when {% raw %}<span class="math inline">\(X\)</span>{% endraw %} is constant, both generated sigma-fields are trivial even for a constant {% raw %}<span class="math inline">\(g\)</span>{% endraw %}.</p>

<p>◻</p>
</div>
<p>For a countable partition, observing the experiment tells us which cell contains the outcome. Conditional probabilities are therefore constant on each cell. The sigma-field formulation extends this description beyond countable partitions. Let {% raw %}<span class="math inline">\((\Omega, \mathscr F, \mathop{\mathrm{\mathbf{P}}})\)</span>{% endraw %} be the underlying probability space for this discussion. Let {% raw %}<span class="math inline">\(\mathscr H\)</span>{% endraw %} be a {% raw %}<span class="math inline">\(\sigma\)</span>{% endraw %}-field generated by a partition {% raw %}<span class="math inline">\(B_1, B_2, \dots\)</span>{% endraw %}. This means an element of {% raw %}<span class="math inline">\(\mathscr H\)</span>{% endraw %} is of the form {% raw %}<span class="math inline">\(\bigcup_{k \in \mathbb N} B_{n_k}\)</span>{% endraw %}, which can be a finite or countably infinite union of {% raw %}<span class="math inline">\(B_1, B_2, \dots\)</span>{% endraw %}. The question is, given {% raw %}<span class="math inline">\(\omega \in \Omega\)</span>{% endraw %}, how do we know which set {% raw %}<span class="math inline">\(B_n\)</span>{% endraw %} contains {% raw %}<span class="math inline">\(\omega\)</span>{% endraw %}? By this construction, the answer to this question is the same as that of which element of {% raw %}<span class="math inline">\(\mathscr H\)</span>{% endraw %} contains {% raw %}<span class="math inline">\(\omega\)</span>{% endraw %}; it turns out the latter question is well-defined even if {% raw %}<span class="math inline">\(\mathscr H \subset \mathscr F\)</span>{% endraw %}, and when {% raw %}<span class="math inline">\(\mathscr H\)</span>{% endraw %} is not generated from a partition, as above (generally, it is not the case that {% raw %}<span class="math inline">\(\mathscr H\)</span>{% endraw %} is generated from a partition). The well-definedness comes from the following heuristic: given {% raw %}<span class="math inline">\(\omega \in \Omega\)</span>{% endraw %}, we can systematically identify, for each {% raw %}<span class="math inline">\(H \in \mathscr H\)</span>{% endraw %}, whether {% raw %}<span class="math inline">\(\omega \in H\)</span>{% endraw %} or {% raw %}<span class="math inline">\(\omega \in H^c\)</span>{% endraw %}. Thus, in principle, we can identify {% raw %}<span class="math inline">\(\mathscr H\)</span>{% endraw %} with an experiment.</p>

<p>The Radon–Nikodym theorem provides the conditional probability once we specify its integrals over all observable events. Thinking of {% raw %}<span class="math inline">\(\mathscr H\)</span>{% endraw %} as an experiment, we define {% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbf{P}}}(A \mid \mathscr H)\)</span>{% endraw %} for every {% raw %}<span class="math inline">\(A \in \mathscr F\)</span>{% endraw %}, as follows. Fixing an event {% raw %}<span class="math inline">\(A \in \mathscr F\)</span>{% endraw %}, define a (finite!) measure on {% raw %}<span class="math inline">\(\mathscr H\)</span>{% endraw %} via the formula </p>

{% raw %}<div class="math display">\[\mathbf Q(H) = \mathop{\mathrm{\mathbf{P}}}(A \cap H) \quad \text{for } H \in \mathscr H ~.\]</div>{% endraw %}
<p> This is well-defined, again, because {% raw %}<span class="math inline">\(\mathscr H \subset \mathscr F\)</span>{% endraw %}. In particular, this means {% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbf{P}}}(H) = 0\)</span>{% endraw %} implies {% raw %}<span class="math inline">\(\mathbf Q(H) = 0\)</span>{% endraw %}. Therefore, applying the Radon-Nikodym theorem (Theorem <a href="{% post_url 2021-11-29-the-radon-nikodym-theorem %}#thm:radon-nikodym" data-reference-type="ref" data-reference="thm:radon-nikodym">3</a>), there exists a random variable {% raw %}<span class="math inline">\(f\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbf{P}}}(A \cap H) = \mathbf Q(H) = \int_H f \dif \mathop{\mathrm{\mathbf{P}}}\)</span>{% endraw %}. Here, {% raw %}<span class="math inline">\(f\)</span>{% endraw %} is {% raw %}<span class="math inline">\(\mathscr H\)</span>{% endraw %}-measurable and integrable with respect to {% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbf{P}}}\)</span>{% endraw %}. Note that the Radon-Nikodym theorem does apply because {% raw %}<span class="math inline">\(\mathbf Q \ll \mathop{\mathrm{\mathbf{P}}}\)</span>{% endraw %}: by a restriction argument, let {% raw %}<span class="math inline">\(\tilde{\mathop{\mathrm{\mathbf{P}}}}\)</span>{% endraw %} be the restriction of {% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbf{P}}}\)</span>{% endraw %} to {% raw %}<span class="math inline">\(\mathscr H \subset \mathscr F\)</span>{% endraw %}. Clearly, {% raw %}<span class="math inline">\(\int_H f \dif \mathop{\mathrm{\mathbf{P}}}= \int_H f \dif \tilde{\mathop{\mathrm{\mathbf{P}}}}\)</span>{% endraw %} for all {% raw %}<span class="math inline">\(H \in \mathscr H\)</span>{% endraw %}. Take {% raw %}<span class="math inline">\(\dif \mathbf Q = f \dif \tilde{\mathop{\mathrm{\mathbf{P}}}}\)</span>{% endraw %} to conclude.</p>

<p>The construction determines an observable random variable through its averages over observable events. Thus {% raw %}<span class="math inline">\(f\)</span>{% endraw %} is usually denoted {% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbf{P}}}(A \mid \mathscr H)\)</span>{% endraw %}, which is a random variable, satisfying the following properties:</p>

<ol>
<li><p>{% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbf{P}}}(A \mid \mathscr H)\)</span>{% endraw %} is {% raw %}<span class="math inline">\(\mathscr H\)</span>{% endraw %}-measurable and integrable.</p></li>
<li><p>The following functional equation is satisfied: </p>

{% raw %}<div class="math display">\[\mathop{\mathrm{\mathbf{P}}}(A \cap H) = \int_H \mathop{\mathrm{\mathbf{P}}}(A \mid \mathscr H) \dif \mathop{\mathrm{\mathbf{P}}}\quad \text{for all } H \in \mathscr H ~.\]</div>{% endraw %}</li>
</ol>
<p>This construction does not give pointwise uniqueness of {% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbf{P}}}(A \mid \mathscr H)\)</span>{% endraw %}; in fact, there are generally many such random variables that agree with each other, with probability one. We call one of these random variables a <em>version</em> of the conditional probability.</p>

<div id="result-3" class="remark" data-note-number="3" data-note-kind="Remark">
<p><strong>Remark 3</strong>.  A set {% raw %}<span class="math inline">\(A \in \mathscr F\)</span>{% endraw %} is, by definition, independent of the {% raw %}<span class="math inline">\(\sigma\)</span>{% endraw %}-field {% raw %}<span class="math inline">\(\mathscr H\)</span>{% endraw %} if it is independent of every {% raw %}<span class="math inline">\(H \in \mathscr H\)</span>{% endraw %}, in the usual sense: {% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbf{P}}}(A \cap H) = \mathop{\mathrm{\mathbf{P}}}(A) \mathop{\mathrm{\mathbf{P}}}(H)\)</span>{% endraw %}. The product on the right equals {% raw %}<span class="math inline">\(\int_H \mathop{\mathrm{\mathbf{P}}}(A) \dif \mathop{\mathrm{\mathbf{P}}}\)</span>{% endraw %}. Therefore, {% raw %}<span class="math inline">\(A\)</span>{% endraw %} is independent of {% raw %}<span class="math inline">\(\mathscr H\)</span>{% endraw %} if and only if {% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbf{P}}}(A \mid \mathscr H) = \mathop{\mathrm{\mathbf{P}}}(A)\)</span>{% endraw %} with probability one.</p>

</div>
<div id="prop:properties-conditional-prob" class="proposition" data-note-number="4" data-note-kind="Proposition">
<p><strong>Proposition 4</strong>. For each fixed event in the assertion below, the following identities and bounds hold almost surely: {% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbf{P}}}(\emptyset \mid \mathscr H) = 0\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbf{P}}}(\Omega \mid \mathscr H) = 1\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbf{P}}}(A \mid \mathscr H) \in [0,1]\)</span>{% endraw %} for all {% raw %}<span class="math inline">\(A \in \mathscr F\)</span>{% endraw %}. Furthermore, if {% raw %}<span class="math inline">\(A_1,A_2,\dots\)</span>{% endraw %} is a finite or countably infinite sequence of disjoint sets, then </p>

{% raw %}<div class="math display">\[\mathop{\mathrm{\mathbf{P}}}\left( \bigcup_{n \in \mathbb N} A_n \, \Bigg| \, \mathscr H \right) = \sum_{n \in \mathbb N} \mathop{\mathrm{\mathbf{P}}}(A_n \mid \mathscr H)\]</div>{% endraw %}
<p> with probability one.</p>

</div>
<div class="proof">
<p><em>Proof.</em> The constant functions zero and one have the required defining integrals for {% raw %}<span class="math inline">\(\varnothing\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\Omega\)</span>{% endraw %}. The Radon–Nikodym construction gives {% raw %}<span class="math inline">\(P(A\mid\mathscr H)\geq0\)</span>{% endraw %} almost surely. Also {% raw %}<span class="math inline">\(P(A\mid\mathscr H)+P(A^c\mid\mathscr H)\)</span>{% endraw %} has the same integrals as the constant one, so uniqueness gives the upper bound one.</p>
<p>For a fixed disjoint sequence {% raw %}<span class="math inline">\((A_n)\)</span>{% endraw %}, choose nonnegative versions {% raw %}<span class="math inline">\(Z_n=P(A_n\mid\mathscr H)\)</span>{% endraw %}. The sum {% raw %}<span class="math inline">\(Z=\sum_nZ_n\)</span>{% endraw %} is measurable, and monotone convergence gives, for every {% raw %}<span class="math inline">\(H\in\mathscr H\)</span>{% endraw %},</p>
{% raw %}<div class="math display">\[\int_HZ\,dP=\sum_nP(H\cap A_n)=P\left(H\cap\bigcup_nA_n\right).\]</div>{% endraw %}
<p>Taking {% raw %}<span class="math inline">\(H=\Omega\)</span>{% endraw %} shows {% raw %}<span class="math inline">\(Z\)</span>{% endraw %} is integrable and finite almost surely. Uniqueness makes it a version of the conditional probability of the union. The exceptional null set may depend on the fixed event or countable family. These statements alone do not give a single null set valid for every event in an uncountable sigma-field; Theorem 6 supplies compatible versions when the events arise from one real random variable. ◻</p>
</div>
<div id="prop:properties-conditional-prob-2" class="proposition" data-note-number="5" data-note-kind="Proposition">
<p><strong>Proposition 5</strong>. For each fixed choice of the events or sequence below, almost surely:</p>

<ol>
<li><p>If {% raw %}<span class="math inline">\(A, B \in \mathscr F\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(A \subset B\)</span>{% endraw %}, then </p>

{% raw %}<div class="math display">\[\begin{aligned}
            \mathop{\mathrm{\mathbf{P}}}(B \setminus A \mid \mathscr H) &amp;= \mathop{\mathrm{\mathbf{P}}}(B \mid \mathscr H) - \mathop{\mathrm{\mathbf{P}}}(A \mid \mathscr H) ~, \\
            \mathop{\mathrm{\mathbf{P}}}(A \mid \mathscr H) &amp;\leq \mathop{\mathrm{\mathbf{P}}}(B \mid \mathscr H) ~.
        
\end{aligned}\]</div>{% endraw %}</li>
<li><p>{% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbf{P}}}(A) = 0\)</span>{% endraw %} implies {% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbf{P}}}(A \mid \mathscr H) = 0\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbf{P}}}(A) = 1\)</span>{% endraw %} implies {% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbf{P}}}(A \mid \mathscr H) = 1\)</span>{% endraw %}.</p></li>
<li><p>(Inclusion-Exclusion) </p>

{% raw %}<div class="math display">\[\mathop{\mathrm{\mathbf{P}}}\left( \bigcup_{1 \leq n \leq N} A_n \, \Bigg| \, \mathscr H \right) = \sum_{1 \leq i \leq N} \mathop{\mathrm{\mathbf{P}}}(A_i \mid \mathscr H) - \sum_{1 \leq i &lt; j \leq N} \mathop{\mathrm{\mathbf{P}}}(A_i \cap A_j \mid \mathscr H) + \cdots\]</div>{% endraw %}</li>
<li><p>If {% raw %}<span class="math inline">\(A_n \uparrow A\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbf{P}}}(A_n \mid \mathscr H) \uparrow \mathop{\mathrm{\mathbf{P}}}(A \mid \mathscr H)\)</span>{% endraw %}.</p></li>
<li><p>If {% raw %}<span class="math inline">\(A_n \downarrow A\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbf{P}}}(A_n \mid \mathscr H) \downarrow \mathop{\mathrm{\mathbf{P}}}(A \mid \mathscr H)\)</span>{% endraw %}.</p></li>
</ol>
</div>
<div class="proof">
<p><em>Proof.</em> Apply disjoint additivity to {% raw %}<span class="math inline">\(B=A\sqcup(B\setminus A)\)</span>{% endraw %}; nonnegativity gives monotonicity. If {% raw %}<span class="math inline">\(P(A)=0\)</span>{% endraw %}, the nonnegative variable {% raw %}<span class="math inline">\(P(A\mid\mathscr H)\)</span>{% endraw %} has expectation zero and is therefore zero almost surely. The case {% raw %}<span class="math inline">\(P(A)=1\)</span>{% endraw %} follows by complements.</p>
<p>For inclusion–exclusion, the finite indicator identity holds pointwise. Replace each indicator by its conditional probability and integrate over any {% raw %}<span class="math inline">\(H\in\mathscr H\)</span>{% endraw %}; the integrals still agree, so uniqueness gives the displayed identity. If {% raw %}<span class="math inline">\(A_n\uparrow A\)</span>{% endraw %}, apply disjoint additivity to {% raw %}<span class="math inline">\(A_1,A_2\setminus A_1,A_3\setminus A_2,\ldots\)</span>{% endraw %}. Its partial sums are versions of {% raw %}<span class="math inline">\(P(A_n\mid\mathscr H)\)</span>{% endraw %}, and its full sum is a version of {% raw %}<span class="math inline">\(P(A\mid\mathscr H)\)</span>{% endraw %}. Countably many almost-sure equalities can be imposed on one common probability-one event, proving the increasing-limit assertion. Apply it to complements for decreasing sequences. ◻</p>
</div>
<div id="thm:existence-cond-prob-dist" class="theorem" data-note-number="6" data-note-kind="Theorem">
<p><strong>Theorem 6</strong> (Existence of Conditional Probability Distribution).  Let {% raw %}<span class="math inline">\(X\)</span>{% endraw %} be a random variable on {% raw %}<span class="math inline">\((\Omega,\mathscr F,\mathop{\mathrm{\mathbf{P}}})\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(\mathscr H \subset \mathscr F\)</span>{% endraw %} be a {% raw %}<span class="math inline">\(\sigma\)</span>{% endraw %}-field. Then, there exists a function {% raw %}<span class="math inline">\(\mu(B,\omega)\)</span>{% endraw %}, defined for each {% raw %}<span class="math inline">\(B \in \mathscr B_{\mathbb R}\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\omega \in \Omega\)</span>{% endraw %}, such that</p>

<ol>
<li><p>for each {% raw %}<span class="math inline">\(\omega \in \Omega\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\mu(\cdot,\omega)\)</span>{% endraw %} is a probability measure on {% raw %}<span class="math inline">\(\mathscr B_{\mathbb R}\)</span>{% endraw %}; and</p></li>
<li><p>for each {% raw %}<span class="math inline">\(B \in \mathscr B_{\mathbb R}\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\mu(B,\cdot)\)</span>{% endraw %} is a version of {% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbf{P}}}(X \in B \mid \mathscr H)\)</span>{% endraw %}.</p></li>
</ol>
</div>
<div class="proof">
<p><em>Proof.</em> Choose a version {% raw %}<span class="math inline">\(f_q=P(X\leq q\mid\mathscr H)\)</span>{% endraw %} for each rational {% raw %}<span class="math inline">\(q\)</span>{% endraw %}. Proposition 5 implies, almost surely, that these versions lie in {% raw %}<span class="math inline">\([0,1]\)</span>{% endraw %}, are nondecreasing in {% raw %}<span class="math inline">\(q\)</span>{% endraw %}, satisfy</p>
{% raw %}<div class="math display">\[\lim_{m\to\infty}f_{-m}=0,\qquad\lim_{m\to\infty}f_m=1,\qquad
f_q=\inf_{r\in\mathbb Q,\ r&gt;q}f_r\quad(q\in\mathbb Q).\]</div>{% endraw %}
<p>For the last identity, use a fixed rational sequence decreasing to each {% raw %}<span class="math inline">\(q\)</span>{% endraw %} and continuity from above. There are only countably many rational comparisons and limits here. Their exceptional sets have a union {% raw %}<span class="math inline">\(N\in\mathscr H\)</span>{% endraw %} with {% raw %}<span class="math inline">\(P(N)=0\)</span>{% endraw %}. On {% raw %}<span class="math inline">\(N\)</span>{% endraw %}, redefine every {% raw %}<span class="math inline">\(f_q\)</span>{% endraw %} to be {% raw %}<span class="math inline">\(\mathbf1_{\{q\geq0\}}\)</span>{% endraw %}. All the displayed properties now hold at every {% raw %}<span class="math inline">\(\omega\)</span>{% endraw %}.</p>
<p>For real {% raw %}<span class="math inline">\(x\)</span>{% endraw %}, set {% raw %}<span class="math inline">\(F_\omega(x)=\inf_{q\in\mathbb Q,\ q&gt;x}f_q(\omega)\)</span>{% endraw %}. This is nondecreasing, tends to zero and one at the two ends, and is right-continuous. For the last property, if {% raw %}<span class="math inline">\(x_j\downarrow x\)</span>{% endraw %}, the rational sets {% raw %}<span class="math inline">\(\{q:q&gt;x_j\}\)</span>{% endraw %} increase to {% raw %}<span class="math inline">\(\{q:q&gt;x\}\)</span>{% endraw %}, so their infima decrease to the stated infimum. Thus {% raw %}<span class="math inline">\(F_\omega\)</span>{% endraw %} is a distribution function and determines a unique probability measure {% raw %}<span class="math inline">\(\mu(\cdot,\omega)\)</span>{% endraw %}. On rational arguments {% raw %}<span class="math inline">\(F_\omega(q)=f_q(\omega)\)</span>{% endraw %}.</p>
<p>Let {% raw %}<span class="math inline">\(\mathcal D\)</span>{% endraw %} be the Borel sets {% raw %}<span class="math inline">\(B\)</span>{% endraw %} for which {% raw %}<span class="math inline">\(\omega\mapsto\mu(B,\omega)\)</span>{% endraw %} is {% raw %}<span class="math inline">\(\mathscr H\)</span>{% endraw %}-measurable and</p>
{% raw %}<div class="math display">\[\int_H\mu(B,\omega)\,P(d\omega)=P(H\cap\{X\in B\})\qquad(H\in\mathscr H).\]</div>{% endraw %}
<p>The preceding construction puts every rational lower half-line in {% raw %}<span class="math inline">\(\mathcal D\)</span>{% endraw %}. The class contains {% raw %}<span class="math inline">\(\mathbb R\)</span>{% endraw %}, is closed under complements by subtracting from one, and under disjoint countable unions by pointwise countable additivity and monotone convergence. It is a Dynkin class. Rational lower half-lines form a generating pi-system, so {% raw %}<span class="math inline">\(\mathcal D=\mathcal B(\mathbb R)\)</span>{% endraw %}. This proves both assertions.</p>
<p>In particular, conditioning a real {% raw %}<span class="math inline">\(Y\)</span>{% endraw %} on {% raw %}<span class="math inline">\(\sigma(X)\)</span>{% endraw %} yields the kernel in Remark 1. Factor each rational conditional probability as {% raw %}<span class="math inline">\(f_q=g_q(X)\)</span>{% endraw %} with Borel {% raw %}<span class="math inline">\(g_q\)</span>{% endraw %}, using measurable factorization. Perform the same countable correction on a Borel set of {% raw %}<span class="math inline">\(P_X\)</span>{% endraw %}-measure zero in the {% raw %}<span class="math inline">\(x\)</span>{% endraw %}-space. The construction above then gives {% raw %}<span class="math inline">\(K(x,B)\)</span>{% endraw %}, Borel in {% raw %}<span class="math inline">\(x\)</span>{% endraw %} for every Borel {% raw %}<span class="math inline">\(B\)</span>{% endraw %}, with the required integral identities. Two such kernels agree outside one {% raw %}<span class="math inline">\(P_X\)</span>{% endraw %}-null set: first compare their rational half-line probabilities, then use uniqueness of a probability measure from those probabilities. ◻</p>
</div>
<h3 data-note-section="1" id="conditional-expectation">1. Conditional Expectation</h3>
<p>Conditional probability is the conditional expectation of an indicator. To extend the construction to general integrable random variables, preserve the same two requirements: measurability with respect to the available information, and equality of integrals over every event in that information. As always, let {% raw %}<span class="math inline">\((\Omega, \mathscr F, \mathop{\mathrm{\mathbf{P}}})\)</span>{% endraw %} be the underlying probability space; without further qualifications, every random variable defined below is assumed to be defined on this probability space.</p>

<p>Let {% raw %}<span class="math inline">\(X\)</span>{% endraw %} be an integrable real random variable, and let {% raw %}<span class="math inline">\(\mathscr G\subseteq\mathscr F\)</span>{% endraw %} be a sigma-field.</p>

<div id="def:conditional-expectation" class="definition" data-note-number="7" data-note-kind="Definition">
<p><strong>Definition 7</strong>.  A random variable, denoted {% raw %}<span class="math inline">\(\mathbb{E}[X \mid \mathscr G]\)</span>{% endraw %}, exists, and is called the <em>conditional expectation of {% raw %}<span class="math inline">\(X\)</span>{% endraw %} given {% raw %}<span class="math inline">\(\mathscr G\)</span>{% endraw %}</em>. This random variable satisfies the following conditions:</p>

<ol>
<li><p>{% raw %}<span class="math inline">\(\mathbb{E}[X \mid \mathscr G]\)</span>{% endraw %} is {% raw %}<span class="math inline">\(\mathscr G\)</span>{% endraw %}-measurable and integrable; and</p></li>
<li><p>{% raw %}<span class="math inline">\(\mathbb{E}[X \mid \mathscr G]\)</span>{% endraw %} satisfies </p>

{% raw %}<div class="math display">\[\int_G \mathbb{E}[X \mid \mathscr G] \dif \mathop{\mathrm{\mathbf{P}}}= \int_G X \dif \mathop{\mathrm{\mathbf{P}}}\quad \text{for all } G \in \mathscr G ~.\]</div>{% endraw %}</li>
</ol>
</div>
<p>The existence of conditional expectation follows from the Radon-Nikodym theorem (Theorem <a href="{% post_url 2021-11-29-the-radon-nikodym-theorem %}#thm:radon-nikodym" data-reference-type="ref" data-reference="thm:radon-nikodym">3</a>). The measure to which the theorem is applied is obtained by integrating the random variable over observable events. First consider the case where {% raw %}<span class="math inline">\(X \geq 0\)</span>{% endraw %}. Then, the measure {% raw %}<span class="math inline">\(\mathbf Q(G) = \int_G X \dif \mathop{\mathrm{\mathbf{P}}}\)</span>{% endraw %}, defined for all {% raw %}<span class="math inline">\(G \in \mathscr G\)</span>{% endraw %}, is absolutely continuous with respect to {% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbf{P}}}\)</span>{% endraw %}, and is finite (because {% raw %}<span class="math inline">\(X\)</span>{% endraw %} is integrable!). By the Radon-Nikodym theorem, this density {% raw %}<span class="math inline">\(f\)</span>{% endraw %} has the required properties in Definition <a href="#def:conditional-expectation" data-reference-type="ref" data-reference="def:conditional-expectation">7</a>. Then, in the general case where {% raw %}<span class="math inline">\(X\)</span>{% endraw %} is not necessarily nonnegative, by definition {% raw %}<span class="math inline">\(X^+ = \max(X,0)\)</span>{% endraw %} and {% raw %}<span class="math inline">\(X^- = -\min(X,0)\)</span>{% endraw %}, it follows directly that {% raw %}<span class="math inline">\(\mathbb{E}[X^+ \mid \mathscr G] - \mathbb{E}[X^- \mid \mathscr G]\)</span>{% endraw %} has the desired properties in Definition <a href="#def:conditional-expectation" data-reference-type="ref" data-reference="def:conditional-expectation">7</a>.</p>

<p>Two cases make the definition concrete. For a simple random variable, conditional expectation is a linear combination of conditional probabilities. For a sigma-field generated by a partition, it is constant on each cell and equals the average over that cell.</p>

<ol>
<li><p>Let {% raw %}<span class="math inline">\(X = \sum_{1 \leq i \leq n} a_i \mathbb 1_{A_i}\)</span>{% endraw %}, where {% raw %}<span class="math inline">\(\{A_i\}_{1 \leq i \leq n}\)</span>{% endraw %} are events. For each {% raw %}<span class="math inline">\(\mathbb 1_{A_i}\)</span>{% endraw %}, the defining properties of {% raw %}<span class="math inline">\(\mathbb{E}[\mathbb 1_{A_i} \mid \mathscr G]\)</span>{% endraw %} <em>and</em> conditional probability {% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbf{P}}}(A_i \mid \mathscr G)\)</span>{% endraw %} coincide. This means {% raw %}<span class="math inline">\(\mathbb{E}[X \mid \mathscr G] = \sum_{1 \leq i \leq n} a_i \mathop{\mathrm{\mathbf{P}}}(A_i \mid \mathscr G)\)</span>{% endraw %}.</p></li>
<li><p>If {% raw %}<span class="math inline">\(\mathscr G\)</span>{% endraw %} is a {% raw %}<span class="math inline">\(\sigma\)</span>{% endraw %}-field generated from {% raw %}<span class="math inline">\(B_1,B_2,\dots\)</span>{% endraw %}, where {% raw %}<span class="math inline">\(\{B_1,B_2,\dots\}\)</span>{% endraw %} is a finite or countably infinite partition of {% raw %}<span class="math inline">\(\Omega\)</span>{% endraw %}, then it follows that {% raw %}<span class="math inline">\(\mathbb{E}[X \mid \mathscr G]\)</span>{% endraw %} has a constant value over each {% raw %}<span class="math inline">\(B_i\)</span>{% endraw %} (note that {% raw %}<span class="math inline">\(\mathbb{E}[X \mid \mathscr G]\)</span>{% endraw %} is, by definition, {% raw %}<span class="math inline">\(\mathscr G\)</span>{% endraw %}-measurable). Call this constant value {% raw %}<span class="math inline">\(b_i\)</span>{% endraw %}. The second condition in Definition <a href="#def:conditional-expectation" data-reference-type="ref" data-reference="def:conditional-expectation">7</a> then implies </p>

{% raw %}<div class="math display">\[(\mathbb{E}[X \mid \mathscr G])_\omega = (\mathop{\mathrm{\mathbf{P}}}(B_i))^{-1} \int_{B_i} X \dif \mathop{\mathrm{\mathbf{P}}}\quad \text{for } \omega \in B_i \text{ and } \mathop{\mathrm{\mathbf{P}}}(B_i) &gt; 0 ~.\]</div>{% endraw %}
<p> If {% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbf{P}}}(B_i)=0\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(\mathbb{E}[X \mid \mathscr G]\)</span>{% endraw %} takes some arbitrary constant.</p></li>
</ol>
<div id="prop:properties-conditional-expectation" class="proposition" data-note-number="8" data-note-kind="Proposition">
<p><strong>Proposition 8</strong> (Properties of Conditional Expectation).  Let {% raw %}<span class="math inline">\(X\)</span>{% endraw %}, {% raw %}<span class="math inline">\(X_n\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(Y\)</span>{% endraw %} be integrable random variables, and {% raw %}<span class="math inline">\(a,b\)</span>{% endraw %} be constants.</p>

<ol>
<li><p>If {% raw %}<span class="math inline">\(X = a\)</span>{% endraw %} with probability one, then {% raw %}<span class="math inline">\(\mathbb{E}[X \mid \mathscr G] = a\)</span>{% endraw %}.</p></li>
<li><p>If {% raw %}<span class="math inline">\(X \leq Y\)</span>{% endraw %} with probability one, then {% raw %}<span class="math inline">\(\mathbb{E}[X \mid \mathscr G] \leq \mathbb{E}[Y \mid \mathscr G]\)</span>{% endraw %}.</p></li>
<li><p>(Linearity) {% raw %}<span class="math inline">\(\mathbb{E}[aX + bY \mid \mathscr G] = a \mathbb{E}[X \mid \mathscr G] + b \mathbb{E}[Y \mid \mathscr G]\)</span>{% endraw %}.</p></li>
<li><p>{% raw %}<span class="math inline">\(|\mathbb{E}[X \mid \mathscr G]| \leq \mathbb{E}[|X| \mid \mathscr G]\)</span>{% endraw %}.</p></li>
<li><p>If {% raw %}<span class="math inline">\(X_n \xrightarrow{n\to\infty} X\)</span>{% endraw %} with probability one, and {% raw %}<span class="math inline">\(|X_n| \leq Y\)</span>{% endraw %} for all {% raw %}<span class="math inline">\(n \in \mathbb N\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(\mathbb{E}[X_n \mid \mathscr G] \xrightarrow{n\to\infty} \mathbb{E}[X \mid \mathscr G]\)</span>{% endraw %} with probability one.</p></li>
</ol>
</div>
<div class="proof">
<p><em>Proof.</em></p>

<p>First note uniqueness: if integrable {% raw %}<span class="math inline">\(\mathscr G\)</span>{% endraw %}-measurable {% raw %}<span class="math inline">\(U,V\)</span>{% endraw %} have the same integrals over every {% raw %}<span class="math inline">\(G\in\mathscr G\)</span>{% endraw %}, integrate {% raw %}<span class="math inline">\(U-V\)</span>{% endraw %} on {% raw %}<span class="math inline">\(\{U&gt;V\}\)</span>{% endraw %} and {% raw %}<span class="math inline">\(V-U\)</span>{% endraw %} on {% raw %}<span class="math inline">\(\{V&gt;U\}\)</span>{% endraw %}. Both nonnegative integrals vanish, so {% raw %}<span class="math inline">\(U=V\)</span>{% endraw %} almost surely. The constant {% raw %}<span class="math inline">\(a\)</span>{% endraw %} itself satisfies the defining identity in (i). For (iii), the proposed linear combination is measurable and integrable, and integrating it over any {% raw %}<span class="math inline">\(G\)</span>{% endraw %} gives {% raw %}<span class="math inline">\(\int_G(aX+bY)\,dP\)</span>{% endraw %}; uniqueness proves linearity.</p>
<p>For (ii), the Radon–Nikodym construction gives a nonnegative version of {% raw %}<span class="math inline">\(\mathbb E(Y-X\mid\mathscr G)\)</span>{% endraw %} when {% raw %}<span class="math inline">\(Y-X\geq0\)</span>{% endraw %}. Apply linearity to obtain the order inequality. Since {% raw %}<span class="math inline">\(-|X|\leq X\leq|X|\)</span>{% endraw %}, applying that inequality twice proves (iv). Taking {% raw %}<span class="math inline">\(G=\Omega\)</span>{% endraw %} in the defining identity also gives {% raw %}<span class="math inline">\(\mathbb E\mathbb E(X\mid\mathscr G)=\mathbb EX\)</span>{% endraw %}. These facts imply the useful contraction</p>
{% raw %}<div class="math display">\[\mathbb E|\mathbb E(X\mid\mathscr G)|\leq\mathbb E|X|.\]</div>{% endraw %}
<p>For the dominated-convergence assertion, let {% raw %}<span class="math inline">\(Z_m=\sup_{n\geq m}|X_n-X|\)</span>{% endraw %}. Then {% raw %}<span class="math inline">\(Z_m\downarrow0\)</span>{% endraw %} almost surely and {% raw %}<span class="math inline">\(Z_m\leq2Y\)</span>{% endraw %}. The variables {% raw %}<span class="math inline">\(\mathbb{E}[Z_m\mid\mathscr G]\)</span>{% endraw %} decrease almost surely; their nonnegative limit has expectation zero because {% raw %}<span class="math inline">\(\mathbb{E}Z_m\to0\)</span>{% endraw %} by ordinary dominated convergence. Thus their limit is zero, and {% raw %}<span class="math inline">\(|\mathbb{E}[X_n-X\mid\mathscr G]|\leq \mathbb{E}[Z_m\mid\mathscr G]\)</span>{% endraw %} for {% raw %}<span class="math inline">\(n\geq m\)</span>{% endraw %} proves the claim.</p>

<p>◻</p>

</div>
<div id="prop:measurability-conditional-expectation" class="proposition" data-note-number="9" data-note-kind="Proposition">
<p><strong>Proposition 9</strong>.  If {% raw %}<span class="math inline">\(X\)</span>{% endraw %} is {% raw %}<span class="math inline">\(\mathscr G\)</span>{% endraw %}-measurable, and {% raw %}<span class="math inline">\(Y\)</span>{% endraw %}, {% raw %}<span class="math inline">\(XY\)</span>{% endraw %} are integrable, then {% raw %}<span class="math inline">\(\mathbb{E}[XY \mid \mathscr G] = X \mathbb{E}[Y \mid \mathscr G]\)</span>{% endraw %} with probability one.</p>

</div>
<div class="proof">
<p><em>Proof.</em> If {% raw %}<span class="math inline">\(X=\mathbf1_B\)</span>{% endraw %} with {% raw %}<span class="math inline">\(B\in\mathscr G\)</span>{% endraw %}, then for every {% raw %}<span class="math inline">\(G\in\mathscr G\)</span>{% endraw %},</p>
{% raw %}<div class="math display">\[\int_G\mathbf1_B\mathbb E(Y\mid\mathscr G)\,dP
=\int_{G\cap B}\mathbb E(Y\mid\mathscr G)\,dP
=\int_{G\cap B}Y\,dP=\int_GXY\,dP.\]</div>{% endraw %}
<p>The proposed product is measurable and integrable, so uniqueness proves the assertion for indicators, and linearity proves it for simple {% raw %}<span class="math inline">\(X\)</span>{% endraw %}. Uniform approximation by simple functions, together with the {% raw %}<span class="math inline">\(L^1\)</span>{% endraw %} contraction above, proves it for bounded measurable {% raw %}<span class="math inline">\(X\)</span>{% endraw %}.</p>
<p>For general real-valued measurable {% raw %}<span class="math inline">\(X\)</span>{% endraw %}, the bounded case and monotone convergence give</p>
{% raw %}<div class="math display">\[\mathbb E\bigl[|X|\mathbb E(|Y|\mid\mathscr G)\bigr]
=\lim_{k\to\infty}\mathbb E\bigl[(|X|\wedge k)|Y|\bigr]=\mathbb E|XY|&lt;\infty.\]</div>{% endraw %}
<p>Thus {% raw %}<span class="math inline">\(X\mathbb E(Y\mid\mathscr G)\)</span>{% endraw %} is integrable. Set {% raw %}<span class="math inline">\(X_k=(-k)\vee(X\wedge k)\)</span>{% endraw %}. Dominated convergence gives {% raw %}<span class="math inline">\(X_kY\to XY\)</span>{% endraw %} in {% raw %}<span class="math inline">\(L^1\)</span>{% endraw %}, and also {% raw %}<span class="math inline">\(X_k\mathbb E(Y\mid\mathscr G)\to X\mathbb E(Y\mid\mathscr G)\)</span>{% endraw %} in {% raw %}<span class="math inline">\(L^1\)</span>{% endraw %}, using the preceding integrable bound. The contraction gives convergence in {% raw %}<span class="math inline">\(L^1\)</span>{% endraw %} of {% raw %}<span class="math inline">\(\mathbb E(X_kY\mid\mathscr G)\)</span>{% endraw %} to {% raw %}<span class="math inline">\(\mathbb E(XY\mid\mathscr G)\)</span>{% endraw %}. Pass to the limit in the bounded-case identity. ◻</p>
</div>
<div id="prop:conditional-expectation-sigma-field-towers" class="proposition" data-note-number="10" data-note-kind="Proposition">
<p><strong>Proposition 10</strong>.  Let {% raw %}<span class="math inline">\(X\)</span>{% endraw %} be an integrable random variable, and {% raw %}<span class="math inline">\(\mathscr G_1\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\mathscr G_2\)</span>{% endraw %} are {% raw %}<span class="math inline">\(\sigma\)</span>{% endraw %}-fields satisfying {% raw %}<span class="math inline">\(\mathscr G_1 \subset \mathscr G_2\)</span>{% endraw %}. Then, {% raw %}<span class="math inline">\(\mathbb{E}[\mathbb{E}[X \mid \mathscr G_2] \mid \mathscr G_1] = \mathbb{E}[X \mid \mathscr G_1]\)</span>{% endraw %}.</p>

</div>
<div class="proof">
<p><em>Proof.</em> The left-hand side is integrable and {% raw %}<span class="math inline">\(\mathscr G_1\)</span>{% endraw %}-measurable. For every {% raw %}<span class="math inline">\(G\in\mathscr G_1\subseteq\mathscr G_2\)</span>{% endraw %}, its defining integral is</p>
{% raw %}<div class="math display">\[\int_G\mathbb E(\mathbb E(X\mid\mathscr G_2)\mid\mathscr G_1)\,dP
=\int_G\mathbb E(X\mid\mathscr G_2)\,dP=\int_GX\,dP.\]</div>{% endraw %}
<p>It therefore satisfies both defining properties of {% raw %}<span class="math inline">\(\mathbb E(X\mid\mathscr G_1)\)</span>{% endraw %}, and uniqueness proves the equality almost surely. ◻</p>
</div>
