<div class="note-content" markdown="0">

<p>Work on a filtered probability space satisfying the usual conditions. {% raw %}<span class="math inline">\(B\)</span>{% endraw %} denotes Brownian motion, and stochastic integrands are predictable with the stated integrability. A local martingale need not be a true martingale: the moment conditions in each claim are essential. See <a href="{% post_url 2023-01-21-brownian-motion-markov-properties-and-path-continuity %}">Brownian motion</a> and <a href="{% post_url 2023-01-07-martingales-maximal-and-upcrossing-inequalities %}">martingale inequalities</a>.</p>

<div id="construction-of-the-stochastic-integral" data-note-section="title">

</div>
<span id="eq:integrability-req"></span>
<span id="eq:agree"></span>
<p>Begin with a continuous martingale {% raw %}<span class="math inline">\(X\)</span>{% endraw %}, with {% raw %}<span class="math inline">\(X_0=0\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\sup_{t\geq0}\mathbb{E}X_t^2&lt;\infty\)</span>{% endraw %}. For Brownian motion on a fixed interval {% raw %}<span class="math inline">\([0,T]\)</span>{% endraw %}, use the stopped integrator {% raw %}<span class="math inline">\(X_t=B_{t\wedge T}\)</span>{% endraw %}. The aim is to define</p>

<span id="eq:stochastic-integral"></span>
{% raw %}<div class="math display">\[\mathcal I_t=\int_0^t H_s\,\mathrm dX_s.\tag{1}\]</div>{% endraw %}

<p>The coefficient multiplying an increment must be chosen from information available before that increment. Predictability expresses this requirement and gives the measurable class on which the integral will be constructed.</p>

<p>The predictable sigma-field {% raw %}<span class="math inline">\(\mathcal P\)</span>{% endraw %} on {% raw %}<span class="math inline">\([0,\infty)\times\Omega\)</span>{% endraw %} is the smallest sigma-field making every bounded left-continuous adapted real process measurable. Equivalently,</p>

{% raw %}<div class="math display">\[\mathcal P=\sigma\{\{(t,\omega):Y_t(\omega)\in C\}:Y\text{ bounded, left-continuous and adapted},\ C\in\mathscr B(\mathbb R)\}.\]</div>{% endraw %}

<p>A process is predictable when it is {% raw %}<span class="math inline">\(\mathcal P\)</span>{% endraw %}-measurable.</p>

<div id="result-1" class="remark" data-note-number="1" data-note-kind="Remark">
<p><strong>Remark 1.</strong> Continuous adapted processes generate the same sigma-field. One inclusion follows because continuity implies left continuity. For the other, extend a bounded left-continuous adapted process {% raw %}<span class="math inline">\(Y\)</span>{% endraw %} to negative times by {% raw %}<span class="math inline">\(Y_s=Y_0\)</span>{% endraw %}, and set</p>

{% raw %}<div class="math display">\[Y_t^n=n\int_{t-1/n}^tY_s\,\mathrm ds.\]</div>{% endraw %}

<p>These processes are continuous and adapted, and converge to {% raw %}<span class="math inline">\(Y_t\)</span>{% endraw %} at every {% raw %}<span class="math inline">\(t\)</span>{% endraw %}, including zero. For an unbounded process first use bounded truncations. This proves the other inclusion.</p>

</div>
<div id="result-2" class="remark" data-note-number="2" data-note-kind="Remark">
<p><strong>Remark 2.</strong> A useful set of generators is</p>

{% raw %}<div class="math display">\[\{(s,t]\times A:0\leq s&lt;t, A\in\mathcal F_s\}\ \cup\ \{\{0\}\times A:A\in\mathcal F_0\}.\]</div>{% endraw %}

<p>Their indicators are left-continuous and adapted. Conversely, a left-continuous adapted process is the pointwise limit of</p>

<span id="eq:elementary-predictable-process"></span>
{% raw %}<div class="math display">\[Y_t^n=Y_0\mathbb1_{\{t=0\}}+
\sum_{k\geq1}Y_{(k-1)/n}\mathbb1_{((k-1)/n,k/n]}(t).\tag{2}\]</div>{% endraw %}

<p>Each coefficient is measurable at the left endpoint of its interval, so each approximation is measurable for the sigma-field generated by these rectangles.</p>

</div>
<p>The construction of <a href="#eq:stochastic-integral">(1)</a> has two parts. First define the integral for elementary predictable processes and prove a second-moment identity. Then use that identity to extend the integral by approximation. We begin with a single time interval.</p>

<span id="eq:Hs"></span>
{% raw %}<div class="math display">\[H_s=K\mathbb1_{(a,b]}(s),\qquad K\text{ bounded and }\mathcal F_a\text{-measurable}.\tag{3}\]</div>{% endraw %}

<p>Define {% raw %}<span class="math inline">\(\mathcal I_t=K(X_{t\wedge b}-X_{t\wedge a})\)</span>{% endraw %}. Its terminal value is {% raw %}<span class="math inline">\(\mathcal I_\infty=K(X_b-X_a)\)</span>{% endraw %}. The three time ranges give</p>

{% raw %}<div class="math display">\[\mathbb{E}[\mathcal I_\infty\mid\mathcal F_t]=
\begin{cases}0,&amp;t\leq a,\\K(X_t-X_a),&amp;a&lt;t&lt;b,\\K(X_b-X_a),&amp;t\geq b.
\end{cases}\]</div>{% endraw %}

<p>For {% raw %}<span class="math inline">\(t\leq a\)</span>{% endraw %}, use the tower property through {% raw %}<span class="math inline">\(\mathcal F_a\)</span>{% endraw %}; for the middle range use the martingale identity directly. Thus {% raw %}<span class="math inline">\(\mathcal I\)</span>{% endraw %} is a continuous square-integrable martingale. Writing {% raw %}<span class="math inline">\(A=\langle X\rangle\)</span>{% endraw %}, the conditional second-moment identity gives</p>

{% raw %}<div class="math display">\[\mathbb{E}\mathcal I_\infty^2=\mathbb{E}[K^2(X_b-X_a)^2]
=\mathbb{E}[K^2(A_b-A_a)].\]</div>{% endraw %}

<p>It also identifies the bracket. For {% raw %}<span class="math inline">\(a\leq t\leq b\)</span>{% endraw %}, expand {% raw %}<span class="math inline">\(X_b-X_a=(X_b-X_t)+(X_t-X_a)\)</span>{% endraw %}. The mixed term has conditional mean zero, and</p>

{% raw %}<div class="math display">\[\mathbb{E}[(X_b-X_a)^2-(A_b-A_a)\mid\mathcal F_t]
=(X_t-X_a)^2-(A_t-A_a).\]</div>{% endraw %}

<p>The cases before {% raw %}<span class="math inline">\(a\)</span>{% endraw %} and after {% raw %}<span class="math inline">\(b\)</span>{% endraw %} follow by the same conditioning as above. Therefore</p>

{% raw %}<div class="math display">\[\mathcal I_t^2-K^2(A_{t\wedge b}-A_{t\wedge a})
\quad\text{is a martingale},\qquad
\langle\mathcal I\rangle_t=\int_0^tH_s^2\,\mathrm dA_s.\]</div>{% endraw %}

<p>For a finite sum of elementary integrands, refine all endpoints into one deterministic partition. We may then write</p>

{% raw %}<div class="math display">\[H_s=\sum_{j=1}^J K_j\mathbb1_{(t_{j-1},t_j]}(s),\qquad
\mathcal I_t=\sum_{j=1}^J K_j(X_{t\wedge t_j}-X_{t\wedge t_{j-1}}),\]</div>{% endraw %}

<p>where {% raw %}<span class="math inline">\(K_j\)</span>{% endraw %} is bounded and {% raw %}<span class="math inline">\(\mathcal F_{t_{j-1}}\)</span>{% endraw %}-measurable. Disjoint intervals are essential for the orthogonality calculation: for {% raw %}<span class="math inline">\(i&lt;j\)</span>{% endraw %}, all factors in the earlier increment and {% raw %}<span class="math inline">\(K_j\)</span>{% endraw %} are measurable at {% raw %}<span class="math inline">\(t_{j-1}\)</span>{% endraw %}, while the conditional expectation of the later increment is zero. Consequently</p>

{% raw %}<div class="math display">\[\mathbb{E}\mathcal I_\infty^2
=\sum_{j=1}^J\mathbb{E}[K_j^2(X_{t_j}-X_{t_{j-1}})^2]
=\mathbb{E}\int_0^\infty H_s^2\,\mathrm dA_s.\]</div>{% endraw %}

<p>The bracket calculation also passes from one interval to the next. On an interval, expanding the square of the accumulated integral adds a term twice its left-endpoint value times the new martingale increment, and the centered square term already handled above. Both have conditional mean zero. It follows that</p>

{% raw %}<div class="math display">\[\mathcal I_t^2-\int_0^tH_s^2\,\mathrm dA_s\quad\text{is a martingale}.\]</div>{% endraw %}

<p>The second-moment identity now specifies the admissible class. Require {% raw %}<span class="math inline">\(H\)</span>{% endraw %} to be predictable and</p>

<span id="eq:integrability-predictable"></span>
{% raw %}<div class="math display">\[\|H\|_{L^2(A)}^2:=\mathbb{E}\int_0^\infty H_s^2\,\mathrm dA_s&lt;\infty.\tag{4}\]</div>{% endraw %}

<p>The measure {% raw %}<span class="math inline">\(\mu(E)=\mathbb{E}\int\mathbb1_E(s,\omega)\,\mathrm dA_s\)</span>{% endraw %} on the predictable sigma-field is finite, because {% raw %}<span class="math inline">\(\mathbb{E}A_\infty=\mathbb{E}X_\infty^2&lt;\infty\)</span>{% endraw %}. Its mass at time zero is zero. The rectangle generators and the monotone-class theorem show that finite elementary sums are dense in {% raw %}<span class="math inline">\(L^2(\mu)\)</span>{% endraw %}: first approximate bounded indicators using the generated sigma-field, then bounded simple functions, and finally truncate a general square-integrable function. Choose elementary {% raw %}<span class="math inline">\(H^n\)</span>{% endraw %} with {% raw %}<span class="math inline">\(\|H^n-H\|_{L^2(A)}\to0\)</span>{% endraw %}.</p>

<p>Their integrals {% raw %}<span class="math inline">\(I^n\)</span>{% endraw %} have terminal values Cauchy in {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %}. Let {% raw %}<span class="math inline">\(I_\infty\)</span>{% endraw %} be the limit and {% raw %}<span class="math inline">\(I_t=\mathbb{E}[I_\infty\mid\mathcal F_t]\)</span>{% endraw %}. Doob’s inequality and the isometry give</p>

{% raw %}<div class="math display">\[\mathbb{E}\sup_{t\geq0}|I_t^n-I_t^m|^2
\leq4\mathbb{E}|I_\infty^n-I_\infty^m|^2
=4\mathbb{E}\int_0^\infty|H_s^n-H_s^m|^2\,\mathrm dA_s.\]</div>{% endraw %}

<p>The same bound with {% raw %}<span class="math inline">\(I\)</span>{% endraw %} in place of {% raw %}<span class="math inline">\(I^m\)</span>{% endraw %} follows by taking the limit. A subsequence converges uniformly almost surely, and its limit supplies a continuous version of {% raw %}<span class="math inline">\(I\)</span>{% endraw %}. Completeness of the filtration preserves adaptation on the exceptional null set. The martingale identity passes to this limit in {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %}; for example,</p>

{% raw %}<div class="math display">\[\left|\mathbb{E}[(I_t^n-I_t)\mathbb1_E]\right|\leq\|I_t^n-I_t\|_2\longrightarrow0,
\qquad E\in\mathcal F_s, s\leq t.\]</div>{% endraw %}

<p>Two approximating sequences give the same limit by the same estimate. The isometry passes to the limit, and so does the centered-square identity. Indeed,</p>

{% raw %}<div class="math display">\[\mathbb{E}\int_0^\infty|(H_s^n)^2-H_s^2|\,\mathrm dA_s
\leq\|H^n-H\|_{L^2(A)}\bigl(\|H^n\|_{L^2(A)}+\|H\|_{L^2(A)}\bigr)\to0.\]</div>{% endraw %}

<p>Also {% raw %}<span class="math inline">\((I_t^n)^2\to I_t^2\)</span>{% endraw %} in {% raw %}<span class="math inline">\(L^1\)</span>{% endraw %}, by Cauchy–Schwarz. Conditional expectation is continuous in {% raw %}<span class="math inline">\(L^1\)</span>{% endraw %}, so the limit of the centered-square martingales is a martingale. We have therefore constructed</p>

{% raw %}<div class="math display">\[I_t=\int_0^tH_s\,\mathrm dX_s,\qquad
\mathbb{E}I_t^2=\mathbb{E}\int_0^tH_s^2\,\mathrm d\langle X\rangle_s,
\qquad \langle I\rangle_t=\int_0^tH_s^2\,\mathrm d\langle X\rangle_s.\]</div>{% endraw %}

<div id="result-3" class="remark" data-note-number="3" data-note-kind="Remark">
<p><strong>Remark 3.</strong> On a finite horizon the integral is a linear map from bounded predictable processes to random variables modulo almost-sure equality. On elementary processes it is specified by</p>

<span id="eq:integral-elementary-definition"></span>
{% raw %}<div class="math display">\[\int_0^t\xi_s\,\mathrm dX_s
=\sum_{k=1}^nK_k(X_{t\wedge t_k}-X_{t\wedge s_k}),
\qquad \xi_s=\sum_{k=1}^nK_k\mathbb1_{(s_k,t_k]}(s).\tag{5}\]</div>{% endraw %}

<p>If predictable {% raw %}<span class="math inline">\(\xi^n\to\xi\)</span>{% endraw %} pointwise and {% raw %}<span class="math inline">\(|\xi^n|\leq K\)</span>{% endraw %} for one deterministic constant, dominated convergence in the measure {% raw %}<span class="math inline">\(\mu\)</span>{% endraw %} and the isometry imply {% raw %}<span class="math inline">\(\int_0^t\xi_s^n\,\mathrm dX_s\to\int_0^t\xi_s\,\mathrm dX_s\)</span>{% endraw %} in {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %}, hence in probability. For a continuous local martingale this conclusion follows by stopping so that its bracket and initial value are controlled.</p>

</div>
<div id="result-4" class="remark" data-note-number="4" data-note-kind="Remark">
<p><strong>Remark 4.</strong> Linearity, the elementary formula, and bounded pointwise continuity in probability characterize the integral uniquely. The class of bounded predictable integrands on which two such maps agree is a vector space closed under bounded pointwise limits. It contains the rectangle indicators (and integrals of time-zero indicators are zero). The functional monotone-class theorem extends agreement to every bounded predictable integrand.</p>
