<div class="note-content" markdown="0">

<p>How much independence does a limit theorem need? For a stationary sequence, one possible answer is to require that events far apart become nearly independent. We first quantify this requirement and relate it to the variance of a sample mean. The final example shows why a small covariance and a small mixing coefficient are different conditions.</p>

<div id="dependent-data" data-note-section="title">

</div>
<p>Consider a stochastic process indexed by some potentially uncountable set {% raw %}<span class="math inline">\(I\)</span>{% endraw %}, which we write as {% raw %}<span class="math inline">\(\{X_i\}_{i \in I}\)</span>{% endraw %}. The observations are uncorrelated when they satisfy {% raw %}<span class="math inline">\(\mathop{\mathrm{Cov}}(X_i,X_j) = 0\)</span>{% endraw %}. Independence implies this equality when the covariances exist, but the converse fails. To recover laws of large numbers and central limit theorems for dependent observations, we need conditions on their joint distributions.</p>

<p>The conditions below measure how much dependence remains between observations separated in the index set {% raw %}<span class="math inline">\(I\)</span>{% endraw %}. For example, {% raw %}<span class="math inline">\(X_i\)</span>{% endraw %} is independent of {% raw %}<span class="math inline">\(X_j\)</span>{% endraw %} for some {% raw %}<span class="math inline">\(j\)</span>{% endraw %} sufficiently “far away” from {% raw %}<span class="math inline">\(i\)</span>{% endraw %} (if {% raw %}<span class="math inline">\(I\)</span>{% endraw %} is a subset of {% raw %}<span class="math inline">\(\mathbb R\)</span>{% endraw %}), but this pairwise condition alone does not control the joint distributions needed for limit theorems. The coefficients below compare entire collections of observations. Under mixing, dependence may persist at every finite separation, provided that it tends to zero.</p>

<p>The coefficients must compare whole collections of observations. Pairwise covariances alone would miss dependence visible only in larger collections. We therefore begin with the information generated by an interval of indices.</p>

<ul>
<li><p>Let {% raw %}<span class="math inline">\(\mathcal F_k^n = \sigma(\{X_i : k \leq i \leq n\})\)</span>{% endraw %} be the {% raw %}<span class="math inline">\(\sigma\)</span>{% endraw %}-field generated by the random variables {% raw %}<span class="math inline">\(\{X_i : k \leq i \leq n\}\)</span>{% endraw %} (again the index set need not be discrete or countable). {% raw %}<span class="math inline">\(k\)</span>{% endraw %} and {% raw %}<span class="math inline">\(n\)</span>{% endraw %} can take the value {% raw %}<span class="math inline">\(\mp \infty\)</span>{% endraw %}, respectively.</p></li>
<li><p>We establish long-range independence by examining sets belonging to “far enough away” {% raw %}<span class="math inline">\(\sigma\)</span>{% endraw %}-fields. Recall measurable sets (events) {% raw %}<span class="math inline">\(A\)</span>{% endraw %} and {% raw %}<span class="math inline">\(B\)</span>{% endraw %} are independent if {% raw %}<span class="math inline">\(\mathop{\mathrm{\mathbb{P}}}(A \cap B) = \mathop{\mathrm{\mathbb{P}}}(A) \mathop{\mathrm{\mathbb{P}}}(B)\)</span>{% endraw %} for a probability measure defined on the common measurable space {% raw %}<span class="math inline">\((\Omega,\mathcal F)\)</span>{% endraw %}, where {% raw %}<span class="math inline">\(\mathcal F\)</span>{% endraw %} is the smallest {% raw %}<span class="math inline">\(\sigma\)</span>{% endraw %}-field containing {% raw %}<span class="math inline">\(\{\mathcal F_k^n\}_{k \leq n}\)</span>{% endraw %}.</p></li>
</ul>
<div id="def:strong-mixing-coefficients" class="definition" data-note-number="1" data-note-kind="Definition">
<p><strong>Definition 1</strong>.  Let {% raw %}<span class="math inline">\(\{X_i:i\in I\}\)</span>{% endraw %} be a stochastic process. The <strong>{% raw %}<span class="math inline">\(\alpha\)</span>{% endraw %}-mixing coefficient</strong> is </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \alpha_X (k) \triangleq \sup_{n \in \mathbb N} \sup_{A \in \mathcal F_{-\infty}^n, B \in \mathcal F_{n+k}^\infty} |\mathop{\mathrm{\mathbb{P}}}(A \cap B) - \mathop{\mathrm{\mathbb{P}}}(A)\mathop{\mathrm{\mathbb{P}}}(B)| ~.
    
\end{aligned}\]</div>{% endraw %}
<p> A stochastic process {% raw %}<span class="math inline">\(X\)</span>{% endraw %} is <strong>strong-mixing</strong> if {% raw %}<span class="math inline">\(\alpha_X(k) \to 0\)</span>{% endraw %} as {% raw %}<span class="math inline">\(k \to \infty\)</span>{% endraw %}. {% raw %}<span class="math inline">\(X\)</span>{% endraw %} is <strong>{% raw %}<span class="math inline">\(m\)</span>{% endraw %}-dependent</strong> if {% raw %}<span class="math inline">\(\alpha_X(k)=0\)</span>{% endraw %} for all {% raw %}<span class="math inline">\(k &gt; m\)</span>{% endraw %}. {% raw %}<span class="math inline">\(X\)</span>{% endraw %} is <strong>stationary</strong> if for all {% raw %}<span class="math inline">\(c,k,j_1,\dots,j_k \in \mathbb N\)</span>{% endraw %}, the joint distributions of {% raw %}<span class="math inline">\((X_{j_1},\dots,X_{j_k})\)</span>{% endraw %} and {% raw %}<span class="math inline">\((X_{j_1+c},\dots,X_{j_k+c})\)</span>{% endraw %} are identical.</p>

</div>

<div id="def:other-mixing-coefficients" class="definition" data-note-number="2" data-note-kind="Definition">
<p><strong>Definition 2</strong>. For the remainder of the post the process is indexed by {% raw %}<span class="math inline">\(\mathbb Z\)</span>{% endraw %}. For sigma-fields {% raw %}<span class="math inline">\(\mathcal A,\mathcal B\)</span>{% endraw %}, define</p>

</div>
{% raw %}<div class="math display">\[\begin{aligned}\phi(\mathcal A,\mathcal B)&amp;=\sup_{A\in\mathcal A,\,B\in\mathcal B,\,P(A)&gt;0}|P(B\mid A)-P(B)|,\\\psi(\mathcal A,\mathcal B)&amp;=\sup_{A\in\mathcal A,\,B\in\mathcal B,\,P(A)P(B)&gt;0}\left|\frac{P(A\cap B)}{P(A)P(B)}-1\right|,\\\rho(\mathcal A,\mathcal B)&amp;=\sup_{U\in L^2(\mathcal A),\,V\in L^2(\mathcal B),\,\operatorname{Var}(U)\operatorname{Var}(V)&gt;0}\frac{|\operatorname{Cov}(U,V)|}{\sqrt{\operatorname{Var}(U)\operatorname{Var}(V)}},\\\beta(\mathcal A,\mathcal B)&amp;=\frac12\sup_{(A_i),(B_j)}\sum_{i,j}|P(A_i\cap B_j)-P(A_i)P(B_j)|.\end{aligned}\]</div>{% endraw %}<p>The last supremum runs over finite measurable partitions of {% raw %}<span class="math inline">\(\Omega\)</span>{% endraw %}, with {% raw %}<span class="math inline">\(A_i\in\mathcal A\)</span>{% endraw %} and {% raw %}<span class="math inline">\(B_j\in\mathcal B\)</span>{% endraw %}. If no nonconstant square-integrable variables exist, set {% raw %}<span class="math inline">\(\rho=0\)</span>{% endraw %}. For each coefficient {% raw %}<span class="math inline">\(c\in\{\alpha,\phi,\psi,\rho,\beta\}\)</span>{% endraw %}, its process version is {% raw %}<span class="math inline">\(c_X(k)=\sup_{t\in\mathbb Z}c(\mathcal F_{-\infty}^t,\mathcal F_{t+k}^{\infty})\)</span>{% endraw %}. The time supremum is part of every definition.</p>

<div id="lem:mixing-coefficients-comparison" class="lemma" data-note-number="3" data-note-kind="Lemma">
<p><strong>Lemma 3</strong> (<span><span class="citation" data-cites="doukhan_mixing_1994">(<a href="#ref-doukhan_mixing_1994" role="doc-biblioref">Doukhan 1994, chap. 1</a>, Proposition 1)</span></span>).  For any {% raw %}<span class="math inline">\(\sigma\)</span>{% endraw %}-fields {% raw %}<span class="math inline">\(\mathscr A, \mathscr B \in \mathcal F\)</span>{% endraw %}, </p>

{% raw %}<div class="math display">\[\begin{aligned}
        2 \alpha(\mathscr A, \mathscr B) \leq \beta (\mathscr A, \mathscr B) &amp;\leq \phi(\mathscr A, \mathscr B) \leq \frac12 \psi(\mathscr A, \mathscr B) ~, \\
        4 \alpha(\mathscr A, \mathscr B) \leq \rho(\mathscr A, \mathscr B) &amp;\leq 2 \sqrt{\phi(\mathscr A, \mathscr B)} \sqrt{\phi(\mathscr B, \mathscr A)} ~, \\
        \rho(\mathscr A, \mathscr B) &amp;\leq \psi(\mathscr A, \mathscr B) ~.
    
\end{aligned}\]</div>{% endraw %}
</div>
<p>The coefficient comparisons are recorded in <a href="https://www2.stat.duke.edu/~scs/Projects/Stable/Conditions/BradleyStrongMixingSurvey2005.pdf">Bradley (2005), §1, inequalities (1.10)–(1.13)</a>. The coefficient comparisons in <a href="#lem:mixing-coefficients-comparison">Lemma 3</a> imply that convergence to zero of any of the other listed coefficients implies strong mixing.</p>

<p>Some of the comparisons in Lemma 3 are immediate from their finite partitions. For {% raw %}<span class="math inline">\(A\in\mathcal A\)</span>{% endraw %} and {% raw %}<span class="math inline">\(B\in\mathcal B\)</span>{% endraw %}, the two-by-two partitions {% raw %}<span class="math inline">\((A,A^c)\)</span>{% endraw %} and {% raw %}<span class="math inline">\((B,B^c)\)</span>{% endraw %} have four absolute covariance entries of the same size, giving {% raw %}<span class="math inline">\(\beta\ge2\alpha\)</span>{% endraw %}. For arbitrary partitions, each conditional row has total absolute deviation at most {% raw %}<span class="math inline">\(2\phi\)</span>{% endraw %}; averaging the rows gives {% raw %}<span class="math inline">\(\beta\le\phi\)</span>{% endraw %}. Also</p>

{% raw %}<div class="math display">\[|P(B\mid A)-P(B)|\le\psi\min\{P(B),P(B^c)\}\le\psi/2,\]</div>{% endraw %}

<p>by applying the definition to both {% raw %}<span class="math inline">\(B\)</span>{% endraw %} and {% raw %}<span class="math inline">\(B^c\)</span>{% endraw %}. Finally, the correlation of the indicators of {% raw %}<span class="math inline">\(A,B\)</span>{% endraw %} is their covariance divided by a standard-deviation product at most {% raw %}<span class="math inline">\(1/4\)</span>{% endraw %}, giving {% raw %}<span class="math inline">\(\rho\ge4\alpha\)</span>{% endraw %}. The two upper bounds for {% raw %}<span class="math inline">\(\rho\)</span>{% endraw %} are the quoted coefficient-comparison results.</p>
<p>The next estimate turns a bound on event probabilities into a bound on covariances. Its successive forms replace boundedness by moment assumptions, at the cost of a smaller power of the mixing coefficient.</p>

<div id="lem:mixing-coefficients-covariance-bound" class="lemma" data-note-number="4" data-note-kind="Lemma">
<p><strong>Lemma 4</strong> (<span><span class="citation" data-cites="hall_martingale_1980">(<a href="#ref-hall_martingale_1980" role="doc-biblioref">Hall and Heyde 1980</a>, Theorem A.5, Corollary A.1, Corollary A.2)</span></span>).  Let {% raw %}<span class="math inline">\(X,Y\)</span>{% endraw %} be random variables defined on {% raw %}<span class="math inline">\((\Omega,\mathcal F,\mathop{\mathrm{\mathbb{P}}})\)</span>{% endraw %}. Suppose {% raw %}<span class="math inline">\(X\)</span>{% endraw %} and {% raw %}<span class="math inline">\(Y\)</span>{% endraw %} are {% raw %}<span class="math inline">\(\mathcal G\)</span>{% endraw %}- and {% raw %}<span class="math inline">\(\mathcal H\)</span>{% endraw %}-measurable, respectively, and {% raw %}<span class="math inline">\(|X| \leq C_1\)</span>{% endraw %} and {% raw %}<span class="math inline">\(|Y| \leq C_2\)</span>{% endraw %}. Then, </p>

{% raw %}<span id="eq:thma5"></span><div class="math display">\[\begin{aligned}
 
        |\mathbb{E}[XY] - \mathbb{E}X \mathbb{E}Y| \leq 4 C_1 C_2 \alpha(\mathcal G,\mathcal H) ~.
    
\end{aligned}\tag{1}\]</div>{% endraw %}
<p> Furthermore, under an additional requirement that {% raw %}<span class="math inline">\(\mathbb{E}|X|^p &lt; \infty\)</span>{% endraw %} for some {% raw %}<span class="math inline">\(p &gt; 1\)</span>{% endraw %}, we have </p>

{% raw %}<span id="eq:cora1"></span><div class="math display">\[\begin{aligned}
 
        |\mathbb{E}[XY] - \mathbb{E}X \mathbb{E}Y| \leq 6 C_2 \|X\|_p \alpha(\mathcal G,\mathcal H)^{1-\frac1p} ~.
    
\end{aligned}\tag{2}\]</div>{% endraw %}
<p> Finally, suppose additionally that {% raw %}<span class="math inline">\(\mathbb{E}|Y|^q &lt; \infty\)</span>{% endraw %} for some {% raw %}<span class="math inline">\(q &gt; 1\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(\frac1p + \frac1q &lt; 1\)</span>{% endraw %}, then </p>

{% raw %}<span id="eq:cora2"></span><div class="math display">\[\begin{aligned}
 
        |\mathbb{E}[XY] - \mathbb{E}X \mathbb{E}Y| \leq 8 \|X\|_p \|Y\|_q \alpha(\mathcal G,\mathcal H)^{1-\frac1p-\frac1q} ~.
    
\end{aligned}\tag{3}\]</div>{% endraw %}
</div>
<div class="proof">
<p><em>Proof.</em></p>

<p>Write {% raw %}<span class="math inline">\(\alpha=\alpha(\mathcal G,\mathcal H)\)</span>{% endraw %}. For bounded variables, shift {% raw %}<span class="math inline">\(X,Y\)</span>{% endraw %} by their lower bounds. The layer-cake representation gives</p>

{% raw %}<div class="math display">\[\operatorname{Cov}(X,Y)=\int_0^{2C_1}\int_0^{2C_2}\{P(X+C_1&gt;s,Y+C_2&gt;t)-P(X+C_1&gt;s)P(Y+C_2&gt;t)\}\,dt\,ds.\]</div>{% endraw %}<p>The integrand is bounded in absolute value by {% raw %}<span class="math inline">\(\alpha\)</span>{% endraw %}, proving (1).</p>

<p>For (2), only {% raw %}<span class="math inline">\(Y\)</span>{% endraw %} remains bounded. If {% raw %}<span class="math inline">\(\alpha=0\)</span>{% endraw %}, the sigma-fields are independent and the covariance is zero. If {% raw %}<span class="math inline">\(\|X\|_p=0\)</span>{% endraw %}, the covariance bound (2) is also immediate. Otherwise set {% raw %}<span class="math inline">\(A=\|X\|_p\alpha^{-1/p}\)</span>{% endraw %} and decompose {% raw %}<span class="math inline">\(X=X_0+X_1\)</span>{% endraw %} with {% raw %}<span class="math inline">\(X_0=X1_{\{|X|\leq A\}}\)</span>{% endraw %}. Then</p>

{% raw %}<div class="math display">\[|\operatorname{Cov}(X,Y)|\leq4AC_2\alpha+2C_2\mathbb{E}|X_1|\leq4AC_2\alpha+2C_2A^{1-p}\|X\|_p^p=6C_2\|X\|_p\alpha^{1-1/p}.\]</div>{% endraw %}<p>For (3), neither variable need be bounded. Let {% raw %}<span class="math inline">\(r=p/(p-1)&lt;q\)</span>{% endraw %} and {% raw %}<span class="math inline">\(B=\|Y\|_q\alpha^{-1/q}\)</span>{% endraw %}. Split {% raw %}<span class="math inline">\(Y=Y_0+Y_1\)</span>{% endraw %} at {% raw %}<span class="math inline">\(B\)</span>{% endraw %}. The preceding bound and Hölder give</p>

{% raw %}<div class="math display">\[|\operatorname{Cov}(X,Y)|\leq6B\|X\|_p\alpha^{1-1/p}+2\|X\|_p\|Y_1\|_r.\]</div>{% endraw %}<p>Since {% raw %}<span class="math inline">\(\|Y_1\|_r\leq B^{1-q/r}\|Y\|_q^{q/r}=\|Y\|_q\alpha^{1-1/p-1/q}\)</span>{% endraw %}, the two terms add to the asserted constant eight. The zero-norm and independent cases are handled as before.</p>

<p>◻</p>

</div>

<div id="result-5" class="lemma" data-note-number="5" data-note-kind="Lemma">
<p><strong>Lemma 5</strong>. For {% raw %}<span class="math inline">\(X\in L^p(\mathcal G)\)</span>{% endraw %}, {% raw %}<span class="math inline">\(Y\in L^q(\mathcal H)\)</span>{% endraw %}, {% raw %}<span class="math inline">\(1&lt;p&lt;\infty\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(1/p+1/q=1\)</span>{% endraw %},</p>

</div>
{% raw %}<div class="math display">\[|\operatorname{Cov}(X,Y)|\leq2\phi(\mathcal G,\mathcal H)^{1/p}\|X\|_p\|Y\|_q.\]</div>{% endraw %}<p>At {% raw %}<span class="math inline">\(p=1,q=\infty\)</span>{% endraw %} the bound is {% raw %}<span class="math inline">\(2\phi(\mathcal G,\mathcal H)\|X\|_1\|Y\|_\infty\)</span>{% endraw %}.</p>

<div class="proof">
<p><em>Proof.</em></p>

<p>First take simple {% raw %}<span class="math inline">\(X,Y\)</span>{% endraw %}, with level-set partitions {% raw %}<span class="math inline">\((A_i)\)</span>{% endraw %} and {% raw %}<span class="math inline">\((B_j)\)</span>{% endraw %}. Write {% raw %}<span class="math inline">\(a_i=P(A_i)&gt;0\)</span>{% endraw %}, {% raw %}<span class="math inline">\(b_j=P(B_j)\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(t_{ij}=P(B_j\mid A_i)-b_j\)</span>{% endraw %}. The total variation bound on each row gives {% raw %}<span class="math inline">\(\sum_j|t_{ij}|\leq2\phi\)</span>{% endraw %}: sum the positive entries and use the definition of {% raw %}<span class="math inline">\(\phi\)</span>{% endraw %} on the union of their {% raw %}<span class="math inline">\(B_j\)</span>{% endraw %}. Also {% raw %}<span class="math inline">\(\sum_i a_i|t_{ij}|\leq2b_j\)</span>{% endraw %}. Weighted Hölder therefore gives, for {% raw %}<span class="math inline">\(1&lt;q&lt;\infty\)</span>{% endraw %},</p>

{% raw %}<div class="math display">\[\sum_i a_i\left|\sum_jt_{ij}y_j\right|^q\leq(2\phi)^{q-1}\sum_{i,j}a_i|t_{ij}||y_j|^q\leq2^q\phi^{q-1}\sum_jb_j|y_j|^q.\]</div>{% endraw %}<p>Pairing {% raw %}<span class="math inline">\(\sum_jt_{ij}y_j\)</span>{% endraw %} with the values of {% raw %}<span class="math inline">\(X\)</span>{% endraw %} and applying Hölder once more proves the stated covariance bound for simple variables. Approximate in {% raw %}<span class="math inline">\(L^p\)</span>{% endraw %} and {% raw %}<span class="math inline">\(L^q\)</span>{% endraw %} to get the general case. For {% raw %}<span class="math inline">\(p=1,q=\infty\)</span>{% endraw %}, the row-sum bound directly gives {% raw %}<span class="math inline">\(|\sum_jt_{ij}y_j|\leq2\phi\|Y\|_\infty\)</span>{% endraw %}; approximate bounded {% raw %}<span class="math inline">\(Y\)</span>{% endraw %} uniformly and {% raw %}<span class="math inline">\(X\)</span>{% endraw %} in {% raw %}<span class="math inline">\(L^1\)</span>{% endraw %}. If {% raw %}<span class="math inline">\(\phi=0\)</span>{% endraw %}, all these covariances are zero.</p>

</div>
<h3 data-note-section="1" id="population-mean">1. Population Mean</h3>

<p>For covariance-stationary data, write {% raw %}<span class="math inline">\(\bar X_n=n^{-1}\sum_{i=1}^nX_i\)</span>{% endraw %} and {% raw %}<span class="math inline">\(R(k)=\operatorname{Cov}(X_0,X_k)\)</span>{% endraw %} for {% raw %}<span class="math inline">\(k\geq0\)</span>{% endraw %}. Counting pairs at each lag gives</p>

{% raw %}<div class="math display">\[\operatorname{Var}(\sqrt n\bar X_n)=R(0)+2\sum_{k=1}^{n-1}(1-k/n)R(k).\]</div>{% endraw %}<p>If {% raw %}<span class="math inline">\(\sum_{k\geq1}|R(k)|&lt;\infty\)</span>{% endraw %}, dominated convergence yields the finite long-run variance {% raw %}<span class="math inline">\(\sigma_\infty^2=R(0)+2\sum_{k\geq1}R(k)\)</span>{% endraw %}. This is a sufficient condition, not a necessary characterization of bounded variances.</p>

<p>For a strictly stationary process bounded by one, Lemma 4 gives {% raw %}<span class="math inline">\(|R(k)|\leq4\alpha_X(k)\)</span>{% endraw %}. Thus summability of {% raw %}<span class="math inline">\(\alpha_X\)</span>{% endraw %} suffices. More generally, if {% raw %}<span class="math inline">\(\mathbb{E}|X_0|^{2+\delta}&lt;\infty\)</span>{% endraw %}, apply (3) with both moment exponents equal to {% raw %}<span class="math inline">\(2+\delta\)</span>{% endraw %} to obtain</p>

{% raw %}<div class="math display">\[|R(k)|\leq8\|X_0\|_{2+\delta}^2\alpha_X(k)^{\delta/(2+\delta)}.\]</div>{% endraw %}<p>Consequently {% raw %}<span class="math inline">\(\sum_{k\geq1}\alpha_X(k)^{\delta/(2+\delta)}&lt;\infty\)</span>{% endraw %} gives absolute covariance summability. These variance calculations alone do not prove a CLT; the next theorem uses the stronger finite-dependence assumption.</p>

<div id="result-6" class="theorem" data-note-number="6" data-note-kind="Theorem">
<p><strong>Theorem 6</strong>.  Suppose {% raw %}<span class="math inline">\(\{X_i\}_{i \in \mathbb N}\)</span>{% endraw %} is a stationary, {% raw %}<span class="math inline">\(m\)</span>{% endraw %}-dependent sequence with mean {% raw %}<span class="math inline">\(\mu\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\mathop{\mathrm{Var}}(X_1) &lt; \infty\)</span>{% endraw %}. Then, </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \sqrt n (\overline X_n - \mu) \xrightarrow{d} \mathcal{N}(0,\sigma_\infty^2) ~,
    
\end{aligned}\]</div>{% endraw %}
<p> where {% raw %}<span class="math inline">\(\sigma_\infty^2 = \mathop{\mathrm{Var}}(X_1) + 2 \sum_{k \in \mathbb N} R(k)\)</span>{% endraw %}.</p>

</div>
<p>Proof of Theorem 6. Center the process, writing {% raw %}<span class="math inline">\(Y_i=X_i-\mu\)</span>{% endraw %}. Because covariances vanish beyond lag {% raw %}<span class="math inline">\(m\)</span>{% endraw %}, the preceding variance formula gives {% raw %}<span class="math inline">\(n^{-1}\operatorname{Var}(\sum_{i=1}^nY_i)\to\sigma_\infty^2\ge0\)</span>{% endraw %}. If this limit is zero, Chebyshev proves convergence to the degenerate normal law. Suppose first that {% raw %}<span class="math inline">\(|Y_i|\le C\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\sigma_\infty^2&gt;0\)</span>{% endraw %}.</p>

<p>Choose {% raw %}<span class="math inline">\(b_n=\lfloor n^{1/3}\rfloor\)</span>{% endraw %}. Partition the observations into consecutive retained blocks of length {% raw %}<span class="math inline">\(b_n\)</span>{% endraw %}, separated by discarded gaps of length {% raw %}<span class="math inline">\(m\)</span>{% endraw %}, and discard the final incomplete block. The retained block sums {% raw %}<span class="math inline">\(B_{n,j}\)</span>{% endraw %} are independent: each block is separated by more than {% raw %}<span class="math inline">\(m\)</span>{% endraw %} from the union of all preceding blocks, so independence follows successively from the sigma-field definition. For any subset {% raw %}<span class="math inline">\(A\)</span>{% endraw %} of indices,</p>

{% raw %}<div class="math display">\[\operatorname{Var}\!\left(\sum_{i\in A}Y_i\right)\le (2m+1)|A|EY_1^2,\]</div>{% endraw %}

<p>because every summand has at most {% raw %}<span class="math inline">\(2m+1\)</span>{% endraw %} potentially nonzero covariances and each covariance is bounded by {% raw %}<span class="math inline">\(EY_1^2\)</span>{% endraw %}. The number of discarded observations is {% raw %}<span class="math inline">\(O(nm/b_n+b_n+m)=o(n)\)</span>{% endraw %}. Their sum divided by {% raw %}<span class="math inline">\(\sqrt n\)</span>{% endraw %} therefore tends to zero in {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %}. The triangle inequality for {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %} norms now gives</p>

{% raw %}<div class="math display">\[s_n^2:=\sum_j\operatorname{Var}(B_{n,j})\sim n\sigma_\infty^2.\]</div>{% endraw %}

<p>Each {% raw %}<span class="math inline">\(|B_{n,j}|\le Cb_n=o(\sqrt n)\)</span>{% endraw %}, so for every fixed {% raw %}<span class="math inline">\(\varepsilon&gt;0\)</span>{% endraw %} the Lindeberg indicators {% raw %}<span class="math inline">\(\mathbf1\{|B_{n,j}|&gt;\varepsilon s_n\}\)</span>{% endraw %} eventually vanish. The independent triangular-array CLT gives {% raw %}<span class="math inline">\(s_n^{-1}\sum_j B_{n,j}\Rightarrow \mathcal{N}(0,1)\)</span>{% endraw %}. Restoring the negligible gaps proves the bounded case.</p>

<p>For general {% raw %}<span class="math inline">\(EY_1^2&lt;\infty\)</span>{% endraw %}, set {% raw %}<span class="math inline">\(Y_i^{(K)}=Y_i\mathbf1\{|Y_i|\le K\}-E[Y_i\mathbf1\{|Y_i|\le K\}]\)</span>{% endraw %}. This is still stationary and {% raw %}<span class="math inline">\(m\)</span>{% endraw %}-dependent, and its CLT follows from the bounded case (including zero limiting variance). The centered tail {% raw %}<span class="math inline">\(D_i^{(K)}=Y_i-Y_i^{(K)}\)</span>{% endraw %} satisfies</p>

{% raw %}<div class="math display">\[\sup_n E\left[\frac1{\sqrt n}\sum_{i=1}^nD_i^{(K)}\right]^2\le(2m+1)E[Y_1^2\mathbf1\{|Y_1|&gt;K\}]\longrightarrow0.\]</div>{% endraw %}

<p>Also {% raw %}<span class="math inline">\(Y_i^{(K)}\to Y_i\)</span>{% endraw %} in {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %}, so each of the finitely many covariance terms in its long-run variance converges to the corresponding original term. Thus {% raw %}<span class="math inline">\(\sigma_K^2\to\sigma_\infty^2\)</span>{% endraw %}. For a bounded Lipschitz test function, the difference between expectations for the original and truncated normalized sums is bounded by its Lipschitz constant times the square root of the preceding tail bound. First let {% raw %}<span class="math inline">\(n\to\infty\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(K\to\infty\)</span>{% endraw %}, to obtain the claimed normal limit. ◻</p>
<p>Further central limit theorems are given in <span class="citation" data-cites="hall_martingale_1980"><a href="#ref-hall_martingale_1980" role="doc-biblioref">Hall and Heyde (1980, §5.4)</a></span>.</p>

<h2 data-note-section="2" id="mixingales">2. Mixingales</h2>
<p>The preceding coefficients compare whole sigma-fields. A mixingale condition instead controls how well a particular centered variable can be predicted from distant information. The filtration is part of the condition; it need not be the natural filtration of the process.</p>
<p><strong>Definition (mixingale).</strong> Let {% raw %}<span class="math inline">\((\Omega,\mathcal F,P)\)</span>{% endraw %} be a probability space, {% raw %}<span class="math inline">\((\mathcal G_i)_{i\in\mathbb Z}\)</span>{% endraw %} an increasing filtration, and {% raw %}<span class="math inline">\(1\leq p&lt;\infty\)</span>{% endraw %}. A sequence {% raw %}<span class="math inline">\((Z_i)_{i\in\mathbb Z}\)</span>{% endraw %} in {% raw %}<span class="math inline">\(L^p(P)\)</span>{% endraw %} is an {% raw %}<span class="math inline">\(L^p\)</span>{% endraw %}-mixingale relative to this filtration if there are deterministic constants {% raw %}<span class="math inline">\(0\leq c_i&lt;\infty\)</span>{% endraw %} and {% raw %}<span class="math inline">\(0\leq\psi_m&lt;\infty\)</span>{% endraw %}, with {% raw %}<span class="math inline">\(\psi_m\to0\)</span>{% endraw %} as the integer {% raw %}<span class="math inline">\(m\to\infty\)</span>{% endraw %}, such that, for every {% raw %}<span class="math inline">\(i\in\mathbb Z\)</span>{% endraw %} and integer {% raw %}<span class="math inline">\(m\geq0\)</span>{% endraw %},</p>
{% raw %}<div class="math display">\[
\begin{aligned}
\|\mathbb E[Z_i\mid\mathcal G_{i-m}]\|_p&amp;\leq c_i\psi_m,\\
\|Z_i-\mathbb E[Z_i\mid\mathcal G_{i+m}]\|_p&amp;\leq c_i\psi_{m+1}.
\end{aligned}
\]</div>{% endraw %}
<p>Here {% raw %}<span class="math inline">\(\|Z\|_p=(\mathbb E|Z|^p)^{1/p}\)</span>{% endraw %}. The sequence {% raw %}<span class="math inline">\(c_i\)</span>{% endraw %} allows the size of the variables to vary with {% raw %}<span class="math inline">\(i\)</span>{% endraw %}, while {% raw %}<span class="math inline">\(\psi_m\)</span>{% endraw %} controls decay with separation. One may replace {% raw %}<span class="math inline">\(\psi_m\)</span>{% endraw %} by {% raw %}<span class="math inline">\(\sup_{r\geq m}\psi_r\)</span>{% endraw %} to make it nonincreasing. The first inequality implies {% raw %}<span class="math inline">\(\mathbb EZ_i=0\)</span>{% endraw %}: conditional Jensen gives {% raw %}<span class="math inline">\(|\mathbb EZ_i|\leq c_i\psi_m\)</span>{% endraw %} for every {% raw %}<span class="math inline">\(m\)</span>{% endraw %}. For an uncentered process, apply the definition to {% raw %}<span class="math inline">\(Z_i=X_i-\mathbb EX_i\)</span>{% endraw %}.</p>
<p>The first bound requires the distant past to predict little of {% raw %}<span class="math inline">\(Z_i\)</span>{% endraw %}. The second requires sufficiently late information to approximate {% raw %}<span class="math inline">\(Z_i\)</span>{% endraw %} in {% raw %}<span class="math inline">\(L^p\)</span>{% endraw %}. If {% raw %}<span class="math inline">\(Z_i\)</span>{% endraw %} is {% raw %}<span class="math inline">\(\mathcal G_i\)</span>{% endraw %}-measurable, the second error is already zero for every {% raw %}<span class="math inline">\(m\geq0\)</span>{% endraw %}. This is the adapted case used below. The square-integrable formulation originates in <a href="https://doi.org/10.1214/aop/1176996269">McLeish (1975)</a>; the results needed here have elementary proofs.</p>
<h3 id="martingale-differences">Martingale differences</h3>
<p><strong>Proposition.</strong> Every {% raw %}<span class="math inline">\(L^p\)</span>{% endraw %} martingale-difference sequence {% raw %}<span class="math inline">\((Z_i,\mathcal G_i)_{i\in\mathbb Z}\)</span>{% endraw %} is a mixingale with {% raw %}<span class="math inline">\(c_i=\|Z_i\|_p\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\psi_0=1\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(\psi_m=0\)</span>{% endraw %} for {% raw %}<span class="math inline">\(m\geq1\)</span>{% endraw %}.</p>

<p><strong>Proof.</strong> For {% raw %}<span class="math inline">\(m\geq1\)</span>{% endraw %}, the tower property gives</p>

{% raw %}<div class="math display">\[\mathbb E[Z_i\mid\mathcal G_{i-m}]
=\mathbb E[\mathbb E(Z_i\mid\mathcal G_{i-1})\mid\mathcal G_{i-m}]=0.\]</div>{% endraw %}

<p>At {% raw %}<span class="math inline">\(m=0\)</span>{% endraw %}, adaptedness gives {% raw %}<span class="math inline">\(\|\mathbb E[Z_i\mid\mathcal G_i]\|_p=\|Z_i\|_p\)</span>{% endraw %}. Also {% raw %}<span class="math inline">\(Z_i\)</span>{% endraw %} is measurable with respect to {% raw %}<span class="math inline">\(\mathcal G_{i+m}\)</span>{% endraw %} for every {% raw %}<span class="math inline">\(m\geq0\)</span>{% endraw %}, so the second mixingale error is zero. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>

<p>The martingale-difference property does not imply strong mixing. Let {% raw %}<span class="math inline">\(V\)</span>{% endraw %} take the values {% raw %}<span class="math inline">\(1,2\)</span>{% endraw %}, each with probability {% raw %}<span class="math inline">\(1/2\)</span>{% endraw %}, and let {% raw %}<span class="math inline">\((\varepsilon_i)_{i\in\mathbb Z}\)</span>{% endraw %} be independent fair signs, independent of {% raw %}<span class="math inline">\(V\)</span>{% endraw %}. Set {% raw %}<span class="math inline">\(Z_i=V\varepsilon_i\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\mathcal G_i=\sigma(V,\varepsilon_j:j\leq i)\)</span>{% endraw %}. This is a stationary bounded martingale-difference sequence, since {% raw %}<span class="math inline">\(\mathbb E[\varepsilon_i\mid\mathcal G_{i-1}]=0\)</span>{% endraw %}. But for every {% raw %}<span class="math inline">\(m\geq1\)</span>{% endraw %}, the events {% raw %}<span class="math inline">\(E=\{|Z_0|=1\}\)</span>{% endraw %} and {% raw %}<span class="math inline">\(F_m=\{|Z_m|=1\}\)</span>{% endraw %} both equal {% raw %}<span class="math inline">\(\{V=1\}\)</span>{% endraw %}. Consequently</p>

{% raw %}<div class="math display">\[|\mathbb P(E\cap F_m)-\mathbb P(E)\mathbb P(F_m)|=\frac14.\]</div>{% endraw %}

<p>Thus the strong-mixing coefficient is at least {% raw %}<span class="math inline">\(1/4\)</span>{% endraw %} at every lag, although the mixingale coefficients vanish for every positive lag.</p>

<p>For example, let {% raw %}<span class="math inline">\((\varepsilon_i)_{i\in\mathbb Z}\)</span>{% endraw %} be iid {% raw %}<span class="math inline">\(\mathcal N(0,1)\)</span>{% endraw %}, take {% raw %}<span class="math inline">\(\mathcal G_i=\sigma(\varepsilon_j:j\leq i)\)</span>{% endraw %}, and set {% raw %}<span class="math inline">\(Z_i=\varepsilon_{i-1}\varepsilon_i\)</span>{% endraw %}. Independence gives</p>
{% raw %}<div class="math display">\[
\mathbb E[Z_i\mid\mathcal G_{i-1}]=0,\qquad
\mathbb E[Z_i^2\mid\mathcal G_{i-1}]=\varepsilon_{i-1}^2,
\qquad \mathbb EZ_i^2=1.
\]</div>{% endraw %}
<p>These differences are not independent: {% raw %}<span class="math inline">\(\mathbb E[Z_i^2Z_{i+1}^2]=\mathbb E\varepsilon_i^4=3\)</span>{% endraw %}, whereas {% raw %}<span class="math inline">\(\mathbb EZ_i^2\mathbb EZ_{i+1}^2=1\)</span>{% endraw %}. Nevertheless, for {% raw %}<span class="math inline">\(i&lt;j\)</span>{% endraw %}, conditioning on {% raw %}<span class="math inline">\(\mathcal G_{j-1}\)</span>{% endraw %} gives {% raw %}<span class="math inline">\(\mathbb E[Z_iZ_j]=0\)</span>{% endraw %}. Consequently {% raw %}<span class="math inline">\(\mathbb E(n^{-1}\sum_{i=1}^nZ_i)^2=1/n\)</span>{% endraw %}. Conditional means, conditional variances, and independence are different restrictions.</p>
<h3 id="from-mixing-to-a-mixingale-bound">From mixing to a mixingale bound</h3>
<p>Let {% raw %}<span class="math inline">\(Z_i=X_i-\mathbb EX_i\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\mathcal G_i=\mathcal F_{-\infty}^i\)</span>{% endraw %}. If {% raw %}<span class="math inline">\(Z_i\in L^2\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\rho_X(m)\to0\)</span>{% endraw %}, then</p>
{% raw %}<div class="math display">\[
\|\mathbb E[Z_i\mid\mathcal G_{i-m}]\|_2
\leq\rho_X(m)\|Z_i\|_2\qquad(m\geq1).
\]</div>{% endraw %}
<p>To prove this, write {% raw %}<span class="math inline">\(W=\mathbb E[Z_i\mid\mathcal G_{i-m}]\)</span>{% endraw %}. It is centered and {% raw %}<span class="math inline">\(\mathbb E[WZ_i]=\mathbb EW^2\)</span>{% endraw %}. If {% raw %}<span class="math inline">\(\|W\|_2&gt;0\)</span>{% endraw %}, apply the definition of maximal correlation to {% raw %}<span class="math inline">\(W\)</span>{% endraw %} and {% raw %}<span class="math inline">\(Z_i\)</span>{% endraw %}, then divide by {% raw %}<span class="math inline">\(\|W\|_2\)</span>{% endraw %}. The zero-norm case is immediate. Thus {% raw %}<span class="math inline">\(c_i=\|Z_i\|_2\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\psi_0=1\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(\psi_m=\rho_X(m)\)</span>{% endraw %} give an adapted {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %}-mixingale.</p>
<p>Strong mixing also suffices with a higher moment. Suppose {% raw %}<span class="math inline">\(Z_i\in L^{2+\delta}\)</span>{% endraw %} for a common {% raw %}<span class="math inline">\(\delta&gt;0\)</span>{% endraw %}. Apply inequality (3) of Lemma 4 to {% raw %}<span class="math inline">\(Z_i\)</span>{% endraw %} and {% raw %}<span class="math inline">\(W/\|W\|_2\)</span>{% endraw %}, with moment exponents {% raw %}<span class="math inline">\(2+\delta\)</span>{% endraw %} and {% raw %}<span class="math inline">\(2\)</span>{% endraw %}. The same conditioning identity yields</p>
{% raw %}<div class="math display">\[
\|W\|_2\leq8\|Z_i\|_{2+\delta}
\alpha_X(m)^{\delta/[2(2+\delta)]}.
\]</div>{% endraw %}
<p>Hence {% raw %}<span class="math inline">\(c_i=\|Z_i\|_{2+\delta}\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\psi_0=8\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(\psi_m=8\alpha_X(m)^{\delta/[2(2+\delta)]}\)</span>{% endraw %} for {% raw %}<span class="math inline">\(m\geq1\)</span>{% endraw %} suffice when {% raw %}<span class="math inline">\(\alpha_X(m)\to0\)</span>{% endraw %}. The exponent here differs from the covariance exponent obtained earlier by putting both variables in {% raw %}<span class="math inline">\(L^{2+\delta}\)</span>{% endraw %}: the conditional-mean argument pairs with an arbitrary {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %} variable. Uniform bounds on {% raw %}<span class="math inline">\(c_i\)</span>{% endraw %} are additional assumptions, needed for the following result.</p>
<h3 id="a-law-of-large-numbers">A law of large numbers</h3>
<p><strong>Proposition (adapted {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %} law).</strong> Suppose {% raw %}<span class="math inline">\((Z_i,\mathcal G_i)\)</span>{% endraw %} is an adapted {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %}-mixingale, {% raw %}<span class="math inline">\(\sup_i\|Z_i\|_2\leq C\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(\sup_i c_i\leq C\)</span>{% endraw %} for some finite {% raw %}<span class="math inline">\(C\)</span>{% endraw %}. Then</p>
{% raw %}<div class="math display">\[
\frac1n\sum_{i=1}^n Z_i\longrightarrow0\quad\text{in }L^2,
\]</div>{% endraw %}
<p>and therefore in probability.</p>
<p><em>Remark.</em> In the proof of the <a href="#a-law-of-large-numbers">adapted mixingale law of large numbers</a>, stationarity of the sequence and summability of the coefficients {% raw %}<span class="math inline">\(\psi_m\)</span>{% endraw %} are not assumed.</p>
<p><em>Proof.</em> For {% raw %}<span class="math inline">\(i&lt;j\)</span>{% endraw %}, adaptedness and Cauchy–Schwarz give</p>
{% raw %}<div class="math display">\[
|\mathbb E[Z_iZ_j]|
=|\mathbb E[Z_i\mathbb E[Z_j\mid\mathcal G_i]]|
\leq C^2\psi_{j-i}.
\]</div>{% endraw %}
<p>Since the variables are centered,</p>
{% raw %}<div class="math display">\[
\mathbb E\left(\frac1n\sum_{i=1}^n Z_i\right)^2
\leq\frac{C^2}{n}
+\frac{2C^2}{n^2}\sum_{k=1}^{n-1}(n-k)\psi_k
\leq\frac{C^2}{n}+\frac{2C^2}{n}\sum_{k=1}^{n-1}\psi_k\longrightarrow0.
\]</div>{% endraw %}
<p>For the last limit, fix {% raw %}<span class="math inline">\(K\)</span>{% endraw %}, separate the first {% raw %}<span class="math inline">\(K\)</span>{% endraw %} terms, and bound the remaining average by {% raw %}<span class="math inline">\(\sup_{k&gt;K}\psi_k\)</span>{% endraw %}. First send {% raw %}<span class="math inline">\(n\to\infty\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(K\to\infty\)</span>{% endraw %}. Chebyshev gives convergence in probability. □</p>
<p>The adapted mixingale law of large numbers establishes consistency of the sample mean under the stated conditional-prediction restriction. The proposition supplies neither a convergence rate nor a central limit theorem. If {% raw %}<span class="math inline">\(\sum_k\psi_k&lt;\infty\)</span>{% endraw %}, the covariance-sum estimate in the proof gives an {% raw %}<span class="math inline">\(O(n^{-1})\)</span>{% endraw %} mean-square bound, but a normal approximation still requires further conditions.</p>
<p>The next example also satisfies this law despite failing strong mixing. For its stationary Bernoulli AR(1) process, put {% raw %}<span class="math inline">\(\mu=p/(1-\rho)\)</span>{% endraw %}, {% raw %}<span class="math inline">\(Z_t=X_t-\mu\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(\mathcal G_t=\sigma(\varepsilon_j:j\leq t)\)</span>{% endraw %}. Iterating the recursion gives</p>
{% raw %}<div class="math display">\[
Z_t=\sum_{j=0}^{m-1}\rho^j(\varepsilon_{t-j}-p)+\rho^mZ_{t-m},
\qquad
\mathbb E[Z_t\mid\mathcal G_{t-m}]=\rho^mZ_{t-m}.
\]</div>{% endraw %}
<p>Thus {% raw %}<span class="math inline">\(c_t=\|Z_t\|_2=\sqrt{p(1-p)/(1-\rho^2)}\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\psi_m=\rho^m\)</span>{% endraw %} work, including {% raw %}<span class="math inline">\(m=0\)</span>{% endraw %}. The innovation and observation past sigma-fields coincide, since the series makes {% raw %}<span class="math inline">\(X_s\)</span>{% endraw %} measurable from past innovations and {% raw %}<span class="math inline">\(\varepsilon_s=X_s-\rho X_{s-1}\)</span>{% endraw %} recovers them from past observations. Remote conditional means decay even though a future observation retains the past innovation digits. The distinction is between predicting this variable in norm and recovering events from the entire sigma-field.</p>

<h2 data-note-section="3" id="important-counterexamples">3. Important Counterexamples</h2>
<h3 data-note-section="3.1" id="ar1-process-is-not-strong-mixing">3.1. AR(1) process is not strong-mixing <span><span class="citation" data-cites="andrews_non-strong_1984">(<a href="#ref-andrews_non-strong_1984" role="doc-biblioref">Andrews 1984</a>)</span></span></h3>
<span id="eq:AR-1--bernoulli"></span><span id="eq:andrews-1984-A-Bs-defs"></span>
<p>Decay of linear coefficients does not by itself imply strong mixing. Let {% raw %}<span class="math inline">\((\varepsilon_t)_{t\in\mathbb Z}\)</span>{% endraw %} be i.i.d. Bernoulli {% raw %}<span class="math inline">\(p\)</span>{% endraw %} variables with {% raw %}<span class="math inline">\(0&lt;p&lt;1\)</span>{% endraw %}, and set</p>

{% raw %}<div class="math display">\[X_t=\sum_{j=0}^{\infty}\rho^j\varepsilon_{t-j},\qquad0&lt;\rho\leq1/2.\tag{4}\]</div>{% endraw %}<p>The series converges absolutely, defines a strictly stationary process, and satisfies {% raw %}<span class="math inline">\(X_t=\rho X_{t-1}+\varepsilon_t\)</span>{% endraw %}. Nevertheless one future value retains the earlier innovation digits.</p>

<div id="lem:andrews-1984-non-mixing-step1" class="lemma" data-note-number="7" data-note-kind="Lemma">
<p><strong>Lemma 7</strong>. If {% raw %}<span class="math inline">\(A\in\mathcal F_{-\infty}^t\)</span>{% endraw %} has {% raw %}<span class="math inline">\(P(A)&gt;0\)</span>{% endraw %} and there are {% raw %}<span class="math inline">\(B_s\in\mathcal F_{t+s}^{\infty}\)</span>{% endraw %} with {% raw %}<span class="math inline">\(P(B_s\mid A)=1\)</span>{% endraw %} and {% raw %}<span class="math inline">\(P(B_s)\leq\ell&lt;1\)</span>{% endraw %} for every {% raw %}<span class="math inline">\(s\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(\alpha_X(s)\geq P(A)(1-\ell)&gt;0\)</span>{% endraw %}.</p>

</div>
<div class="proof">
<p><em>Proof.</em> Use {% raw %}<span class="math inline">\(P(A\cap B_s)=P(A)\)</span>{% endraw %} in the definition of {% raw %}<span class="math inline">\(\alpha_X(s)\)</span>{% endraw %}. The uniform strict bound {% raw %}<span class="math inline">\(\ell&lt;1\)</span>{% endraw %} is necessary.</p>

<p>◻</p>
</div>
<div id="lem:andrews-1984-non-mixing-step2" class="lemma" data-note-number="8" data-note-kind="Lemma">
<p><strong>Lemma 8</strong>. For each fixed {% raw %}<span class="math inline">\(s\)</span>{% endraw %}, the innovation {% raw %}<span class="math inline">\(\varepsilon_t\)</span>{% endraw %} is a Borel function of {% raw %}<span class="math inline">\(X_{t+s}\)</span>{% endraw %} almost surely.</p>

</div>
<div class="proof">
<p><em>Proof.</em></p>

<p>For {% raw %}<span class="math inline">\(0&lt;\rho&lt;1/2\)</span>{% endraw %}, digit strings are unique. If two strings first differ at position {% raw %}<span class="math inline">\(j\)</span>{% endraw %}, the difference of their series has magnitude at least</p>

{% raw %}<div class="math display">\[\rho^j-\sum_{k&gt;j}\rho^k=\rho^j\frac{1-2\rho}{1-\rho}&gt;0.\]</div>{% endraw %}<p>More constructively, the leading digit is zero if {% raw %}<span class="math inline">\(x&lt;1\)</span>{% endraw %} and one if {% raw %}<span class="math inline">\(x\geq1\)</span>{% endraw %}, since a string starting with zero has value at most {% raw %}<span class="math inline">\(\rho/(1-\rho)&lt;1\)</span>{% endraw %}. Subtract that digit and divide by {% raw %}<span class="math inline">\(\rho\)</span>{% endraw %} to recover the next digit; iterating gives Borel digit functions.</p>

<p>At {% raw %}<span class="math inline">\(\rho=1/2\)</span>{% endraw %}, this is ordinary binary expansion of {% raw %}<span class="math inline">\(X/2\)</span>{% endraw %}. Nonuniqueness occurs only at the countably many dyadic values, whose expansions are eventually constant. An i.i.d. Bernoulli sequence with {% raw %}<span class="math inline">\(0&lt;p&lt;1\)</span>{% endraw %} is eventually all zeros or all ones with probability zero. Choose either Borel convention at the exceptional values. The {% raw %}<span class="math inline">\(s\)</span>{% endraw %}th recovered digit of {% raw %}<span class="math inline">\(X_{t+s}\)</span>{% endraw %} is {% raw %}<span class="math inline">\(\varepsilon_t\)</span>{% endraw %} almost surely.</p>

<p>◻</p>

</div>
<div id="lem:andrews-1984-non-mixing-step3" class="lemma" data-note-number="9" data-note-kind="Lemma">
<p><strong>Lemma 9</strong>. For this process, {% raw %}<span class="math inline">\(\alpha_X(s)\geq p(1-p)\)</span>{% endraw %} for every positive integer {% raw %}<span class="math inline">\(s\)</span>{% endraw %}. In particular it is not strong mixing.</p>

</div>
<div class="proof">
<p><em>Proof.</em> The event {% raw %}<span class="math inline">\(A=\{\varepsilon_t=1\}\)</span>{% endraw %} belongs to the past sigma-field because {% raw %}<span class="math inline">\(\varepsilon_t=X_t-\rho X_{t-1}\)</span>{% endraw %}. Let {% raw %}<span class="math inline">\(B_s\)</span>{% endraw %} be the event that the {% raw %}<span class="math inline">\(s\)</span>{% endraw %}th digit recovered from {% raw %}<span class="math inline">\(X_{t+s}\)</span>{% endraw %} is one. Then {% raw %}<span class="math inline">\(B_s\)</span>{% endraw %} belongs to the future sigma-field and equals {% raw %}<span class="math inline">\(A\)</span>{% endraw %} up to a null set. Thus {% raw %}<span class="math inline">\(P(A\cap B_s)-P(A)P(B_s)=p-p^2\)</span>{% endraw %}.</p>
