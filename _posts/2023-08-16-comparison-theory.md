<div class="note-content" markdown="0">

<p>Throughout, manifolds and maps are smooth unless stated otherwise. On a Riemannian manifold, {% raw %}<span class="math inline">\(\nabla\)</span>{% endraw %} denotes the Levi–Civita connection. The needed local constructions start with <a href="{% post_url 2022-02-05-differentiable-manifolds-charts-constructions-and-examples %}">coordinate charts</a>.</p>

<div id="comparison-theory" data-note-section="title">

</div>
<p>A curvature bound estimates the separation of nearby geodesics. Write {% raw %}<span class="math inline">\(T=\gamma'\)</span>{% endraw %} for a unit-speed geodesic and {% raw %}<span class="math inline">\(P_t:T_{\gamma(0)}M\to T_{\gamma(t)}M\)</span>{% endraw %} for parallel transport. In constant curvature {% raw %}<span class="math inline">\(k\)</span>{% endraw %}, decompose {% raw %}<span class="math inline">\(v=v^\top+v^\perp\)</span>{% endraw %} relative to {% raw %}<span class="math inline">\(T(0)\)</span>{% endraw %}. The Jacobi field with {% raw %}<span class="math inline">\(J(0)=0,\ J'(0)=v\)</span>{% endraw %} is</p>
{% raw %}<div class="math display">\[J(t)=tP_tv^\top+s_k(t)P_tv^\perp.\]</div>{% endraw %}
<p> Indeed, the tangential Jacobi equation is {% raw %}<span class="math inline">\(j''=0\)</span>{% endraw %}, while the normal equation is {% raw %}<span class="math inline">\(j''+kj=0\)</span>{% endraw %}. Thus the familiar formulas {% raw %}<span class="math inline">\(\sin(t)P_tv,\ tP_tv,\ \sinh(t)P_tv\)</span>{% endraw %} for the unit sphere, Euclidean space, and hyperbolic space apply to <em>normal</em> initial vectors. They express the initial separation and subsequent convergence on the sphere, linear separation in Euclidean space, and exponential separation in hyperbolic space. The results below compare variable curvature with these scalar model equations; see also <a href="#ref-cheeger_comparison_1975">Cheeger and Ebin (1975)</a>.</p>

<h3 data-note-section="1" id="rauch-comparison-theorem">1. Rauch Comparison Theorem</h3>
<p>We begin with comparison against scalar model solutions, then prove Rauch’s theorem by comparing index forms. This separates the explicit model calculations from the argument that applies to general manifolds. In what follows, for {% raw %}<span class="math inline">\(\delta \in \mathbb R\)</span>{% endraw %}, let </p>

{% raw %}<span id="eq:jacobi-cos"></span><span id="eq:jacobi-sine"></span><div class="math display">\[\begin{aligned}
     c_\delta (t) &amp;\triangleq \begin{cases}
        \cos (\sqrt{\delta} t) &amp; \text{ if } \delta &gt; 0 \\
        1 &amp; \text{ if } \delta = 0 \\
        \cosh (\sqrt{-\delta} t) &amp; \text{ if } \delta &lt; 0
    \end{cases} ~, \\
     s_\delta (t) &amp;\triangleq \begin{cases}
        \frac{1}{\sqrt{\delta}} \sin (\sqrt{\delta} t) &amp; \text{ if } \delta &gt; 0 \\
        t &amp; \text{ if } \delta = 0 \\
        \frac{1}{\sqrt{-\delta}} \sinh (\sqrt{-\delta} t) &amp; \text{ if } \delta &lt; 0
    \end{cases} ~.
\end{aligned}\tag{1}\]</div>{% endraw %}
<p> Note that these are the solutions to the Jacobi equation for constant sectional curvature {% raw %}<span class="math inline">\(\delta\)</span>{% endraw %}. As usual, let {% raw %}<span class="math inline">\(\gamma(t)\)</span>{% endraw %} be a geodesic on {% raw %}<span class="math inline">\(M\)</span>{% endraw %} parametrized by arclength, and {% raw %}<span class="math inline">\(J(t)\)</span>{% endraw %} denote a Jacobi field along {% raw %}<span class="math inline">\(\gamma(t)\)</span>{% endraw %}.</p>


<div id="result-1" class="theorem" data-note-number="1" data-note-kind="Theorem">
<p><strong>Theorem 1.</strong> Let {% raw %}<span class="math inline">\(K\leq\delta\)</span>{% endraw %} along the unit-speed geodesic {% raw %}<span class="math inline">\(\gamma\)</span>{% endraw %}, and let {% raw %}<span class="math inline">\(J\)</span>{% endraw %} be a Jacobi field. Assume either {% raw %}<span class="math inline">\(J\perp T\)</span>{% endraw %} or {% raw %}<span class="math inline">\(\delta\geq0\)</span>{% endraw %}. Put {% raw %}<span class="math inline">\(a=|J(0)|,\ b=(|J|)'(0+)\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(f_\delta=ac_\delta+bs_\delta\)</span>{% endraw %}. When {% raw %}<span class="math inline">\(J(0)=0\)</span>{% endraw %}, the right derivative is {% raw %}<span class="math inline">\(b=|J'(0)|\)</span>{% endraw %}. Suppose {% raw %}<span class="math inline">\(f_\delta&gt;0\)</span>{% endraw %} on {% raw %}<span class="math inline">\((0,\tau)\)</span>{% endraw %}. Then</p>
 {% raw %}<span id="eq:rauch-prelim-1"></span><span id="eq:rauch-prelim-2"></span><span id="eq:rauch-prelim-3"></span>
<div class="math display">\[\langle J,J'\rangle f_\delta\geq |J|^2f_\delta',\qquad 1\leq\frac{|J(t_1)|}{f_\delta(t_1)}\leq\frac{|J(t_2)|}{f_\delta(t_2)} \quad(0&lt;t_1\leq t_2&lt;\tau),\tag{2}\]</div>{% endraw %}
<p> and {% raw %}<span class="math inline">\(|J(t)|\geq f_\delta(t)\)</span>{% endraw %}. The inequalities without quotients extend to finite endpoints where the fields are defined.</p>
</div>
<div class="proof">
<p><em>Proof.</em> Set {% raw %}<span class="math inline">\(h=|J|\)</span>{% endraw %} on an interval on which {% raw %}<span class="math inline">\(J\neq0\)</span>{% endraw %}. Our curvature convention is {% raw %}<span class="math inline">\(J''+R(T,J)T=0\)</span>{% endraw %}, so</p>
{% raw %}<div class="math display">\[h''+\delta h =\frac{|J'|^2-(h')^2}{h} +\frac{\delta|J|^2-\langle R(T,J)T,J\rangle}{h}\geq0.\]</div>{% endraw %}
<p> The first numerator is nonnegative by Cauchy–Schwarz. For a normal field the second is nonnegative by the curvature bound. For a field with a tangential component, {% raw %}<span class="math inline">\(R(T,J)T=R(T,J^\perp)T\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(\langle R(T,J)T,J\rangle\leq\delta|J^\perp|^2\leq\delta|J|^2\)</span>{% endraw %} when {% raw %}<span class="math inline">\(\delta\geq0\)</span>{% endraw %}.</p>
<p>Let {% raw %}<span class="math inline">\(W=h'f_\delta-hf_\delta'\)</span>{% endraw %}. The scalar model equation gives</p>
{% raw %}<div class="math display">\[W'=(h''+\delta h)f_\delta\geq0,\qquad \left(\frac h{f_\delta}\right)'=\frac W{f_\delta^2}.\]</div>{% endraw %}
<p> The initial limit of {% raw %}<span class="math inline">\(W\)</span>{% endraw %} is zero. If {% raw %}<span class="math inline">\(a&gt;0\)</span>{% endraw %}, {% raw %}<span class="math inline">\(h/f_\delta\to1\)</span>{% endraw %}; if {% raw %}<span class="math inline">\(a=0\)</span>{% endraw %}, positivity of the model forces {% raw %}<span class="math inline">\(b&gt;0\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(J(t)=tP_tJ'(0)+O(t^2)\)</span>{% endraw %}, so the same limit holds. Consequently {% raw %}<span class="math inline">\(h/f_\delta\geq1\)</span>{% endraw %} and is nondecreasing up to the first possible zero of {% raw %}<span class="math inline">\(J\)</span>{% endraw %}. Such a zero strictly before {% raw %}<span class="math inline">\(\tau\)</span>{% endraw %} would contradict {% raw %}<span class="math inline">\(h\geq f_\delta&gt;0\)</span>{% endraw %} by continuity. This proves the result on the whole interval. Multiplying {% raw %}<span class="math inline">\(W\geq0\)</span>{% endraw %} by {% raw %}<span class="math inline">\(h\)</span>{% endraw %} gives the first displayed inequality, and continuity gives the endpoint assertions. ◻</p>
</div>
<p>We can also work with manifolds with a lower bound on their sectional curvature.</p>

<div id="result-2" class="theorem" data-note-number="2" data-note-kind="Theorem">
<p><strong>Theorem 2.</strong> Let {% raw %}<span class="math inline">\(\gamma\)</span>{% endraw %} be a unit-speed geodesic with {% raw %}<span class="math inline">\(\lambda\leq K\leq\mu\)</span>{% endraw %}, and suppose {% raw %}<span class="math inline">\(J(0)\)</span>{% endraw %} and {% raw %}<span class="math inline">\(J'(0)\)</span>{% endraw %} are linearly dependent. Assume that {% raw %}<span class="math inline">\(J\)</span>{% endraw %} is normal, or that {% raw %}<span class="math inline">\(\lambda\leq0\leq\mu\)</span>{% endraw %}. Write</p>
{% raw %}<div class="math display">\[r=\frac{\lambda+\mu}{2},\quad \eta=\frac{\mu-\lambda}{2},\quad f_q(t)=|J(0)|c_q(t)+(|J|)'(0+)s_q(t).\]</div>{% endraw %}
<p> Suppose {% raw %}<span class="math inline">\(s_r&gt;0\)</span>{% endraw %} on {% raw %}<span class="math inline">\((0,\tau)\)</span>{% endraw %} and {% raw %}<span class="math inline">\(f_r\geq0\)</span>{% endraw %} on {% raw %}<span class="math inline">\([0,\tau)\)</span>{% endraw %}. Then {% raw %}<span class="math inline">\(|J(t)|\leq f_\lambda(t)\)</span>{% endraw %} for {% raw %}<span class="math inline">\(0\leq t&lt;\tau\)</span>{% endraw %}, and at a finite endpoint by continuity.</p>
<p>The condition on {% raw %}<span class="math inline">\(f_r\)</span>{% endraw %} matters: even in a flat space, {% raw %}<span class="math inline">\(J(t)=(1-t)P_tv\)</span>{% endraw %} would otherwise give the false bound {% raw %}<span class="math inline">\(|1-t|\leq1-t\)</span>{% endraw %} after {% raw %}<span class="math inline">\(t=1\)</span>{% endraw %}. For a field with a tangential component, the condition {% raw %}<span class="math inline">\(0\in[\lambda,\mu]\)</span>{% endraw %} ensures that the curvature operator's zero tangential eigenvalue lies in the same spectral interval.</p>
</div>
<div class="proof">
<p><em>Proof.</em> Use parallel transport to identify the tangent spaces with one Euclidean space, and put {% raw %}<span class="math inline">\(A(t)Z=R(T,Z)T\)</span>{% endraw %}. On the normal space, {% raw %}<span class="math inline">\(A\)</span>{% endraw %} is self-adjoint with eigenvalues in {% raw %}<span class="math inline">\([\lambda,\mu]\)</span>{% endraw %}; on the whole tangent space this remains true under {% raw %}<span class="math inline">\(\lambda\leq0\leq\mu\)</span>{% endraw %}. Hence {% raw %}<span class="math inline">\(\|rI-A(t)\|\leq\eta\)</span>{% endraw %}.</p>
<p>Let {% raw %}<span class="math inline">\(V''+rV=0\)</span>{% endraw %} have the initial values of {% raw %}<span class="math inline">\(J\)</span>{% endraw %}. Linear dependence of the initial vectors gives {% raw %}<span class="math inline">\(V=f_re\)</span>{% endraw %} for a fixed unit vector {% raw %}<span class="math inline">\(e\)</span>{% endraw %}, with the zero field handled separately. Our sign assumption gives {% raw %}<span class="math inline">\(|V|=f_r\)</span>{% endraw %}. Variation of constants, applied to {% raw %}<span class="math inline">\(H=J-V\)</span>{% endraw %}, gives</p>
{% raw %}<div class="math display">\[H(t)=\int_0^t s_r(t-u)(rI-A(u))J(u)\,du.\]</div>{% endraw %}
<p> Since the kernel is nonnegative for {% raw %}<span class="math inline">\(0\leq u\leq t&lt;\tau\)</span>{% endraw %},</p>
{% raw %}<div class="math display">\[|H(t)|\leq g(t):=\eta\int_0^t s_r(t-u)|J(u)|\,du.\]</div>{% endraw %}
<p> Thus {% raw %}<span class="math inline">\(g(0)=g'(0)=0\)</span>{% endraw %}, and</p>
{% raw %}<div class="math display">\[g''+\lambda g=\eta(|J|-g)\leq\eta f_r.\]</div>{% endraw %}
<p> Now {% raw %}<span class="math inline">\(f=f_\lambda-f_r\)</span>{% endraw %} solves {% raw %}<span class="math inline">\(f''+\lambda f=\eta f_r\)</span>{% endraw %} with zero initial values. The kernel {% raw %}<span class="math inline">\(s_\lambda\)</span>{% endraw %} is also nonnegative on {% raw %}<span class="math inline">\([0,\tau)\)</span>{% endraw %}: if {% raw %}<span class="math inline">\(\lambda&gt;0\)</span>{% endraw %}, its first positive zero is no earlier than that of {% raw %}<span class="math inline">\(s_r\)</span>{% endraw %}, since {% raw %}<span class="math inline">\(\lambda\leq r\)</span>{% endraw %}; if {% raw %}<span class="math inline">\(\lambda\leq0\)</span>{% endraw %}, it has no positive zero. Therefore</p>
{% raw %}<div class="math display">\[f(t)-g(t)=\int_0^t s_\lambda(t-u) \bigl(\eta f_r(u)-g''(u)-\lambda g(u)\bigr)\,du\geq0.\]</div>{% endraw %}
<p> It follows that {% raw %}<span class="math inline">\(|J|\leq |V|+|H|\leq f_r+g\leq f_\lambda\)</span>{% endraw %}. This also supplies explicitly the scalar comparison step in the auxiliary-ODE argument. ◻</p>
</div>
<p>The Rauch comparison theorem, in its original form, is the following statement on comparing Jacobi fields.</p>

<div id="thm:rauch-comparison" class="theorem" data-note-number="3" data-note-kind="Theorem">
<p><strong>Theorem 3 (Rauch comparison).</strong> Let {% raw %}<span class="math inline">\(\dim M=d\leq\dim\widetilde M\)</span>{% endraw %}, and let {% raw %}<span class="math inline">\(\gamma,\widetilde\gamma\)</span>{% endraw %} be unit-speed geodesics on {% raw %}<span class="math inline">\([0,a]\)</span>{% endraw %}. Let {% raw %}<span class="math inline">\(J,\widetilde J\)</span>{% endraw %} be Jacobi fields with</p>
{% raw %}<div class="math display">\[J(0)=\widetilde J(0)=0,\qquad \langle J'(0),T(0)\rangle=\langle\widetilde J'(0),\widetilde T(0)\rangle,\qquad |J'(0)|=|\widetilde J'(0)|.\]</div>{% endraw %}
<p> Suppose {% raw %}<span class="math inline">\(\widetilde\gamma(t)\)</span>{% endraw %} is not conjugate to {% raw %}<span class="math inline">\(\widetilde\gamma(0)\)</span>{% endraw %} for {% raw %}<span class="math inline">\(0&lt;t\leq a\)</span>{% endraw %}, and that every radial plane along {% raw %}<span class="math inline">\(\widetilde\gamma\)</span>{% endraw %} has sectional curvature at least that of every radial plane along {% raw %}<span class="math inline">\(\gamma\)</span>{% endraw %} at the same time. Then {% raw %}<span class="math inline">\(|\widetilde J(t)|\leq|J(t)|\)</span>{% endraw %}.</p>
<p>If their common initial <em>normal</em> derivative is nonzero and equality holds at some {% raw %}<span class="math inline">\(t_0&gt;0\)</span>{% endraw %}, then</p>
{% raw %}<div class="math display">\[\widetilde K(\widetilde T(t),\widetilde J(t)) =K(T(t),J(t))\qquad(0&lt;t\leq t_0).\]</div>{% endraw %}
<p> At {% raw %}<span class="math inline">\(t=0\)</span>{% endraw %}, interpret the planes using the nonzero normal parts of the initial derivatives. Purely tangential fields give equality of lengths without any curvature rigidity. The same length comparison holds for equal nonzero constant speeds by a common change of parameter; for zero speed the fields are linear in a fixed tangent space and the assertion is immediate.</p>
</div>
<div class="proof">
<p><em>Proof.</em> The tangential parts are {% raw %}<span class="math inline">\(t\alpha T\)</span>{% endraw %} and {% raw %}<span class="math inline">\(t\alpha\widetilde T\)</span>{% endraw %}, with the same scalar {% raw %}<span class="math inline">\(\alpha\)</span>{% endraw %}. Subtract them; their squared lengths agree, so it suffices to compare the normal parts. If their common initial norm is zero, uniqueness for the Jacobi equation makes both normal parts zero. Otherwise {% raw %}<span class="math inline">\(\widetilde J\neq0\)</span>{% endraw %} on {% raw %}<span class="math inline">\((0,a]\)</span>{% endraw %}.</p>
<p>Work initially before the first possible zero of {% raw %}<span class="math inline">\(J\)</span>{% endraw %}. Fix {% raw %}<span class="math inline">\(b\)</span>{% endraw %} in this interval and set</p>
{% raw %}<div class="math display">\[U(t)=\frac{J(t)}{|J(b)|},\qquad \widetilde U(t)=\frac{\widetilde J(t)}{|\widetilde J(b)|}\quad(0\leq t\leq b).\]</div>{% endraw %}
<p> Integration by parts in the Jacobi equation yields</p>
{% raw %}<div class="math display">\[\frac{d}{db}\log|J(b)|^2=2\langle U'(b),U(b)\rangle=2I(U,U),\]</div>{% endraw %}
<p> where</p>
{% raw %}<div class="math display">\[I(V,V)=\int_0^b\bigl(|V'|^2-\langle R(T,V)T,V\rangle\bigr)\,dt.\]</div>{% endraw %}
<p> There is a parallel linear isometric embedding {% raw %}<span class="math inline">\(\Phi\)</span>{% endraw %} of the normal bundle of {% raw %}<span class="math inline">\(\gamma\)</span>{% endraw %} into that of {% raw %}<span class="math inline">\(\widetilde\gamma\)</span>{% endraw %}, chosen so that {% raw %}<span class="math inline">\(\Phi U(b)=\widetilde U(b)\)</span>{% endraw %}. To construct it, choose orthonormal frames at {% raw %}<span class="math inline">\(b\)</span>{% endraw %} starting with these unit vectors and extend by parallel transport. It preserves derivatives and lengths. Curvature comparison and the index lemma give, respectively,</p>
{% raw %}<div class="math display">\[\widetilde I(\widetilde U,\widetilde U) \leq\widetilde I(\Phi U,\Phi U)\leq I(U,U).\]</div>{% endraw %}
<p> The first inequality uses the same endpoint values and the absence of conjugate points on the higher-curvature geodesic. Hence</p>
{% raw %}<div class="math display">\[\frac{d}{db}\log\frac{|J(b)|^2}{|\widetilde J(b)|^2}\geq0.\]</div>{% endraw %}
<p> The ratio tends to one as {% raw %}<span class="math inline">\(b\downarrow0\)</span>{% endraw %}, by the common nonzero initial norm. It is therefore at least one and nondecreasing. A first zero of {% raw %}<span class="math inline">\(J\)</span>{% endraw %} would contradict this lower bound, so the comparison holds throughout {% raw %}<span class="math inline">\((0,a]\)</span>{% endraw %}. Restore the equal tangential squared lengths to conclude.</p>
<p>If equality holds at {% raw %}<span class="math inline">\(t_0\)</span>{% endraw %}, the normal ratio is identically one up to {% raw %}<span class="math inline">\(t_0\)</span>{% endraw %}. Both index inequalities at {% raw %}<span class="math inline">\(b=t_0\)</span>{% endraw %} are equalities. Strictness of the index lemma for a zero-endpoint difference gives {% raw %}<span class="math inline">\(\Phi U=\widetilde U\)</span>{% endraw %} on the whole segment. Moreover,</p>
{% raw %}<div class="math display">\[0=I(U,U)-\widetilde I(\Phi U,\Phi U) =\int_0^{t_0}\bigl(\widetilde K(\widetilde T,\Phi U)-K(T,U)\bigr)|U|^2\,dt.\]</div>{% endraw %}
<p> The continuous integrand is nonnegative and {% raw %}<span class="math inline">\(U(t)\neq0\)</span>{% endraw %} for {% raw %}<span class="math inline">\(t&gt;0\)</span>{% endraw %}; it must vanish pointwise. This proves the asserted curvature equality, including the initial limiting planes by continuity. ◻</p>
</div>
<div id="prop:sectional-conjugate-distances-rauch" class="proposition" data-note-number="4" data-note-kind="Proposition">
<p><strong>Proposition 4.</strong> Let {% raw %}<span class="math inline">\(M\)</span>{% endraw %} be a complete Riemannian manifold of dimension at least two, with {% raw %}<span class="math inline">\(0&lt;L\leq K\leq H\)</span>{% endraw %}. Along a unit-speed geodesic starting at {% raw %}<span class="math inline">\(p\)</span>{% endraw %}, the <em>first positive conjugate time to {% raw %}<span class="math inline">\(p\)</span>{% endraw %}</em>, denoted {% raw %}<span class="math inline">\(\tau_p\)</span>{% endraw %}, satisfies</p>
{% raw %}<div class="math display">\[\frac{\pi}{\sqrt H}\leq\tau_p\leq\frac{\pi}{\sqrt L}.\]</div>{% endraw %}
<p> These are lengths along the geodesic. One may restart the assertion at any point of the geodesic; it does not assert a lower bound for successive members of the list of all points conjugate to one fixed base point.</p>
</div>
<div class="proof">
<p><em>Proof.</em> The lower bound comes from comparing {% raw %}<span class="math inline">\(M\)</span>{% endraw %} to {% raw %}<span class="math inline">\(\mathbb S^d (H)\)</span>{% endraw %}, i.e. {% raw %}<span class="math inline">\(d\)</span>{% endraw %}-sphere of constant sectional curvature {% raw %}<span class="math inline">\(H\)</span>{% endraw %}. Take some {% raw %}<span class="math inline">\(p \in M\)</span>{% endraw %}. Let {% raw %}<span class="math inline">\(\gamma : [0,a] \to M\)</span>{% endraw %} be a normalized geodesic in {% raw %}<span class="math inline">\(M\)</span>{% endraw %} with {% raw %}<span class="math inline">\(\gamma(0) = p\)</span>{% endraw %}, and let {% raw %}<span class="math inline">\(J\)</span>{% endraw %} be a Jacobi field along {% raw %}<span class="math inline">\(\gamma\)</span>{% endraw %} with {% raw %}<span class="math inline">\(J(0) = 0\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\langle J, \gamma&#x27; \rangle = 0\)</span>{% endraw %}. To start the comparison, choose {% raw %}<span class="math inline">\(\widetilde p \in \mathbb S^d (H)\)</span>{% endraw %} and a normalized geodesic {% raw %}<span class="math inline">\(\widetilde \gamma : [0,a] \to \mathbb S^d (H)\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(\widetilde \gamma (0) = \widetilde p\)</span>{% endraw %}. Similarly, let {% raw %}<span class="math inline">\(\widetilde J\)</span>{% endraw %} be a Jacobi field along {% raw %}<span class="math inline">\(\widetilde \gamma\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(\widetilde J(0) = 0\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\langle \widetilde J, \widetilde \gamma&#x27; \rangle = 0\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(|J&#x27;(0)| = |\widetilde J&#x27;(0)|\)</span>{% endraw %}. By the usual argument, {% raw %}<span class="math inline">\(\widetilde \gamma\)</span>{% endraw %} does not have a conjugate point to {% raw %}<span class="math inline">\(\widetilde \gamma(0)\)</span>{% endraw %} on the interval {% raw %}<span class="math inline">\(t \in (0,\frac{\pi}{\sqrt{H}})\)</span>{% endraw %}, therefore, by the Rauch comparison theorem (Theorem <a href="#thm:rauch-comparison" data-reference-type="ref" data-reference="thm:rauch-comparison">3</a>), we have that {% raw %}<span class="math inline">\(|J(t)| \geq |\widetilde J(t)| &gt; 0\)</span>{% endraw %} on {% raw %}<span class="math inline">\(t \in (0,\frac{\pi}{\sqrt{H}})\)</span>{% endraw %}. Therefore, the distance from {% raw %}<span class="math inline">\(p\)</span>{% endraw %} to its first conjugate point is no less than {% raw %}<span class="math inline">\(\frac{\pi}{\sqrt{H}}\)</span>{% endraw %}.</p>

<p>The upper bound comes from comparing {% raw %}<span class="math inline">\(\mathbb S^d(L)\)</span>{% endraw %} to {% raw %}<span class="math inline">\(M\)</span>{% endraw %}. By way of contradiction, suppose {% raw %}<span class="math inline">\(\tau_p &gt; \frac{\pi}{\sqrt{L}}\)</span>{% endraw %}. We apply the Rauch comparison theorem with {% raw %}<span class="math inline">\(\mathbb S^d(L)\)</span>{% endraw %} as {% raw %}<span class="math inline">\(M\)</span>{% endraw %} and our manifold as {% raw %}<span class="math inline">\(\widetilde M\)</span>{% endraw %} (since {% raw %}<span class="math inline">\(\widetilde K = K_M \geq L = K_{\mathbb S^d(L)}\)</span>{% endraw %}). Then, {% raw %}<span class="math inline">\(|\widetilde J(t)| \leq |J(t)|\)</span>{% endraw %} for {% raw %}<span class="math inline">\(t \in (0, \frac{\pi}{\sqrt{L}}]\)</span>{% endraw %}. Since {% raw %}<span class="math inline">\(\tau_p &gt; \frac{\pi}{\sqrt{L}}\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\widetilde J(t)\)</span>{% endraw %} does not vanish on {% raw %}<span class="math inline">\((0, \frac{\pi}{\sqrt{L}}]\)</span>{% endraw %}. In particular, {% raw %}<span class="math inline">\(0 &lt; |\widetilde J(\frac{\pi}{\sqrt{L}})| \leq |J(\frac{\pi}{\sqrt{L}})|\)</span>{% endraw %}. But {% raw %}<span class="math inline">\(J(t)\)</span>{% endraw %} on {% raw %}<span class="math inline">\(\mathbb S^d(L)\)</span>{% endraw %} vanishes strictly at {% raw %}<span class="math inline">\(\frac{\pi}{\sqrt{L}}\)</span>{% endraw %}, so {% raw %}<span class="math inline">\(|J(\frac{\pi}{\sqrt{L}})| = 0\)</span>{% endraw %}, which is a contradiction. ◻</p>

</div>
<div id="prop:rauch-length-comparisons" class="proposition" data-note-number="5" data-note-kind="Proposition">
<p><strong>Proposition 5</strong>.  Let {% raw %}<span class="math inline">\(M\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\widetilde M\)</span>{% endraw %} be differentiable manifolds. Suppose for all {% raw %}<span class="math inline">\(p \in M\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\widetilde p \in \widetilde M\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\sigma \subset T_p M\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\widetilde \sigma \in T_{\widetilde p} \widetilde M\)</span>{% endraw %}, we have {% raw %}<span class="math inline">\(\widetilde K (\widetilde \sigma) \geq K(\sigma)\)</span>{% endraw %}. Consider a linear isometry {% raw %}<span class="math inline">\(i: T_p M \to T_{\widetilde p} \widetilde M\)</span>{% endraw %}. Let {% raw %}<span class="math inline">\(r &gt; 0\)</span>{% endraw %} be such that the restriction {% raw %}<span class="math inline">\(\exp_p|_{B_r(0)}\)</span>{% endraw %} is a diffeomorphism, and {% raw %}<span class="math inline">\(\exp_{\widetilde p}|_{\widetilde B_r (0)}\)</span>{% endraw %} is a diffeomorphism onto its image. Let {% raw %}<span class="math inline">\(c:[0,a] \to \exp_p (B_r (0))\)</span>{% endraw %} be a differentiable curve, and let {% raw %}<span class="math inline">\(\widetilde c : [0,a] \to \exp_{\widetilde p} (\widetilde B_r (0))\)</span>{% endraw %} be defined as </p>

{% raw %}<div class="math display">\[\widetilde c(s) = \exp_{\widetilde p} \circ i \circ \exp_p^{-1} (c(s)) ~,~ \text{ for } s \in [0,a] ~.\]</div>{% endraw %}
<p> Then, {% raw %}<span class="math inline">\(L(c) \geq L(\widetilde c)\)</span>{% endraw %}.</p>

<p>Here “linear isometry” may mean an isometric embedding into a higher-dimensional tangent space. Require the exponential maps on both displayed balls to be diffeomorphisms onto their images, so the model radial segments have no conjugate points. These are normal neighborhoods; mere set-theoretic invertibility is not being used as a substitute for nonsingularity.</p>
</div>
<div class="proof">
<p><em>Proof.</em> This follows from an application of the Rauch comparison theorem. To start, let {% raw %}<span class="math inline">\(c_0 : [0,a] \to B_r(0)\)</span>{% endraw %} be the <em>unique</em> curve in {% raw %}<span class="math inline">\(B_r(0)\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(\exp_p (c_0 (s)) = c(s)\)</span>{% endraw %}. This is possible because the restriction of {% raw %}<span class="math inline">\(\exp_p\)</span>{% endraw %} to {% raw %}<span class="math inline">\(B_r(0)\)</span>{% endraw %} is a diffeomorphism. Now, consider the rectangle {% raw %}<span class="math inline">\(\Gamma(s,t) : (s,t) \mapsto \exp_p (t c_0(s))\)</span>{% endraw %}. Take the variation field {% raw %}<span class="math inline">\(V_s\)</span>{% endraw %} of {% raw %}<span class="math inline">\(\Gamma(s,t)\)</span>{% endraw %}, which is a Jacobi field along {% raw %}<span class="math inline">\(\gamma_s : t \mapsto \exp_p (t c_0(s))\)</span>{% endraw %}, with the initial conditions {% raw %}<span class="math inline">\(V_s(0) = 0\)</span>{% endraw %} and {% raw %}<span class="math inline">\(V_s (1) = c&#x27;(s)\)</span>{% endraw %}. Furthermore, this implies </p>

{% raw %}<div class="math display">\[V_s = \dpd{\Gamma}{s} (s,t) = (\dif \exp_p)_{tc_0(s)} (t c&#x27;_0 (s)) ~.\]</div>{% endraw %}
<p> As such, {% raw %}<span class="math inline">\(\nabla_{\dif/\!\dif t} V_s(0) = c&#x27;_0 (s)\)</span>{% endraw %}. Repeat the same arguments for the rectangle {% raw %}<span class="math inline">\(\widetilde \Gamma (s,t) = \exp_{\widetilde p} (t i (c_0 (s)))\)</span>{% endraw %}: there exists a Jacobi field {% raw %}<span class="math inline">\(\widetilde V_s (t)\)</span>{% endraw %} along {% raw %}<span class="math inline">\(\widetilde \gamma_s : t \mapsto \exp_{\widetilde p} (t i (c_0(s)))\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(\widetilde V_s (0) = 0\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\widetilde V_s (1) = \widetilde c&#x27; (s)\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(\nabla_{\dif/\!\dif t} \widetilde V_s(0) = i ( c&#x27;_0 (s))\)</span>{% endraw %}. Because a linear isometry preserves lengths, it follows that {% raw %}<span class="math inline">\(| c&#x27;_0 (s) | = | i ( c&#x27;_0(s) ) |\)</span>{% endraw %}: observe that </p>

{% raw %}<div class="math display">\[\begin{aligned}
        |V_s(0)| &amp;= |\widetilde V_s(0)| = 0 ~, \\
        |V&#x27;_s(0)| &amp;= |\widetilde V&#x27;_s(0)| ~, \\
        \langle \widetilde V&#x27;_s (0), \widetilde \gamma&#x27;_s (0) \rangle &amp;= \langle i (c&#x27;_0 (s)), i (c_0 (s)) \rangle = \langle c&#x27;_0 (s), c_0 (s) \rangle = \langle V&#x27;_s (0), \gamma&#x27;_s (0) \rangle ~.
    
\end{aligned}\]</div>{% endraw %}
<p> We are now ready to apply the Rauch comparison theorem: from a direct application, we get </p>

{% raw %}<span id="eq:rauch-comparison-length-eq"></span><div class="math display">\[\begin{aligned}
 
        |\widetilde c&#x27;(s)| = |\widetilde V_s (1)| \leq |V_s (1)| = |c&#x27; (s)| ~.
    
\end{aligned}\tag{3}\]</div>{% endraw %}
<p> Integrating both sides of <a href="#eq:rauch-comparison-length-eq" data-reference-type="eqref" data-reference="eq:rauch-comparison-length-eq">(3)</a> from {% raw %}<span class="math inline">\(0\)</span>{% endraw %} to {% raw %}<span class="math inline">\(a\)</span>{% endraw %} gives the desired result. ◻</p>

<p>If {% raw %}<span class="math inline">\(c_0(s)\neq0\)</span>{% endraw %}, reparameterize both radial geodesics by their common speed before applying Theorem 3. If {% raw %}<span class="math inline">\(c_0(s)=0\)</span>{% endraw %}, both differentials of the exponential maps at zero are the identity, so {% raw %}<span class="math inline">\(|\widetilde c'(s)|=|c'(s)|\)</span>{% endraw %} directly. Thus the pointwise speed comparison, and hence its integral, covers every parameter value.</p>
</div>
