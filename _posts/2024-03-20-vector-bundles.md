<div id="vector-bundles" data-note-section="title">

</div>
<p>A vector bundle is a family of vector spaces that locally looks like a product. Local trivializations supply bases, and matrix-valued transition functions describe how those bases change on overlaps. The tangent bundle is the first example; normal bundles and bundles of covectors follow the same pattern.</p>

<p>We develop the definitions used in Section <a href="{% post_url 2022-05-11-connections-lie-brackets-and-curvature %}#sec:connection-curvature-pt" data-reference-type="ref" data-reference="sec:connection-curvature-pt">Connections, Lie Brackets, and Curvature</a>. As a recap, a triple {% raw %}<span class="math inline">\((\mathcal E, \Pi, M)\)</span>{% endraw %} is called a <em>differentiable vector bundle of rank {% raw %}<span class="math inline">\(n\)</span>{% endraw %}</em> if {% raw %}<span class="math inline">\(\mathcal E\)</span>{% endraw %} and {% raw %}<span class="math inline">\(M\)</span>{% endraw %} are differentiable manifolds, {% raw %}<span class="math inline">\(\Pi : \mathcal E \to M\)</span>{% endraw %} is a differentiable projection map, and each fibre {% raw %}<span class="math inline">\(\mathcal E_X \triangleq \Pi^{-1} (X)\)</span>{% endraw %} for {% raw %}<span class="math inline">\(X \in M\)</span>{% endraw %} carries the structure of a {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-dimensional vector space. Furthermore, the following <em>local triviality condition</em> holds: for all {% raw %}<span class="math inline">\(X \in M\)</span>{% endraw %}, there exists a neighbourhood {% raw %}<span class="math inline">\(U\)</span>{% endraw %} and a diffeomorphism {% raw %}<span class="math inline">\(\varphi : \Pi^{-1} (U) \to U \times \mathbb R^n\)</span>{% endraw %} with the property that for all {% raw %}<span class="math inline">\(y \in U\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\varphi_y \triangleq \varphi\big|_{\mathcal E_y} : \mathcal E_y \to \{y\} \times \mathbb R^n\)</span>{% endraw %} is a vector space isomorphism. The pair {% raw %}<span class="math inline">\((\varphi, U)\)</span>{% endraw %} is called a bundle chart.</p>

<p>Throughout the smooth discussion, manifolds are Hausdorff and second countable. A <strong>smooth vector bundle</strong> requires both a smooth projection and smooth local trivializations; smooth structures on the two spaces alone do not guarantee these properties. The same definition works over a manifold with boundary, using compatible boundary charts.</p>

<div id="result-1" class="example" data-note-number="1" data-note-kind="Example">
<p><strong>Example 1</strong> (Product bundle).  A rank {% raw %}<span class="math inline">\(n\)</span>{% endraw %} vector bundle of <em>any space</em> {% raw %}<span class="math inline">\(M\)</span>{% endraw %} is the product space, {% raw %}<span class="math inline">\(\mathcal E = M \times \mathbb R^n\)</span>{% endraw %}, with {% raw %}<span class="math inline">\(\pi = \pi_1 : M \times \mathbb R^n \to M\)</span>{% endraw %} as the projection map. This is the product bundle, which is trivial.</p>

</div>
<p>The coordinate description of tangent vectors gives the local trivializations required by the definition.</p>

<div id="prop:TM-is-vector-bundle" class="proposition" data-note-number="2" data-note-kind="Proposition">
<p><strong>Proposition 2</strong> (Tangent bundle is a vector bundle).  Let {% raw %}<span class="math inline">\(M\)</span>{% endraw %} be a smooth manifold of dimension {% raw %}<span class="math inline">\(n\)</span>{% endraw %}, and let {% raw %}<span class="math inline">\(TM\)</span>{% endraw %} be its tangent bundle. With its standard projection map, its natural vector space structure on each fibre, and the topology and smooth structure constructed in Theorem <a href="{% post_url 2022-03-17-tangent-spaces-and-riemannian-metrics %}#thm:TM-natural-2d-structure" data-reference-type="ref" data-reference="thm:TM-natural-2d-structure">5</a>, {% raw %}<span class="math inline">\(TM\)</span>{% endraw %} is a smooth vector bundle of rank {% raw %}<span class="math inline">\(n\)</span>{% endraw %} over {% raw %}<span class="math inline">\(M\)</span>{% endraw %}.</p>

</div>
<div class="proof">
<p><em>Proof.</em> Let {% raw %}<span class="math inline">\((U,\varphi)\)</span>{% endraw %} be a smooth chart for {% raw %}<span class="math inline">\(M\)</span>{% endraw %}. Let {% raw %}<span class="math inline">\(\{x^i\}\)</span>{% endraw %} denote its coordinate functions. Then, define a map {% raw %}<span class="math inline">\(\Phi : \pi^{-1} (U) \to U \times \mathbb R^n\)</span>{% endraw %} by the formula </p>

{% raw %}<div class="math display">\[\Phi \left( v^i \dpd{}{{x^i}}\bigg|_p \right) = (p, (v^1,\cdots,v^n)) ~.\]</div>{% endraw %}
<p> This clearly satisfies {% raw %}<span class="math inline">\(\pi_1 \circ \Phi = \pi\)</span>{% endraw %}. The map {% raw %}<span class="math inline">\(\Phi\)</span>{% endraw %} is also linear on fibres. The coordinate map {% raw %}<span class="math inline">\(\widetilde \varphi\)</span>{% endraw %} constructed in Theorem <a href="{% post_url 2022-03-17-tangent-spaces-and-riemannian-metrics %}#thm:TM-natural-2d-structure" data-reference-type="ref" data-reference="thm:TM-natural-2d-structure">5</a> is clearly equivalent to the composition </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \pi^{-1} (U) \xrightarrow{\Phi} U \times \mathbb R^n \xrightarrow{\varphi \times \operatorname{id}_{\mathbb R^n}} \varphi(U) \times \mathbb R^n ~.
    
\end{aligned}\]</div>{% endraw %}
<p> Furthermore, {% raw %}<span class="math inline">\(\Phi\)</span>{% endraw %} is a diffeomorphism, as a composition of diffeomorphisms. Therefore, {% raw %}<span class="math inline">\(\Phi\)</span>{% endraw %} satisfies all the conditions for a smooth local trivialization. ◻</p>

</div>
<p>As with coordinate charts, smooth local trivializations have <em>transition functions</em> on a differentiable manifold {% raw %}<span class="math inline">\(M\)</span>{% endraw %}. The composition of two smooth local trivializations has a simple form on sets where they overlap.</p>

<div id="lem:transition-function-smooth-local-trivialization" class="lemma" data-note-number="3" data-note-kind="Lemma">
<p><strong>Lemma 3</strong>.  Let {% raw %}<span class="math inline">\(\pi : \mathcal E \to M\)</span>{% endraw %} be a smooth vector bundle of rank {% raw %}<span class="math inline">\(k\)</span>{% endraw %} over {% raw %}<span class="math inline">\(M\)</span>{% endraw %}. Suppose {% raw %}<span class="math inline">\(\Phi: \pi^{-1}(U) \to U \times \mathbb R^k\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\Psi: \pi^{-1}(V) \to V \times \mathbb R^k\)</span>{% endraw %} are two smooth local trivializations of {% raw %}<span class="math inline">\(\mathcal E\)</span>{% endraw %} with {% raw %}<span class="math inline">\(U \cap V \neq \emptyset\)</span>{% endraw %}. There exists a smooth map, denoted {% raw %}<span class="math inline">\(\tau : U \cap V \to \operatorname{GL}_k (\mathbb R)\)</span>{% endraw %} such that the composition {% raw %}<span class="math inline">\(\Phi \circ \Psi^{-1} : (U \cap V) \times \mathbb R^k \to (U \cap V) \times \mathbb R^k\)</span>{% endraw %} is characterized by the formula </p>

{% raw %}<div class="math display">\[\Phi \circ \Psi^{-1} (p,v) = (p, \tau(p) v) ~,\]</div>{% endraw %}
<p> where {% raw %}<span class="math inline">\(\tau (p) v\)</span>{% endraw %} denotes the action of {% raw %}<span class="math inline">\(\tau(p) \in \mathbb R^{k \times k}\)</span>{% endraw %} on the vector {% raw %}<span class="math inline">\(v \in \mathbb R^k\)</span>{% endraw %}.</p>

</div>
<p>The transition fixes the base point and is linear on each fibre. Its matrix entries can be obtained by evaluating the transition on the standard basis, which also verifies their smooth dependence on the base point.</p>

<p>Note that if {% raw %}<span class="math inline">\(M\)</span>{% endraw %} is a smooth manifold, and {% raw %}<span class="math inline">\(\Phi, \Psi\)</span>{% endraw %} are smooth local trivializations of {% raw %}<span class="math inline">\(TM\)</span>{% endraw %} associated with two different smooth charts, then it follows from Lemma <a href="#lem:transition-function-smooth-local-trivialization" data-reference-type="ref" data-reference="lem:transition-function-smooth-local-trivialization">3</a> that the transition function, {% raw %}<span class="math inline">\(\tau\)</span>{% endraw %}, is the Jacobian matrix of the coordinate transition map. Furthermore, like the tangent bundle, vector bundles are often most easily described by giving a collection of vector spaces, one for each point of the base manifold. In order to make such a set into a smooth vector bundle, we would first have to construct a manifold topology and a smooth structure on the disjoint union of all the vector spaces, and then construct the local trivializations and show that they have the requisite properties.</p>

<div id="lem:vector-bundle-chart-existence" class="lemma" data-note-number="4" data-note-kind="Lemma">
<p><strong>Lemma 4</strong> (Vector bundle chart lemma).  Let {% raw %}<span class="math inline">\(M\)</span>{% endraw %} be a differentiable manifold, and suppose that for each {% raw %}<span class="math inline">\(p \in M\)</span>{% endraw %}, there is an associated real vector space {% raw %}<span class="math inline">\(E_p\)</span>{% endraw %} of dimension {% raw %}<span class="math inline">\(k\)</span>{% endraw %} (which is fixed). Let {% raw %}<span class="math inline">\(E = \bigsqcup_{p \in M} E_p\)</span>{% endraw %}, and let {% raw %}<span class="math inline">\(\pi: E \to M\)</span>{% endraw %} be the map that takes each element of {% raw %}<span class="math inline">\(E_p\)</span>{% endraw %} to {% raw %}<span class="math inline">\(p\)</span>{% endraw %}. Suppose we have</p>

<ol>
<li><p>an open cover {% raw %}<span class="math inline">\(\{U_\alpha\}_{\alpha \in A}\)</span>{% endraw %} of {% raw %}<span class="math inline">\(M\)</span>{% endraw %};</p></li>
<li><p>for each {% raw %}<span class="math inline">\(\alpha \in A\)</span>{% endraw %}, there is a bijection {% raw %}<span class="math inline">\(\Phi_\alpha : \pi^{-1} (U_\alpha) \to U_\alpha \times \mathbb R^k\)</span>{% endraw %}, whose restriction to {% raw %}<span class="math inline">\(E_p\)</span>{% endraw %} is a vector space isomorphism from {% raw %}<span class="math inline">\(E_p \to \{p\} \times \mathbb R^k \cong \mathbb R^k\)</span>{% endraw %}; and</p></li>
<li><p>for each {% raw %}<span class="math inline">\(\alpha,\beta \in A\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(U_\alpha \cap U_\beta \neq \emptyset\)</span>{% endraw %}, there exists a smooth map {% raw %}<span class="math inline">\(\tau_{\alpha\beta} : U_\alpha \cap U_\beta \to \operatorname{GL}_k (\mathbb R)\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(\Phi_\alpha \circ \Phi_\beta^{-1} : (U_\alpha \cap U_\beta) \times \mathbb R^k \to (U_\alpha \cap U_\beta) \times \mathbb R^k\)</span>{% endraw %} is given by the formula </p>

{% raw %}<div class="math display">\[\Phi_\alpha \circ \Phi_\beta^{-1} (p,v) = (p, \tau_{\alpha\beta} (p) v ) ~.\]</div>{% endraw %}</li>
</ol>
<p>Then, {% raw %}<span class="math inline">\(\mathcal E\)</span>{% endraw %} has a <em>unique</em> topology and smooth structure, making it into a differentiable manifold <em>and</em> a differentiable rank {% raw %}<span class="math inline">\(k\)</span>{% endraw %} vector bundle over {% raw %}<span class="math inline">\(M\)</span>{% endraw %}, with {% raw %}<span class="math inline">\(\pi\)</span>{% endraw %} as its projection map, and {% raw %}<span class="math inline">\(\{(U_\alpha, \Phi_\alpha)\}_{\alpha \in A}\)</span>{% endraw %} as smooth local trivializations.</p>

</div>
<p><strong>Proof of the chart lemma.</strong> Declare a subset {% raw %}<span class="math inline">\(O\subset E\)</span>{% endraw %} open exactly when every {% raw %}<span class="math inline">\(\Phi_\alpha(O\cap\pi^{-1}(U_\alpha))\)</span>{% endraw %} is open in {% raw %}<span class="math inline">\(U_\alpha\times\mathbb R^k\)</span>{% endraw %}. The transition maps and their inverses are continuous, so each {% raw %}<span class="math inline">\(\pi^{-1}(U_\alpha)\)</span>{% endraw %} is open and {% raw %}<span class="math inline">\(\Phi_\alpha\)</span>{% endraw %} is a homeomorphism. If two points of {% raw %}<span class="math inline">\(E\)</span>{% endraw %} lie over different base points, disjoint base neighbourhoods separate them. If they lie over the same base point, one trivialization separates them in the Hausdorff product. Thus {% raw %}<span class="math inline">\(E\)</span>{% endraw %} is Hausdorff.</p>
<p>The base is second countable and hence Lindelöf, so a countable subcollection of the {% raw %}<span class="math inline">\(U_\alpha\)</span>{% endraw %} covers it. Countable product bases in the corresponding trivializations give a countable basis for {% raw %}<span class="math inline">\(E\)</span>{% endraw %}. Composing the {% raw %}<span class="math inline">\(\Phi_\alpha\)</span>{% endraw %} with base coordinate charts gives Euclidean charts. On overlaps their transition maps are smooth, since they consist of a smooth base change and multiplication by the smooth matrix {% raw %}<span class="math inline">\(\tau_{\alpha\beta}\)</span>{% endraw %}. These charts make {% raw %}<span class="math inline">\(E\)</span>{% endraw %} a smooth manifold of dimension {% raw %}<span class="math inline">\(\dim M+k\)</span>{% endraw %}, with smooth projection and fibre-linear trivializations. Any other structure making these same maps trivializations has the same open sets and compatible charts, so it coincides with this one. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>

<p>A section chooses one vector in every fibre of its domain. Let {% raw %}<span class="math inline">\(\pi : \mathcal E \to M\)</span>{% endraw %} be a vector bundle.</p>

<div id="result-5" class="definition" data-note-number="5" data-note-kind="Definition">
<p><strong>Definition 5</strong>.  A <em>section</em> of {% raw %}<span class="math inline">\(\mathcal E\)</span>{% endraw %} is a section of the map {% raw %}<span class="math inline">\(\pi\)</span>{% endraw %}, i.e. a continuous map {% raw %}<span class="math inline">\(\sigma: M \to \mathcal E\)</span>{% endraw %} satisfying {% raw %}<span class="math inline">\(\pi \circ \sigma = \operatorname{id}_M\)</span>{% endraw %}. A <em>local section</em> of {% raw %}<span class="math inline">\(\mathcal E\)</span>{% endraw %} is a continuous map {% raw %}<span class="math inline">\(\sigma : U \to E\)</span>{% endraw %} defined on some open subset {% raw %}<span class="math inline">\(U \subset M\)</span>{% endraw %} satisfying {% raw %}<span class="math inline">\(\pi \circ \sigma = \operatorname{id}_U\)</span>{% endraw %}. If {% raw %}<span class="math inline">\(M\)</span>{% endraw %} is a differentiable manifold <em>and</em> {% raw %}<span class="math inline">\(\mathcal E\)</span>{% endraw %} is a smooth vector bundle, a smooth section of {% raw %}<span class="math inline">\(\mathcal E\)</span>{% endraw %} is one that is a smooth map from its domain to {% raw %}<span class="math inline">\(\mathcal E\)</span>{% endraw %}. Finally, the <em>zero section</em> of {% raw %}<span class="math inline">\(\mathcal E\)</span>{% endraw %} is the section {% raw %}<span class="math inline">\(\sigma : M \to \mathcal E\)</span>{% endraw %} given by {% raw %}<span class="math inline">\(\sigma(p) = 0 \in E_p\)</span>{% endraw %} for each {% raw %}<span class="math inline">\(p \in M\)</span>{% endraw %}. The <em>support</em> of a section {% raw %}<span class="math inline">\(\sigma\)</span>{% endraw %}, denoted {% raw %}<span class="math inline">\(\operatorname{spt} (\sigma)\)</span>{% endraw %}, is defined as {% raw %}<span class="math inline">\(\operatorname{spt} (\sigma) \triangleq \overline{\{p \in M : \sigma(p) \neq 0\}}\)</span>{% endraw %}.</p>

</div>
<p>Note that vector fields are <em>smooth sections</em> of the tangent bundle, and tangent bundles are examples of vector bundles. Therefore, we can analogously define <em>local and global frames</em> for (smooth) vector bundles, {% raw %}<span class="math inline">\(\pi : \mathcal E \to M\)</span>{% endraw %}. If {% raw %}<span class="math inline">\(\Phi : \pi^{-1}(U) \to U \times \mathbb R^k\)</span>{% endraw %} is a smooth local trivialization of {% raw %}<span class="math inline">\(\mathcal E\)</span>{% endraw %}, it follows that we can define {% raw %}<span class="math inline">\(\sigma_1,\cdots,\sigma_k : U \to \mathcal E\)</span>{% endraw %} by the formula {% raw %}<span class="math inline">\(\sigma_i(p) = \Phi^{-1} (p,e_i) = \Phi^{-1} \circ \widetilde e_i (p)\)</span>{% endraw %}. This corresponds to the following commutative diagram:</p>

</figure>
<p>Note that each {% raw %}<span class="math inline">\(\sigma_i\)</span>{% endraw %} is smooth because {% raw %}<span class="math inline">\(\Phi\)</span>{% endraw %} is a diffeomorphism, and {% raw %}<span class="math inline">\(\pi_1 \circ \Phi = \pi\)</span>{% endraw %}. It follows that {% raw %}<span class="math inline">\(\pi \circ \sigma_i (p) = \pi \circ \Phi^{-1} (p,e_i) = \pi_1 (p,e_i) = p\)</span>{% endraw %}, i.e. {% raw %}<span class="math inline">\(\sigma_i\)</span>{% endraw %} is a section. Finally, observe that {% raw %}<span class="math inline">\(\{\sigma_i(p)\}\)</span>{% endraw %} forms a basis for {% raw %}<span class="math inline">\(E_p\)</span>{% endraw %}: {% raw %}<span class="math inline">\(\Phi\)</span>{% endraw %} restricted to {% raw %}<span class="math inline">\(E_p\)</span>{% endraw %} is an isomorphism onto {% raw %}<span class="math inline">\(\{p\} \times \mathbb R^k\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(\Phi(\sigma_i(p)) = (p,e_i)\)</span>{% endraw %}, i.e. {% raw %}<span class="math inline">\(\Phi\)</span>{% endraw %} takes {% raw %}<span class="math inline">\(\{\sigma_i(p)\}\)</span>{% endraw %} to the standard basis for {% raw %}<span class="math inline">\(\{p\} \times \mathbb R^k \cong \mathbb R^k\)</span>{% endraw %}. As such, we say {% raw %}<span class="math inline">\(\{\sigma_i(p)\}\)</span>{% endraw %} is the local frame associated with {% raw %}<span class="math inline">\(\Phi\)</span>{% endraw %}. In fact, this is true generally.</p>

<div id="result-6" class="proposition" data-note-number="6" data-note-kind="Proposition">
<p><strong>Proposition 6</strong>.  Every smooth local frame for a smooth vector bundle is associated with a smooth local trivialization, as above.</p>

</div>
<p><strong>Proof of Proposition 6.</strong> In an existing trivialization over a smaller neighbourhood, the columns representing a smooth frame {% raw %}<span class="math inline">\(\sigma_1,\ldots,\sigma_k\)</span>{% endraw %} form a smooth invertible matrix {% raw %}<span class="math inline">\(A(p)\)</span>{% endraw %}. The map</p>
{% raw %}<div class="math display">\[S(p,c)=\sum_i c_i\sigma_i(p)\]</div>{% endraw %}

<p>is represented there by {% raw %}<span class="math inline">\((p,c)\mapsto(p,A(p)c)\)</span>{% endraw %}, whose inverse is {% raw %}<span class="math inline">\((p,v)\mapsto(p,A(p)^{-1}v)\)</span>{% endraw %}. Matrix inversion is smooth on {% raw %}<span class="math inline">\(\operatorname{GL}_k(\mathbb R)\)</span>{% endraw %}, so these are local diffeomorphisms. They agree on overlaps because coefficients in a basis are unique. Consequently {% raw %}<span class="math inline">\(S:U\times\mathbb R^k\to E|_U\)</span>{% endraw %} is a diffeomorphism and {% raw %}<span class="math inline">\(S^{-1}\)</span>{% endraw %} is the required trivialization. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>

<p>Frames reduce smoothness questions to scalar functions. We use them to characterize smooth sections and the differentiable structure on {% raw %}<span class="math inline">\(TM\)</span>{% endraw %}.</p>

<div id="prop:smoothness-sections-vector-bundles-characterization" class="proposition" data-note-number="7" data-note-kind="Proposition">
<p><strong>Proposition 7</strong> (Smoothness of sections of vector bundles is related to smoothness of local frames).  Let {% raw %}<span class="math inline">\(\pi : \mathcal E \to M\)</span>{% endraw %} be a smooth vector bundle, and {% raw %}<span class="math inline">\(\tau : M \to \mathcal E\)</span>{% endraw %} denote a section of the vector bundle. Let {% raw %}<span class="math inline">\(\{\sigma_i\}\)</span>{% endraw %} be a smooth local frame for {% raw %}<span class="math inline">\(\mathcal E\)</span>{% endraw %} over an open subset {% raw %}<span class="math inline">\(U \subset M\)</span>{% endraw %}. Then, {% raw %}<span class="math inline">\(\tau\)</span>{% endraw %} is smooth on the frame domain if and only if its component functions with respect to {% raw %}<span class="math inline">\(\sigma_i\)</span>{% endraw %} are smooth.</p>

</div>
<p><strong>Proof of Proposition 7.</strong> In the frame trivialization from Proposition 6, the section is {% raw %}<span class="math inline">\(p\mapsto(p,\tau^1(p),\ldots,\tau^k(p))\)</span>{% endraw %}. It is smooth on {% raw %}<span class="math inline">\(U\)</span>{% endraw %} exactly when these components are smooth on {% raw %}<span class="math inline">\(U\)</span>{% endraw %}. Global smoothness requires this condition on a cover of {% raw %}<span class="math inline">\(M\)</span>{% endraw %}, not just one local frame domain. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>

<div id="result-8" class="remark" data-note-number="8" data-note-kind="Remark">
<p><strong>Remark 8</strong>.  In the notations of Proposition <a href="#prop:smoothness-sections-vector-bundles-characterization" data-reference-type="ref" data-reference="prop:smoothness-sections-vector-bundles-characterization">7</a>, at any {% raw %}<span class="math inline">\(p \in U \subset M\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\tau(p) = \tau^i(p) \sigma_i(p)\)</span>{% endraw %} for some uniquely determined coefficients {% raw %}<span class="math inline">\(\{\tau^1(p),\cdots,\tau^n(p)\}\)</span>{% endraw %}. These functions {% raw %}<span class="math inline">\(\tau^i : U\to\mathbb R\)</span>{% endraw %} are called the <em>component functions of {% raw %}<span class="math inline">\(\tau\)</span>{% endraw %}, with respect to the given local frame {% raw %}<span class="math inline">\(\sigma_i\)</span>{% endraw %}</em>.</p>

</div>
<div id="prop:uniqueness-differentiable-structure-TM" class="proposition" data-note-number="9" data-note-kind="Proposition">
<p><strong>Proposition 9</strong> (Uniqueness of differentiable structure on {% raw %}<span class="math inline">\(TM\)</span>{% endraw %}).  With the qualifications and constructions in Theorem <a href="{% post_url 2022-03-17-tangent-spaces-and-riemannian-metrics %}#thm:TM-natural-2d-structure" data-reference-type="ref" data-reference="thm:TM-natural-2d-structure">5</a>, the topology and differentiable structure constructed are the unique ones with respect to which {% raw %}<span class="math inline">\(\pi : TM \to M\)</span>{% endraw %} is a smooth vector bundle with the given vector space structure on the fibres, <em>and</em> such that all coordinate vector fields are smooth local sections.</p>

</div>
<p><strong>Proof of Proposition 9.</strong> Any vector-bundle structure in which the coordinate fields are smooth admits, by Proposition 6, the trivialization taking {% raw %}<span class="math inline">\(\sum_i v^i\partial_i|_p\)</span>{% endraw %} to {% raw %}<span class="math inline">\((p,v^1,\ldots,v^n)\)</span>{% endraw %}. These are exactly the canonical tangent-bundle trivializations. They therefore force both the topology and the smooth atlas by the chart lemma. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>

<h4 data-note-section="1" id="bundle-homomorphisms">1. Bundle Homomorphisms</h4>
<div id="def:bundle-homomorphism" class="definition" data-note-number="10" data-note-kind="Definition">
<p><strong>Definition 10</strong>.  Let {% raw %}<span class="math inline">\(\pi : \mathcal E \to M\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\pi&#x27; : \mathcal E&#x27; \to M&#x27;\)</span>{% endraw %} be vector bundles. A continuous map {% raw %}<span class="math inline">\(F: \mathcal E \to \mathcal E&#x27;\)</span>{% endraw %} is a <em>bundle homomorphism</em> if there exists a map {% raw %}<span class="math inline">\(f : M \to M&#x27;\)</span>{% endraw %} satisfying {% raw %}<span class="math inline">\(\pi&#x27; \circ F = f \circ \pi\)</span>{% endraw %}, i.e. such that the following diagram commutes:</p>

<p>Furthermore, for each {% raw %}<span class="math inline">\(p \in M\)</span>{% endraw %}, the restricted map {% raw %}<span class="math inline">\(F|_{\mathcal E_p} : \mathcal E_p \to \mathcal E&#x27;_{f(p)}\)</span>{% endraw %} is linear. Here, we say <em>{% raw %}<span class="math inline">\(F\)</span>{% endraw %} covers {% raw %}<span class="math inline">\(f\)</span>{% endraw %}</em>.</p>

</div>
<div id="result-11" class="lemma" data-note-number="11" data-note-kind="Lemma">
<p><strong>Lemma 11</strong>.  Under the qualifications in Definition <a href="#def:bundle-homomorphism" data-reference-type="ref" data-reference="def:bundle-homomorphism">10</a>, if {% raw %}<span class="math inline">\(F\)</span>{% endraw %} is a bundle homomorphism that covers {% raw %}<span class="math inline">\(f\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(f\)</span>{% endraw %} is continuous, and <em>uniquely</em> determined by {% raw %}<span class="math inline">\(F\)</span>{% endraw %}. If the bundles and {% raw %}<span class="math inline">\(F\)</span>{% endraw %} are smooth, then so is {% raw %}<span class="math inline">\(f\)</span>{% endraw %}.</p>

</div>
<p>The verification and proof is routine by noting that {% raw %}<span class="math inline">\(f = \pi&#x27; \circ F \circ \sigma_0\)</span>{% endraw %}, where {% raw %}<span class="math inline">\(\sigma_0 : M \to \mathcal E\)</span>{% endraw %} is the zero section.</p>

<p>The terminology for vector fields and vector bundles extends to bundle maps. For instance, a <em>bundle isomorphism</em> is a <em>bijective</em> bundle homomorphism whose inverse is also a bundle homomorphism. If, additionally, {% raw %}<span class="math inline">\(F\)</span>{% endraw %} is a diffeomorphism, then we say it is a <em>smooth bundle isomorphism</em>. We say two bundles are <em>isomorphic</em> if there exists a bundle isomorphism between the total spaces. As always, we can further qualify the last definition with “smooth”, if the requisite bundle isomorphism is smooth.</p>

<p>For bundles over the same base, we use the following definition. When we define vector bundles over the same base space {% raw %}<span class="math inline">\(M\)</span>{% endraw %}, we use <em>bundle homomorphism over {% raw %}<span class="math inline">\(M\)</span>{% endraw %}</em> to mean a bundle homomorphism covering the identity map of {% raw %}<span class="math inline">\(M\)</span>{% endraw %}—in other words, a continuous map {% raw %}<span class="math inline">\(F : \mathcal E \to \mathcal E&#x27;\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(\pi&#x27; \circ F = \pi\)</span>{% endraw %}, i.e. such that the following diagram commutes:</p>

The same nomenclature carries over from before, where we speak of bundle homomorphisms between vector bundles on different base spaces.</p>

<div id="result-12" class="lemma" data-note-number="12" data-note-kind="Lemma">
<p><strong>Lemma 12</strong>.  Suppose {% raw %}<span class="math inline">\(\pi: \mathcal E \to M\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\pi&#x27;: \mathcal E&#x27; \to M\)</span>{% endraw %} are differentiable vector bundles over a differentiable manifold {% raw %}<span class="math inline">\(M\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(F: \mathcal E \to \mathcal E&#x27;\)</span>{% endraw %} is a bijective smooth bundle homomorphism over {% raw %}<span class="math inline">\(M\)</span>{% endraw %}. Then, {% raw %}<span class="math inline">\(F\)</span>{% endraw %} is a smooth bundle isomorphism.</p>

</div>
<p><strong>Proof of Lemma 12.</strong> In local trivializations over the same base neighbourhood, {% raw %}<span class="math inline">\(F\)</span>{% endraw %} has the form {% raw %}<span class="math inline">\((p,v)\mapsto(p,A(p)v)\)</span>{% endraw %}. Its matrix is smooth: its columns are obtained by applying {% raw %}<span class="math inline">\(F\)</span>{% endraw %} to the constant frame sections. Bijectivity implies that {% raw %}<span class="math inline">\(A(p)\)</span>{% endraw %} is a square invertible matrix for every {% raw %}<span class="math inline">\(p\)</span>{% endraw %}. Thus {% raw %}<span class="math inline">\((p,w)\mapsto(p,A(p)^{-1}w)\)</span>{% endraw %} is a smooth local formula for {% raw %}<span class="math inline">\(F^{-1}\)</span>{% endraw %}. These inverses agree on overlaps, so {% raw %}<span class="math inline">\(F^{-1}\)</span>{% endraw %} is a smooth bundle homomorphism. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>

<div id="result-13" class="remark" data-note-number="13" data-note-kind="Remark">
<p><strong>Remark 13</strong>.  Vector bundles give rise to the induced structure. Let {% raw %}<span class="math inline">\(\pi: \mathcal E \to M\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\pi&#x27;: \mathcal E&#x27; \to M\)</span>{% endraw %} be differentiable vector bundles over a differentiable manifold {% raw %}<span class="math inline">\(M\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(F: \mathcal E \to \mathcal E&#x27;\)</span>{% endraw %} be a smooth bundle homomorphism over {% raw %}<span class="math inline">\(M\)</span>{% endraw %}. Let {% raw %}<span class="math inline">\(\Gamma(\mathcal E)\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\Gamma(\mathcal E&#x27;)\)</span>{% endraw %} denote spaces of smooth global sections. Then, the <em>induced map between spaces of global sections</em> is given by </p>

{% raw %}<div class="math display">\[\widetilde F : \Gamma(\mathcal E) \to \Gamma(\mathcal E&#x27;) : \sigma \mapsto F \circ \sigma\]</div>{% endraw %}
<p> with the (pointwise) formula {% raw %}<span class="math inline">\(\widetilde F(\sigma)(p) = F(\sigma(p))\)</span>{% endraw %}. Furthermore, {% raw %}<span class="math inline">\(\widetilde F(\sigma)\)</span>{% endraw %} is a section of {% raw %}<span class="math inline">\(\mathcal E&#x27;\)</span>{% endraw %}, and this is smooth by composition. The induced map {% raw %}<span class="math inline">\(\widetilde F\)</span>{% endraw %} on sections is linear over {% raw %}<span class="math inline">\(\mathbb R\)</span>{% endraw %}, because bundle homomorphism is linear on fibres. But more is true: {% raw %}<span class="math inline">\(\widetilde F\)</span>{% endraw %} is linear over {% raw %}<span class="math inline">\(\mathcal C^\infty (M)\)</span>{% endraw %}, in the sense that for any {% raw %}<span class="math inline">\(a,b \in \mathscr C^\infty (M)\)</span>{% endraw %} and smooth sections {% raw %}<span class="math inline">\(\sigma_1,\sigma_2 \in \Gamma(\mathcal E)\)</span>{% endraw %}, </p>

{% raw %}<div class="math display">\[\widetilde F(a\sigma_1 + b\sigma_2) = a \widetilde F(\sigma_1) + b \widetilde F(\sigma_2) ~.\]</div>{% endraw %}
<p> Linearity over smooth functions expresses the pointwise character of the bundle map. The next lemma shows that this property also characterizes maps on sections that come from bundle homomorphisms.</p>

</div>
<div id="result-14" class="lemma" data-note-number="14" data-note-kind="Lemma">
<p><strong>Lemma 14.</strong> Let {% raw %}<span class="math inline">\(E,E&#39;\)</span>{% endraw %} be smooth vector bundles over {% raw %}<span class="math inline">\(M\)</span>{% endraw %}. A map {% raw %}<span class="math inline">\(\mathscr F:\Gamma(E)\to\Gamma(E&#39;)\)</span>{% endraw %} is {% raw %}<span class="math inline">\(C^\infty(M)\)</span>{% endraw %}-linear if and only if there exists a unique smooth bundle homomorphism {% raw %}<span class="math inline">\(F:E\to E&#39;\)</span>{% endraw %} over {% raw %}<span class="math inline">\(M\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(\mathscr F(\sigma)=F\circ\sigma\)</span>{% endraw %} for every smooth global section {% raw %}<span class="math inline">\(\sigma\)</span>{% endraw %}.</p>
<p><strong>Proof.</strong> A bundle homomorphism gives such a module map by fibrewise linearity. Conversely, first observe locality: if {% raw %}<span class="math inline">\(\sigma\)</span>{% endraw %} vanishes near {% raw %}<span class="math inline">\(p\)</span>{% endraw %}, choose a smooth cutoff {% raw %}<span class="math inline">\(\chi=1\)</span>{% endraw %} near {% raw %}<span class="math inline">\(p\)</span>{% endraw %} supported where {% raw %}<span class="math inline">\(\sigma=0\)</span>{% endraw %}. Then {% raw %}<span class="math inline">\(\chi\sigma=0\)</span>{% endraw %}, so {% raw %}<span class="math inline">\(\chi\mathscr F(\sigma)=0\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\mathscr F(\sigma)(p)=0\)</span>{% endraw %}.</p>
<p>Choose a local frame {% raw %}<span class="math inline">\(e_i\)</span>{% endraw %} near {% raw %}<span class="math inline">\(p\)</span>{% endraw %}, extend cutoff multiples to global sections {% raw %}<span class="math inline">\(\widetilde e_i\)</span>{% endraw %} agreeing with {% raw %}<span class="math inline">\(e_i\)</span>{% endraw %} near {% raw %}<span class="math inline">\(p\)</span>{% endraw %}, and write {% raw %}<span class="math inline">\(\sigma=\sum_i a_i e_i\)</span>{% endraw %} there. Cutoff extensions of the {% raw %}<span class="math inline">\(a_i\)</span>{% endraw %} and locality give</p>
{% raw %}<div class="math display">\[\mathscr F(\sigma)(p)=\sum_i a_i(p)\mathscr F(\widetilde e_i)(p).\]</div>{% endraw %}

<p>In particular, this is zero if {% raw %}<span class="math inline">\(\sigma(p)=0\)</span>{% endraw %}. Every fibre vector {% raw %}<span class="math inline">\(v\in E_p\)</span>{% endraw %} is the value of a global smooth section, obtained by extending a local constant-coefficient section with a cutoff. Define {% raw %}<span class="math inline">\(F_p(v)=\mathscr F(\sigma)(p)\)</span>{% endraw %} for any such section with {% raw %}<span class="math inline">\(\sigma(p)=v\)</span>{% endraw %}. The preceding observation makes this independent of the choice, and module linearity makes {% raw %}<span class="math inline">\(F_p\)</span>{% endraw %} linear. Near {% raw %}<span class="math inline">\(p\)</span>{% endraw %}, the columns of its matrix are the smooth sections {% raw %}<span class="math inline">\(\mathscr F(\widetilde e_i)\)</span>{% endraw %} in a target trivialization, so {% raw %}<span class="math inline">\(F\)</span>{% endraw %} is smooth. The defining identity and uniqueness now hold at every fibre. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>
</div>

<h4 data-note-section="2" id="subbundles">2. Subbundles</h4>
<p>The definition of a subbundle is contained in Definition <a href="{% post_url 2022-05-11-connections-lie-brackets-and-curvature %}#def:subbundle" data-reference-type="ref" data-reference="def:subbundle">11</a>. We switch notation to use {% raw %}<span class="math inline">\(\mathcal D \subset \mathcal E\)</span>{% endraw %} as the topological subspace of {% raw %}<span class="math inline">\(\mathcal E\)</span>{% endraw %}, and use {% raw %}<span class="math inline">\(\mathcal D_p = \mathcal D \cap \mathcal E_p\)</span>{% endraw %} as the linear subspace of {% raw %}<span class="math inline">\(\mathcal E_p\)</span>{% endraw %}. Since {% raw %}<span class="math inline">\(\mathcal D\)</span>{% endraw %} is a vector bundle over {% raw %}<span class="math inline">\(M\)</span>{% endraw %}, it follows that all fibres {% raw %}<span class="math inline">\(\mathcal D_p\)</span>{% endraw %} must be nonempty, <em>and</em> have the same dimension. It follows from these definitions that we can also characterize smoothness of the vector subbundle via imposing conditions on local sections.</p>

<div id="prop:smoothness-vector-subbundles-characterization" class="proposition" data-note-number="15" data-note-kind="Proposition">
<p><strong>Proposition 15</strong> (Characterization of smoothness of vector subbundles).  Let {% raw %}<span class="math inline">\(\pi : \mathcal E \to M\)</span>{% endraw %} be a smooth vector bundle, and for each {% raw %}<span class="math inline">\(p \in M\)</span>{% endraw %}, define a {% raw %}<span class="math inline">\(k\)</span>{% endraw %}-dimensional linear subspace {% raw %}<span class="math inline">\(\mathcal D_p \subset \mathcal E_p\)</span>{% endraw %}. Then, {% raw %}<span class="math inline">\(\mathcal D = \bigcup_{p \in M} \mathcal D_p\)</span>{% endraw %} is a smooth subbundle of {% raw %}<span class="math inline">\(\mathcal E\)</span>{% endraw %} if and only if, for each {% raw %}<span class="math inline">\(p \in M\)</span>{% endraw %}, there exists a neighbourhood {% raw %}<span class="math inline">\(U = U_p\)</span>{% endraw %} such that there are smooth local sections {% raw %}<span class="math inline">\(\sigma_1,\cdots,\sigma_k : U \to \mathcal E\)</span>{% endraw %}, with the property that {% raw %}<span class="math inline">\(\{\sigma_1(q),\cdots,\sigma_k(q)\}\)</span>{% endraw %} form a basis for {% raw %}<span class="math inline">\(\mathcal D_q\)</span>{% endraw %} at each {% raw %}<span class="math inline">\(q \in U\)</span>{% endraw %}.</p>

</div>
<p><strong>Proof of the subbundle criterion.</strong> If {% raw %}<span class="math inline">\(D\)</span>{% endraw %} is a smooth subbundle, a bundle trivialization of {% raw %}<span class="math inline">\(D\)</span>{% endraw %} gives a smooth local frame, whose inclusion in {% raw %}<span class="math inline">\(E\)</span>{% endraw %} is smooth. Conversely, suppose the indicated sections {% raw %}<span class="math inline">\(\sigma_1,\ldots,\sigma_k\)</span>{% endraw %} exist. In a trivialization of {% raw %}<span class="math inline">\(E\)</span>{% endraw %}, complete their values at one point to a basis by constant vectors. The determinant remains nonzero on a smaller neighbourhood, so this gives a smooth frame of {% raw %}<span class="math inline">\(E\)</span>{% endraw %} whose first {% raw %}<span class="math inline">\(k\)</span>{% endraw %} members span {% raw %}<span class="math inline">\(D\)</span>{% endraw %}. In its associated trivialization, {% raw %}<span class="math inline">\(D\)</span>{% endraw %} is precisely {% raw %}<span class="math inline">\(U\times(\mathbb R^k\times\{0\})\)</span>{% endraw %}. This proves the required subspace topology, smooth structure, and smooth inclusion. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>

<div id="result-16" class="example" data-note-number="16" data-note-kind="Example">
<p><strong>Example 16</strong>.  Suppose {% raw %}<span class="math inline">\(\pi : \mathcal E \to M\)</span>{% endraw %} is any trivial bundle. Let {% raw %}<span class="math inline">\(\{E_1,\cdots,E_k\}\)</span>{% endraw %} be a smooth global frame for {% raw %}<span class="math inline">\(\mathcal E\)</span>{% endraw %}. For {% raw %}<span class="math inline">\(0 \leq m \leq k\)</span>{% endraw %}, the subset {% raw %}<span class="math inline">\(\mathcal D \subset \mathcal E\)</span>{% endraw %}, defined by {% raw %}<span class="math inline">\(\mathcal D_p = \operatorname{span} (\{E_1|_p, \cdots, E_m|_p\})\)</span>{% endraw %} for each {% raw %}<span class="math inline">\(p \in M\)</span>{% endraw %} is a smooth subbundle of {% raw %}<span class="math inline">\(\mathcal E\)</span>{% endraw %}.</p>

</div>
<p>Kernels and images of bundle homomorphisms supply further examples, provided their dimensions remain constant. Suppose {% raw %}<span class="math inline">\(\pi : \mathcal E \to M\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\pi&#x27; : \mathcal E&#x27; \to M\)</span>{% endraw %} are vector bundles, and {% raw %}<span class="math inline">\(F : \mathcal E \to \mathcal E&#x27;\)</span>{% endraw %} is a bundle homomorphism over {% raw %}<span class="math inline">\(M\)</span>{% endraw %}. For each {% raw %}<span class="math inline">\(p \in M\)</span>{% endraw %}, the rank of the linear map {% raw %}<span class="math inline">\(F|_{E_p}\)</span>{% endraw %} is called the <em>rank of {% raw %}<span class="math inline">\(F\)</span>{% endraw %} at {% raw %}<span class="math inline">\(p\)</span>{% endraw %}</em>. We say {% raw %}<span class="math inline">\(F\)</span>{% endraw %} has <em>constant rank</em> if {% raw %}<span class="math inline">\(F|_{E_p}\)</span>{% endraw %} is of the same rank for all {% raw %}<span class="math inline">\(p \in M\)</span>{% endraw %}.</p>

<div id="thm:ker-im-subbundles-M" class="theorem" data-note-number="17" data-note-kind="Theorem">
<p><strong>Theorem 17.</strong> Let {% raw %}<span class="math inline">\(F:E\to E&#39;\)</span>{% endraw %} be a <strong>smooth</strong> bundle homomorphism between smooth bundles of fixed ranks over {% raw %}<span class="math inline">\(M\)</span>{% endraw %}. Its kernel and image are smooth subbundles of fixed ranks if and only if {% raw %}<span class="math inline">\(F\)</span>{% endraw %} has constant rank. If the convention allows ranks to vary between connected components, replace “constant” by “locally constant.”</p>
<p><strong>Proof.</strong> In local frames let {% raw %}<span class="math inline">\(A(p)\)</span>{% endraw %} be the smooth {% raw %}<span class="math inline">\(\ell\times k\)</span>{% endraw %} matrix of {% raw %}<span class="math inline">\(F\)</span>{% endraw %}. Suppose its rank is the constant {% raw %}<span class="math inline">\(r\)</span>{% endraw %}. Near any point choose an invertible {% raw %}<span class="math inline">\(r\times r\)</span>{% endraw %} minor and reorder rows and columns to write</p>
{% raw %}<div class="math display">\[A=\begin{pmatrix}B&amp;C\\D&amp;E\end{pmatrix},\qquad \det B\ne0.\]</div>{% endraw %}

<p>Rank {% raw %}<span class="math inline">\(r\)</span>{% endraw %} forces {% raw %}<span class="math inline">\(E=DB^{-1}C\)</span>{% endraw %}: subtract {% raw %}<span class="math inline">\(DB^{-1}\)</span>{% endraw %} times the first block row from the second, leaving a lower-right block that must vanish. The first {% raw %}<span class="math inline">\(r\)</span>{% endraw %} columns of {% raw %}<span class="math inline">\(A\)</span>{% endraw %} are a smooth basis of its image, while the columns of</p>
{% raw %}<div class="math display">\[\begin{pmatrix}-B^{-1}C\\I_{k-r}\end{pmatrix}\]</div>{% endraw %}

<p>are a smooth basis of its kernel. Proposition 15 gives both subbundles; the cases {% raw %}<span class="math inline">\(r=0\)</span>{% endraw %} and {% raw %}<span class="math inline">\(r=k\)</span>{% endraw %} have the evident zero or empty frames. Conversely, the rank of an image subbundle is the rank of {% raw %}<span class="math inline">\(F\)</span>{% endraw %}, so it is constant under the fixed-rank convention. Without smoothness of {% raw %}<span class="math inline">\(F\)</span>{% endraw %}, constant rank alone yields no smooth frame. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>
</div>

<p>A consequence of the construction above is clear on {% raw %}<span class="math inline">\(\mathbb R^n\)</span>{% endraw %}.</p>

<div id="lem:orthogonal-complement-subbundle-Rn" class="lemma" data-note-number="18" data-note-kind="Lemma">
<p><strong>Lemma 18.</strong> Let {% raw %}<span class="math inline">\(i:M\to\mathbb R^n\)</span>{% endraw %} be an immersion and {% raw %}<span class="math inline">\(D\)</span>{% endraw %} a smooth rank-{% raw %}<span class="math inline">\(k\)</span>{% endraw %} subbundle of the pullback bundle {% raw %}<span class="math inline">\(i^*T\mathbb R^n\cong M\times\mathbb R^n\)</span>{% endraw %}. The fibrewise Euclidean orthogonal complement {% raw %}<span class="math inline">\(D^\perp\)</span>{% endraw %} is a smooth rank-{% raw %}<span class="math inline">\((n-k)\)</span>{% endraw %} subbundle and has smooth local orthonormal frames.</p>
<p><strong>Proof.</strong> Fix a smooth local frame {% raw %}<span class="math inline">\(X_1,\ldots,X_k\)</span>{% endraw %} for {% raw %}<span class="math inline">\(D\)</span>{% endraw %}. Complete its values at a point {% raw %}<span class="math inline">\(p\)</span>{% endraw %} to a basis of {% raw %}<span class="math inline">\(\mathbb R^n\)</span>{% endraw %} by constant vectors {% raw %}<span class="math inline">\(c_{k+1},\ldots,c_n\)</span>{% endraw %}. On a smaller neighbourhood the determinant remains nonzero. Gram–Schmidt applied to this smooth frame gives smooth orthonormal fields: each subtraction is smooth and every normalizing denominator is positive. The first {% raw %}<span class="math inline">\(k\)</span>{% endraw %} span {% raw %}<span class="math inline">\(D\)</span>{% endraw %}, so the last {% raw %}<span class="math inline">\(n-k\)</span>{% endraw %} span {% raw %}<span class="math inline">\(D^\perp\)</span>{% endraw %}. Proposition 15 proves the assertion. No extension to an ambient closed slice is required. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>
</div>
<div id="lem:normal-subbundle-submanifold-Rn" class="lemma" data-note-number="19" data-note-kind="Lemma">
<p><strong>Lemma 19.</strong> For an immersion {% raw %}<span class="math inline">\(i:M^m\to\mathbb R^n\)</span>{% endraw %}, its normal bundle is the smooth rank-{% raw %}<span class="math inline">\((n-m)\)</span>{% endraw %} subbundle</p>
{% raw %}<div class="math display">\[NM=\{(p,v)\in M\times\mathbb R^n:v\perp di_p(T_pM)\}.\]</div>{% endraw %}

<p><strong>Proof.</strong> The differential has constant rank {% raw %}<span class="math inline">\(m\)</span>{% endraw %}, so its image is a smooth subbundle by Theorem 17. Apply Lemma 18. When the immersion is an inclusion, this is the usual notation {% raw %}<span class="math inline">\(TM\subset T\mathbb R^n|_M\)</span>{% endraw %}. For a noninjective immersion, the base point {% raw %}<span class="math inline">\(p\)</span>{% endraw %} is retained even when two points have the same image. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>
</div>

<div id="result-20" class="remark" data-note-number="20" data-note-kind="Remark">
<p><strong>Remark 20.</strong> A smooth distribution {% raw %}<span class="math inline">\(D\subset TM\)</span>{% endraw %} defines an accessibility relation: {% raw %}<span class="math inline">\(p\sim q\)</span>{% endraw %} when a smooth curve from {% raw %}<span class="math inline">\(p\)</span>{% endraw %} to {% raw %}<span class="math inline">\(q\)</span>{% endraw %} has velocity in {% raw %}<span class="math inline">\(D\)</span>{% endraw %} at every time. Constant curves and time reversal give reflexivity and symmetry. To concatenate two curves smoothly, first reparametrize them by smooth nondecreasing functions constant near both endpoints; the new velocities remain scalar multiples of the old ones. This proves transitivity.</p>
<p>If {% raw %}<span class="math inline">\(D\)</span>{% endraw %} is integrable, Frobenius coordinates identify its accessibility classes with connected maximal integral manifolds, the <strong>leaves</strong> of its foliation. Leaves are immersed submanifolds; they need not be embedded. For instance, on {% raw %}<span class="math inline">\(\mathbb T^2\subset\mathbb C^2\)</span>{% endraw %} take</p>
{% raw %}<div class="math display">\[V(z_1,z_2)=(i\omega_1z_1,i\omega_2z_2),\qquad D=\operatorname{span}\{V\}.\]</div>{% endraw %}

<p>For {% raw %}<span class="math inline">\((\omega_1,\omega_2)\ne(0,0)\)</span>{% endraw %} this is a rank-one integrable distribution, with leaf</p>
{% raw %}<div class="math display">\[L_z=\{(e^{it\omega_1}z_1,e^{it\omega_2}z_2):t\in\mathbb R\}.\]</div>{% endraw %}

<p>Indeed a tangent curve satisfies {% raw %}<span class="math inline">\(\gamma&#39;=a(t)V(\gamma)\)</span>{% endraw %}, and integrating {% raw %}<span class="math inline">\(a\)</span>{% endraw %} gives this same orbit. If {% raw %}<span class="math inline">\(\omega_2=0\)</span>{% endraw %} or {% raw %}<span class="math inline">\(\omega_1/\omega_2\in\mathbb Q\)</span>{% endraw %}, the orbit is a periodic embedded circle. If {% raw %}<span class="math inline">\(\omega_1/\omega_2\)</span>{% endraw %} is irrational, the parametrization is injective and immersive. At the times returning the second coordinate to a fixed value, the first coordinate is an irrational rotation orbit and is dense in its circle. To see the latter fact, the pigeonhole principle supplies nonzero integer multiples of the irrational angle arbitrarily close to zero modulo one; their successive multiples approximate any prescribed point with error at most that small angle. Allowing an additional fixed time shift then proves density in the full torus.</p>
<p>Such a dense leaf is not embedded: a local embedded one-dimensional slice would leave a nonempty open part of a coordinate neighbourhood disjoint from the leaf, contradicting density. Its intrinsic manifold topology is therefore finer than the subspace topology. If both {% raw %}<span class="math inline">\(\omega_i\)</span>{% endraw %} vanish, the distribution has rank zero and the leaves are single points.</p>
</div>

<h4 data-note-section="3" id="fibre-bundles">3. Fibre Bundles</h4>
<p>The local-product definition also makes sense when the fibres are arbitrary topological spaces. Removing the linear structure leads to fibre bundles.</p>

<div id="result-21" class="definition" data-note-number="21" data-note-kind="Definition">
<p><strong>Definition 21</strong>.  Let {% raw %}<span class="math inline">\(M\)</span>{% endraw %} and {% raw %}<span class="math inline">\(F\)</span>{% endraw %} be topological spaces. A <em>fibre bundle over {% raw %}<span class="math inline">\(M\)</span>{% endraw %}, with model fibre {% raw %}<span class="math inline">\(F\)</span>{% endraw %}</em>, is a topological space {% raw %}<span class="math inline">\(\mathcal E\)</span>{% endraw %} with surjective, continuous map {% raw %}<span class="math inline">\(\pi : \mathcal E \to M\)</span>{% endraw %} such that for each {% raw %}<span class="math inline">\(x \in M\)</span>{% endraw %}, there exists a neighbourhood {% raw %}<span class="math inline">\(U=U_x \subset M\)</span>{% endraw %} <em>and</em> a homeomorphism {% raw %}<span class="math inline">\(\Phi : \pi^{-1} (U) \to U \times F\)</span>{% endraw %} such that the following diagram commutes:</p>

<figure class="note-diagram" id="diagram-fibre-bundle-trivialization" data-diagram="fibre-bundle-trivialization" style="--diagram-width: 316px; --diagram-min-width: 237px">
<div class="note-diagram__canvas" tabindex="0" role="region" aria-label="A local trivialization identifies the bundle above U with the product U × F and preserves the projection onto U."><a href="{{ '/assets/images/notes/tikz/fibre-bundle-trivialization.svg' | relative_url }}?v=c1520042a7ff" title="Open diagram at full size"><img src="{{ '/assets/images/notes/tikz/fibre-bundle-trivialization.svg' | relative_url }}?v=c1520042a7ff" alt="A local trivialization identifies the bundle above U with the product U × F and preserves the projection onto U." loading="lazy" decoding="async"></a></div>
<figcaption>A local trivialization identifies the bundle above U with the product U × F and preserves the projection onto U.</figcaption>
</figure>
<p>The pair {% raw %}<span class="math inline">\((U,\Phi)\)</span>{% endraw %} is called a <em>local trivialization of {% raw %}<span class="math inline">\(\mathcal E\)</span>{% endraw %} over {% raw %}<span class="math inline">\(U\)</span>{% endraw %}</em>. {% raw %}<span class="math inline">\(\mathcal E\)</span>{% endraw %} is called the <em>total space of the bundle</em>, {% raw %}<span class="math inline">\(M\)</span>{% endraw %} is the <em>base space</em>, and {% raw %}<span class="math inline">\(\pi\)</span>{% endraw %} is the <em>projection map</em> (associated with the fibre bundle). If {% raw %}<span class="math inline">\(E,M,F\)</span>{% endraw %} are differentiable manifolds, {% raw %}<span class="math inline">\(\pi\)</span>{% endraw %} is smooth, and local trivializations can be chosen to be diffeomorphisms, then the bundle is called a <em>smooth fibre bundle</em>.</p>

</div>
<div id="result-22" class="definition" data-note-number="22" data-note-kind="Definition">
<p><strong>Definition 22</strong>.  <em>Trivial fibre bundle</em> is one that admits a local trivialization over the entire base space. If the fibre bundle is a smooth bundle, <em>and</em> the global trivialization is a diffeomorphism, then we say the fibre bundle is <em>smoothly trivial</em>.</p>

</div>
<div id="result-23" class="example" data-note-number="23" data-note-kind="Example">
<p><strong>Example 23</strong>.  Every rank {% raw %}<span class="math inline">\(k\)</span>{% endraw %} vector bundle is a fibre bundle, with model fibre {% raw %}<span class="math inline">\(\mathbb R^k\)</span>{% endraw %}.</p>

</div>
<div id="result-24" class="example" data-note-number="24" data-note-kind="Example">
<p><strong>Example 24</strong>.  The product space {% raw %}<span class="math inline">\(M \times F\)</span>{% endraw %} is a fibre bundle with the projection map {% raw %}<span class="math inline">\(\pi_1 : M \times F \to M\)</span>{% endraw %}. This is called the <em>product fibre bundle</em>.</p>

</div>
<div id="result-25" class="example" data-note-number="25" data-note-kind="Example">
<p><strong>Example 25.</strong> A covering map whose fibres all have the same cardinality is a fibre bundle with a discrete model fibre {% raw %}<span class="math inline">\(S\)</span>{% endraw %} of that cardinality. This condition holds, in particular, for a covering of a connected manifold. For an evenly covered open set {% raw %}<span class="math inline">\(U\)</span>{% endraw %}, label the <strong>sheets</strong> of {% raw %}<span class="math inline">\(\pi^{-1}(U)\)</span>{% endraw %} by {% raw %}<span class="math inline">\(S\)</span>{% endraw %} and define {% raw %}<span class="math inline">\(\Phi(x)=(\pi(x),s)\)</span>{% endraw %} on sheet {% raw %}<span class="math inline">\(s\)</span>{% endraw %}. Each sheet maps homeomorphically to {% raw %}<span class="math inline">\(U\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(S\)</span>{% endraw %} is discrete, so {% raw %}<span class="math inline">\(\Phi\)</span>{% endraw %} and its inverse are continuous. For disconnected bases, fibre cardinalities can differ between components; in that case there is no single model fibre for the entire covering. Sheets should not be confused with connected components when {% raw %}<span class="math inline">\(U\)</span>{% endraw %} itself is disconnected.</p>
</div>
