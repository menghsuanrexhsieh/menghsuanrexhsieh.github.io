<div class="note-content" markdown="0">

<p>Threshold indicators on the real line are separated in the uniform norm, yet their empirical averages converge uniformly. A sample sees only finitely many membership patterns. VC dimension controls how many patterns a class can produce, and this combinatorial bound gives covering numbers uniformly over the sampling distribution.</p>
<p>Let {% raw %}<span class="math inline">\(X_1,\ldots,X_n\)</span>{% endraw %} be iid with law {% raw %}<span class="math inline">\(P\)</span>{% endraw %}, write {% raw %}<span class="math inline">\(P_nf=n^{-1}\sum_i f(X_i)\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\mathbb G_nf=\sqrt n(P_n-P)f\)</span>{% endraw %}, and let {% raw %}<span class="math inline">\(\varepsilon_i\)</span>{% endraw %} be independent Rademacher signs independent of the sample. Assume the function classes below are pointwise measurable, so the suprema used in expectations are measurable; alternatively use the outer-expectation conventions of the <a href="{% post_url 2022-09-03-empirical-processes-tensorization-and-the-entropy-method %}">empirical-process setup</a>.</p>
<div id="sec:vc"><h3 data-note-section="1" id="vc-dimension">1. VC Dimension</h3></div>
<p>For a class of sets {% raw %}<span class="math inline">\(\mathscr C\)</span>{% endraw %}, its trace on a finite set {% raw %}<span class="math inline">\(I\)</span>{% endraw %} is {% raw %}<span class="math inline">\(\mathscr C|_I=\{C\cap I:C\in\mathscr C\}\)</span>{% endraw %}. The set {% raw %}<span class="math inline">\(I\)</span>{% endraw %} is shattered when this trace is all of {% raw %}<span class="math inline">\(2^I\)</span>{% endraw %}. The VC dimension {% raw %}<span class="math inline">\(d\)</span>{% endraw %} is the largest size of a shattered finite set, or infinity if these sizes are unbounded. For a nonempty class with {% raw %}<span class="math inline">\(d=0\)</span>{% endraw %}, every point has the same membership in every member, so the class contains just one distinct set.</p>
<p>For half-lines, a sample of size {% raw %}<span class="math inline">\(n\)</span>{% endraw %} has at most {% raw %}<span class="math inline">\(n+1\)</span>{% endraw %} distinct traces. A finite-class estimate therefore gives an expected uniform error of order {% raw %}<span class="math inline">\(\sqrt{\log(n+1)/n}\)</span>{% endraw %}. This already implies the uniform law, but chaining will remove the logarithm. The obstruction in the uniform norm remains: distinct half-lines have distance one, so their covering number is infinite for radii below one.</p>
<div id="lem:sauer-shelah" class="lemma" data-note-number="1" data-note-kind="Lemma"><p><strong>Lemma 1 (Sauer–Shelah).</strong> If {% raw %}<span class="math inline">\(d=\operatorname{VC}(\mathscr C)&lt;\infty\)</span>{% endraw %}, then for {% raw %}<span class="math inline">\(|I|=n\)</span>{% endraw %},</p>
{% raw %}<div class="math display">\[|\mathscr C|_I|\le\sum_{j=0}^{\min(d,n)}\binom nj.\]</div>{% endraw %}
<p>When {% raw %}<span class="math inline">\(1\le d\le n\)</span>{% endraw %}, the sum is at most {% raw %}<span class="math inline">\((en/d)^d\)</span>{% endraw %}. For {% raw %}<span class="math inline">\(d=0\)</span>{% endraw %} it equals one, and for {% raw %}<span class="math inline">\(d&gt;n\)</span>{% endraw %} the bound is {% raw %}<span class="math inline">\(2^n\)</span>{% endraw %}.</p></div>
<p>The combinatorial part is the following stronger observation. It counts shattered sets, rather than merely bounding their sizes.</p>
<div id="thm:pajor" class="theorem" data-note-number="2" data-note-kind="Theorem"><p><strong>Theorem 2 (Pajor).</strong> For a family {% raw %}<span class="math inline">\(\mathscr A\subseteq2^I\)</span>{% endraw %} on a finite ground set, let {% raw %}<span class="math inline">\(\operatorname{Sh}(\mathscr A)\)</span>{% endraw %} denote its collection of shattered subsets. Then {% raw %}<span class="math inline">\(|\operatorname{Sh}(\mathscr A)|\ge|\mathscr A|\)</span>{% endraw %}.</p></div>
<div class="proof"><p><em>Proof.</em> Induct on {% raw %}<span class="math inline">\(|I|\)</span>{% endraw %}, with the empty ground set immediate. Fix {% raw %}<span class="math inline">\(x\in I\)</span>{% endraw %}, and let {% raw %}<span class="math inline">\(\mathscr A_+\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\mathscr A_-\)</span>{% endraw %} be the traces on {% raw %}<span class="math inline">\(I\setminus\{x\}\)</span>{% endraw %} of members containing and not containing {% raw %}<span class="math inline">\(x\)</span>{% endraw %}, respectively. A set shattered by either family is shattered by {% raw %}<span class="math inline">\(\mathscr A\)</span>{% endraw %}. A set {% raw %}<span class="math inline">\(J\)</span>{% endraw %} shattered by both gives the additional shattered set {% raw %}<span class="math inline">\(J\cup\{x\}\)</span>{% endraw %}. These two collections are disjoint, so</p>
<span id="eq:s-s-step1"></span>{% raw %}<div class="math display">\[|\operatorname{Sh}(\mathscr A)|\ge|\operatorname{Sh}(\mathscr A_+)\cup\operatorname{Sh}(\mathscr A_-)|+|\operatorname{Sh}(\mathscr A_+)\cap\operatorname{Sh}(\mathscr A_-)|\ge|\mathscr A_+|+|\mathscr A_-|=|\mathscr A|.\]</div>{% endraw %}
<p>This proves Theorem 2. Applying it to the trace of {% raw %}<span class="math inline">\(\mathscr C\)</span>{% endraw %}, whose shattered subsets have size at most {% raw %}<span class="math inline">\(d\)</span>{% endraw %}, proves the first part of Lemma 1. For its second part set {% raw %}<span class="math inline">\(t=d/n\in(0,1]\)</span>{% endraw %}; then</p>
<span id="eq:s-s-step2"></span>{% raw %}<div class="math display">\[t^d\sum_{j=0}^d\binom nj\le\sum_{j=0}^d\binom njt^j\le(1+t)^n\le e^d.\]</div>{% endraw %}
<p>Dividing by {% raw %}<span class="math inline">\(t^d\)</span>{% endraw %} gives the claim. ◻</p></div>
<p>Identify each set with its indicator. Its squared {% raw %}<span class="math inline">\(L^2(P)\)</span>{% endraw %} distance to another set is the probability of their symmetric difference. The next theorem turns the trace bound into a distribution-free metric bound.</p>
<div id="thm:dudley-metric-dimension-L2" class="theorem" data-note-number="3" data-note-kind="Theorem"><p><strong>Theorem 3.</strong> There are universal constants {% raw %}<span class="math inline">\(C,c\)</span>{% endraw %} such that, for {% raw %}<span class="math inline">\(d\ge1\)</span>{% endraw %}, every probability measure {% raw %}<span class="math inline">\(P\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(0&lt;\delta&lt;1\)</span>{% endraw %},</p>
{% raw %}<div class="math display">\[N(\delta,\mathscr C,L^2(P))\le(C/\delta)^{cd}.\]</div>{% endraw %}
<p>If {% raw %}<span class="math inline">\(d=0\)</span>{% endraw %}, the covering number is one.</p></div>
<div id="lem:extraction" class="lemma" data-note-number="4" data-note-kind="Lemma"><p><strong>Lemma 4 (Extraction).</strong> Suppose {% raw %}<span class="math inline">\(N\ge2\)</span>{% endraw %}, {% raw %}<span class="math inline">\(|f_i|\le1\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(\|f_i-f_j\|_{P,2}&gt;\delta\)</span>{% endraw %} for {% raw %}<span class="math inline">\(i\ne j\)</span>{% endraw %}, where {% raw %}<span class="math inline">\(0&lt;\delta&lt;1\)</span>{% endraw %}. There are {% raw %}<span class="math inline">\(r\le C\delta^{-4}\log N\)</span>{% endraw %} points whose empirical measure {% raw %}<span class="math inline">\(P_r\)</span>{% endraw %} satisfies {% raw %}<span class="math inline">\(\|f_i-f_j\|_{P_r,2}&gt;\delta/2\)</span>{% endraw %} for every pair.</p></div>
<div class="proof"><p><em>Proof.</em> Draw {% raw %}<span class="math inline">\(r=\lceil32\delta^{-4}\log N\rceil\)</span>{% endraw %} iid points. Each squared difference {% raw %}<span class="math inline">\(W=(f_i-f_j)^2\)</span>{% endraw %} lies in {% raw %}<span class="math inline">\([0,4]\)</span>{% endraw %} and has mean greater than {% raw %}<span class="math inline">\(\delta^2\)</span>{% endraw %}. Hoeffding's inequality gives</p>
{% raw %}<div class="math display">\[P\{P_rW\le\delta^2/4\}\le\exp(-9r\delta^4/128).\]</div>{% endraw %}
<p>Here the required bounded-variable inequality follows directly from exponential moments. For {% raw %}<span class="math inline">\(0\le W\le4\)</span>{% endraw %}, the second derivative of {% raw %}<span class="math inline">\(\log\mathbb{E}e^{tW}\)</span>{% endraw %} is the variance under exponential tilting, at most {% raw %}<span class="math inline">\(4\)</span>{% endraw %}; integrating twice gives {% raw %}<span class="math inline">\(\log\mathbb{E}e^{t(W-\mathbb{E}W)}\le2t^2\)</span>{% endraw %}. Apply this to the independent copies and optimize the lower-tail Chernoff bound at deviation {% raw %}<span class="math inline">\(3\delta^2/4\)</span>{% endraw %}.</p>
<p>The union bound over fewer than {% raw %}<span class="math inline">\(N^2/2\)</span>{% endraw %} pairs is strictly below one. Some sample therefore has all the required separations. ◻</p></div>
<div id="result-5" class="remark" data-note-number="5" data-note-kind="Remark"><p><strong>Remark 5.</strong> The conclusion concerns the empirical measure {% raw %}<span class="math inline">\(P_r=r^{-1}\sum_{k=1}^r\delta_{x_k}\)</span>{% endraw %}, and the radius decreases from {% raw %}<span class="math inline">\(\delta\)</span>{% endraw %} to {% raw %}<span class="math inline">\(\delta/2\)</span>{% endraw %}. It is enough that the functions remain distinct on these points; preserving the original radius is unnecessary.</p></div>
<div class="proof"><p><em>Proof of Theorem 3.</em> Start with any finite {% raw %}<span class="math inline">\(\delta\)</span>{% endraw %}-separated family of size {% raw %}<span class="math inline">\(N\ge2\)</span>{% endraw %}. Extraction produces {% raw %}<span class="math inline">\(r\le C\delta^{-4}\log N\)</span>{% endraw %} points on which its indicator traces are distinct. If {% raw %}<span class="math inline">\(r&lt;d\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(N\le2^r\le2^d\)</span>{% endraw %}. Otherwise Sauer–Shelah yields {% raw %}<span class="math inline">\(N\le(er/d)^d\)</span>{% endraw %}. Writing {% raw %}<span class="math inline">\(y=(\log N)/d\)</span>{% endraw %}, we obtain {% raw %}<span class="math inline">\(e^y\le C\delta^{-4}y\)</span>{% endraw %}. Since {% raw %}<span class="math inline">\(y\le2e^{y/2}\)</span>{% endraw %}, this implies {% raw %}<span class="math inline">\(y\le2\log(2C\delta^{-4})\)</span>{% endraw %}. Thus every finite packing has size at most {% raw %}<span class="math inline">\((C/\delta)^{cd}\)</span>{% endraw %}. A greedy packing must consequently terminate, and the resulting maximal packing is a cover. This also proves existence of a finite cover, without first assuming a maximal finite packing exists. See the <a href="{% post_url 2022-09-20-symmetrization-bracketing-and-covering-numbers %}#lem:covering-packing-comparisons">covering–packing comparison</a>. ◻</p></div>
<div id="thm:u-g-c-classes" class="theorem" data-note-number="6" data-note-kind="Theorem"><p><strong>Theorem 6.</strong> A measurable VC class of indicators satisfies</p>
{% raw %}<div class="math display">\[\mathbb{E}\sup_{C\in\mathscr C}|P_nC-PC|\le C\sqrt{(1\vee d)/n}.\]</div>{% endraw %}
<p>With probability at least {% raw %}<span class="math inline">\(1-\eta\)</span>{% endraw %}, this supremum is at most {% raw %}<span class="math inline">\(C\sqrt{(1\vee d)/n}+\sqrt{\log(1/\eta)/(2n)}\)</span>{% endraw %}.</p></div>
<div class="proof"><p><em>Proof.</em> Symmetrize, add the zero function to anchor the process, and condition on the observations. For {% raw %}<span class="math inline">\(a_i=f(X_i)-g(X_i)\)</span>{% endraw %}, independence of the signs and {% raw %}<span class="math inline">\(\cosh u\le e^{u^2/2}\)</span>{% endraw %} give directly
</p>{% raw %}<div class="math display">\[\mathbb{E}_\varepsilon\exp\!\left(\frac{\lambda}{\sqrt n}\sum_i\varepsilon_i a_i\right)=\prod_i\cosh(\lambda a_i/\sqrt n)\le\exp\!\left(\frac{\lambda^2}{2n}\sum_i a_i^2\right).\]</div>{% endraw %}
<p>Thus the conditional increments are subgaussian in {% raw %}<span class="math inline">\(L^2(P_n)\)</span>{% endraw %}. The elementary inequality for {% raw %}<span class="math inline">\(\cosh\)</span>{% endraw %} follows by integrating {% raw %}<span class="math inline">\((\log\cosh u)''=\operatorname{sech}^2u\le1\)</span>{% endraw %}. This supplies the exact exponential-moment bound needed here; see also the <a href="{% post_url 2022-09-13-concentration-inequalities %}#eg:rademacher-subgaussian">Rademacher example</a>. Adding the empty set raises VC dimension by at most one. Theorem 3 and <a href="{% post_url 2022-10-11-chaining %}#thm:dudley-entropy-finite-T">Dudley's inequality</a> give</p>
{% raw %}<div class="math display">\[\mathbb{E}_\varepsilon\sup_{f\in\mathcal F}\left|n^{-1/2}\sum_i\varepsilon_i f(X_i)\right|\le C\int_0^1\sqrt{(d+1)\log(C/u)}\,du\le C\sqrt{d+1}.\]</div>{% endraw %}
<p>Undo conditioning and divide by {% raw %}<span class="math inline">\(\sqrt n\)</span>{% endraw %}. Changing one observation changes the original supremum by at most {% raw %}<span class="math inline">\(1/n\)</span>{% endraw %}, so bounded differences proves the probability bound. In particular, Borel–Cantelli gives the uniform law almost surely. The {% raw %}<span class="math inline">\(1\vee d\)</span>{% endraw %} is needed: a single nonconstant indicator has dimension zero and can still fluctuate. ◻</p></div>
<div id="thm:empirical-process-boolean-functions-VC-dimension" class="theorem" data-note-number="7" data-note-kind="Theorem"><p><strong>Theorem 7.</strong> Equivalently, {% raw %}<span class="math inline">\(\mathbb{E}\|\mathbb G_n\|_{\mathcal F}\le C\sqrt{1\vee d}\)</span>{% endraw %}. For half-lines {% raw %}<span class="math inline">\(d=1\)</span>{% endraw %}, giving the {% raw %}<span class="math inline">\(n^{-1/2}\)</span>{% endraw %} expected uniform error for empirical distribution functions.</p></div>
<p>The conditioning in this proof is on the observations, not on the signs. The empirical metric is then fixed while the signs supply the subgaussian increments. This is the same reduction used in the <a href="{% post_url 2022-10-15-maximal-inequalities-via-uniform-entropy-and-bracketing %}#rem:g-c-uniform-entropy">uniform-entropy bound</a>.</p>
<p>For real functions we use their subgraphs:</p><span id="eq:subgraph"></span>
{% raw %}<div class="math display">\[C_f=\{(x,t):t&lt;f(x)\},\qquad V=\operatorname{VC}(\{C_f:f\in\mathcal F\}).\]</div>{% endraw %}
<div id="thm:covering-number-vc-class-functions" class="theorem" data-note-number="8" data-note-kind="Theorem"><p><strong>Theorem 8.</strong> Let {% raw %}<span class="math inline">\(\mathcal F\)</span>{% endraw %} be a nonempty VC-subgraph class with measurable envelope {% raw %}<span class="math inline">\(F\)</span>{% endraw %}. For {% raw %}<span class="math inline">\(1\le r&lt;\infty\)</span>{% endraw %}, {% raw %}<span class="math inline">\(0&lt;\|F\|_{P,r}&lt;\infty\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(0&lt;\delta&lt;1\)</span>{% endraw %},</p>
{% raw %}<div class="math display">\[N(\delta\|F\|_{P,r},\mathcal F,L^r(P))\le(C/\delta)^{cr(1\vee V)}.\]</div>{% endraw %}
<p>The constants are universal. If {% raw %}<span class="math inline">\(F=0\)</span>{% endraw %} almost surely, the covering number is one. This bound is deliberately stated with universal constants; it does not claim a sharp exponent.</p></div>
<div class="proof"><p><em>Proof.</em> First take {% raw %}<span class="math inline">\(r=1\)</span>{% endraw %} and use the probability measure</p>
{% raw %}<div class="math display">\[d\widetilde P(x,t)=\frac{\mathbf1\{|t|\le F(x)\}}{2PF}\,dP(x)\,dt.\]</div>{% endraw %}
<p>It satisfies {% raw %}<span class="math inline">\(\widetilde P(C_f\triangle C_g)=P|f-g|/(2PF)\)</span>{% endraw %}. Apply Theorem 3 at radius {% raw %}<span class="math inline">\(\sqrt{\delta/2}\)</span>{% endraw %} to the subgraphs. This bounds the desired {% raw %}<span class="math inline">\(L^1(P)\)</span>{% endraw %} covering number by a power of {% raw %}<span class="math inline">\(1/\delta\)</span>{% endraw %}.</p>
<p>For {% raw %}<span class="math inline">\(r&gt;1\)</span>{% endraw %}, let {% raw %}<span class="math inline">\(dQ=F^{r-1}dP/PF^{r-1}\)</span>{% endraw %}. Since {% raw %}<span class="math inline">\(|f-g|\le2F\)</span>{% endraw %},</p>
{% raw %}<div class="math display">\[P|f-g|^r\le2^{r-1}PF^{r-1}\,Q|f-g|,\qquad QF=\frac{PF^r}{PF^{r-1}}.\]</div>{% endraw %}
<p>An {% raw %}<span class="math inline">\(L^1(Q)\)</span>{% endraw %} cover at relative radius {% raw %}<span class="math inline">\(\delta^r/2^{r-1}\)</span>{% endraw %} is therefore an {% raw %}<span class="math inline">\(L^r(P)\)</span>{% endraw %} cover at radius {% raw %}<span class="math inline">\(\delta\|F\|_{P,r}\)</span>{% endraw %}. Applying the first part proves the stated exponent. Centers can be chosen in the class, after at most a factor two in radius. ◻</p></div>
<div id="result-9" class="remark" data-note-number="9" data-note-kind="Remark"><p><strong>Remark 9.</strong> Theorem 8 bounds the normalized uniform entropy integral by {% raw %}<span class="math inline">\(C\sqrt{1\vee V}\)</span>{% endraw %}. The bound is polynomial in inverse radius, with exponent proportional to dimension; it is not polynomial in dimension for fixed radius.</p></div>
<div id="result-10" class="example" data-note-number="10" data-note-kind="Example"><p><strong>Example 10 (Oscillations).</strong> The class {% raw %}<span class="math inline">\(\{x\mapsto\sin(tx):t\in\mathbb R\}\)</span>{% endraw %} on {% raw %}<span class="math inline">\([0,1]\)</span>{% endraw %} has infinite VC-subgraph dimension. For any {% raw %}<span class="math inline">\(k\)</span>{% endraw %}, set {% raw %}<span class="math inline">\(x_j=2^{j-k}\)</span>{% endraw %}, {% raw %}<span class="math inline">\(1\le j\le k\)</span>{% endraw %}. Given desired signs, choose bits {% raw %}<span class="math inline">\(b_j=0\)</span>{% endraw %} for positive and {% raw %}<span class="math inline">\(b_j=1\)</span>{% endraw %} for negative, and put</p>
{% raw %}<div class="math display">\[u=\sum_{j=1}^k b_j2^{-j}+2^{-k}/3,\qquad t=2\pi2^{k-1}u.\]</div>{% endraw %}
<p>The fractional part of {% raw %}<span class="math inline">\(2^{j-1}u\)</span>{% endraw %} is in {% raw %}<span class="math inline">\((0,1/2)\)</span>{% endraw %} when {% raw %}<span class="math inline">\(b_j=0\)</span>{% endraw %}, and in {% raw %}<span class="math inline">\((1/2,1)\)</span>{% endraw %} when {% raw %}<span class="math inline">\(b_j=1\)</span>{% endraw %}. Hence {% raw %}<span class="math inline">\(\sin(tx_j)\)</span>{% endraw %} has exactly the prescribed nonzero sign. The points {% raw %}<span class="math inline">\((x_j,0)\)</span>{% endraw %} are shattered. A one-dimensional parameter can therefore generate arbitrarily complicated traces.</p></div>
<div id="result-11" class="lemma" data-note-number="11" data-note-kind="Lemma"><p><strong>Lemma 11 (Convex hulls).</strong> Let {% raw %}<span class="math inline">\(\operatorname{conv}(\mathcal F)\)</span>{% endraw %} consist of finite convex combinations of members of {% raw %}<span class="math inline">\(\mathcal F\)</span>{% endraw %}. For every linear functional {% raw %}<span class="math inline">\(L\)</span>{% endraw %} defined on their span,</p>
{% raw %}<div class="math display">\[\sup_{f\in\operatorname{conv}(\mathcal F)}|Lf|=\sup_{f\in\mathcal F}|Lf|.\]</div>{% endraw %}
<p>Indeed, {% raw %}<span class="math inline">\(|L\sum_i a_if_i|\le\sum_i a_i|Lf_i|\)</span>{% endraw %} for {% raw %}<span class="math inline">\(a_i\ge0\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\sum_i a_i=1\)</span>{% endraw %}, and the reverse inequality follows from inclusion. Taking {% raw %}<span class="math inline">\(L=P_n-P\)</span>{% endraw %} transfers the uniform law, with the same error, to the convex hull.</p></div>
<div id="result-12" class="corollary" data-note-number="12" data-note-kind="Corollary"><p><strong>Corollary 12.</strong> A pointwise measurable VC-subgraph class with integrable envelope is Glivenko–Cantelli.</p></div>
<div class="proof"><p><em>Proof.</em> For each integer {% raw %}<span class="math inline">\(M\)</span>{% endraw %}, the class {% raw %}<span class="math inline">\(f\mathbf1\{F\le M\}\)</span>{% endraw %} remains VC-subgraph: outside the truncation set, all subgraphs have fixed membership. Its envelope is bounded, and Theorem 8, symmetrization, and chaining give expected uniform error tending to zero. Bounded differences and Borel–Cantelli give almost-sure convergence for each {% raw %}<span class="math inline">\(M\)</span>{% endraw %}. The remaining error is at most {% raw %}<span class="math inline">\(P_n(F\mathbf1\{F&gt;M\})+P(F\mathbf1\{F&gt;M\})\)</span>{% endraw %}. The strong law and then {% raw %}<span class="math inline">\(M\to\infty\)</span>{% endraw %} make this vanish. ◻</p></div>
<p>A variance bound can improve the global estimate for a bounded class. The next result makes the centering and the entropy hypothesis explicit.</p>
<div id="thm:max-inequality-vc-class-functions-uniform-envelope" class="theorem" data-note-number="13" data-note-kind="Theorem"><p><strong>Theorem 13.</strong> Suppose {% raw %}<span class="math inline">\(Pf=0\)</span>{% endraw %}, {% raw %}<span class="math inline">\(|f|\le U\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(\sup_f Pf^2\le\sigma^2\le U^2\)</span>{% endraw %}, where {% raw %}<span class="math inline">\(0&lt;\sigma\le U\)</span>{% endraw %}. Assume, uniformly over probability measures {% raw %}<span class="math inline">\(Q\)</span>{% endraw %},</p>
<span id="thm:max-inequality-vc-class-functions-uniform-envelope-a1"></span>
{% raw %}<div class="math display">\[N(\delta U,\mathcal F\cup\{0\},L^2(Q))\le(A/\delta)^v,\qquad0&lt;\delta&lt;1,\quad A\ge e^2,\quad v\ge1.\]</div>{% endraw %}
<p>Then, with a universal constant,</p>
{% raw %}<div class="math display">\[\mathbb{E}\sup_{f\in\mathcal F}\left|\sum_{i=1}^n f(X_i)\right|\le C\left[\sqrt n\,\sigma\sqrt{v\log(AU/\sigma)}+Uv\log(AU/\sigma)\right].\]</div>{% endraw %}
<p>A bounded VC-subgraph class satisfies the entropy hypothesis with {% raw %}<span class="math inline">\(v=C(1\vee V)\)</span>{% endraw %} and universal {% raw %}<span class="math inline">\(A\)</span>{% endraw %}. For an uncentered class apply <a href="#thm:max-inequality-vc-class-functions-uniform-envelope">Theorem 13</a> to {% raw %}<span class="math inline">\(f-Pf\)</span>{% endraw %}, whose envelope is at most twice the original envelope.</p></div>
<div class="proof"><p><em>Proof.</em> Scale to {% raw %}<span class="math inline">\(U=1\)</span>{% endraw %}. Set {% raw %}<span class="math inline">\(R=\mathbb{E}\sup_f|n^{-1/2}\sum_i\varepsilon_i f(X_i)|\)</span>{% endraw %}, {% raw %}<span class="math inline">\(D_n=\sup_f P_nf^2\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(D=\mathbb{E}D_n\)</span>{% endraw %}. Conditional chaining, followed by concavity of {% raw %}<span class="math inline">\(x\mapsto\sqrt{x\log(A/\sqrt x)}\)</span>{% endraw %} on {% raw %}<span class="math inline">\([0,1]\)</span>{% endraw %}, gives</p>
{% raw %}<div class="math display">\[R\le C\sqrt v\,\mathbb{E}\sqrt{D_n\log(A/\sqrt{D_n})}\le C\sqrt{vD\log(A/\sqrt D)}.\]</div>{% endraw %}
<p>At zero the expression is interpreted by continuity. Symmetrization and contraction for the map {% raw %}<span class="math inline">\(x\mapsto x^2\)</span>{% endraw %}, which is 2-Lipschitz on {% raw %}<span class="math inline">\([-1,1]\)</span>{% endraw %}, give {% raw %}<span class="math inline">\(D\le\sigma^2+CR/\sqrt n\)</span>{% endraw %}. If {% raw %}<span class="math inline">\(D\le\sigma^2\)</span>{% endraw %}, monotonicity gives {% raw %}<span class="math inline">\(R\le C\sigma\sqrt{vL}\)</span>{% endraw %}, where {% raw %}<span class="math inline">\(L=\log(A/\sigma)\)</span>{% endraw %}. If {% raw %}<span class="math inline">\(D&gt;\sigma^2\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(\log(A/\sqrt D)\le L\)</span>{% endraw %}, so</p>
{% raw %}<div class="math display">\[R^2\le CvL(\sigma^2+CR/\sqrt n).\]</div>{% endraw %}
<p>Solving this quadratic yields {% raw %}<span class="math inline">\(R\le C[\sigma\sqrt{vL}+vL/\sqrt n]\)</span>{% endraw %}. Symmetrization and rescaling finish the proof. For centering, cover the original class in {% raw %}<span class="math inline">\(L^2((Q+P)/2)\)</span>{% endraw %}; the triangle inequality and Cauchy–Schwarz show that the same centers, after centering, cover in {% raw %}<span class="math inline">\(L^2(Q)\)</span>{% endraw %} with radius enlarged by at most {% raw %}<span class="math inline">\(2\sqrt2\)</span>{% endraw %}. Thus centering preserves the required polynomial entropy bound. ◻</p></div>
<p>Here are the analytic steps in the local bound. For {% raw %}<span class="math inline">\(0&lt;c\le1\)</span>{% endraw %}, substitute {% raw %}<span class="math inline">\(u=cv\)</span>{% endraw %} and use {% raw %}<span class="math inline">\(\sqrt{a+b}\le\sqrt a+\sqrt b\)</span>{% endraw %} to obtain</p>

{% raw %}<div class="math display">\[\int_0^c\sqrt{\log(A/u)}\,du\le c\left[\sqrt{\log(A/c)}+\int_0^1\sqrt{\log(1/v)}\,dv\right]\le Cc\sqrt{\log(A/c)}.\]</div>{% endraw %}

<p>The last integral is {% raw %}<span class="math inline">\(\Gamma(3/2)\)</span>{% endraw %}, by {% raw %}<span class="math inline">\(v=e^{-t}\)</span>{% endraw %}. If {% raw %}<span class="math inline">\(q(x)=x\log(A/\sqrt x)\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(q'(x)=\log(A/\sqrt x)-1/2&gt;0\)</span>{% endraw %} and {% raw %}<span class="math inline">\(q''(x)=-1/(2x)&lt;0\)</span>{% endraw %} on {% raw %}<span class="math inline">\((0,1]\)</span>{% endraw %}. Composing its nonnegative concave extension with the increasing concave square root proves the Jensen step. More explicitly, symmetrization and contraction give</p>

{% raw %}<div class="math display">\[D\le\sigma^2+\mathbb E\sup_f|(P_n-P)f^2|\le\sigma^2+\frac2{\sqrt n}\mathbb E\sup_f\left|n^{-1/2}\sum_i\varepsilon_i f(X_i)^2\right|\le\sigma^2+\frac{8R}{\sqrt n}.\]</div>{% endraw %}

<p>Finally, an inequality {% raw %}<span class="math inline">\(R^2\le a+bR\)</span>{% endraw %}, with {% raw %}<span class="math inline">\(a,b\ge0\)</span>{% endraw %}, implies {% raw %}<span class="math inline">\(R\le(b+\sqrt{b^2+4a})/2\le b+\sqrt a\)</span>{% endraw %}. This gives both terms of Theorem 13, including the regime in which the second term dominates. The contraction inequality and its coordinate-by-coordinate proof are given in the preceding maximal-inequalities note.</p>
<div id="result-14" class="example" data-note-number="14" data-note-kind="Example"><p><strong>Example 14 (Polynomials).</strong> The real polynomials of degree at most {% raw %}<span class="math inline">\(m\)</span>{% endraw %} form a VC-subgraph class of dimension {% raw %}<span class="math inline">\(m+1\)</span>{% endraw %}. Lagrange interpolation shatters {% raw %}<span class="math inline">\(m+1\)</span>{% endraw %} distinct points {% raw %}<span class="math inline">\((x_i,0)\)</span>{% endraw %}. To prove the upper bound, take {% raw %}<span class="math inline">\(m+2\)</span>{% endraw %} arbitrary subgraph points {% raw %}<span class="math inline">\((x_i,y_i)\)</span>{% endraw %} and a nonzero vector {% raw %}<span class="math inline">\(a\)</span>{% endraw %} satisfying {% raw %}<span class="math inline">\(\sum_i a_i(1,x_i,\ldots,x_i^m)=0\)</span>{% endraw %}. Then every polynomial satisfies</p>
{% raw %}<div class="math display">\[\sum_i a_i(p(x_i)-y_i)=-\sum_i a_i y_i=:c.\]</div>{% endraw %}
<p>Because {% raw %}<span class="math inline">\(\sum_i a_i=0\)</span>{% endraw %}, there are both positive and negative coefficients. Labeling {% raw %}<span class="math inline">\(p(x_i)&gt;y_i\)</span>{% endraw %} exactly at the positive coefficients forces the left side to be positive; reversing these labels forces it to be negative. At least one of these two patterns contradicts the fixed value {% raw %}<span class="math inline">\(c\)</span>{% endraw %}. Thus {% raw %}<span class="math inline">\(m+2\)</span>{% endraw %} points cannot be shattered. This argument also handles equalities at the subgraph boundary.</p>
<p>For the <a href="{% post_url 2022-11-05-localization-and-the-uniform-law %}#ex:bounding-rademacher-complexity-quadratic">quadratic example</a>, an envelope restriction is essential. Suppose {% raw %}<span class="math inline">\(P\)</span>{% endraw %} is supported on {% raw %}<span class="math inline">\([-1,1]\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\mathcal Q\)</span>{% endraw %} consists of quadratics satisfying {% raw %}<span class="math inline">\(\sup_{[-1,1]}|p|\le1\)</span>{% endraw %}. Theorem 8 and conditional chaining give, for every sample,</p>
{% raw %}<div class="math display">\[\mathbb{E}_\varepsilon\sup_{p\in\mathcal Q}\left|n^{-1}\sum_i\varepsilon_i p(x_i)\right|\le Cn^{-1/2}.\]</div>{% endraw %}
<p>The squared class is contained in the degree-four polynomials and has envelope one. Applying the same argument and bounded differences to it shows that, with probability at least {% raw %}<span class="math inline">\(1-\eta\)</span>{% endraw %},</p>
{% raw %}<div class="math display">\[\sup_{p\in\mathcal Q}|\|p\|_{P_n,2}-\|p\|_{P,2}|\le C\left(\frac{1+\log(1/\eta)}n\right)^{1/4}.\]</div>{% endraw %}
<p>Here we used {% raw %}<span class="math inline">\(|\sqrt a-\sqrt b|^2\le|a-b|\)</span>{% endraw %}. This provides the coarse {% raw %}<span class="math inline">\(n^{-1/4}\)</span>{% endraw %} norm-comparison scale directly. The <a href="{% post_url 2022-11-05-localization-and-the-uniform-law %}#thm:bounding-rademacher-complexity-star-shaped-c-unif-bouned">localized fixed-point method</a> can be used when finer dependence on a local radius is needed. Neither argument applies to all unbounded-coefficient quadratics with a fixed envelope.</p></div>
