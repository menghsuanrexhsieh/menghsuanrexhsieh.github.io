<div class="note-content" markdown="0">

<p>A quotient of a Hausdorff space need not be Hausdorff, so explicit projective charts do not settle the separation question by themselves. For complex projective space, normalize each nonzero vector to unit length. The remaining ambiguity is multiplication by a unit complex number, giving an action of a compact group on a sphere.</p>

<p>We use compactness to separate distinct orbits by neighbourhoods in the quotient. The argument has two parts: prove the separation result for compact group actions, then compare the sphere quotient with the usual definition of projective space.</p>

<div id="app:technical" data-note-section="title">

</div>
<h3 data-note-section="1" id="app:CPn-hausdorff">1. Proof that {% raw %}<span class="math inline">\(\mathbb CP^n\)</span>{% endraw %} is Hausdorff</h3>
<p>We prove the separation property directly from the quotient construction. We first collect the compactness and separation facts used in the quotient argument.</p>

<div id="lem:hausdorff-facts" class="lemma" data-note-number="1" data-note-kind="Lemma">
<p><strong>Lemma 1</strong>.  </p>

<ol>
<li><p><span id="lem:hausdorff-facts-1" data-label="lem:hausdorff-facts-1"></span> Let {% raw %}<span class="math inline">\(X\)</span>{% endraw %} be a Hausdorff space, and {% raw %}<span class="math inline">\(K\)</span>{% endraw %} be a compact subset of {% raw %}<span class="math inline">\(X\)</span>{% endraw %}. Then, {% raw %}<span class="math inline">\(K\)</span>{% endraw %} is closed.</p></li>
<li><p><span id="lem:hausdorff-facts-2" data-label="lem:hausdorff-facts-2"></span> Let {% raw %}<span class="math inline">\(X\)</span>{% endraw %} be a compact space and {% raw %}<span class="math inline">\(Y\)</span>{% endraw %} be a Hausdorff space. Suppose {% raw %}<span class="math inline">\(f:  X \to Y\)</span>{% endraw %} is a bijective continuous function. Then, {% raw %}<span class="math inline">\(f\)</span>{% endraw %} is a homeomorphism.</p></li>
<li><p><span id="lem:hausdorff-facts-3" data-label="lem:hausdorff-facts-3"></span> Any compact Hausdorff space is normal, i.e. for any given disjoint closed subsets {% raw %}<span class="math inline">\(E\)</span>{% endraw %} and {% raw %}<span class="math inline">\(F\)</span>{% endraw %}, there exist open neighbourhoods {% raw %}<span class="math inline">\(U\)</span>{% endraw %} of {% raw %}<span class="math inline">\(E\)</span>{% endraw %} and {% raw %}<span class="math inline">\(V\)</span>{% endraw %} of {% raw %}<span class="math inline">\(F\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(U \cap V = \emptyset\)</span>{% endraw %}.</p></li>
<li><p><span id="lem:hausdorff-facts-4" data-label="lem:hausdorff-facts-4"></span> Let {% raw %}<span class="math inline">\(X\)</span>{% endraw %} and {% raw %}<span class="math inline">\(Y\)</span>{% endraw %} be compact spaces. Then, the product space {% raw %}<span class="math inline">\(X \times Y\)</span>{% endraw %} is also compact.</p></li>
</ol>
</div>
<p><strong>Proof of Lemma 1.</strong> For part 1, fix {% raw %}<span class="math inline">\(x\notin K\)</span>{% endraw %}. For every {% raw %}<span class="math inline">\(y\in K\)</span>{% endraw %}, choose disjoint open neighbourhoods {% raw %}<span class="math inline">\(U_y\ni x\)</span>{% endraw %} and {% raw %}<span class="math inline">\(V_y\ni y\)</span>{% endraw %}. A finite collection {% raw %}<span class="math inline">\(V_{y_1},\ldots,V_{y_N}\)</span>{% endraw %} covers {% raw %}<span class="math inline">\(K\)</span>{% endraw %}. Then {% raw %}<span class="math inline">\(U=\bigcap_iU_{y_i}\)</span>{% endraw %} is an open neighbourhood of {% raw %}<span class="math inline">\(x\)</span>{% endraw %} disjoint from {% raw %}<span class="math inline">\(K\)</span>{% endraw %}. Thus the complement of {% raw %}<span class="math inline">\(K\)</span>{% endraw %} is open. The intersection must use the neighbourhoods of {% raw %}<span class="math inline">\(x\)</span>{% endraw %}, not the neighbourhoods covering {% raw %}<span class="math inline">\(K\)</span>{% endraw %}.</p>
<p>For part 2, a closed subset {% raw %}<span class="math inline">\(A\)</span>{% endraw %} of compact {% raw %}<span class="math inline">\(X\)</span>{% endraw %} is compact: append {% raw %}<span class="math inline">\(X\setminus A\)</span>{% endraw %} to any relative open cover and use a finite subcover of {% raw %}<span class="math inline">\(X\)</span>{% endraw %}. Its continuous image {% raw %}<span class="math inline">\(f(A)\)</span>{% endraw %} is compact, and hence closed in Hausdorff {% raw %}<span class="math inline">\(Y\)</span>{% endraw %} by part 1. Thus the continuous bijection {% raw %}<span class="math inline">\(f\)</span>{% endraw %} is closed, which means its inverse is continuous.</p>
<p>For part 3, let {% raw %}<span class="math inline">\(E,F\)</span>{% endraw %} be disjoint closed subsets of compact Hausdorff {% raw %}<span class="math inline">\(X\)</span>{% endraw %}. Both are compact. For each {% raw %}<span class="math inline">\(e\in E\)</span>{% endraw %}, the preceding finite-neighbourhood argument gives disjoint open sets {% raw %}<span class="math inline">\(U_e\ni e\)</span>{% endraw %} and {% raw %}<span class="math inline">\(V_e\supset F\)</span>{% endraw %}. Choose {% raw %}<span class="math inline">\(U_{e_1},\ldots,U_{e_N}\)</span>{% endraw %} covering {% raw %}<span class="math inline">\(E\)</span>{% endraw %}, and put </p>
{% raw %}<div class="math display">\[U=\bigcup_iU_{e_i},\qquad V=\bigcap_iV_{e_i}.\]</div>{% endraw %}
<p> Both are open, contain their respective closed sets, and are disjoint: a point in {% raw %}<span class="math inline">\(U_{e_i}\)</span>{% endraw %} cannot be in {% raw %}<span class="math inline">\(V\subseteq V_{e_i}\)</span>{% endraw %}.</p>
<p>For part 4, let an open cover of {% raw %}<span class="math inline">\(X\times Y\)</span>{% endraw %} be given. For each fixed {% raw %}<span class="math inline">\(x\)</span>{% endraw %}, choose product neighbourhoods {% raw %}<span class="math inline">\(U_{x,y}\times V_{x,y}\)</span>{% endraw %} lying in cover elements and covering {% raw %}<span class="math inline">\(\{x\}\times Y\)</span>{% endraw %}. Compactness of {% raw %}<span class="math inline">\(Y\)</span>{% endraw %} gives finitely many {% raw %}<span class="math inline">\(V_{x,y_i}\)</span>{% endraw %} covering {% raw %}<span class="math inline">\(Y\)</span>{% endraw %}. Their corresponding {% raw %}<span class="math inline">\(U_{x,y_i}\)</span>{% endraw %} have an intersection {% raw %}<span class="math inline">\(U_x\)</span>{% endraw %} containing {% raw %}<span class="math inline">\(x\)</span>{% endraw %}, and finitely many original cover elements cover the strip {% raw %}<span class="math inline">\(U_x\times Y\)</span>{% endraw %}. Finally choose finitely many {% raw %}<span class="math inline">\(U_x\)</span>{% endraw %} covering compact {% raw %}<span class="math inline">\(X\)</span>{% endraw %}. The associated finite collections cover {% raw %}<span class="math inline">\(X\times Y\)</span>{% endraw %}. ◻</p>

<div id="lem:hausdorff-quotient" class="lemma" data-note-number="2" data-note-kind="Lemma">
<p><strong>Lemma 2</strong>.  Let {% raw %}<span class="math inline">\(X\)</span>{% endraw %} be a compact, Hausdorff space and {% raw %}<span class="math inline">\(G\)</span>{% endraw %} be a compact topological group. Suppose {% raw %}<span class="math inline">\(G\)</span>{% endraw %} acts on {% raw %}<span class="math inline">\(X\)</span>{% endraw %} continuously, i.e. the function {% raw %}<span class="math inline">\(m : G \times X \to X : (g,x) \mapsto gx\)</span>{% endraw %} is continuous. Let {% raw %}<span class="math inline">\(\pi: X \to X/G\)</span>{% endraw %} be the quotient map. Then,</p>

<ol>
<li><p><span id="lem:hausdorff-quotient-1" data-label="lem:hausdorff-quotient-1"></span> {% raw %}<span class="math inline">\(\pi\)</span>{% endraw %} is an open mapping;</p></li>
<li><p><span id="lem:hausdorff-quotient-2" data-label="lem:hausdorff-quotient-2"></span> {% raw %}<span class="math inline">\(\pi\)</span>{% endraw %} is a closed mapping;</p></li>
<li><p><span id="lem:hausdorff-quotient-3" data-label="lem:hausdorff-quotient-3"></span> the orbit {% raw %}<span class="math inline">\(X/G\)</span>{% endraw %} is Hausdorff.</p></li>
</ol>
</div>
<div class="proof">
<p><em>Proof of Lemma <a href="#lem:hausdorff-quotient" data-reference-type="ref" data-reference="lem:hausdorff-quotient">2</a>.</em> We first show that {% raw %}<span class="math inline">\(\pi\)</span>{% endraw %} is an open mapping: to do so, we need to show that {% raw %}<span class="math inline">\(\pi(U)\)</span>{% endraw %} is open in {% raw %}<span class="math inline">\(X/G\)</span>{% endraw %} for any open set {% raw %}<span class="math inline">\(U \subset X\)</span>{% endraw %}: equivalently, we need to show that {% raw %}<span class="math inline">\(\pi^{-1} (\pi(U))\)</span>{% endraw %} is open in {% raw %}<span class="math inline">\(X\)</span>{% endraw %}. We <u>claim</u> that </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \pi^{-1}(\pi(U)) = \bigcup_{g \in G} g(U) ~.
    
\end{aligned}\]</div>{% endraw %}
<p> First, for any {% raw %}<span class="math inline">\(g \in G\)</span>{% endraw %}, {% raw %}<span class="math inline">\(g:X\to X\)</span>{% endraw %} is a homeomorphism, therefore {% raw %}<span class="math inline">\(g(U)\)</span>{% endraw %} is open in {% raw %}<span class="math inline">\(X\)</span>{% endraw %} for any open subset {% raw %}<span class="math inline">\(U \subset X\)</span>{% endraw %}. Second, to see that one inclusion holds: pick any {% raw %}<span class="math inline">\(a \in \pi^{-1} (\pi(U))\)</span>{% endraw %}; therefore, {% raw %}<span class="math inline">\(\pi(a) \in \pi(U)\)</span>{% endraw %}, i.e. there exists some {% raw %}<span class="math inline">\(b \in U\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(\pi(a) = \pi(b)\)</span>{% endraw %}. Therefore, {% raw %}<span class="math inline">\(a = gb \in g(U)\)</span>{% endraw %} for some {% raw %}<span class="math inline">\(g \in G\)</span>{% endraw %}. As such, it must be that {% raw %}<span class="math inline">\(a \in \bigcup_{g \in G} g(U)\)</span>{% endraw %}. Third, for the reverse inclusion: pick any {% raw %}<span class="math inline">\(c \in \bigcup_{g \in G} g(U)\)</span>{% endraw %}. Then, it must be that {% raw %}<span class="math inline">\(c \in g(U)\)</span>{% endraw %} for some {% raw %}<span class="math inline">\(g \in G\)</span>{% endraw %}, implying {% raw %}<span class="math inline">\(c = gd\)</span>{% endraw %} for some {% raw %}<span class="math inline">\(d \in U\)</span>{% endraw %}. Since {% raw %}<span class="math inline">\(\pi(gd) = \pi(d)\)</span>{% endraw %}, it follows that {% raw %}<span class="math inline">\(\pi(c) = \pi(d) \in \pi(U)\)</span>{% endraw %}, from which the desired inclusion follows. The claim is therefore proven, and from here so is (1).</p>

<p>Next we show {% raw %}<span class="math inline">\(\pi\)</span>{% endraw %} is a closed mapping: note that because {% raw %}<span class="math inline">\(X\)</span>{% endraw %} is compact, any closed subset of {% raw %}<span class="math inline">\(X\)</span>{% endraw %} is also compact. So, let {% raw %}<span class="math inline">\(A\)</span>{% endraw %} be a closed subset of {% raw %}<span class="math inline">\(X\)</span>{% endraw %}, implying {% raw %}<span class="math inline">\(A\)</span>{% endraw %} is compact. Since any product of compact spaces is compact, {% raw %}<span class="math inline">\(G \times A\)</span>{% endraw %} is compact. Since {% raw %}<span class="math inline">\(G(A) = m(G, A)\)</span>{% endraw %} and {% raw %}<span class="math inline">\(m\)</span>{% endraw %} is continuous, {% raw %}<span class="math inline">\(G(A)=\bigcup_{g \in G} g(A)\)</span>{% endraw %} is compact. From here, note that {% raw %}<span class="math inline">\(\pi^{-1}(\pi(A)) = G(A)\)</span>{% endraw %} is a compact subset of a Hausdorff space {% raw %}<span class="math inline">\(X\)</span>{% endraw %}, it is therefore closed. This proves (2).</p>

<p>To prove part 3, distinct orbits {% raw %}<span class="math inline">\(Gx,Gy\)</span>{% endraw %} are disjoint compact sets: each is the continuous image of compact {% raw %}<span class="math inline">\(G\)</span>{% endraw %}. By normality choose disjoint open {% raw %}<span class="math inline">\(U,V\subset X\)</span>{% endraw %} containing them. Since {% raw %}<span class="math inline">\(\pi\)</span>{% endraw %} is closed, the sets </p>
{% raw %}<div class="math display">\[\widetilde U=(X/G)\setminus\pi(X\setminus U),\qquad\widetilde V=(X/G)\setminus\pi(X\setminus V)\]</div>{% endraw %}
<p> are open. The first consists of orbits entirely contained in {% raw %}<span class="math inline">\(U\)</span>{% endraw %}, and the second of orbits entirely contained in {% raw %}<span class="math inline">\(V\)</span>{% endraw %}. Thus {% raw %}<span class="math inline">\([x]\in\widetilde U\)</span>{% endraw %}, {% raw %}<span class="math inline">\([y]\in\widetilde V\)</span>{% endraw %}, and the two sets are disjoint. This uses the closed complements of {% raw %}<span class="math inline">\(U,V\)</span>{% endraw %}; an open neighbourhood itself need not be closed. Therefore {% raw %}<span class="math inline">\(X/G\)</span>{% endraw %} is Hausdorff. ◻</p>

</div>
<div id="result-3" class="remark" data-note-number="3" data-note-kind="Remark">
<p><strong>Remark 3</strong>.  Let {% raw %}<span class="math inline">\(\mathbb S^1\)</span>{% endraw %} act on {% raw %}<span class="math inline">\(\mathbb S^{2n+1}\)</span>{% endraw %} via {% raw %}<span class="math inline">\(\mathbb S^1 \times \mathbb S^{2n+1} : (\lambda,x) \mapsto \lambda x\)</span>{% endraw %}. This action is continuous: the function {% raw %}<span class="math inline">\(\eta : \mathbb C \times \mathbb C^{n+1} \to \mathbb C^{n+1} : (\lambda, x) \mapsto \lambda x\)</span>{% endraw %} is continuous. The action of {% raw %}<span class="math inline">\(\mathbb S^1\)</span>{% endraw %} on {% raw %}<span class="math inline">\(\mathbb S^{2n+1}\)</span>{% endraw %} is the restriction of {% raw %}<span class="math inline">\(\eta\)</span>{% endraw %} to {% raw %}<span class="math inline">\(\mathbb S^1 \times \mathbb S^{2n+1}\)</span>{% endraw %}, which is therefore continuous. Therefore, identifying two points {% raw %}<span class="math inline">\(x,y \in \mathbb S^{2n+1}\)</span>{% endraw %} via {% raw %}<span class="math inline">\(\lambda \in \mathbb S^1\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(x = \lambda y\)</span>{% endraw %} defines equivalence classes. The quotient space of {% raw %}<span class="math inline">\(\mathbb S^{2n+1}\)</span>{% endraw %} modulo this relation gives meaning to the notation {% raw %}<span class="math inline">\(\mathbb S^{2n+1} / \mathbb S^1\)</span>{% endraw %}. We denote the equivalence class of {% raw %}<span class="math inline">\(x \in \mathbb S^{2n+1}\)</span>{% endraw %} (modulo this relation as described) by {% raw %}<span class="math inline">\([x]_{\mathbb S^1}\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(q : \mathbb S^{2n+1} \to \mathbb S^{2n+1} / \mathbb S^1\)</span>{% endraw %} is the quotient map.</p>

</div>
<div id="lem:CPn-homeomorphic-to-S2n-1-S1" class="lemma" data-note-number="4" data-note-kind="Lemma">
<p><strong>Lemma 4</strong>.  The complex projective space {% raw %}<span class="math inline">\(\mathbb CP^n\)</span>{% endraw %} is homeomorphic to {% raw %}<span class="math inline">\(\mathbb S^{2n+1}/\mathbb S^1\)</span>{% endraw %}.</p>

</div>
<p><strong>Proof of Lemma 4.</strong> Let {% raw %}<span class="math inline">\(\pi:\mathbb C^{n+1}\setminus\{0\}\to\mathbb CP^n\)</span>{% endraw %} be the quotient by nonzero complex scalar multiplication, and {% raw %}<span class="math inline">\(q:S^{2n+1}\to S^{2n+1}/S^1\)</span>{% endraw %} the circle quotient. Normalization {% raw %}<span class="math inline">\(r(z)=z/\|z\|\)</span>{% endraw %} is continuous. If {% raw %}<span class="math inline">\(z=\mu z&#39;\)</span>{% endraw %} for {% raw %}<span class="math inline">\(\mu\ne0\)</span>{% endraw %}, then </p>
{% raw %}<div class="math display">\[r(z)=\frac{\mu}{|\mu|}r(z&#39;),\]</div>{% endraw %}
<p> so {% raw %}<span class="math inline">\(f([z])=[r(z)]_{S^1}\)</span>{% endraw %} is well-defined. Conversely, if {% raw %}<span class="math inline">\(f([z])=f([z&#39;])\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(r(z)=\lambda r(z&#39;)\)</span>{% endraw %} for some {% raw %}<span class="math inline">\(|\lambda|=1\)</span>{% endraw %}, and </p>
{% raw %}<div class="math display">\[z=\lambda\frac{\|z\|}{\|z&#39;\|}z&#39;.\]</div>{% endraw %}
<p> This is a nonzero complex multiple, proving injectivity. Every unit vector is fixed by {% raw %}<span class="math inline">\(r\)</span>{% endraw %}, proving surjectivity. The diagram records {% raw %}<span class="math inline">\(f\circ\pi=q\circ r\)</span>{% endraw %}.</p>

<p>For any open {% raw %}<span class="math inline">\(W\subset S^{2n+1}/S^1\)</span>{% endraw %}, </p>
{% raw %}<div class="math display">\[\pi^{-1}(f^{-1}(W))=(q\circ r)^{-1}(W)\]</div>{% endraw %}
<p> is open. By the definition of the quotient topology for {% raw %}<span class="math inline">\(\pi\)</span>{% endraw %}, this says {% raw %}<span class="math inline">\(f^{-1}(W)\)</span>{% endraw %} is open, so {% raw %}<span class="math inline">\(f\)</span>{% endraw %} is continuous. No inverse function {% raw %}<span class="math inline">\(\pi^{-1}\)</span>{% endraw %} exists or is needed.</p>
<p>To check the inverse continuously, the restriction {% raw %}<span class="math inline">\(\pi|_{S^{2n+1}}\)</span>{% endraw %} is constant on circle orbits, so it descends to {% raw %}<span class="math inline">\(g:S^{2n+1}/S^1\to\mathbb CP^n\)</span>{% endraw %}, {% raw %}<span class="math inline">\(g([u]_{S^1})=[u]\)</span>{% endraw %}. The identity {% raw %}<span class="math inline">\(g\circ q=\pi|_{S^{2n+1}}\)</span>{% endraw %} and the quotient topology for {% raw %}<span class="math inline">\(q\)</span>{% endraw %} prove that {% raw %}<span class="math inline">\(g\)</span>{% endraw %} is continuous. Directly {% raw %}<span class="math inline">\(g\circ f=\mathrm{id}\)</span>{% endraw %} and {% raw %}<span class="math inline">\(f\circ g=\mathrm{id}\)</span>{% endraw %}. Thus {% raw %}<span class="math inline">\(f\)</span>{% endraw %} is a homeomorphism. As a further check, {% raw %}<span class="math inline">\(\mathbb CP^n\)</span>{% endraw %} is compact because {% raw %}<span class="math inline">\(\pi|_{S^{2n+1}}\)</span>{% endraw %} is a continuous surjection from the compact sphere; this compactness argument does not presuppose Hausdorffness. ◻</p>

<div id="lem:hausdorff-iff-homeomorphic" class="lemma" data-note-number="5" data-note-kind="Lemma">
<p><strong>Lemma 5</strong>.  Let {% raw %}<span class="math inline">\(X,Y\)</span>{% endraw %} be topological spaces, and {% raw %}<span class="math inline">\(f: X \to Y\)</span>{% endraw %} is a homeomorphism. Then, {% raw %}<span class="math inline">\(X\)</span>{% endraw %} is Hausdorff if and only if {% raw %}<span class="math inline">\(Y\)</span>{% endraw %} is Hausdorff.</p>

</div>
<div class="proof">
<p><em>Proof.</em> For the “only if” direction, assume {% raw %}<span class="math inline">\(X\)</span>{% endraw %} is Hausdorff; then, by the surjectivity of {% raw %}<span class="math inline">\(f\)</span>{% endraw %}, for any {% raw %}<span class="math inline">\(y_1,y_2 \in Y\)</span>{% endraw %} there must exist {% raw %}<span class="math inline">\(x_1,x_2 \in X\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(y_1=f(x_1)\)</span>{% endraw %} and {% raw %}<span class="math inline">\(y_2=f(x_2)\)</span>{% endraw %}. By injectivity, {% raw %}<span class="math inline">\(x_1 \neq x_2\)</span>{% endraw %}. Since {% raw %}<span class="math inline">\(X\)</span>{% endraw %} is Hausdorff, there exists open neighbourhoods {% raw %}<span class="math inline">\(U_1\)</span>{% endraw %} of {% raw %}<span class="math inline">\(x_1\)</span>{% endraw %} and {% raw %}<span class="math inline">\(U_2\)</span>{% endraw %} of {% raw %}<span class="math inline">\(x_2\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(U_1 \cap U_2 = \emptyset\)</span>{% endraw %}. Now, let {% raw %}<span class="math inline">\(V_1 = f(U_1)\)</span>{% endraw %} and {% raw %}<span class="math inline">\(V_2 = f(U_2)\)</span>{% endraw %}. Because {% raw %}<span class="math inline">\(f\)</span>{% endraw %} is a homeomorphism, it is therefore an open mapping, and {% raw %}<span class="math inline">\(V_i\)</span>{% endraw %} are open neighourhoods of {% raw %}<span class="math inline">\(y_i\)</span>{% endraw %} for {% raw %}<span class="math inline">\(i = 1,2\)</span>{% endraw %}. We <u>claim</u> that {% raw %}<span class="math inline">\(V_1 \cap V_2 = \emptyset\)</span>{% endraw %}. If not, then there exists some {% raw %}<span class="math inline">\(w \in V_1 \cap V_2\)</span>{% endraw %}; by the surjectivity of {% raw %}<span class="math inline">\(f\)</span>{% endraw %}, there exists some {% raw %}<span class="math inline">\(x_w \in X\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(w = f(x_w)\)</span>{% endraw %}. But this means {% raw %}<span class="math inline">\(x_w \in f^{-1}(V_1 \cap V_2) \subset U_1 \cap U_2 = \emptyset\)</span>{% endraw %}, which is absurd. This concludes the proof. (Note that the “if” argument is identical, because {% raw %}<span class="math inline">\(f\)</span>{% endraw %} is a homeomorphism.) ◻</p>

</div>
<div class="proof">
<p><em>Proof that {% raw %}<span class="math inline">\(\mathbb CP^n\)</span>{% endraw %} is Hausdorff.</em> {% raw %}<span class="math inline">\(\mathbb CP^n\)</span>{% endraw %} is homeomorphic to {% raw %}<span class="math inline">\(\mathbb S^{2n+1}/\mathbb S^1\)</span>{% endraw %} by Lemma <a href="#lem:CPn-homeomorphic-to-S2n-1-S1" data-reference-type="ref" data-reference="lem:CPn-homeomorphic-to-S2n+1/S1">4</a>, and {% raw %}<span class="math inline">\(\mathbb S^{2n+1}/\mathbb S^1\)</span>{% endraw %} is Hausdorff by Lemma <a href="#lem:hausdorff-quotient" data-reference-type="ref" data-reference="lem:hausdorff-quotient">2</a>, part 3. Therefore, an application of Lemma <a href="#lem:hausdorff-iff-homeomorphic" data-reference-type="ref" data-reference="lem:hausdorff-iff-homeomorphic">5</a> implies {% raw %}<span class="math inline">\(\mathbb CP^n\)</span>{% endraw %} is Hausdorff. ◻</p>
