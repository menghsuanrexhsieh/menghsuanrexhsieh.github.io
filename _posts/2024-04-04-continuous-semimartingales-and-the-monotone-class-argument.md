<div class="note-content" markdown="0">

<p>This article constructs quadratic variation from martingale increments, proves the Kunita–Watanabe inequality, and extends stochastic integration from {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %}-bounded martingales to continuous local martingales and semimartingales. The first construction uses only discrete martingale sums and maximal inequalities.</p>



<p>Except in the initial set-theoretic argument, the filtered probability space satisfies the usual conditions. A continuous local martingale has an integrable initial value. We center it when defining its bracket, and state separately any second-moment condition on its initial value.</p>


<div id="sec:monotone-class" data-note-section="title">

</div>
<p>Let {% raw %}<span class="math inline">\(E\)</span>{% endraw %} be a set, let {% raw %}<span class="math inline">\(\mathcal P(E)\)</span>{% endraw %} be its power set, and let {% raw %}<span class="math inline">\(C\subseteq\mathcal P(E)\)</span>{% endraw %}. Write {% raw %}<span class="math inline">\(\sigma(C)\)</span>{% endraw %} for the {% raw %}<span class="math inline">\(\sigma\)</span>{% endraw %}-field generated by {% raw %}<span class="math inline">\(C\)</span>{% endraw %}. We use the following form of the {% raw %}<span class="math inline">\(\pi\)</span>{% endraw %}-{% raw %}<span class="math inline">\(\lambda\)</span>{% endraw %} theorem.</p>


<p>A collection {% raw %}<span class="math inline">\(\mathcal M\subseteq\mathcal P(E)\)</span>{% endraw %} is a Dynkin system if:</p>


<ol>
<li><p>{% raw %}<span class="math inline">\(E \in \mathcal M\)</span>{% endraw %};</p></li>
<li><p>if {% raw %}<span class="math inline">\(A,B \in \mathcal M\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(A \subset B\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(B \setminus A \in \mathcal M\)</span>{% endraw %}; and</p></li>
<li><p>if {% raw %}<span class="math inline">\(\{A_n\}_{n\geq 0}\)</span>{% endraw %} is an increasing sequence of sets such that {% raw %}<span class="math inline">\(A_n \in \mathcal M\)</span>{% endraw %} for all {% raw %}<span class="math inline">\(n\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(\bigcup_{n \geq 0} A_n \in \mathcal M\)</span>{% endraw %}.</p></li>
</ol>
<p>Every {% raw %}<span class="math inline">\(\sigma\)</span>{% endraw %}-field is a Dynkin system. Define the smallest Dynkin system containing {% raw %}<span class="math inline">\(C\)</span>{% endraw %} by</p>


{% raw %}<div class="math display">\[\begin{aligned}
    \mathcal M(C) = \bigcap_{C \subset \mathcal M \,,\, \mathcal M \text{ is a monotone class}} \mathcal M ~.
\end{aligned}\]</div>{% endraw %}
<div id="thm:monotone-class" class="theorem" data-note-number="1" data-note-kind="Theorem">
<p><strong>Theorem 1 ({% raw %}<span class="math inline">\(\pi\)</span>{% endraw %}-{% raw %}<span class="math inline">\(\lambda\)</span>{% endraw %} theorem).</strong> If {% raw %}<span class="math inline">\(C\)</span>{% endraw %} is closed under finite intersections, then {% raw %}<span class="math inline">\(\mathcal M(C)=\sigma(C)\)</span>{% endraw %}.</p>


</div>
<div class="proof">
<p><em>Proof.</em> Since {% raw %}<span class="math inline">\(\sigma(C)\)</span>{% endraw %} is a Dynkin system, {% raw %}<span class="math inline">\(\mathcal M(C)\subseteq\sigma(C)\)</span>{% endraw %}. A Dynkin system closed under finite intersections is a {% raw %}<span class="math inline">\(\sigma\)</span>{% endraw %}-field: nested differences give complements, complements and intersections give finite unions, and increasing unions give countable unions. We therefore prove intersection closure.</p>


<p>Write {% raw %}<span class="math inline">\(\mathcal D=\mathcal M(C)\)</span>{% endraw %}. For {% raw %}<span class="math inline">\(A\in C\)</span>{% endraw %}, let {% raw %}<span class="math inline">\(\mathcal D_A=\{B\in\mathcal D:A\cap B\in\mathcal D\}\)</span>{% endraw %}. It contains {% raw %}<span class="math inline">\(E\)</span>{% endraw %}, is closed under increasing unions, and is closed under nested differences because {% raw %}<span class="math inline">\(A\cap(B'\setminus B)=(A\cap B')\setminus(A\cap B)\)</span>{% endraw %} when {% raw %}<span class="math inline">\(B\subseteq B'\)</span>{% endraw %}. Thus it is a Dynkin system. Intersection closure of {% raw %}<span class="math inline">\(C\)</span>{% endraw %} gives {% raw %}<span class="math inline">\(C\subseteq\mathcal D_A\)</span>{% endraw %}, so minimality gives {% raw %}<span class="math inline">\(\mathcal D_A=\mathcal D\)</span>{% endraw %}.</p>


<p>Now fix {% raw %}<span class="math inline">\(A\in\mathcal D\)</span>{% endraw %}. The Dynkin-system argument applies to {% raw %}<span class="math inline">\(\mathcal D_A\)</span>{% endraw %}, and the first stage, with the factors interchanged, gives {% raw %}<span class="math inline">\(C\subset\mathcal D_A\)</span>{% endraw %}. Hence {% raw %}<span class="math inline">\(\mathcal D_A=\mathcal D\)</span>{% endraw %} again. This proves intersection stability for two arbitrary members of {% raw %}<span class="math inline">\(\mathcal D\)</span>{% endraw %}, so {% raw %}<span class="math inline">\(\mathcal D\)</span>{% endraw %} is a sigma-field and equals {% raw %}<span class="math inline">\(\sigma(C)\)</span>{% endraw %}. ◻</p>

</div>
<div id="functional-monotone-class">
<p><strong>Corollary (Functional form).</strong> Let {% raw %}<span class="math inline">\(V\)</span>{% endraw %} be a vector space of bounded real functions on {% raw %}<span class="math inline">\(E\)</span>{% endraw %}, containing the constants and closed under pointwise limits of uniformly bounded sequences. If {% raw %}<span class="math inline">\(V\)</span>{% endraw %} contains the indicators of an intersection-stable class {% raw %}<span class="math inline">\(C\)</span>{% endraw %}, then it contains every bounded {% raw %}<span class="math inline">\(\sigma(C)\)</span>{% endraw %}-measurable function.</p>

<p><em>Proof.</em> The collection {% raw %}<span class="math inline">\(\{A:\mathbf1_A\in V\}\)</span>{% endraw %} is a Dynkin system: constants give {% raw %}<span class="math inline">\(E\)</span>{% endraw %}, linearity gives nested differences, and bounded pointwise closure gives increasing unions. Theorem 1 gives every {% raw %}<span class="math inline">\(\sigma(C)\)</span>{% endraw %}-measurable indicator. Linearity gives simple functions, and uniformly bounded simple approximations give every bounded measurable function. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>
</div>
<h2 data-note-section="1" id="sec:cts-semimartingales">1. Continuous Semimartingales</h2>
<div id="thm:cts-semimartingale-limit-characterization" class="theorem" data-note-number="2" data-note-kind="Theorem">
<p><strong>Theorem 2.</strong> Let {% raw %}<span class="math inline">\(M\)</span>{% endraw %} be a continuous local martingale with {% raw %}<span class="math inline">\(M_0=0\)</span>{% endraw %}. There is a unique continuous adapted increasing process {% raw %}<span class="math inline">\(A\)</span>{% endraw %}, with {% raw %}<span class="math inline">\(A_0=0\)</span>{% endraw %}, such that {% raw %}<span class="math inline">\(M^2-A\)</span>{% endraw %} is a continuous local martingale. We write {% raw %}<span class="math inline">\(A=\langle M\rangle\)</span>{% endraw %}. For every deterministic sequence of partitions {% raw %}<span class="math inline">\(\pi_n\)</span>{% endraw %} of {% raw %}<span class="math inline">\([0,T]\)</span>{% endraw %} whose mesh tends to zero,</p>

{% raw %}<div class="math display">\[\sum_{[u,v]\in\pi_n}(M_v-M_u)^2\xrightarrow{P}\langle M\rangle_T.\]</div>{% endraw %}

<p>For a nonzero integrable initial value, define {% raw %}<span class="math inline">\(\langle M\rangle=\langle M-M_0\rangle\)</span>{% endraw %}. The corresponding centered-square characterization always holds. The uncentered assertion {% raw %}<span class="math inline">\(M^2-\langle M\rangle\)</span>{% endraw %} is a local martingale under our integrable-initial-value convention if {% raw %}<span class="math inline">\(M_0\in L^2\)</span>{% endraw %}.</p>

</div>
<p>We give a construction from martingale increments, before using stochastic integration. Suppose first {% raw %}<span class="math inline">\(M_0=0\)</span>{% endraw %} and {% raw %}<span class="math inline">\(|M_t|\leq D\)</span>{% endraw %}. For a finite partition {% raw %}<span class="math inline">\(\pi\)</span>{% endraw %} of {% raw %}<span class="math inline">\([0,T]\)</span>{% endraw %}, set</p>

{% raw %}<div class="math display">\[X_t^\pi=\sum_{[u,v]\in\pi}M_u(M_{t\wedge v}-M_{t\wedge u}),\qquad0\leq t\leq T.\]</div>{% endraw %}

<p>Each summand is a martingale. After time {% raw %}<span class="math inline">\(u\)</span>{% endraw %}, its coefficient is measurable; before time {% raw %}<span class="math inline">\(u\)</span>{% endraw %}, condition first at {% raw %}<span class="math inline">\(u\)</span>{% endraw %}, where the expected future increment is zero. Thus {% raw %}<span class="math inline">\(X^\pi\)</span>{% endraw %} is a bounded continuous martingale.</p>

<div id="lem:second-moment-zero-limit" class="lemma" data-note-number="3" data-note-kind="Lemma">
<p><strong>Lemma 3.</strong> As the meshes of {% raw %}<span class="math inline">\(\pi\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\sigma\)</span>{% endraw %} tend to zero, {% raw %}<span class="math inline">\(\mathbb{E}|X_T^\pi-X_T^\sigma|^2\to0\)</span>{% endraw %}.</p>

</div>
<p>Take the common refinement {% raw %}<span class="math inline">\(\rho\)</span>{% endraw %}. The difference is a martingale transform {% raw %}<span class="math inline">\(\sum_jD_j\Delta M_j\)</span>{% endraw %}, where {% raw %}<span class="math inline">\(D_j\)</span>{% endraw %} is the difference of the two relevant left-endpoint values and is measurable at the left endpoint of the refined interval. Orthogonality of martingale increments gives</p>

{% raw %}<div class="math display">\[\mathbb{E}|X_T^\pi-X_T^\sigma|^2
=\mathbb{E}\sum_jD_j^2(\Delta M_j)^2
\leq\left(\mathbb{E}\max_j|D_j|^4\right)^{1/2}
\left(\mathbb{E} Q_\rho^2\right)^{1/2},\qquad Q_\rho=\sum_j(\Delta M_j)^2.\]</div>{% endraw %}

<p>The first factor tends to zero by path continuity and bounded convergence. To bound the second uniformly, expand {% raw %}<span class="math inline">\(Q_\rho^2\)</span>{% endraw %}. The fourth-power terms are at most {% raw %}<span class="math inline">\(4D^2\mathbb{E} Q_\rho\)</span>{% endraw %}. Conditional orthogonality gives {% raw %}<span class="math inline">\(\mathbb{E}[\sum_{k&gt;j}(\Delta M_k)^2\mid\mathcal F_{t_j}]=\mathbb{E}[(M_T-M_{t_j})^2\mid\mathcal F_{t_j}]\leq4D^2\)</span>{% endraw %}. Hence</p>

{% raw %}<div class="math display">\[\mathbb{E} Q_\rho^2\leq12D^2\mathbb{E} Q_\rho
=12D^2\mathbb{E} M_T^2\leq12D^4.\]</div>{% endraw %}

<p>This proves the lemma for arbitrary partitions, without a nesting assumption.</p>

<p>Doob’s inequality now makes {% raw %}<span class="math inline">\(X^{\pi_n}\)</span>{% endraw %} Cauchy in the norm {% raw %}<span class="math inline">\(\bigl(\mathbb{E}\sup_{t\leq T}|X_t|^2\bigr)^{1/2}\)</span>{% endraw %}. A subsequence with summable expected uniform differences converges uniformly almost surely; its limit {% raw %}<span class="math inline">\(Y\)</span>{% endraw %} is continuous, adapted, and a martingale, and the full sequence converges in that norm. Set {% raw %}<span class="math inline">\(A_t=M_t^2-2Y_t\)</span>{% endraw %}. At partition points, the telescoping identity is</p>

{% raw %}<div class="math display">\[M_{t_i}^2-2X_{t_i}^{\pi_n}=\sum_{j\leq i}(M_{t_j}-M_{t_{j-1}})^2.\]</div>{% endraw %}

<p>The right side is increasing in {% raw %}<span class="math inline">\(i\)</span>{% endraw %}. Approximate any two fixed times by partition points, use uniform convergence and continuity, and then intersect over rational times. This proves that {% raw %}<span class="math inline">\(A\)</span>{% endraw %} is continuous and increasing, with {% raw %}<span class="math inline">\(A_0=0\)</span>{% endraw %}. Also, {% raw %}<span class="math inline">\(M^2-A=2Y\)</span>{% endraw %} is a martingale. At {% raw %}<span class="math inline">\(T\)</span>{% endraw %}, the same identity gives convergence of square sums in {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %}.</p>

<p>Uniqueness uses the elementary fact that a continuous local martingale of finite variation, starting at zero, vanishes. Stop such a process {% raw %}<span class="math inline">\(N\)</span>{% endraw %} when either its absolute value or its total variation reaches an integer, and at an integer time. For the stopped bounded martingale and a partition of {% raw %}<span class="math inline">\([0,T]\)</span>{% endraw %}, orthogonality gives</p>

{% raw %}<div class="math display">\[\mathbb{E}N_T^2=\mathbb{E}\sum_j(\Delta N_j)^2
\leq\mathbb{E}\left[\max_j|\Delta N_j|\operatorname{Var}_{[0,T]}(N)\right]\longrightarrow0.\]</div>{% endraw %}

<p>Continuity and the stopped bounds justify dominated convergence. Removing the stops proves {% raw %}<span class="math inline">\(N=0\)</span>{% endraw %}. The difference of two candidate compensators has these properties, proving uniqueness. It also makes constructions on different finite horizons consistent.</p>

<p>For a general zero-start continuous local martingale, use {% raw %}<span class="math inline">\(\tau_n=\inf\{t\geq0:|M_t|\geq n\}\wedge n\)</span>{% endraw %}. The bounded stopped martingales have brackets that agree on overlaps by uniqueness. They therefore define a continuous increasing bracket for {% raw %}<span class="math inline">\(M\)</span>{% endraw %}. On {% raw %}<span class="math inline">\(\{\tau_n&gt;T\}\)</span>{% endraw %}, square sums and brackets agree with those of the stopped process; these events have probability tending to one. This gives the asserted convergence in probability. For nonzero initial values, center first. If {% raw %}<span class="math inline">\(M_0\in L^2\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(M_0^2+2M_0(M-M_0)\)</span>{% endraw %} is a local martingale, by Example 7 below, which justifies the uncentered formula.</p>

<div id="result-4" class="lemma" data-note-number="4" data-note-kind="Lemma">
<p><strong>Lemma 4</strong>.  Let {% raw %}<span class="math inline">\(M=\{M_t\}_{t\geq0}\)</span>{% endraw %} be a continuous local martingale and let {% raw %}<span class="math inline">\(T\)</span>{% endraw %} be a stopping time. Then, for every {% raw %}<span class="math inline">\(t\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\langle M^T, M^T \rangle_t = \langle M, M \rangle_{t \wedge T}\)</span>{% endraw %} almost surely.</p>

</div>
<div class="proof">
<p><em>Proof.</em> By the centered-square characterization, {% raw %}<span class="math inline">\((M-M_0)^2-\langle M\rangle\)</span>{% endraw %} is a continuous local martingale. Stopping at {% raw %}<span class="math inline">\(T\)</span>{% endraw %} gives {% raw %}<span class="math inline">\((M_{t\wedge T}-M_0)^2-\langle M\rangle_{t\wedge T}\)</span>{% endraw %}. The stopped bracket is continuous, adapted, increasing, and zero initially. Uniqueness in Theorem 2, applied to {% raw %}<span class="math inline">\(M^T-M_0\)</span>{% endraw %}, therefore identifies it with {% raw %}<span class="math inline">\(\langle M^T\rangle\)</span>{% endraw %}. This argument requires no second moment for {% raw %}<span class="math inline">\(M_0\)</span>{% endraw %}. ◻</p>

</div>
<div id="result-5" class="lemma" data-note-number="5" data-note-kind="Lemma">
<p><strong>Lemma 5</strong>.  Let {% raw %}<span class="math inline">\(M\)</span>{% endraw %} be a continuous local martingale such that {% raw %}<span class="math inline">\(M_0 = 0\)</span>{% endraw %}. Then, {% raw %}<span class="math inline">\(\langle M, M \rangle = 0\)</span>{% endraw %} if and only if {% raw %}<span class="math inline">\(M \equiv 0\)</span>{% endraw %}.</p>

</div>
<div class="proof">
<p><em>Proof.</em> If {% raw %}<span class="math inline">\(\langle M\rangle=0\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(M^2\)</span>{% endraw %} is a nonnegative continuous local martingale, hence a supermartingale. Thus {% raw %}<span class="math inline">\(\mathbb E M_t^2\leq\mathbb E M_0^2=0\)</span>{% endraw %} for each {% raw %}<span class="math inline">\(t\)</span>{% endraw %}. Intersect the probability-one events {% raw %}<span class="math inline">\(M_t=0\)</span>{% endraw %} over rational {% raw %}<span class="math inline">\(t\)</span>{% endraw %}, and use continuity to obtain {% raw %}<span class="math inline">\(M\equiv0\)</span>{% endraw %}. Conversely, the zero process has zero bracket by Theorem 2. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>


</div>
<p>Two continuous local martingales {% raw %}<span class="math inline">\(M\)</span>{% endraw %} and {% raw %}<span class="math inline">\(N\)</span>{% endraw %} are said to be <em>orthogonal</em> if {% raw %}<span class="math inline">\(\langle M,N\rangle=0\)</span>{% endraw %}. By polarization of the centered-square characterization, this is equivalent to {% raw %}<span class="math inline">\((M-M_0)(N-N_0)\)</span>{% endraw %} being a continuous local martingale: the difference between this product and its covariation is a local martingale, and a continuous local martingale of finite variation starting at zero vanishes. If {% raw %}<span class="math inline">\(M_0N_0\in L^1\)</span>{% endraw %}, the equivalent condition can also be written with the uncentered product {% raw %}<span class="math inline">\(MN\)</span>{% endraw %}, because the two cross terms {% raw %}<span class="math inline">\(M_0(N-N_0)\)</span>{% endraw %} and {% raw %}<span class="math inline">\(N_0(M-M_0)\)</span>{% endraw %} are local martingales by Example 7. The initial-product condition is necessary for that formulation. In particular, two independent Brownian motions starting at zero are orthogonal. The Kunita–Watanabe inequality is the corresponding Cauchy–Schwarz bound for integrals against covariation.</p>

<div id="result-6" class="theorem" data-note-number="6" data-note-kind="Theorem">
<p><strong>Theorem 6</strong> (Kunita-Watanabe; <span><span class="citation" data-cites="le_gall_brownian_2016">Le Gall (<a href="#ref-le_gall_brownian_2016" role="doc-biblioref">2016</a>, Proposition 4.18)</span></span>).  Let {% raw %}<span class="math inline">\(M\)</span>{% endraw %} and {% raw %}<span class="math inline">\(N\)</span>{% endraw %} be two continuous local martingales, and {% raw %}<span class="math inline">\(H\)</span>{% endraw %} and {% raw %}<span class="math inline">\(K\)</span>{% endraw %} be two measurable processes. Then, </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \int_0^\infty |H_s| |K_s| \,|\dif\langle M,N\rangle_s| \leq \left( \int_0^\infty H_s^2 \dif \, \langle M, M \rangle_s \right)^{\frac12} \left( \int_0^\infty K_s^2 \dif \, \langle N, N \rangle_s \right)^{\frac12} 
    
\end{aligned}\]</div>{% endraw %}
<p> almost surely.</p>

</div>
<p><em>Proof.</em> Put {% raw %}<span class="math inline">\(C=\langle M,N\rangle=(\langle M+N\rangle-\langle M-N\rangle)/4\)</span>{% endraw %}. The increment-square limits imply that</p>

{% raw %}<div class="math display">\[d\langle aM+bN\rangle=a^2d\langle M\rangle+2ab\,dC+b^2d\langle N\rangle\]</div>{% endraw %}

<p>is a positive measure for every rational {% raw %}<span class="math inline">\(a,b\)</span>{% endraw %}, outside one null set. Fix a path outside that set and work on a finite interval. Set {% raw %}<span class="math inline">\(\mu=d\langle M\rangle+d\langle N\rangle\)</span>{% endraw %}. If {% raw %}<span class="math inline">\(\mu(E)=0\)</span>{% endraw %}, positivity for {% raw %}<span class="math inline">\((a,b)=(1,1)\)</span>{% endraw %} and {% raw %}<span class="math inline">\((1,-1)\)</span>{% endraw %} gives both {% raw %}<span class="math inline">\(2C(E)\geq0\)</span>{% endraw %} and {% raw %}<span class="math inline">\(-2C(E)\geq0\)</span>{% endraw %}; hence {% raw %}<span class="math inline">\(C(E)=0\)</span>{% endraw %}. Thus {% raw %}<span class="math inline">\(dC\ll\mu\)</span>{% endraw %}, and all three Radon–Nikodym densities exist. Write them as {% raw %}<span class="math inline">\(m,c,n\)</span>{% endraw %}. Positivity gives {% raw %}<span class="math inline">\(a^2m+2abc+b^2n\geq0\)</span>{% endraw %} almost everywhere simultaneously for rational {% raw %}<span class="math inline">\(a,b\)</span>{% endraw %}, and then for real {% raw %}<span class="math inline">\(a,b\)</span>{% endraw %} by continuity. The density matrix is positive semidefinite, so {% raw %}<span class="math inline">\(|c|\leq\sqrt{mn}\)</span>{% endraw %}. Therefore</p>

{% raw %}<div class="math display">\[\int|H||K|\,d|C|\leq\int |H|\sqrt m\,|K|\sqrt n\,d\mu
\leq\left(\int H^2\,d\langle M\rangle\right)^{1/2}
\left(\int K^2\,d\langle N\rangle\right)^{1/2}.\]</div>{% endraw %}

<p>Truncation proves the inequality for arbitrary measurable integrands; monotone convergence extends it to the half-line. If one squared integral is zero, the left side is zero, irrespective of whether the other is finite. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>


<div id="result-7" class="example" data-note-number="7" data-note-kind="Example">
<p><strong>Example 7.</strong> If {% raw %}<span class="math inline">\(Z\)</span>{% endraw %} is a finite {% raw %}<span class="math inline">\(\mathcal F_0\)</span>{% endraw %}-measurable random variable and {% raw %}<span class="math inline">\(M\)</span>{% endraw %} is a continuous local martingale with {% raw %}<span class="math inline">\(M_0=0\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(ZM\)</span>{% endraw %} is a continuous local martingale. Choose an increasing sequence of stopping times, with deterministic cutoffs, making the stopped martingales bounded; denote it by {% raw %}<span class="math inline">\(\sigma_n\)</span>{% endraw %} for {% raw %}<span class="math inline">\(M\)</span>{% endraw %}. Set {% raw %}<span class="math inline">\(\tau_n=\sigma_n\)</span>{% endraw %} on {% raw %}<span class="math inline">\(\{|Z|\leq n\}\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\tau_n=0\)</span>{% endraw %} otherwise. These are increasing stopping times tending to infinity. The process</p>

{% raw %}<div class="math display">\[(ZM)_{t\wedge\tau_n}=Z\mathbb1_{\{|Z|\leq n\}}M_{t\wedge\sigma_n}\]</div>{% endraw %}

<p>is a uniformly integrable martingale, since the multiplier is bounded and {% raw %}<span class="math inline">\(\mathcal F_0\)</span>{% endraw %}-measurable. If {% raw %}<span class="math inline">\(M_0\ne0\)</span>{% endraw %}, apply this argument to {% raw %}<span class="math inline">\(M-M_0\)</span>{% endraw %}. To include the constant initial process, one also needs {% raw %}<span class="math inline">\(ZM_0\in L^1\)</span>{% endraw %}.</p>


</div>
<div id="result-8" class="example" data-note-number="8" data-note-kind="Example">
<p><strong>Example 8 (Moments of an increasing process).</strong> Let {% raw %}<span class="math inline">\(A\)</span>{% endraw %} be continuous, adapted, and increasing, with {% raw %}<span class="math inline">\(A_0=0\)</span>{% endraw %} and {% raw %}<span class="math inline">\(A_\infty&lt;\infty\)</span>{% endraw %} almost surely. Suppose {% raw %}<span class="math inline">\(Z\geq0\)</span>{% endraw %} is integrable and, for every stopping time {% raw %}<span class="math inline">\(T\)</span>{% endraw %},</p>


{% raw %}<div class="math display">\[\mathbb{E}(A_\infty-A_T)\leq\mathbb{E}[Z\mathbb1_{\{T&lt;\infty\}}],\]</div>{% endraw %}

<p>where {% raw %}<span class="math inline">\(A_T=A_\infty\)</span>{% endraw %} when {% raw %}<span class="math inline">\(T=\infty\)</span>{% endraw %}. At {% raw %}<span class="math inline">\(T_\lambda=\inf\{t:A_t&gt;\lambda\}\)</span>{% endraw %}, continuity gives {% raw %}<span class="math inline">\(A_{T_\lambda}=\lambda\)</span>{% endraw %} on {% raw %}<span class="math inline">\(\{A_\infty&gt;\lambda\}\)</span>{% endraw %}. Therefore</p>

{% raw %}<div class="math display">\[\mathbb{E}(A_\infty-\lambda)_+\leq\mathbb{E}[Z\mathbb1_{\{A_\infty&gt;\lambda\}}].\]</div>{% endraw %}

<p>For an increasing {% raw %}<span class="math inline">\(C^1\)</span>{% endraw %} function {% raw %}<span class="math inline">\(f\geq0\)</span>{% endraw %} with {% raw %}<span class="math inline">\(f(0)=0\)</span>{% endraw %}, put {% raw %}<span class="math inline">\(F(x)=\int_0^xf(y)\,dy\)</span>{% endraw %}. The nonnegative identity {% raw %}<span class="math inline">\(F(x)=\int_0^\infty(x-\lambda)_+f'(\lambda)\,d\lambda\)</span>{% endraw %} and Tonelli’s theorem yield</p>

{% raw %}<div class="math display">\[\mathbb{E}F(A_\infty)\leq\mathbb{E}[Zf(A_\infty)].\]</div>{% endraw %}

<p>This calculation remains valid with infinite values and avoids subtracting two infinite expectations. In particular, for {% raw %}<span class="math inline">\(p\geq2\)</span>{% endraw %}, it gives {% raw %}<span class="math inline">\(\mathbb{E}A_\infty^p\leq p\mathbb{E}[ZA_\infty^{p-1}]\)</span>{% endraw %}.</p>

<p>If {% raw %}<span class="math inline">\(M\)</span>{% endraw %} is a continuous {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %}-bounded martingale with {% raw %}<span class="math inline">\(M_0=0\)</span>{% endraw %}, take {% raw %}<span class="math inline">\(A=\langle M\rangle\)</span>{% endraw %}, {% raw %}<span class="math inline">\(Z=M_\infty^2\)</span>{% endraw %}. The stopped square martingale is uniformly integrable: {% raw %}<span class="math inline">\(M_T^2\leq\mathbb{E}[M_\infty^2\mid\mathcal F_T]\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(A_T\leq A_\infty\in L^1\)</span>{% endraw %}. Optional sampling then gives</p>

{% raw %}<div class="math display">\[\mathbb{E}(A_\infty-A_T)=\mathbb{E}(M_\infty^2-M_T^2)
\leq\mathbb{E}[M_\infty^2\mathbb1_{\{T&lt;\infty\}}].\]</div>{% endraw %}

<p>If {% raw %}<span class="math inline">\(\mathbb{E}|M_\infty|^{2p}&lt;\infty\)</span>{% endraw %}, stop first at {% raw %}<span class="math inline">\(\rho_n=\inf\{t:A_t\geq n\}\)</span>{% endraw %}. The stopped bracket has finite {% raw %}<span class="math inline">\(p\)</span>{% endraw %}-th moment, so Hölder’s inequality can be divided through without an infinity assumption:</p>

{% raw %}<div class="math display">\[\mathbb{E}A_{\rho_n}^p\leq p\mathbb{E}[A_{\rho_n}^{p-1}M_{\rho_n}^2]
\leq p(\mathbb{E}A_{\rho_n}^p)^{(p-1)/p}(\mathbb{E}|M_\infty|^{2p})^{1/p}.\]</div>{% endraw %}

<p>Conditional Jensen was used in the last step, since {% raw %}<span class="math inline">\(M_{\rho_n}=\mathbb{E}[M_\infty\mid\mathcal F_{\rho_n}]\)</span>{% endraw %}. Monotone convergence gives {% raw %}<span class="math inline">\(\mathbb{E}\langle M\rangle_\infty^p\leq p^p\mathbb{E}|M_\infty|^{2p}\)</span>{% endraw %}. Thus, for a continuous local martingale {% raw %}<span class="math inline">\(N_0=0\)</span>{% endraw %} and a stopping time {% raw %}<span class="math inline">\(T\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(N^T\)</span>{% endraw %} is uniformly integrable,</p>

{% raw %}<div class="math display">\[\mathbb{E}\langle N\rangle_T^p\leq p^p\mathbb{E}|N_T|^{2p},\qquad p\geq2.\]</div>{% endraw %}

<p>If the right side is finite, {% raw %}<span class="math inline">\(N^T_t=\mathbb{E}[N_T\mid\mathcal F_t]\)</span>{% endraw %} is {% raw %}<span class="math inline">\(L^{2p}\)</span>{% endraw %}-bounded and the preceding proof applies; otherwise the bound is automatic. For {% raw %}<span class="math inline">\(T=\infty\)</span>{% endraw %}, {% raw %}<span class="math inline">\(N_T\)</span>{% endraw %} denotes the terminal limit of the uniformly integrable stopped martingale.</p>

<p>Uniform integrability is essential. For Brownian motion and {% raw %}<span class="math inline">\(a\ne0\)</span>{% endraw %}, {% raw %}<span class="math inline">\(T_a=\inf\{t:B_t=a\}&lt;\infty\)</span>{% endraw %} almost surely, but {% raw %}<span class="math inline">\(\mathbb{E}T_a=\infty\)</span>{% endraw %}. Indeed, the reflection principle gives {% raw %}<span class="math inline">\(\mathbb P(T_a&gt;t)=2\Phi(|a|/\sqrt t)-1\sim\sqrt{2/\pi}|a|/\sqrt t\)</span>{% endraw %}, whose integral diverges. Hence {% raw %}<span class="math inline">\(\mathbb{E}\langle B\rangle_{T_a}^p=\infty\)</span>{% endraw %} for {% raw %}<span class="math inline">\(p\geq1\)</span>{% endraw %}, while {% raw %}<span class="math inline">\(|B_{T_a}|^{2p}=|a|^{2p}\)</span>{% endraw %}. The stopped process is not uniformly integrable, since that would imply {% raw %}<span class="math inline">\(0=\mathbb{E}B_0=\mathbb{E}B_{T_a}=a\)</span>{% endraw %}.</p>

</div>
<h4 data-note-section="1.1" id="further-developments-on-stochastic-integration">1.1. Further Developments on Stochastic Integration</h4>
<p>Following <span class="citation" data-cites="le_gall_brownian_2016">(<a href="#ref-le_gall_brownian_2016" role="doc-biblioref">Le Gall 2016</a>)</span>, for {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %}-bounded martingales {% raw %}<span class="math inline">\(M\)</span>{% endraw %}, define the Hilbert space </p>

{% raw %}<div class="math display">\[\begin{aligned}
    \mathcal H^2 = \{L^2 \text{-bounded continuous martingales } M \text{ such that } M_0 = 0 \} ~.
\end{aligned}\]</div>{% endraw %}
<p>For a zero-start continuous local martingale {% raw %}<span class="math inline">\(M\)</span>{% endraw %}, membership in {% raw %}<span class="math inline">\(\mathcal H^2\)</span>{% endraw %} is equivalent to {% raw %}<span class="math inline">\(\mathbb E\langle M\rangle_\infty&lt;\infty\)</span>{% endraw %}, as proved below. In that case {% raw %}<span class="math inline">\(M_t=\mathbb E[M_\infty\mid\mathcal F_t]\)</span>{% endraw %}, where {% raw %}<span class="math inline">\(M_\infty\)</span>{% endraw %} is the almost-sure and {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %} limit. The inner product is</p>


{% raw %}<div class="math display">\[\begin{aligned}
    (M,N)_{\mathcal H^2} = \mathbb{E}\langle M, N \rangle_\infty = \mathbb{E}[M_\infty N_\infty] 
\end{aligned}\]</div>{% endraw %}
<p>This is a symmetric bilinear form. Lemma 5 gives positive definiteness. To prove completeness, it suffices to control the terminal values and then recover a continuous version of their conditional-expectation limit.</p>


<p>The completeness assertion can be checked at terminal values. If {% raw %}<span class="math inline">\((M^n)\)</span>{% endraw %} is Cauchy in {% raw %}<span class="math inline">\(\mathcal H^2\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(M_\infty^n\)</span>{% endraw %} is Cauchy in {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %}; write its limit as {% raw %}<span class="math inline">\(Z\)</span>{% endraw %}. Set {% raw %}<span class="math inline">\(M_t=\mathbb E[Z\mid\mathcal F_t]\)</span>{% endraw %}. Conditional expectation is a contraction, and Doob’s inequality gives</p>
{% raw %}<div class="math display">\[\mathbb E\sup_{t\geq0}|M_t^n-M_t^m|^2\leq4\mathbb E|M_\infty^n-M_\infty^m|^2.\]</div>{% endraw %}

<p>Choose a subsequence with summable expected uniform differences. It converges uniformly almost surely to a continuous adapted process. At each fixed time this agrees with the conditional-expectation limit, so it supplies a continuous version of {% raw %}<span class="math inline">\(M\)</span>{% endraw %}. Also {% raw %}<span class="math inline">\(\mathbb E[Z\mid\mathcal F_0]=0\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(\|M^n-M\|_{\mathcal H^2}=\|M_\infty^n-Z\|_2\to0\)</span>{% endraw %}. Thus {% raw %}<span class="math inline">\(\mathcal H^2\)</span>{% endraw %} is complete.</p>
<h2 id="h2-martingales">The bracket criterion for {% raw %}<span class="math inline">\(\mathcal H^2\)</span>{% endraw %}</h2>

<p>For the bracket criterion used here, let {% raw %}<span class="math inline">\(M\)</span>{% endraw %} be a zero-start continuous local martingale with {% raw %}<span class="math inline">\(\mathbb E\langle M\rangle_\infty&lt;\infty\)</span>{% endraw %}. Choose increasing stops {% raw %}<span class="math inline">\(\sigma_n\)</span>{% endraw %} making {% raw %}<span class="math inline">\(M^{\sigma_n}\)</span>{% endraw %} bounded, with deterministic cutoffs. The bounded-martingale square identity and optional sampling give, for {% raw %}<span class="math inline">\(m\geq n\)</span>{% endraw %},</p>
{% raw %}<div class="math display">\[\mathbb E|M_{\sigma_m}-M_{\sigma_n}|^2
=\mathbb E[\langle M\rangle_{\sigma_m}-\langle M\rangle_{\sigma_n}]\longrightarrow0.\]</div>{% endraw %}

<p>The integrable bracket dominates the differences. The terminal values therefore have an {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %} limit, and their closed martingales converge as in the preceding paragraph to {% raw %}<span class="math inline">\(M\)</span>{% endraw %}. Conversely, if {% raw %}<span class="math inline">\(M\in\mathcal H^2\)</span>{% endraw %}, stopping first and using {% raw %}<span class="math inline">\(\sup_t|M_t|^2\in L^1\)</span>{% endraw %} gives {% raw %}<span class="math inline">\(\mathbb E\langle M\rangle_\infty=\mathbb E M_\infty^2\)</span>{% endraw %}. Polarization yields the stated scalar-product identity.</p>

<p>The <a href="{% post_url 2023-11-02-construction-of-the-stochastic-integral %}#construction-of-the-stochastic-integral">construction of the stochastic integral</a> uses the predictable {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %} space</p>


{% raw %}<div class="math display">\[\begin{aligned}
    L^2 (M) = L^2 (\Omega \times \mathbb R_+, \mathcal P, \dif P \dif \, \langle M, M \rangle_s) ~,
\end{aligned}\]</div>{% endraw %}
<p>Here {% raw %}<span class="math inline">\(\mathcal P\)</span>{% endraw %} is the predictable {% raw %}<span class="math inline">\(\sigma\)</span>{% endraw %}-field, and the measure assigns mass {% raw %}<span class="math inline">\(\mathbb E\int_0^\infty\mathbf1_E(s,\omega)\,d\langle M\rangle_s\)</span>{% endraw %} to {% raw %}<span class="math inline">\(E\in\mathcal P\)</span>{% endraw %}. The global construction gives the following properties.</p>


<ul>
<li><p>The set of all elementary processes (defined based on predictable processes {% raw %}<span class="math inline">\(H\)</span>{% endraw %}) defines a linear subspace of {% raw %}<span class="math inline">\(L^2 (M)\)</span>{% endraw %}, denoted {% raw %}<span class="math inline">\(\mathcal E\)</span>{% endraw %}, is dense in {% raw %}<span class="math inline">\(L^2 (M)\)</span>{% endraw %}.</p></li>
<li><p>For a stopped process of {% raw %}<span class="math inline">\(M \in \mathcal H^2\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\langle M^T, M^T \rangle_\infty = \langle M, M \rangle_T\)</span>{% endraw %}. Also, for {% raw %}<span class="math inline">\(H \in L^2 (M)\)</span>{% endraw %}, {% raw %}<span class="math inline">\((\mathbb 1_{[0,T]} H)_s (\omega) = \mathbb 1_{\{0 \leq s \leq T(\omega)\}} H_s (\omega)\)</span>{% endraw %} also belongs to {% raw %}<span class="math inline">\(L^2 (M)\)</span>{% endraw %}, because {% raw %}<span class="math inline">\(\mathbb 1_{[0,T]}\)</span>{% endraw %} is a predictable process: it is adapted to {% raw %}<span class="math inline">\(\mathcal F_t\)</span>{% endraw %} and has left-continuous sample paths.</p></li>
<li><p>For every {% raw %}<span class="math inline">\(M \in \mathcal H^2\)</span>{% endraw %} and {% raw %}<span class="math inline">\(H \in \mathcal E\)</span>{% endraw %}, the formula </p>

{% raw %}<div class="math display">\[\begin{aligned}
        (H \cdot M)_t = \sum_{0 \leq i \leq n-1} H_{(i)} (M_{t_{i+1} \wedge t} - M_{t_i \wedge t})
    
\end{aligned}\]</div>{% endraw %}
<p> defines a process {% raw %}<span class="math inline">\(H \cdot M \in \mathcal H^2\)</span>{% endraw %}. One can also show that the map {% raw %}<span class="math inline">\(H \mapsto H \cdot M\)</span>{% endraw %} is an isometry from {% raw %}<span class="math inline">\(L^2 (M) \to \mathcal H^2\)</span>{% endraw %}, and that {% raw %}<span class="math inline">\(H \cdot M\)</span>{% endraw %} is the unique martingale of {% raw %}<span class="math inline">\(\mathcal H^2\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(\langle H \cdot M, N \rangle = H \cdot \langle M, N \rangle\)</span>{% endraw %} for all {% raw %}<span class="math inline">\(N \in \mathcal H^2\)</span>{% endraw %}. The following stopping time property also holds: {% raw %}<span class="math inline">\((\mathbb 1_{[0,T]} H) \cdot M = (H \cdot M)^T = H \cdot M^T\)</span>{% endraw %}. Here, {% raw %}<span class="math inline">\((H \cdot M)_t = \int_0^t H_s \dif M_s\)</span>{% endraw %} is the stochastic integral of {% raw %}<span class="math inline">\(H\)</span>{% endraw %} with respect to {% raw %}<span class="math inline">\(M\)</span>{% endraw %}.</p></li>
</ul>
<p>The Hilbert-space construction gives the integral under a global second-moment bound. Stopping extends it to a continuous local martingale {% raw %}<span class="math inline">\(M\)</span>{% endraw %}. To that end, define </p>

{% raw %}<div class="math display">\[\begin{aligned}
    L^2_{\rm loc} (M) &amp;= \left\{ \text{predictable process } H : \int_0^t H_s^2 \dif \, \langle M, M \rangle_s &lt; \infty ~,~ \forall t \geq 0 ~,~ \rm a.s. \right\} ~, \\
    L^2 (M) &amp;= \left\{ \text{predictable process } H : \mathbb{E}\int_0^\infty H_s^2 \dif \, \langle M, M \rangle_s &lt; \infty \right\} ~.
\end{aligned}\]</div>{% endraw %}
<p>The following proposition extends the integral to {% raw %}<span class="math inline">\(H\in L^2_{\mathrm{loc}}(M)\)</span>{% endraw %}.</p>


<div id="result-9" class="proposition" data-note-number="9" data-note-kind="Proposition">
<p><strong>Proposition 9</strong> (<span><span class="citation" data-cites="le_gall_brownian_2016">Le Gall (<a href="#ref-le_gall_brownian_2016" role="doc-biblioref">2016</a>, Theorem 5.6)</span></span>).  Let {% raw %}<span class="math inline">\(M\)</span>{% endraw %} be a continuous local martingale. For all {% raw %}<span class="math inline">\(H \in L^2_{\rm loc} (M)\)</span>{% endraw %}, there exists a unique continuous local martingale starting at zero, denoted {% raw %}<span class="math inline">\(H \cdot M\)</span>{% endraw %}, such that, for all continuous local martingale {% raw %}<span class="math inline">\(N\)</span>{% endraw %}, </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \langle H \cdot M, N \rangle = H \cdot \langle M, N \rangle ~.
    
\end{aligned}\]</div>{% endraw %}
<p> The following stopping time property also holds: {% raw %}<span class="math inline">\((\mathbb 1_{[0,T]} H) \cdot M = (H \cdot M)^T = H \cdot M^T\)</span>{% endraw %}. Also, if {% raw %}<span class="math inline">\(H \in L^2_{\rm loc} (M)\)</span>{% endraw %} and {% raw %}<span class="math inline">\(K\)</span>{% endraw %} is a predictable process, then {% raw %}<span class="math inline">\(K \in L^2_{\rm loc} (H \cdot M)\)</span>{% endraw %} if and only if {% raw %}<span class="math inline">\(HK \in L^2_{\rm loc} (M)\)</span>{% endraw %}. Then, the following associativity property holds: {% raw %}<span class="math inline">\(K \cdot (H \cdot M) = (HK) \cdot M\)</span>{% endraw %}. The stochastic integral defined here agrees with that defined for elementary processes if {% raw %}<span class="math inline">\(M \in \mathcal H^2\)</span>{% endraw %} and {% raw %}<span class="math inline">\(H \in L^2 (M)\)</span>{% endraw %}.</p>

</div>
<h4 id="21-144-proof-of-the-local-integral-extension">
Proof of the local integral extension
</h4>
<p>First let {% raw %}<span class="math inline">\(M,N\in\mathcal H^2\)</span>{% endraw %} and {% raw %}<span class="math inline">\(H\in L^2(M)\)</span>{% endraw %}. For a bounded elementary {% raw %}<span class="math inline">\(H\)</span>{% endraw %}, the increment-product characterization of covariation gives</p>
{% raw %}<div class="math display">\[\langle H\cdot M,N\rangle_t=\int_0^tH_s\,d\langle M,N\rangle_s.\]</div>{% endraw %}

<p>For one elementary interval, include its endpoints in the approximating partitions. On that interval the increments of the integral are the increments of {% raw %}<span class="math inline">\(M\)</span>{% endraw %} multiplied by its fixed left-endpoint coefficient. The covariation sums therefore give the identity directly, and finite sums give it for every elementary {% raw %}<span class="math inline">\(H\)</span>{% endraw %}.</p>
<p>For general {% raw %}<span class="math inline">\(H\)</span>{% endraw %}, choose elementary {% raw %}<span class="math inline">\(H^n\to H\)</span>{% endraw %} in {% raw %}<span class="math inline">\(L^2(M)\)</span>{% endraw %}. The isometry gives {% raw %}<span class="math inline">\(H^n\cdot M\to H\cdot M\)</span>{% endraw %} in {% raw %}<span class="math inline">\(\mathcal H^2\)</span>{% endraw %}. The Kunita–Watanabe inequality bounds the expected total variations of the two errors by</p>
{% raw %}<div class="math display">\[\begin{aligned}
\mathbb E\int_0^\infty|H_s^n-H_s|\,|d\langle M,N\rangle_s|
&amp;\leq\|H^n-H\|_{L^2(M)}\|N\|_{\mathcal H^2},\\
\mathbb E\operatorname{Var}\bigl(\langle (H^n-H)\cdot M,N\rangle\bigr)_\infty
&amp;\leq\|(H^n-H)\cdot M\|_{\mathcal H^2}\|N\|_{\mathcal H^2}.
\end{aligned}\]</div>{% endraw %}

<p>Both tend to zero, proving the identity. If {% raw %}<span class="math inline">\(I,J\in\mathcal H^2\)</span>{% endraw %} both have the asserted covariations, take {% raw %}<span class="math inline">\(N=I-J\)</span>{% endraw %}. Their difference has zero bracket and is zero by Lemma 5. This proves uniqueness.</p>
<p>The stopping identity does not require a stopping time to have deterministic values. For a bounded grid-valued stopping time {% raw %}<span class="math inline">\(T\)</span>{% endraw %}, the process {% raw %}<span class="math inline">\(\mathbb1_{[0,T]}\)</span>{% endraw %} is elementary on that grid: its coefficient on {% raw %}<span class="math inline">\((t_{j-1},t_j]\)</span>{% endraw %} is {% raw %}<span class="math inline">\(\mathbb1_{\{T\geq t_j\}}\in\mathcal F_{t_{j-1}}\)</span>{% endraw %}. Refining with the elementary intervals of {% raw %}<span class="math inline">\(H\)</span>{% endraw %} proves the identity by finite sums. Round a bounded general {% raw %}<span class="math inline">\(T\)</span>{% endraw %} upwards to successively finer grids. The indicators converge pointwise to {% raw %}<span class="math inline">\(\mathbb1_{[0,T]}\)</span>{% endraw %}, while path continuity gives convergence of the stopped integrals. The isometry and dominated convergence in {% raw %}<span class="math inline">\(\mathbb E\,d\langle M\rangle\)</span>{% endraw %} identify the two limits. Approximate a general {% raw %}<span class="math inline">\(H\)</span>{% endraw %} in {% raw %}<span class="math inline">\(L^2(M)\)</span>{% endraw %}, and then let bounded time cutoffs increase. This proves</p>
{% raw %}<div class="math display">\[(\mathbb1_{[0,T]}H)\cdot M=(H\cdot M)^T=H\cdot M^T.\]</div>{% endraw %}

<p>Now center a general local martingale {% raw %}<span class="math inline">\(M\)</span>{% endraw %} by subtracting {% raw %}<span class="math inline">\(M_0\)</span>{% endraw %}, which does not affect its increments or bracket. Write {% raw %}<span class="math inline">\(A=\langle M\rangle\)</span>{% endraw %} and {% raw %}<span class="math inline">\(C_t=\int_0^tH_s^2\,dA_s\)</span>{% endraw %}. The assumed local integrability makes {% raw %}<span class="math inline">\(C\)</span>{% endraw %} finite and continuous on every bounded interval. The stopping times</p>
{% raw %}<div class="math display">\[\tau_n=\inf\{t\geq0:A_t+C_t\geq n\}\wedge n\]</div>{% endraw %}

<p>increase to infinity. The stopped integrator is in {% raw %}<span class="math inline">\(\mathcal H^2\)</span>{% endraw %} by the bracket criterion, and {% raw %}<span class="math inline">\(H\)</span>{% endraw %} has squared integral norm at most {% raw %}<span class="math inline">\(n\)</span>{% endraw %} with respect to it. Construct {% raw %}<span class="math inline">\(I^n=H\cdot M^{\tau_n}\)</span>{% endraw %} using the global theory. The stopping identity gives {% raw %}<span class="math inline">\((I^{n+1})^{\tau_n}=I^n\)</span>{% endraw %}, so these continuous martingales agree on overlaps and define a continuous local martingale {% raw %}<span class="math inline">\(I\)</span>{% endraw %} with {% raw %}<span class="math inline">\(I^{\tau_n}=I^n\)</span>{% endraw %}. This construction is independent of the chosen stops, by comparison on common stopped intervals.</p>
<p>For any continuous local martingale {% raw %}<span class="math inline">\(N\)</span>{% endraw %}, stop further so that its centered bracket has bounded expectation. The global covariation identity applies to these common stops, and removing them gives {% raw %}<span class="math inline">\(\langle I,N\rangle=H\cdot\langle M,N\rangle\)</span>{% endraw %}. Taking {% raw %}<span class="math inline">\(N\)</span>{% endraw %} equal to a difference of two candidates again proves uniqueness. Taking first {% raw %}<span class="math inline">\(N=M\)</span>{% endraw %} and then {% raw %}<span class="math inline">\(N=I\)</span>{% endraw %} gives {% raw %}<span class="math inline">\(\langle I\rangle=H^2\cdot\langle M\rangle\)</span>{% endraw %}. Therefore</p>
{% raw %}<div class="math display">\[\int_0^tK_s^2\,d\langle I\rangle_s
=\int_0^t(K_sH_s)^2\,d\langle M\rangle_s.\]</div>{% endraw %}

<p>The displayed identity proves the equivalence of the integrability conditions. For each continuous local martingale {% raw %}<span class="math inline">\(N\)</span>{% endraw %}, the covariation identities give {% raw %}<span class="math inline">\(\langle K\cdot I,N\rangle=KH\cdot\langle M,N\rangle\)</span>{% endraw %}. Uniqueness therefore yields {% raw %}<span class="math inline">\(K\cdot(H\cdot M)=(KH)\cdot M\)</span>{% endraw %}. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>


<p>A continuous semimartingale has a decomposition {% raw %}<span class="math inline">\(X=X_0+M+V\)</span>{% endraw %}, where {% raw %}<span class="math inline">\(M\)</span>{% endraw %} is a continuous local martingale, {% raw %}<span class="math inline">\(V\)</span>{% endraw %} is a continuous adapted process of finite variation on compact intervals, and {% raw %}<span class="math inline">\(M_0=V_0=0\)</span>{% endraw %}. The decomposition is unique because the difference of two candidates is a zero-start continuous local martingale of finite variation. For locally bounded predictable {% raw %}<span class="math inline">\(H\)</span>{% endraw %}, define {% raw %}<span class="math inline">\(H\cdot X=H\cdot M+H\cdot V\)</span>{% endraw %}, using the stochastic integral for {% raw %}<span class="math inline">\(M\)</span>{% endraw %} and the pathwise Stieltjes integral for {% raw %}<span class="math inline">\(V\)</span>{% endraw %}. We write</p>


{% raw %}<div class="math display">\[\begin{aligned}
    (H \cdot X)_t = \int_0^t H_s \dif X_s ~.
\end{aligned}\]</div>{% endraw %}
<p>The two parts of the integral satisfy the following identities.</p>


<div id="result-10" class="lemma" data-note-number="10" data-note-kind="Lemma">
<p><strong>Lemma 10</strong>.  Let {% raw %}<span class="math inline">\(X\)</span>{% endraw %} be a continuous semimartingale, and {% raw %}<span class="math inline">\(H\)</span>{% endraw %} be a locally bounded predictable process. The stochastic integral of {% raw %}<span class="math inline">\(H\)</span>{% endraw %} with respect to {% raw %}<span class="math inline">\(X\)</span>{% endraw %}, as defined, satisfies</p>

<ol>
<li><p>{% raw %}<span class="math inline">\((H,X) \mapsto H \cdot X\)</span>{% endraw %} is bilinear.</p></li>
<li><p>{% raw %}<span class="math inline">\(H \cdot (K \cdot X) = (HK) \cdot X\)</span>{% endraw %} if {% raw %}<span class="math inline">\(H\)</span>{% endraw %} and {% raw %}<span class="math inline">\(K\)</span>{% endraw %} are locally bounded and predictable processes.</p></li>
<li><p>The stopping time property holds: for every stopping time {% raw %}<span class="math inline">\(T\)</span>{% endraw %}, {% raw %}<span class="math inline">\((H \cdot X)^T = H \mathbb 1_{[0,T]} \cdot X = H \cdot X^T\)</span>{% endraw %}.</p></li>
<li><p>If {% raw %}<span class="math inline">\(X\)</span>{% endraw %} is a continuous local martingale, then so is {% raw %}<span class="math inline">\(H\cdot X\)</span>{% endraw %}. If {% raw %}<span class="math inline">\(X\)</span>{% endraw %} has finite variation, then {% raw %}<span class="math inline">\(H\cdot X\)</span>{% endraw %} has finite variation: on each bounded interval its total variation is at most {% raw %}<span class="math inline">\(\int |H_s|\,|dX_s|\)</span>{% endraw %}, which is finite because {% raw %}<span class="math inline">\(H\)</span>{% endraw %} is locally bounded. This second assertion is a pathwise integration fact.</p></li>
<li><p>Let {% raw %}<span class="math inline">\(0 = t_0 &lt; t_1 &lt; \dots &lt; t_n\)</span>{% endraw %}, and define the elementary process {% raw %}<span class="math inline">\(H\)</span>{% endraw %} via </p>

{% raw %}<div class="math display">\[\begin{aligned}
            H_s (\omega) = \sum_{0 \leq i \leq n-1} H_{(i)} (\omega) \mathbb 1_{(t_i,t_{i+1}]} (s) ~.
        
\end{aligned}\]</div>{% endraw %}
<p> Suppose {% raw %}<span class="math inline">\(H_{(i)}\)</span>{% endraw %} is {% raw %}<span class="math inline">\(\mathcal F_{t_i}\)</span>{% endraw %}-measurable for all {% raw %}<span class="math inline">\(0 \leq i \leq n-1\)</span>{% endraw %}. Then, </p>

{% raw %}<div class="math display">\[\begin{aligned}
            (H \cdot X)_t = \sum_{0 \leq i \leq n-1} H_{(i)} (X_{t_{i+1} \wedge t} - X_{t_i \wedge t}) ~.
        
\end{aligned}\]</div>{% endraw %}</li>
</ol>
</div>
<div class="proof">
<p><em>Proof.</em> For elementary bounded integrands, bilinearity and the stopping property follow directly from finite sums. Extension by the isometry proves them for square-integrable integrands, and stopping proves the local versions. The finite-variation parts follow from ordinary Stieltjes integration. Associativity can also be checked through covariation: {% raw %}<span class="math inline">\(\langle K\cdot(H\cdot M),N\rangle=KH\cdot\langle M,N\rangle\)</span>{% endraw %}, and uniqueness identifies the integral. Its integrability condition is exactly {% raw %}<span class="math inline">\(\int K^2\,d\langle H\cdot M\rangle=\int(KH)^2\,d\langle M\rangle\)</span>{% endraw %}.</p>

<p>For (5), let there be {% raw %}<span class="math inline">\(m\)</span>{% endraw %} elementary intervals, and assume each finite coefficient {% raw %}<span class="math inline">\(H_{(i)}\)</span>{% endraw %} is {% raw %}<span class="math inline">\(\mathcal F_{t_i}\)</span>{% endraw %}-measurable. Define {% raw %}<span class="math inline">\(\tau_n=\min\{t_i:|H_{(i)}|&gt;n\}\)</span>{% endraw %}, with minimum of the empty set equal to infinity. This is a stopping time because {% raw %}<span class="math inline">\(\{\tau_n\leq t\}\)</span>{% endraw %} is a finite union of events in {% raw %}<span class="math inline">\(\mathcal F_t\)</span>{% endraw %}. Since there are only finitely many coefficients, {% raw %}<span class="math inline">\(\tau_n\uparrow\infty\)</span>{% endraw %} pathwise. Also,</p>

{% raw %}<div class="math display">\[H_s\mathbb1_{\{s\leq\tau_n\}}=
\sum_{i=0}^{m-1}H_{(i)}\mathbb1_{\{\tau_n&gt;t_i\}}\mathbb1_{(t_i,t_{i+1}]}(s),\]</div>{% endraw %}

<p>whose coefficients are bounded by {% raw %}<span class="math inline">\(n\)</span>{% endraw %}. The bounded elementary formula, combined with a reducing sequence for the integrator’s local-martingale part, therefore applies. Remove both stops to obtain the finite-sum formula. No continuity of the elementary process is asserted or needed. ◻</p>
