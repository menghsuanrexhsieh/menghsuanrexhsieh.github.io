<div class="note-content" markdown="0">

<p>A single finite cover approximates a process at one resolution. A fine cover reduces approximation error but increases the number of points over which we must take a maximum. Chaining avoids paying the fine-cover cost for every increment: it approximates each index successively, using small increments between neighboring resolutions. Dudley’s entropy integral records the total cost across these scales.</p>

<p>Let {% raw %}<span class="math inline">\(X_1,\ldots,X_n\)</span>{% endraw %} be i.i.d. with law {% raw %}<span class="math inline">\(P\)</span>{% endraw %}. For a function {% raw %}<span class="math inline">\(f\)</span>{% endraw %}, write {% raw %}<span class="math inline">\(Pf=\mathbb{E} f(X_1)\)</span>{% endraw %}, {% raw %}<span class="math inline">\(P_nf=n^{-1}\sum_{i=1}^n f(X_i)\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(\mathbb G_nf=\sqrt n(P_n-P)f\)</span>{% endraw %}. Rademacher variables are independent random signs, independent of the observations. See the <a href="{% post_url 2022-09-03-empirical-processes-tensorization-and-the-entropy-method %}">empirical-process setup</a> for measurability conventions.</p>

<div id="chaining" data-note-section="title">

</div>
<p>We replace the pathwise Lipschitz condition by a tail bound for each increment. Namely, we first want to relax the requirement that {% raw %}<span class="math inline">\(|X_t - X_s| \lesssim d(t,s)\)</span>{% endraw %} almost surely. Instead, we want to replace this by a condition that allows us to control these increments via “how far” {% raw %}<span class="math inline">\(s\)</span>{% endraw %} and {% raw %}<span class="math inline">\(t\)</span>{% endraw %} are in the metric space {% raw %}<span class="math inline">\(T\)</span>{% endraw %}. Before giving such a relaxation, here is a general result that applies for subgaussian random variables.</p>

<div id="prop:maximal-inequality-random-psuedo-Lipschitz" class="proposition" data-note-number="1" data-note-kind="Proposition">
<p><strong>Proposition 1</strong>.  Suppose {% raw %}<span class="math inline">\(T\)</span>{% endraw %} is a nonempty finite set, and let {% raw %}<span class="math inline">\(\{X_t\}_{t \in T}\)</span>{% endraw %} be a stochastic process. For all {% raw %}<span class="math inline">\(t \in T\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\eta \geq 0\)</span>{% endraw %}, assume the following inequality holds: </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \mathbf P\,\,\!\!(|X_t| \geq \eta) \leq 2 e^{-\frac{\eta^2}{2\sigma^2}} ~,
    
\end{aligned}\]</div>{% endraw %}
<p> where {% raw %}<span class="math inline">\(\sigma &gt; 0\)</span>{% endraw %} is fixed. Then, there exists a universal positive constant {% raw %}<span class="math inline">\(C\)</span>{% endraw %} such that </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \mathbb{E} \sup_{t \in T} \: |X_t| \leq C \sigma \sqrt{\log(2|T|)} ~.
    
\end{aligned}\]</div>{% endraw %}
</div>
<div class="proof">
<p><em>Proof.</em> Since {% raw %}<span class="math inline">\(\sup_{t \in T} \: |X_t|\)</span>{% endraw %} is positive, we have </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \mathbb{E} \sup_{t \in T} \: |X_t| = \int_0^\infty \mathbf P\,\,\!\!\left( \sup_{t \in T} \: |X_t| \geq \eta \right) \dif \eta 
    
\end{aligned}\]</div>{% endraw %}
<p> by an elementary result. Then, it remains to bound the tail probability for every {% raw %}<span class="math inline">\(\eta \geq 0\)</span>{% endraw %}. By assumption, </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \mathbf P\,\,\!\!\left( \sup_{t \in T} \: |X_t| \geq \eta \right) = \mathbf P\,\,\!\!\left( \bigcup_{t\in T} \{ |X_t| \geq \eta \} \right) \leq \sum_{t \in T} \mathbf P\,\,\!\!(|X_t| \geq \eta) \leq 2|T| e^{-\frac{\eta^2}{2\sigma^2}} ~.
    
\end{aligned}\]</div>{% endraw %}
<p> For some suitably chosen “intermediate cutoff point” {% raw %}<span class="math inline">\(\eta_0\)</span>{% endraw %}, we have </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \mathbb{E} \sup_{t \in T} \: |X_t| &amp;= \int_0^{\eta_0} \mathbf P\,\,\!\!\left( \sup_{t \in T} \: |X_t| \geq \eta \right) \dif \eta + \int_{\eta_0}^\infty \mathbf P\,\,\!\!\left( \sup_{t \in T} \: |X_t| \geq \eta \right) \dif \eta  \\
        &amp;\leq \eta_0 + \int_{\eta_0}^\infty 2|T| e^{-\frac{\eta^2}{2\sigma^2}} \dif \eta \\
        &amp;\leq \eta_0 + \int_{\eta_0}^\infty 2|T| \frac{\eta}{\eta_0} e^{-\frac{\eta^2}{2\sigma^2}} \dif \eta \\
        &amp;= \eta_0 + \frac{2|T| \sigma^2}{\eta_0} e^{-\frac{\eta_0^2}{2\sigma^2}} ~.
    
\end{aligned}\]</div>{% endraw %}
<p> Clearly, if {% raw %}<span class="math inline">\(T\)</span>{% endraw %} is large, the upper bound is crude. Therefore, pick {% raw %}<span class="math inline">\(\eta_0\)</span>{% endraw %} such that the (growing) constant {% raw %}<span class="math inline">\(2|T|\)</span>{% endraw %} vanishes, or </p>

{% raw %}<div class="math display">\[\begin{aligned}
         e^{-\frac{\eta_0^2}{2\sigma^2}} = (2|T|)^{-1} \iff \eta_0 = \sqrt{2 \sigma^2 \log(2|T|)} ~.
    
\end{aligned}\]</div>{% endraw %}
<p> Therefore, we have </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \mathbb{E} \sup_{t \in T} \: |X_t| &amp;\leq \sqrt{2 \sigma^2 \log(2|T|)} + \frac{\sigma^2}{\sqrt{2 \sigma^2 \log(2|T|)}} \lesssim C \sigma \sqrt{\log(2|T|)} ~,
    
\end{aligned}\]</div>{% endraw %}
<p> as desired. ◻</p>

</div>
<p>This motivates the following definition of a <em>subgaussian process</em>: a random process {% raw %}<span class="math inline">\(\{X_t\}_{t \in T}\)</span>{% endraw %}, where {% raw %}<span class="math inline">\((T,d)\)</span>{% endraw %} is a metric space, is <em>subgaussian</em> if {% raw %}<span class="math inline">\(\mathbb{E} X_t = 0\)</span>{% endraw %} and </p>

{% raw %}<div class="math display">\[\begin{aligned}
    \mathbb{E} e^{\lambda(X_t-X_s)} \leq e^{\frac{\lambda^2 d(s,t)^2}{2}} 
\end{aligned}\]</div>{% endraw %}
<p> for all {% raw %}<span class="math inline">\(s,t \in T\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\lambda \geq 0\)</span>{% endraw %}. Note that this immediately implies (and is equivalent to, up to constants) </p>

{% raw %}<div class="math display">\[\begin{aligned}
    \mathbf P\,\,\!\!(|X_t - X_s| \geq x) \leq C e^{-\frac{x^2}{C d(s,t)^2}} ~.
\end{aligned}\]</div>{% endraw %}
<p>For the forward implication, exponential Markov optimized at {% raw %}<span class="math inline">\(\lambda=x/d(s,t)^2\)</span>{% endraw %} gives the upper tail; interchange {% raw %}<span class="math inline">\(s,t\)</span>{% endraw %} for the lower tail. Adding gives {% raw %}<span class="math inline">\(C=2\)</span>{% endraw %}. For zero distance the increment vanishes almost surely by the moment bound.</p>
<p>For completeness, the converse also follows with a changed universal constant when the increments are centered. If {% raw %}<span class="math inline">\(Y=X_t-X_s\)</span>{% endraw %}, {% raw %}<span class="math inline">\(r=d(s,t)&gt;0\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(P(|Y|&gt;u)\leq C e^{-u^2/(Cr^2)}\)</span>{% endraw %}, enlarge {% raw %}<span class="math inline">\(C\)</span>{% endraw %} to at least one and let {% raw %}<span class="math inline">\(Y'\)</span>{% endraw %} be an independent copy. Then {% raw %}<span class="math inline">\(W=Y-Y'\)</span>{% endraw %} is symmetric, and {% raw %}<span class="math inline">\(P(|W|&gt;u)\leq2C e^{-u^2/(4Cr^2)}\)</span>{% endraw %}. Tail integration gives {% raw %}<span class="math inline">\(\mathbb EW^{2k}\leq2C(4Cr^2)^k k!\)</span>{% endraw %}. Jensen, the nonnegative series for cosh, and {% raw %}<span class="math inline">\((2k)!\geq(k!)^2\)</span>{% endraw %} imply</p>
{% raw %}<div class="math display">\[\mathbb Ee^{\lambda Y}\leq\mathbb Ee^{\lambda W}\leq1+2C\sum_{k\geq1}\frac{(4C\lambda^2r^2)^k}{k!}\leq e^{8C^2\lambda^2r^2}.\]</div>{% endraw %}
<p>The last inequality uses {% raw %}<span class="math inline">\(1+A(e^x-1)\leq e^{Ax}\)</span>{% endraw %} for {% raw %}<span class="math inline">\(A\geq1,x\geq0\)</span>{% endraw %}. Thus a tail bound and a centered moment bound describe the same increment condition up to constants. Dudley's entropy bound combines these increment estimates across successive finite nets.</p>
<div id="thm:dudley-entropy-finite-T" class="theorem" data-note-number="2" data-note-kind="Theorem">
<p><strong>Theorem 2</strong> (Dudley’s entropy bound; finite {% raw %}<span class="math inline">\(T\)</span>{% endraw %}).  Let {% raw %}<span class="math inline">\((T,d)\)</span>{% endraw %} be a finite metric space. Let {% raw %}<span class="math inline">\(\{X_t\}_{t\in T}\)</span>{% endraw %} be a subgaussian process. Then, there exists a universal positive constant {% raw %}<span class="math inline">\(C\)</span>{% endraw %} such that the following inequality holds for every {% raw %}<span class="math inline">\(t_0 \in T\)</span>{% endraw %}: </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \mathbb{E} \sup_{t \in T} \: |X_t - X_{t_0}| \leq C \int_0^\infty \sqrt{\log D(\varepsilon, T, d)} \dif \varepsilon \lesssim \int_0^\infty \sqrt{\log N(\varepsilon,T,d)} \dif \varepsilon ~.
    
\end{aligned}\]</div>{% endraw %}
</div>
<p>Clearly, since {% raw %}<span class="math inline">\(T\)</span>{% endraw %} is a finite set, the diameter of {% raw %}<span class="math inline">\(T\)</span>{% endraw %}, denoted {% raw %}<span class="math inline">\(\operatorname{diam}(T)\)</span>{% endraw %}, is finite, so </p>

{% raw %}<div class="math display">\[\begin{aligned}
    \int_0^\infty \sqrt{\log D(\varepsilon, T, d)} \dif \varepsilon = \int_0^{\operatorname{diam}(T)} \sqrt{\log D(\varepsilon, T, d)} \dif \varepsilon ~.
\end{aligned}\]</div>{% endraw %}
<p> It then follows from the scaling property of the packing number that </p>

{% raw %}<div class="math display">\[\begin{aligned}
    &amp;\int_0^{\operatorname{diam}(T)} \sqrt{\log D(\varepsilon, T, d)} \dif \varepsilon \\
    &amp;= \int_0^{\operatorname{diam}(T)/2} \sqrt{\log D(\varepsilon, T, d)} \dif \varepsilon + \int_{\operatorname{diam}(T)/2}^{\operatorname{diam}(T)} \sqrt{\log D(\varepsilon, T, d)} \dif \varepsilon \\
    &amp;\leq \int_0^{\operatorname{diam}(T)/2} \sqrt{\log D(\varepsilon, T, d)} \dif \varepsilon + \int_0^{\operatorname{diam}(T)/2} \sqrt{\log D\left(\varepsilon + \frac{\operatorname{diam}(T)}{2}, T, d\right)} \dif \varepsilon \\
    &amp;\leq 2 \int_0^{\operatorname{diam}(T)/2} \sqrt{\log D(\varepsilon, T, d)} \dif \varepsilon ~.
\end{aligned}\]</div>{% endraw %}
<p> Dudley’s entropy bound can then be stated equivalently as </p>

{% raw %}<div class="math display">\[\begin{aligned}
    \mathbb{E} \sup_{t \in T} \: |X_t - X_{t_0}| \leq 2C \int_0^{\operatorname{diam}(T)/2} \sqrt{\log D(\varepsilon, T, d)} \dif \varepsilon ~.
\end{aligned}\]</div>{% endraw %}
<p>We prove Dudley’s entropy bound by <em>chaining</em>. Here, {% raw %}<span class="math inline">\(T\)</span>{% endraw %} is finite, so it makes sense to construct a shrinking sequence of chains that, altogether, “link” the set {% raw %}<span class="math inline">\(T\)</span>{% endraw %} together. On each of these links, we apply Proposition <a href="#prop:maximal-inequality-random-psuedo-Lipschitz" data-reference-type="ref" data-reference="prop:maximal-inequality-random-psuedo-Lipschitz">1</a> to show that these bounds contribute small amounts to {% raw %}<span class="math inline">\(\mathbb{E} \sup_{t \in T} \: |X_t - X_{t_0}|\)</span>{% endraw %}. The conclusion then follows from arguing that we can choose arbitrarily small chains to send the approximation error to zero.</p>

<div class="proof">
<p><em>Proof.</em> Put {% raw %}<span class="math inline">\(R=\operatorname{diam}(T)\)</span>{% endraw %}. If {% raw %}<span class="math inline">\(R=0\)</span>{% endraw %}, there is only one index and the claim is immediate. Otherwise set {% raw %}<span class="math inline">\(r_k=2^{-k}R\)</span>{% endraw %}. For {% raw %}<span class="math inline">\(k\geq1\)</span>{% endraw %}, choose a largest strictly {% raw %}<span class="math inline">\(r_k\)</span>{% endraw %}-separated subset {% raw %}<span class="math inline">\(T_k\)</span>{% endraw %}, of size {% raw %}<span class="math inline">\(D(r_k,T,d)\)</span>{% endraw %}. It is an {% raw %}<span class="math inline">\(r_k\)</span>{% endraw %}-net, since an uncovered point could be added. Let {% raw %}<span class="math inline">\(\pi_k(t)\)</span>{% endraw %} be a closest net point. Set {% raw %}<span class="math inline">\(T_0=\{t_0\}\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\pi_0(t)=t_0\)</span>{% endraw %}. For sufficiently large {% raw %}<span class="math inline">\(K\)</span>{% endraw %}, {% raw %}<span class="math inline">\(r_K\)</span>{% endraw %} is below every positive distance in the finite space, so {% raw %}<span class="math inline">\(T_K=T\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\pi_K(t)=t\)</span>{% endraw %}.</p>
<p>The telescoping chain and triangle inequality give</p>
{% raw %}<div class="math display">\[\max_t|X_t-X_{t_0}|\leq\sum_{k=1}^K\max_t|X_{\pi_k(t)}-X_{\pi_{k-1}(t)}|.\]</div>{% endraw %}
<p>Each edge at level {% raw %}<span class="math inline">\(k\)</span>{% endraw %} has length at most {% raw %}<span class="math inline">\(r_k+r_{k-1}=3r_k\)</span>{% endraw %}, including {% raw %}<span class="math inline">\(k=1\)</span>{% endraw %} because {% raw %}<span class="math inline">\(d(t,t_0)\leq R\)</span>{% endraw %}. There are at most {% raw %}<span class="math inline">\(|T_k||T_{k-1}|\leq D(r_k,T,d)^2\)</span>{% endraw %} distinct edges. Exponential moments and Jensen, applied to both signs of each edge, give</p>
{% raw %}<div class="math display">\[\mathbb E\max_t|X_{\pi_k(t)}-X_{\pi_{k-1}(t)}|\leq3r_k\sqrt{2\log(2D(r_k,T,d)^2)}\leq3\sqrt6\,r_k\sqrt{\log D(r_k,T,d)}.\]</div>{% endraw %}
<p>For the last inequality, {% raw %}<span class="math inline">\(D(r_k,T,d)\geq2\)</span>{% endraw %}: two points attaining the diameter are farther apart than {% raw %}<span class="math inline">\(r_k\leq R/2\)</span>{% endraw %}. The same numerical constant works at every level. The finite maximum bound used here follows from {% raw %}<span class="math inline">\(\lambda\mathbb E\max|Y_j|\leq\log(2m)+\lambda^2(3r_k)^2/2\)</span>{% endraw %}, optimized over {% raw %}<span class="math inline">\(\lambda&gt;0\)</span>{% endraw %}.</p>
<p>Since packing numbers decrease with radius,</p>
{% raw %}<div class="math display">\[r_k\sqrt{\log D(r_k,T,d)}\leq2\int_{r_k/2}^{r_k}\sqrt{\log D(u,T,d)}\,du.\]</div>{% endraw %}
<p>Sum these disjoint dyadic intervals to obtain</p>
{% raw %}<div class="math display">\[\mathbb E\max_t|X_t-X_{t_0}|\leq6\sqrt6\int_0^{R/2}\sqrt{\log D(u,T,d)}\,du\leq12\sqrt6\int_0^{R/4}\sqrt{\log D(u,T,d)}\,du.\]</div>{% endraw %}
<p>The second inequality uses monotonicity to bound the integral over {% raw %}<span class="math inline">\([R/4,R/2]\)</span>{% endraw %} by the one over {% raw %}<span class="math inline">\([0,R/4]\)</span>{% endraw %}. This proves the stronger truncated packing bound, and hence the stated full integral. Finally {% raw %}<span class="math inline">\(D(u,T,d)\leq N(u/2,T,d)\)</span>{% endraw %}; substituting {% raw %}<span class="math inline">\(u=2v\)</span>{% endraw %} bounds the packing integral by twice the corresponding covering integral. This also proves the truncated covering version with an adjusted universal constant. ◻</p>
</div>
<p>For infinite index sets we approximate a countable determining set by increasing finite subsets and use monotone convergence. A dense set of indices alone does not determine the process values: a sample-path separability condition is needed to identify the full supremum with a countable one.</p>
<p>We need a mild restriction on the metric space {% raw %}<span class="math inline">\((T,d)\)</span>{% endraw %}. A stochastic process {% raw %}<span class="math inline">\(\{X_t\}_{t \in T}\)</span>{% endraw %} is <em>separable</em> if there exists a countable subset {% raw %}<span class="math inline">\(\widetilde T\)</span>{% endraw %} of {% raw %}<span class="math inline">\(T\)</span>{% endraw %}, and a measure zero set {% raw %}<span class="math inline">\(N\)</span>{% endraw %}, such that for all {% raw %}<span class="math inline">\(\omega \notin N\)</span>{% endraw %} and {% raw %}<span class="math inline">\(t \in T\)</span>{% endraw %}, there exists a sequence {% raw %}<span class="math inline">\(\{t_n\}\)</span>{% endraw %} in {% raw %}<span class="math inline">\(\widetilde T\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(\lim\limits_{n \to \infty} d(t_n, t) = 0\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\lim\limits_{n \to \infty} X_{t_n} (\omega) = X_t (\omega)\)</span>{% endraw %}. A useful characterization of a separable stochastic process is the following: if {% raw %}<span class="math inline">\((T,d)\)</span>{% endraw %} is separable, and {% raw %}<span class="math inline">\(\{X_t\}_{t \in T}\)</span>{% endraw %} has continuous sample paths almost surely, then {% raw %}<span class="math inline">\(\{X_t\}_{t \in T}\)</span>{% endraw %} is separable. Furthermore, if {% raw %}<span class="math inline">\(\{X_t\}_{t \in T}\)</span>{% endraw %} is separable, then {% raw %}<span class="math inline">\(\sup_{t \in T} \: |X_t - X_{t_0}| = \sup_{t \in \widetilde T} |X_t - X_{t_0}|\)</span>{% endraw %} almost surely for all {% raw %}<span class="math inline">\(t_0 \in T\)</span>{% endraw %}.</p>

<p>We are now ready to state and prove Dudley’s entropy bound in full generality, when {% raw %}<span class="math inline">\(T\)</span>{% endraw %} is not necessarily a finite set.</p>

<div id="thm:dudley-entropy-bound-infinite-T" class="theorem" data-note-number="3" data-note-kind="Theorem">
<p><strong>Theorem 3</strong>.  Let {% raw %}<span class="math inline">\((T,d)\)</span>{% endraw %} be a separable metric space. Let {% raw %}<span class="math inline">\(\{X_t\}_{t\in T}\)</span>{% endraw %} be a separable subgaussian process. Then, there exists a universal positive constant {% raw %}<span class="math inline">\(C\)</span>{% endraw %} such that the following inequality holds for every {% raw %}<span class="math inline">\(t_0 \in T\)</span>{% endraw %}: </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \mathbb{E} \sup_{t \in T} \: |X_t - X_{t_0}| \leq C \int_0^{2^{-2} \overline D} \sqrt{\log D(\varepsilon, T, d)} \dif \varepsilon \lesssim \int_0^{2^{-2} \overline D} \sqrt{\log N(\varepsilon,T,d)} \dif \varepsilon ~,
    
\end{aligned}\]</div>{% endraw %}
<p> where {% raw %}<span class="math inline">\(\overline D \triangleq \operatorname{diam}(T)\)</span>{% endraw %}, and this need not be finite.</p>

</div>
<div class="proof">
<p><em>Proof.</em> There exists a countable, dense subset {% raw %}<span class="math inline">\(\widetilde T\)</span>{% endraw %} of {% raw %}<span class="math inline">\(T\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(\sup_{t \in T} \: |X_t - X_{t_0}| = \sup_{t \in \widetilde T} |X_t - X_{t_0}|\)</span>{% endraw %} almost surely for all {% raw %}<span class="math inline">\(t_0 \in T\)</span>{% endraw %}. Add {% raw %}<span class="math inline">\(t_0\)</span>{% endraw %} to {% raw %}<span class="math inline">\(\widetilde T\)</span>{% endraw %} if necessary and enumerate {% raw %}<span class="math inline">\(\widetilde T\)</span>{% endraw %} with {% raw %}<span class="math inline">\(t_0\)</span>{% endraw %} first. For each {% raw %}<span class="math inline">\(k\geq1\)</span>{% endraw %}, let {% raw %}<span class="math inline">\(\widetilde T_k\)</span>{% endraw %} consist of the first {% raw %}<span class="math inline">\(k\)</span>{% endraw %} points. Then {% raw %}<span class="math inline">\(t_0\in\widetilde T_k\)</span>{% endraw %} for every {% raw %}<span class="math inline">\(k\)</span>{% endraw %}. Applying Theorem <a href="#thm:dudley-entropy-finite-T" data-reference-type="ref" data-reference="thm:dudley-entropy-finite-T">2</a> to {% raw %}<span class="math inline">\(\{X_t\}_{t \in \widetilde T_k}\)</span>{% endraw %}, and writing {% raw %}<span class="math inline">\(\overline D_k = \operatorname{diam}(\widetilde T_k)\)</span>{% endraw %}, we have </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \mathbb{E} \sup_{t \in \widetilde T_k} |X_t - X_{t_0}| &amp;\leq C \int_{0}^{2^{-2} \overline D_k} \sqrt{\log D(\varepsilon, \widetilde T_k, d)} \dif \varepsilon \leq C \int_{0}^{2^{-2} \overline D} \sqrt{\log D(\varepsilon, T, d)} \dif \varepsilon ~.
    
\end{aligned}\]</div>{% endraw %}
<p> Passing both sides of the inequality to {% raw %}<span class="math inline">\(k\to\infty\)</span>{% endraw %}, we must then have, by the monotone convergence theorem, </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \mathbb{E} \sup_{t \in T} \: |X_t - X_{t_0}| \leq C \int_{0}^{2^{-2} \overline D} \sqrt{\log D(\varepsilon, T, d)} \dif \varepsilon ~.
    
\end{aligned}\]</div>{% endraw %}
<p> Applying the fact that {% raw %}<span class="math inline">\(\sup_{t \in T} \: |X_t - X_{t_0}| = \sup_{t \in \widetilde T} |X_t - X_{t_0}|\)</span>{% endraw %} almost surely concludes the proof. ◻</p>

</div>
<div id="rem:discretized-entropy-dudley-bound" class="remark" data-note-number="4" data-note-kind="Remark">
<p><strong>Remark 4 (Explicit constants).</strong> A version of the same argument gives</p>
{% raw %}<div class="math display">\[\mathbb E\sup_{t\in T}|X_t-X_{t_0}|\leq6\sqrt6\sum_{k\in\mathbb Z}2^{-k}\sqrt{\log N(2^{-k},T,d)}\leq12\sqrt6\int_0^\infty\sqrt{\log N(u,T,d)}\,du.\]</div>{% endraw %}
<p>For finite {% raw %}<span class="math inline">\(T\)</span>{% endraw %} of positive diameter, choose the largest <em>integer</em> {% raw %}<span class="math inline">\(k_0\)</span>{% endraw %} with {% raw %}<span class="math inline">\(2^{-k_0}\geq\operatorname{diam}(T)\)</span>{% endraw %}. Repeat the preceding proof at radii {% raw %}<span class="math inline">\(r_k=2^{-k}\)</span>{% endraw %}, {% raw %}<span class="math inline">\(k&gt;k_0\)</span>{% endraw %}, using largest separated nets and the starting singleton. Each level costs at most {% raw %}<span class="math inline">\(3\sqrt6\,2^{-k}\sqrt{\log D(2^{-k},T,d)}\)</span>{% endraw %}. Since {% raw %}<span class="math inline">\(D(2^{-k})\leq N(2^{-k-1})\)</span>{% endraw %}, shifting the index gives the first bound with {% raw %}<span class="math inline">\(6\sqrt6\)</span>{% endraw %}. The one-point case is zero. Finally,</p>
{% raw %}<div class="math display">\[2^{-k}\sqrt{\log N(2^{-k})}\leq2\int_{2^{-k-1}}^{2^{-k}}\sqrt{\log N(u)}\,du,\]</div>{% endraw %}
<p>which proves the integral bound. For an infinite separable process, apply the finite packing argument to increasing finite determining sets. Their packing numbers are bounded by those of {% raw %}<span class="math inline">\(T\)</span>{% endraw %}; compare these with the covering numbers of {% raw %}<span class="math inline">\(T\)</span>{% endraw %}, then pass to the limit. This avoids assuming that internal covering numbers are monotone under taking subsets. The constants here follow from the displayed estimates; the source's smaller constants were not justified by its absolute-maximum argument.</p>
</div>
<p>Chaining also gives probability bounds for the oscillation between nearby indices, rather than only an expectation bound for the global supremum. To do this, we define the <strong>uniform entropy integral</strong> (or <strong>covering integral</strong>, <span class="citation" data-cites="pollard_convergence_1984">(à la <a href="#ref-pollard_convergence_1984" role="doc-biblioref">Pollard 1984</a>)</span>) </p>

{% raw %}<span id="eq:uniform-entropy-integral"></span><div class="math display">\[\begin{aligned}
 
    J(\delta, T, d) \triangleq \int_0^\delta \sqrt{2 \log (N(\varrho,T,d)^2 / \varrho)} \dif \varrho \quad \text{for }~ \delta \in (0,1] ~.
\end{aligned}\tag{1}\]</div>{% endraw %}
<p> The <em>chaining lemma</em> below keeps track of the exceptional event at every scale. Covering-number bounds make it possible to sum the probabilities of those events.</p>

<p>In the chaining lemma, {% raw %}<span class="math inline">\((T,d)\)</span>{% endraw %} is a nonempty metric space (the same proof works after identifying zero-distance points in a pseudometric). Finiteness of {% raw %}<span class="math inline">\(J(\delta_0)\)</span>{% endraw %} at one positive radius implies finite covering numbers at every positive radius: an infinite number at any smaller radius would force an infinite integrand on a nontrivial interval. Monotonicity handles larger radii. It also implies finiteness and continuity of {% raw %}<span class="math inline">\(J\)</span>{% endraw %} throughout {% raw %}<span class="math inline">\([0,1]\)</span>{% endraw %}, with {% raw %}<span class="math inline">\(J(0)=0\)</span>{% endraw %}, because the integrand is bounded on intervals separated from zero.</p>
<div id="lem:chaining-lemma" class="lemma" data-note-number="5" data-note-kind="Lemma">
<p><strong>Lemma 5</strong> (Chaining).  Let {% raw %}<span class="math inline">\(\{Z(t):t \in T\}\)</span>{% endraw %} be a stochastic process whose index set {% raw %}<span class="math inline">\(T\)</span>{% endraw %} has a finite covering integral {% raw %}<span class="math inline">\(J(\delta, T, d)\)</span>{% endraw %}. Suppose further that there exists a constant {% raw %}<span class="math inline">\(D>0\)</span>{% endraw %} such that for all {% raw %}<span class="math inline">\(s,t\)</span>{% endraw %}, </p>

{% raw %}<span id="eq:subg-increments"></span><div class="math display">\[\begin{aligned}
        \mathbf P\,\,\!\!(|Z(s) - Z(t)| &gt; \eta d(s,t)) \leq 2 e^{-\eta^2/(2 D^2)} \quad \text{for }~ \eta &gt; 0 ~. 
    
\end{aligned}\tag{2}\]</div>{% endraw %}
<p> For {% raw %}<span class="math inline">\(\delta\in(0,1]\)</span>{% endraw %}, define the covering number </p>

{% raw %}<div class="math display">\[N(\delta)\equiv N(\delta,T,d) \equiv \min\left\{m:\exists\,t_1,\dots,t_m\in T\text{ s.t. }\forall t\in T,\ \min_{1\le j\le m}d(t,t_j)\le \delta\right\},\]</div>{% endraw %}
<p> and define </p>

{% raw %}<span id="eq:def-H"></span><span id="eq:def-J"></span><div class="math display">\[\begin{aligned}
    H(u)&amp; \equiv \left(2\log \left(\frac{N(u)^2}{u}\right)\right)^{1/2},\qquad u\in(0,1],
    
    \\
    J(\delta,T,d)&amp; \equiv \int_{0}^{\delta} H(u)\,du\in[0,\infty].
    
    
\end{aligned}\tag{3}\]</div>{% endraw %}
<p> Assume {% raw %}<span class="math inline">\(J(\varepsilon,T,d)&lt;\infty\)</span>{% endraw %} for the {% raw %}<span class="math inline">\(\varepsilon\)</span>{% endraw %} used below. Then, there exists a countable dense subset {% raw %}<span class="math inline">\(T^* \subset T\)</span>{% endraw %} such that for {% raw %}<span class="math inline">\(\varepsilon \in (0,1)\)</span>{% endraw %}, </p>

{% raw %}<span id="eq:goal-prob"></span><div class="math display">\[\begin{aligned}
        \mathbf P\,\,\!\!(|Z(s) - Z(t)| &gt; 26 D J(d(s,t), T, d) ~\text{for some}~ s,t \in T^* ~\text{s.t.}~ d(s,t) \leq \varepsilon) \leq 2 \varepsilon ~. 
    
\end{aligned}\tag{4}\]</div>{% endraw %}
<p> Furthermore, if {% raw %}<span class="math inline">\(Z\)</span>{% endraw %} has continuous sample paths, then {% raw %}<span class="math inline">\(T^*\)</span>{% endraw %} can be replaced by {% raw %}<span class="math inline">\(T\)</span>{% endraw %}.</p>

</div>
<div class="proof">
<p><em>Proof.</em> Fix {% raw %}<span class="math inline">\(\varepsilon\in(0,1)\)</span>{% endraw %}. We prove <a href="#eq:goal-prob" data-reference-type="eqref" data-reference="eq:goal-prob">(4)</a> in explicit steps. Define radii </p>

{% raw %}<span id="eq:delta_i"></span><div class="math display">\[\begin{aligned}
\delta_i \equiv \frac{\varepsilon}{2^i},\qquad i=1,2,3,\dots

\end{aligned}\tag{5}\]</div>{% endraw %}
<p> so that {% raw %}<span class="math inline">\(\sum_{i=1}^\infty \delta_i=\varepsilon\)</span>{% endraw %}.</p>

<ol>
<li><p>We construct finite sets {% raw %}<span class="math inline">\(T_i\subset T\)</span>{% endraw %} satisfying:</p>

<ol>
<li><p>{% raw %}<span class="math inline">\(T_i\)</span>{% endraw %} is a {% raw %}<span class="math inline">\(2\delta_i\)</span>{% endraw %}-net: for every {% raw %}<span class="math inline">\(t\in T\)</span>{% endraw %}, there exists {% raw %}<span class="math inline">\(\pi_i(t)\in T_i\)</span>{% endraw %} such that </p>

{% raw %}<span id="eq:projection-net"></span><div class="math display">\[\begin{aligned}
    d\left(t,\pi_i(t)\right)\le 2\delta_i.
    
    
\end{aligned}\tag{6}\]</div>{% endraw %}</li>
<li><p>(Nesting) {% raw %}<span class="math inline">\(T_i\subset T_{i+1}\)</span>{% endraw %} for all {% raw %}<span class="math inline">\(i\)</span>{% endraw %}.</p></li>
<li><p>(Cardinality bound) {% raw %}<span class="math inline">\(|T_i|\le N(\delta_i)\)</span>{% endraw %} for all {% raw %}<span class="math inline">\(i\)</span>{% endraw %}.</p></li>
</ol>
<p><em>Construction.</em> Start from one point and enlarge it to a maximal set {% raw %}<span class="math inline">\(T_1\)</span>{% endraw %} with pairwise distances strictly greater than {% raw %}<span class="math inline">\(2\delta_1\)</span>{% endraw %}. A {% raw %}<span class="math inline">\(\delta_1\)</span>{% endraw %}-cover contains at most one selected point in each ball, so this procedure stops after at most {% raw %}<span class="math inline">\(N(\delta_1)\)</span>{% endraw %} steps. Inductively {% raw %}<span class="math inline">\(T_i\)</span>{% endraw %} is already {% raw %}<span class="math inline">\(2\delta_{i+1}\)</span>{% endraw %}-separated, since {% raw %}<span class="math inline">\(\delta_{i+1}&lt;\delta_i\)</span>{% endraw %}; extend it by the same procedure to a maximal {% raw %}<span class="math inline">\(2\delta_{i+1}\)</span>{% endraw %}-separated set {% raw %}<span class="math inline">\(T_{i+1}\)</span>{% endraw %}. Thus nesting, separation, and the cardinality bound hold at every scale.</p>

<p><em>Verification of (S1.1).</em> If {% raw %}<span class="math inline">\(T_{i+1}\)</span>{% endraw %} is maximal {% raw %}<span class="math inline">\(2\delta_{i+1}\)</span>{% endraw %}-separated, then it is a {% raw %}<span class="math inline">\(2\delta_{i+1}\)</span>{% endraw %}-net: otherwise there exists {% raw %}<span class="math inline">\(t\in T\)</span>{% endraw %} with {% raw %}<span class="math inline">\(d(t,u)&gt;2\delta_{i+1}\)</span>{% endraw %} for all {% raw %}<span class="math inline">\(u\in T_{i+1}\)</span>{% endraw %}, so we could add {% raw %}<span class="math inline">\(t\)</span>{% endraw %}, contradicting maximality. Thus <a href="#eq:projection-net" data-reference-type="eqref" data-reference="eq:projection-net">(6)</a> holds with {% raw %}<span class="math inline">\(i+1\)</span>{% endraw %}.</p>

<p><em>Verification of (S1.3).</em> Let {% raw %}<span class="math inline">\(A\subset T\)</span>{% endraw %} be any {% raw %}<span class="math inline">\(2\delta\)</span>{% endraw %}-separated subset. Take a {% raw %}<span class="math inline">\(\delta\)</span>{% endraw %}-cover of {% raw %}<span class="math inline">\(T\)</span>{% endraw %} with {% raw %}<span class="math inline">\(N(\delta)\)</span>{% endraw %} balls {% raw %}<span class="math inline">\(\{B(t_j,\delta)\}_{j=1}^{N(\delta)}\)</span>{% endraw %} centered at points in {% raw %}<span class="math inline">\(T\)</span>{% endraw %}. Since {% raw %}<span class="math inline">\(A\)</span>{% endraw %} is {% raw %}<span class="math inline">\(2\delta\)</span>{% endraw %}-separated, each ball contains <em>at most one</em> point of {% raw %}<span class="math inline">\(A\)</span>{% endraw %} (otherwise two points in the same ball would have distance {% raw %}<span class="math inline">\(\le 2\delta\)</span>{% endraw %}). Hence {% raw %}<span class="math inline">\(|A|\le N(\delta)\)</span>{% endraw %}. Apply this with {% raw %}<span class="math inline">\(A=T_i\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\delta=\delta_i\)</span>{% endraw %} to get {% raw %}<span class="math inline">\(|T_i|\le N(\delta_i)\)</span>{% endraw %}.</p>

<p>Finally define </p>

{% raw %}<span id="eq:def-Tstar"></span><div class="math display">\[\begin{aligned}
T^\ast \equiv \bigcup_{i=1}^\infty T_i.

\end{aligned}\tag{7}\]</div>{% endraw %}
<p> Then {% raw %}<span class="math inline">\(T^\ast\)</span>{% endraw %} is countable (countable union of finite sets). It is dense because for any {% raw %}<span class="math inline">\(t\in T\)</span>{% endraw %}, <a href="#eq:projection-net" data-reference-type="eqref" data-reference="eq:projection-net">(6)</a> gives {% raw %}<span class="math inline">\(d(t,T_i)\le 2\delta_i\to 0\)</span>{% endraw %}, hence {% raw %}<span class="math inline">\(d(t,T^\ast)=0\)</span>{% endraw %}.</p></li>
<li><p>Define “bad” events at each scale. For each {% raw %}<span class="math inline">\(i\ge 1\)</span>{% endraw %}, define the event </p>

{% raw %}<span id="eq:def-Ai"></span><div class="math display">\[\begin{aligned}
A_i
 \equiv \left\{\exists\,u,v\in T_i:\ |Z(u)-Z(v)|&gt; D\, d(u,v) H(\delta_i)\right\},

\end{aligned}\tag{8}\]</div>{% endraw %}
<p> where {% raw %}<span class="math inline">\(H(\cdot)\)</span>{% endraw %} is defined in <a href="#eq:def-H" data-reference-type="eqref" data-reference="eq:def-H">(3)</a>.</p></li>
<li><p>Bound {% raw %}<span class="math inline">\(\mathbf P\,\,\!\!(A_i)\)</span>{% endraw %}. Fix {% raw %}<span class="math inline">\(i\)</span>{% endraw %}. For any <em>fixed</em> pair {% raw %}<span class="math inline">\((u,v)\in T_i\times T_i\)</span>{% endraw %}, apply <a href="#eq:subg-increments" data-reference-type="eqref" data-reference="eq:subg-increments">(2)</a> with </p>

{% raw %}<div class="math display">\[\eta \equiv D H(\delta_i)\]</div>{% endraw %}
<p> to obtain </p>

{% raw %}<span id="eq:pair-bound"></span><div class="math display">\[\begin{aligned}
\mathbf P\,\,\!\!\left(|Z(u)-Z(v)|&gt; D H(\delta_i) d(u,v)\right)
&amp;\le 2\exp\left(-\frac{(D H(\delta_i))^2}{2D^2}\right) =2\exp\left(-\frac{H(\delta_i)^2}{2}\right) 
\nonumber\\
&amp;= 2\exp\left(-\log \left(\frac{N(\delta_i)^2}{\delta_i}\right)\right) =\frac{2\delta_i}{N(\delta_i)^2}.

\end{aligned}\tag{9}\]</div>{% endraw %}
<p> Now take a union bound over all pairs in {% raw %}<span class="math inline">\(T_i\times T_i\)</span>{% endraw %}: </p>

{% raw %}<span id="eq:PAi"></span><div class="math display">\[\begin{aligned}
\mathbf P\,\,\!\!(A_i)
&amp;\le \sum_{(u,v)\in T_i\times T_i}\mathbf P\,\,\!\!\left(|Z(u)-Z(v)|&gt; D\, d(u,v) H(\delta_i)\right)
\nonumber\\
&amp;\le |T_i|^2\cdot 2\frac{\delta_i}{N(\delta_i)^2}
\le N(\delta_i)^2\cdot 2\frac{\delta_i}{N(\delta_i)^2}
=2\delta_i.

\end{aligned}\tag{10}\]</div>{% endraw %}</li>
<li><p>Bound the union of bad events. By another union bound and <a href="#eq:PAi" data-reference-type="eqref" data-reference="eq:PAi">(10)</a>, </p>

{% raw %}<span id="eq:union-bad"></span><div class="math display">\[\begin{aligned}
\mathbf P\,\,\!\!\left(\bigcup_{i=1}^\infty A_i\right)
\le \sum_{i=1}^\infty \mathbf P\,\,\!\!(A_i)
\le \sum_{i=1}^\infty 2\delta_i
=2\sum_{i=1}^\infty \delta_i
=2\varepsilon.

\end{aligned}\tag{11}\]</div>{% endraw %}
<p> Define the “good” event </p>

{% raw %}<div class="math display">\[G \equiv \left(\bigcup_{i=1}^\infty A_i\right)^c.\]</div>{% endraw %}
<p> On {% raw %}<span class="math inline">\(G\)</span>{% endraw %}, for every {% raw %}<span class="math inline">\(i\)</span>{% endraw %} and all {% raw %}<span class="math inline">\(u,v\in T_i\)</span>{% endraw %}, </p>

{% raw %}<span id="eq:good-scale-bound"></span><div class="math display">\[\begin{aligned}
|Z(u)-Z(v)|\le D d(u,v) H(\delta_i).

\end{aligned}\tag{12}\]</div>{% endraw %}</li>
<li><p>Construct chains between nearby points in {% raw %}<span class="math inline">\(T^\ast\)</span>{% endraw %}. Let {% raw %}<span class="math inline">\(s,t\in T^\ast\)</span>{% endraw %} satisfy {% raw %}<span class="math inline">\(d(s,t)\le\varepsilon\)</span>{% endraw %}. For positive distance, choose {% raw %}<span class="math inline">\(m\)</span>{% endraw %} large enough so that {% raw %}<span class="math inline">\(s,t\in T_m\)</span>{% endraw %} (possible since {% raw %}<span class="math inline">\(T^\ast=\cup_i T_i\)</span>{% endraw %} and the {% raw %}<span class="math inline">\(T_i\)</span>{% endraw %} are nested). Choose {% raw %}<span class="math inline">\(n\ge 1\)</span>{% endraw %} such that </p>

{% raw %}<span id="eq:choose-n"></span><div class="math display">\[\begin{aligned}
\delta_n\le d(s,t)\le 2\delta_n
\qquad\text{(equivalently, $\delta_{n-1}=2\delta_n\ge d(s,t)$).}

\end{aligned}\tag{13}\]</div>{% endraw %}
<p> Increase {% raw %}<span class="math inline">\(m\)</span>{% endraw %} to be at least {% raw %}<span class="math inline">\(n\)</span>{% endraw %} if necessary. Define a chain {% raw %}<span class="math inline">\(\{s_k\}_{k=n}^m\)</span>{% endraw %} by setting {% raw %}<span class="math inline">\(s_m \equiv s\)</span>{% endraw %} and recursively </p>

{% raw %}<span id="eq:chain-s"></span><div class="math display">\[\begin{aligned}
s_k \equiv \pi_k(s_{k+1})\in T_k,\qquad k=m-1,m-2,\dots,n,

\end{aligned}\tag{14}\]</div>{% endraw %}
<p> and similarly define {% raw %}<span class="math inline">\(\{t_k\}_{k=n}^m\)</span>{% endraw %} with {% raw %}<span class="math inline">\(t_m \equiv t\)</span>{% endraw %} and {% raw %}<span class="math inline">\(t_k \equiv \pi_k(t_{k+1})\)</span>{% endraw %}. By <a href="#eq:projection-net" data-reference-type="eqref" data-reference="eq:projection-net">(6)</a> applied to {% raw %}<span class="math inline">\(s_{k+1}\in T_{k+1}\subset T\)</span>{% endraw %}, we have </p>

{% raw %}<span id="eq:chain-step-dist"></span><div class="math display">\[\begin{aligned}
d(s_{k+1},s_k)\le 2\delta_k,\qquad
d(t_{k+1},t_k)\le 2\delta_k,
\qquad k=n,\dots,m-1.

\end{aligned}\tag{15}\]</div>{% endraw %}</li>
<li><p>By repeated application of triangle inequality, </p>

{% raw %}<span id="eq:triangle-decomp"></span><div class="math display">\[\begin{aligned}
|Z(s)-Z(t)|
&amp;=|Z(s_m)-Z(t_m)|
\nonumber\\
&amp;\le |Z(s_n)-Z(t_n)|+\sum_{k=n}^{m-1}\left(|Z(s_{k+1})-Z(s_k)|+|Z(t_{k+1})-Z(t_k)|\right).

\end{aligned}\tag{16}\]</div>{% endraw %}</li>
<li><p>Control {% raw %}<span class="math inline">\(d(s_n,t_n)\)</span>{% endraw %}. Again by triangle inequality and <a href="#eq:chain-step-dist" data-reference-type="eqref" data-reference="eq:chain-step-dist">(15)</a>, </p>

{% raw %}<span id="eq:dsn-tn"></span><div class="math display">\[\begin{aligned}
d(s_n,t_n)
&amp;\le d(s,t)+\sum_{k=n}^{m-1}\left(d(s_{k+1},s_k)+d(t_{k+1},t_k)\right)
\nonumber\\
&amp;\le d(s,t)+\sum_{k=n}^{m-1} (2\delta_k+2\delta_k)
= d(s,t)+4\sum_{k=n}^{m-1}\delta_k
\nonumber\\
&amp;\le 2\delta_n + 4\sum_{k=n}^{\infty}\delta_k
\qquad\text{(by (13))}
\nonumber\\
&amp;=2\delta_n + 4\cdot \left(\delta_n+\delta_{n+1}+\cdots\right)
=2\delta_n+4\cdot (2\delta_n)
=10\delta_n,

\end{aligned}\tag{17}\]</div>{% endraw %}
<p> where we used {% raw %}<span class="math inline">\(\sum_{k=n}^\infty \delta_k = \delta_n/(1-1/2)=2\delta_n\)</span>{% endraw %}.</p></li>
<li><p>Bound the RHS of <a href="#eq:triangle-decomp" data-reference-type="eqref" data-reference="eq:triangle-decomp">(16)</a> on {% raw %}<span class="math inline">\(G\)</span>{% endraw %}. Work on the event {% raw %}<span class="math inline">\(G\)</span>{% endraw %}; we have:</p>

<p><em>(a) The middle-scale term.</em> Since {% raw %}<span class="math inline">\(s_n,t_n\in T_n\)</span>{% endraw %}, apply <a href="#eq:good-scale-bound" data-reference-type="eqref" data-reference="eq:good-scale-bound">(12)</a> with {% raw %}<span class="math inline">\(i=n\)</span>{% endraw %}: </p>

{% raw %}<span id="eq:ZsnZtn"></span><div class="math display">\[\begin{aligned}
|Z(s_n)-Z(t_n)|
\le D d(s_n,t_n) H(\delta_n)
\le 10D \delta_n H(\delta_n),

\end{aligned}\tag{18}\]</div>{% endraw %}
<p> using <a href="#eq:dsn-tn" data-reference-type="eqref" data-reference="eq:dsn-tn">(17)</a>.</p>

<p><em>(b) The chaining increments.</em> For each {% raw %}<span class="math inline">\(k\in\{n,\dots,m-1\}\)</span>{% endraw %}, note that {% raw %}<span class="math inline">\(s_k,s_{k+1}\in T_{k+1}\)</span>{% endraw %} because {% raw %}<span class="math inline">\(T_k\subset T_{k+1}\)</span>{% endraw %}. Hence <a href="#eq:good-scale-bound" data-reference-type="eqref" data-reference="eq:good-scale-bound">(12)</a> with {% raw %}<span class="math inline">\(i=k+1\)</span>{% endraw %} gives </p>

{% raw %}<span id="eq:increment-s"></span><div class="math display">\[\begin{aligned}
|Z(s_{k+1})-Z(s_k)|
\le D d(s_{k+1},s_k) H(\delta_{k+1})
\le 2D \delta_k H(\delta_{k+1}),

\end{aligned}\tag{19}\]</div>{% endraw %}
<p> where we used {% raw %}<span class="math inline">\(d(s_{k+1},s_k)\le 2\delta_k\)</span>{% endraw %} from <a href="#eq:chain-step-dist" data-reference-type="eqref" data-reference="eq:chain-step-dist">(15)</a>. Similarly, </p>

{% raw %}<span id="eq:increment-t"></span><div class="math display">\[\begin{aligned}
|Z(t_{k+1})-Z(t_k)|
\le 2D \delta_k H(\delta_{k+1}).

\end{aligned}\tag{20}\]</div>{% endraw %}
<p> Plugging <a href="#eq:ZsnZtn" data-reference-type="eqref" data-reference="eq:ZsnZtn">(18)</a>–<a href="#eq:increment-t" data-reference-type="eqref" data-reference="eq:increment-t">(20)</a> into <a href="#eq:triangle-decomp" data-reference-type="eqref" data-reference="eq:triangle-decomp">(16)</a> yields on {% raw %}<span class="math inline">\(G\)</span>{% endraw %}: </p>

{% raw %}<span id="eq:pre-integral"></span><div class="math display">\[\begin{aligned}
|Z(s)-Z(t)|
&amp;\le 10D \delta_n H(\delta_n)
+ \sum_{k=n}^{m-1}\left(2D \delta_k H(\delta_{k+1})+2D \delta_k H(\delta_{k+1})\right)
\nonumber\\
&amp;=10D \delta_n H(\delta_n)+4D\sum_{k=n}^{m-1}\delta_k H(\delta_{k+1})
\nonumber\\
&amp;\le 10D \delta_n H(\delta_n)+4D\sum_{k=n}^{\infty}\delta_k H(\delta_{k+1}).

\end{aligned}\tag{21}\]</div>{% endraw %}</li>
<li><p>Convert the sums into the entropy integral. Both {% raw %}<span class="math inline">\(N(u)\)</span>{% endraw %} and {% raw %}<span class="math inline">\(1/u\)</span>{% endraw %} are nonincreasing in {% raw %}<span class="math inline">\(u\in(0,1]\)</span>{% endraw %}, and they are positive. Consequently {% raw %}<span class="math inline">\(H(u)=\sqrt{2\log(N(u)^2/u)}\)</span>{% endraw %} itself is nonincreasing. No replacement by a different entropy function is needed.</p>

<p><em>(a) Bound {% raw %}<span class="math inline">\(\delta_n H(\delta_n)\)</span>{% endraw %} by {% raw %}<span class="math inline">\(J(\delta_n)\)</span>{% endraw %}.</em> Since {% raw %}<span class="math inline">\(H\)</span>{% endraw %} is nonincreasing, </p>

{% raw %}<span id="eq:deltaH-by-J"></span><div class="math display">\[\begin{aligned}
J(\delta_n)=\int_0^{\delta_n}H(u)\,du
 \ge \int_0^{\delta_n}H(\delta_n)\,du
=\delta_n H(\delta_n),

\end{aligned}\tag{22}\]</div>{% endraw %}
<p> hence </p>

{% raw %}<span id="eq:firstterm-by-J"></span><div class="math display">\[\begin{aligned}
10D \delta_n H(\delta_n)\le 10D J(\delta_n).

\end{aligned}\tag{23}\]</div>{% endraw %}
<p><em>(b) Bound the sum at the next smaller scale.</em> For {% raw %}<span class="math inline">\(u\in[\delta_{k+2},\delta_{k+1}]\)</span>{% endraw %}, monotonicity gives {% raw %}<span class="math inline">\(H(u)\ge H(\delta_{k+1})\)</span>{% endraw %}. The interval has length {% raw %}<span class="math inline">\(\delta_k/4\)</span>{% endraw %}, so</p>
<span id="eq:dyadic-integral-sandwich"></span>
{% raw %}<div class="math display">\[\delta_k H(\delta_{k+1})\le4\int_{\delta_{k+2}}^{\delta_{k+1}}H(u)du.\tag{24}\]</div>{% endraw %}
<span id="eq:sum-by-J"></span>
{% raw %}<div class="math display">\[\sum_{k=n}^\infty\delta_kH(\delta_{k+1})\le4J(\delta_{n+1})\le4J(\delta_n).\tag{25}\]</div>{% endraw %}
<span id="eq:secondterm-by-J"></span>
{% raw %}<div class="math display">\[4D\sum_{k=n}^\infty\delta_kH(\delta_{k+1})\le16D J(\delta_n).\tag{26}\]</div>{% endraw %}
<p>Combining (21), (23), and (26) gives</p>
<span id="eq:18-to-26"></span>
{% raw %}<div class="math display">\[|Z(s)-Z(t)|\le(10D+16D)J(\delta_n)=26D J(\delta_n).\tag{27}\]</div>{% endraw %}

<p> and since {% raw %}<span class="math inline">\(d(s,t)\ge \delta_n\)</span>{% endraw %} by <a href="#eq:choose-n" data-reference-type="eqref" data-reference="eq:choose-n">(13)</a> and {% raw %}<span class="math inline">\(J(\cdot)\)</span>{% endraw %} is nondecreasing, </p>

{% raw %}<span id="eq:J-monotone"></span><div class="math display">\[\begin{aligned}
J(\delta_n)\le J(d(s,t)).

\end{aligned}\tag{28}\]</div>{% endraw %}
<p> Hence on {% raw %}<span class="math inline">\(G\)</span>{% endraw %}, </p>

{% raw %}<span id="eq:on-good"></span><div class="math display">\[\begin{aligned}
|Z(s)-Z(t)|\le 26D J(d(s,t)).

\end{aligned}\tag{29}\]</div>{% endraw %}</li>
<li><p>Define the event </p>

{% raw %}<div class="math display">\[E \equiv \left\{\exists\,s,t\in T^\ast\text{ with }d(s,t)\le \varepsilon\text{ and }|Z(s)-Z(t)|&gt;26D J(d(s,t))\right\}.\]</div>{% endraw %}
<p> By <a href="#eq:on-good" data-reference-type="eqref" data-reference="eq:on-good">(29)</a>, {% raw %}<span class="math inline">\(E\subseteq G^c=\cup_{i=1}^\infty A_i\)</span>{% endraw %}, hence by <a href="#eq:union-bad" data-reference-type="eqref" data-reference="eq:union-bad">(11)</a>, </p>

{% raw %}<div class="math display">\[\mathbf P\,\,\!\!(E)\le \mathbf P\,\,\!\!\left(\bigcup_{i=1}^\infty A_i\right)\le 2\varepsilon,\]</div>{% endraw %}
<p> which is exactly <a href="#eq:goal-prob" data-reference-type="eqref" data-reference="eq:goal-prob">(4)</a>.</p></li>
<li><p>The auxiliary dense set just constructed can depend on {% raw %}<span class="math inline">\(\varepsilon\)</span>{% endraw %}. To obtain one countable set for the statement, fix any countable dense {% raw %}<span class="math inline">\(T_0\)</span>{% endraw %} in advance. For each {% raw %}<span class="math inline">\(t\in T_0\)</span>{% endraw %}, approximate it by points of the auxiliary set. The increment tail bound makes their process values converge to {% raw %}<span class="math inline">\(Z(t)\)</span>{% endraw %} in probability. A diagonal subsequence gives simultaneous almost-sure convergence for all {% raw %}<span class="math inline">\(t\in T_0\)</span>{% endraw %}. On the good event the inequality therefore passes to every pair in {% raw %}<span class="math inline">\(T_0\)</span>{% endraw %} at distance strictly less than {% raw %}<span class="math inline">\(\varepsilon\)</span>{% endraw %}; continuity of the finite integral {% raw %}<span class="math inline">\(J\)</span>{% endraw %} justifies this passage. Apply the argument with {% raw %}<span class="math inline">\(\varepsilon'&gt;\varepsilon\)</span>{% endraw %} and let {% raw %}<span class="math inline">\(\varepsilon'\downarrow\varepsilon\)</span>{% endraw %} to include pairs at distance exactly {% raw %}<span class="math inline">\(\varepsilon\)</span>{% endraw %}, retaining probability bound {% raw %}<span class="math inline">\(2\varepsilon\)</span>{% endraw %}. Zero-distance pairs have equal process values almost surely by the increment assumption; countability permits this simultaneously. Thus take {% raw %}<span class="math inline">\(T^*=T_0\)</span>{% endraw %}.</p>
<p>If the sample paths are {% raw %}<span class="math inline">\(d\)</span>{% endraw %}-continuous, the same limit argument passes from {% raw %}<span class="math inline">\(T_0\)</span>{% endraw %} to all of {% raw %}<span class="math inline">\(T\)</span>{% endraw %}, again first using a radius {% raw %}<span class="math inline">\(\varepsilon'&gt;\varepsilon\)</span>{% endraw %} to avoid a boundary issue. For measurability, the set of pairs {% raw %}<span class="math inline">\(\{(s,t):d(s,t)\leq\varepsilon\}\)</span>{% endraw %} is a separable subspace of {% raw %}<span class="math inline">\(T\times T\)</span>{% endraw %}. Choose a countable dense set in this pair space. Continuity of the paths and of {% raw %}<span class="math inline">\(J\)</span>{% endraw %} makes the supremum of {% raw %}<span class="math inline">\(|Z(s)-Z(t)|-26DJ(d(s,t))\)</span>{% endraw %} equal to its supremum over those countably many pairs, outside the common continuity null set. This proves the final assertion.</p></li>

</ol>
<p>This concludes the proof. ◻</p>
