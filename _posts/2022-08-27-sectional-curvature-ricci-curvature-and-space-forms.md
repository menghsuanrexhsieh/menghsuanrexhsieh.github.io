<div class="note-content" markdown="0">

<p>Let {% raw %}<span class="math inline">\((M,g)\)</span>{% endraw %} be a smooth Riemannian manifold. Write {% raw %}<span class="math inline">\(\nabla\)</span>{% endraw %} for its Levi–Civita connection and {% raw %}<span class="math inline">\(T_pM\)</span>{% endraw %} for the tangent space at {% raw %}<span class="math inline">\(p\)</span>{% endraw %}. The coordinate conventions are those in <a href="{% post_url 2022-03-17-tangent-spaces-and-riemannian-metrics %}">tangent spaces and derivations</a>.</p>

<div id="sectional-curvature-and-ricci-curvature" data-note-section="title">

</div>
<p>The curvature tensor contains more information than is easy to read from its components. Sectional curvature extracts a number from each tangent two-plane, while Ricci curvature averages sectional contributions through a fixed direction. We first examine the zero-curvature case, where a parallel coordinate frame is available under the torsion-free hypothesis.</p>

<div id="result-1" class="definition" data-note-number="1" data-note-kind="Definition">
<p><strong>Definition 1</strong>.  An affine connection {% raw %}<span class="math inline">\(\nabla\)</span>{% endraw %} on {% raw %}<span class="math inline">\(TM\)</span>{% endraw %} is <em>flat</em> if for all {% raw %}<span class="math inline">\(p \in M\)</span>{% endraw %}, there exists a neighbourhood {% raw %}<span class="math inline">\(U = U_p\)</span>{% endraw %} with local coordinates such that <em>all</em> coordinate vector fields {% raw %}<span class="math inline">\(\pd{}{{x^i}}\)</span>{% endraw %} are parallel, i.e. {% raw %}<span class="math inline">\(\nabla \pd{}{{x^i}} = 0\)</span>{% endraw %} for all {% raw %}<span class="math inline">\(i\)</span>{% endraw %}.</p>

<p>This is the coordinate-flat convention. Many texts call a connection flat when its curvature alone vanishes; that weaker condition gives local parallel frames, which need not be coordinate frames if torsion is present. Theorem 2 includes torsion precisely because this definition asks for parallel <em>coordinate</em> fields.</p>
</div>
<div id="result-2" class="theorem" data-note-number="2" data-note-kind="Theorem">
<p><strong>Theorem 2</strong>.  An affine connection {% raw %}<span class="math inline">\(\nabla\)</span>{% endraw %} on {% raw %}<span class="math inline">\(TM\)</span>{% endraw %} is flat if and only if its curvature and torsion vanish identically.</p>

</div>
<div class="proof">
<p><em>Proof.</em> If all coordinate fields are parallel, all Christoffel symbols vanish on the chart. Coordinate fields commute, so the torsion vanishes, and the curvature formula contains only derivatives and products of zero coefficients. Thus both tensors vanish.</p>
<p>Conversely suppose curvature and torsion vanish. In local coordinates let {% raw %}<span class="math inline">\(\Gamma_i\)</span>{% endraw %} be the matrix with entries {% raw %}<span class="math inline">\((\Gamma_i)^k{}_j=\Gamma^k_{ij}\)</span>{% endraw %}. A matrix of parallel-frame columns must solve</p>
<p> {% raw %}<div class="math display">\[\partial_iB=-\Gamma_iB.\]</div>{% endraw %}</p>
<p> This is a system of partial differential equations, not a collection of independent ODEs. To justify solvability, on the product of the coordinate domain with {% raw %}<span class="math inline">\(\operatorname{GL}(n,\mathbb R)\)</span>{% endraw %} define horizontal fields {% raw %}<span class="math inline">\(H_i\)</span>{% endraw %} whose base component is {% raw %}<span class="math inline">\(\partial_i\)</span>{% endraw %} and whose matrix component is {% raw %}<span class="math inline">\(-\Gamma_iB\)</span>{% endraw %}. Direct differentiation gives</p>
<p> {% raw %}<div class="math display">\[[H_i,H_j]_{\rm vertical} =(\partial_j\Gamma_i-\partial_i\Gamma_j+\Gamma_j\Gamma_i-\Gamma_i\Gamma_j)B=0,\]</div>{% endraw %}</p>
<p> by zero curvature. Their base components are independent, so they span an involutive rank-{% raw %}<span class="math inline">\(n\)</span>{% endraw %} distribution. Frobenius gives an integral submanifold through {% raw %}<span class="math inline">\((p,I)\)</span>{% endraw %}; projection to the coordinate domain has invertible differential there. On a smaller neighbourhood the integral submanifold is therefore a graph {% raw %}<span class="math inline">\(B(x)\)</span>{% endraw %}, and tangency to the {% raw %}<span class="math inline">\(H_i\)</span>{% endraw %}'s gives the required system. Its columns define a parallel frame {% raw %}<span class="math inline">\(E_1,\ldots,E_n\)</span>{% endraw %}.</p>
<p>Let {% raw %}<span class="math inline">\(\theta^1,\ldots,\theta^n\)</span>{% endraw %} be the dual coframe. It is parallel because differentiating {% raw %}<span class="math inline">\(\theta^a(E_b)=\delta^a_b\)</span>{% endraw %} gives zero. Torsion-freeness implies each {% raw %}<span class="math inline">\(\theta^a\)</span>{% endraw %} is closed:</p>
<p> {% raw %}<div class="math display">\[d\theta^a(X,Y)=(\nabla_X\theta^a)(Y)-(\nabla_Y\theta^a)(X)+\theta^a(T(X,Y))=0.\]</div>{% endraw %}</p>
<p> On a star-shaped coordinate ball a closed form {% raw %}<span class="math inline">\(\theta=\mu_i(x)dx^i\)</span>{% endraw %} has the potential {% raw %}<span class="math inline">\(z(x)=\int_0^1\mu_i(tx)x^i\,dt\)</span>{% endraw %}. Differentiating and using {% raw %}<span class="math inline">\(\partial_j\mu_i=\partial_i\mu_j\)</span>{% endraw %} gives {% raw %}<span class="math inline">\(\partial_jz=\int_0^1\frac d{dt}(t\mu_j(tx))dt=\mu_j(x)\)</span>{% endraw %}. Apply this to every coframe member. The resulting {% raw %}<span class="math inline">\(z^a\)</span>{% endraw %}'s have independent differentials and hence form local coordinates by the inverse function theorem. Since {% raw %}<span class="math inline">\(dz^a(E_b)=\delta^a_b\)</span>{% endraw %}, their coordinate fields are exactly the parallel frame. ◻</p>
</div>
<p>We now turn from flatness to scalar measurements of curvature. Normalizing by the squared area of the parallelogram spanned by two tangent vectors makes sectional curvature a quantity associated with the plane itself.</p>

<span id="eq:sectional-curvature"></span>
<div id="def:sectional-curvature" class="definition" data-note-number="3" data-note-kind="Definition">
<p><strong>Definition 3.</strong> With {% raw %}<span class="math inline">\(R(X,Y)Z=\nabla_Y\nabla_XZ-\nabla_X\nabla_YZ+\nabla_{[X,Y]}Z\)</span>{% endraw %}, the sectional curvature of the plane spanned by independent vectors {% raw %}<span class="math inline">\(X,Y\in T_pM\)</span>{% endraw %} is</p>
<p> {% raw %}<div class="math display">\[\kappa(X,Y)=\frac{\langle R(X,Y)X,Y\rangle}{|X\wedge Y|^2},\qquad |X\wedge Y|^2=|X|^2|Y|^2-\langle X,Y\rangle^2.\tag{1}\]</div>{% endraw %}</p>
<p> The denominator is the <em>squared</em> area. Replacing {% raw %}<span class="math inline">\((X,Y)\)</span>{% endraw %} by another basis {% raw %}<span class="math inline">\((aX+bY,cX+dY)\)</span>{% endraw %} multiplies both numerator and denominator by {% raw %}<span class="math inline">\((ad-bc)^2\)</span>{% endraw %}, by skew-symmetry in the two curvature pairs. Hence the quotient depends only on the plane. The order {% raw %}<span class="math inline">\(X,Y\)</span>{% endraw %} in the final two slots is needed for positive curvature of a round sphere under this curvature convention.</p>
</div>
<span id="eq:ricci-curvature"></span>
<div id="def:ricci-curvature" class="definition" data-note-number="4" data-note-kind="Definition">
<p><strong>Definition 4.</strong> For an orthonormal basis {% raw %}<span class="math inline">\(e_1,\ldots,e_n\)</span>{% endraw %} of {% raw %}<span class="math inline">\(T_pM\)</span>{% endraw %}, define</p>
<p> {% raw %}<div class="math display">\[\operatorname{Ric}(X,Y)=\sum_{i=1}^n\langle R(X,e_i)Y,e_i\rangle.\tag{2}\]</div>{% endraw %}</p>
<p> This is a bilinear form on tangent vectors, not a function of a plane. It is independent of the orthonormal basis because it is a trace; under an orthogonal basis change, summing the two basis-change coefficients gives the Kronecker delta. Pair symmetry of curvature gives symmetry in {% raw %}<span class="math inline">\(X,Y\)</span>{% endraw %}. For a unit vector {% raw %}<span class="math inline">\(X=e_n\)</span>{% endraw %}, it equals {% raw %}<span class="math inline">\(\sum_{i&lt;n}\kappa(X,e_i)\)</span>{% endraw %}.</p>
</div>
<p>Clearly, if we know the sectional curvature of <em>all</em> planes containing {% raw %}<span class="math inline">\(p \in M\)</span>{% endraw %}, then we can recover the Riemann curvature tensor. The calculation uses polarization: expand the curvature expression on sums of vectors, then use the curvature symmetries to recover the mixed terms.</p>

<span id="eq:sectional-curvature-riemann-curvature-tensor-formula"></span>
<div id="result-5" class="lemma" data-note-number="5" data-note-kind="Lemma">
<p><strong>Lemma 5 (Curvature from sectional curvatures).</strong> Set {% raw %}<span class="math inline">\(C(X,Y,Z,W)=\langle R(X,Y)Z,W\rangle\)</span>{% endraw %} and {% raw %}<span class="math inline">\(Q(X,Y)=C(X,Y,X,Y)\)</span>{% endraw %}. The sectional curvatures determine {% raw %}<span class="math inline">\(Q\)</span>{% endraw %}, since {% raw %}<span class="math inline">\(Q(X,Y)=\kappa(X,Y)|X\wedge Y|^2\)</span>{% endraw %} for independent vectors and {% raw %}<span class="math inline">\(Q=0\)</span>{% endraw %} for dependent vectors. Define</p>
<p> {% raw %}<div class="math display">\[B(X,Z;Y)=\frac12\{Q(X+Z,Y)-Q(X,Y)-Q(Z,Y)\},\]</div>{% endraw %}</p>
<p></p>
<p> {% raw %}<div class="math display">\[D(X,Z;Y,W)=B(X,Z;Y+W)-B(X,Z;Y)-B(X,Z;W).\]</div>{% endraw %}</p>
<p> Then the full curvature tensor is recovered by</p>
<p> {% raw %}<div class="math display">\[C(X,Y,Z,W)=\frac13\{D(X,Z;Y,W)-D(X,W;Y,Z)\}.\tag{3}\]</div>{% endraw %}</p>
</div>
<span id="eq:id-1-sect-curvature-proof"></span><span id="eq:id-2-sect-curvature-proof"></span><span id="eq:id-3-sect-curvature-proof"></span>
<div class="proof">
<p><em>Proof.</em> Bilinearity and pair symmetry give</p>
<p> {% raw %}<div class="math display">\[B(X,Z;Y)=C(X,Y,Z,Y).\tag{4}\]</div>{% endraw %}</p>
<p> Polarizing the remaining repeated slot gives</p>
<p> {% raw %}<div class="math display">\[D(X,Z;Y,W)=C(X,Y,Z,W)+C(X,W,Z,Y).\tag{5}\]</div>{% endraw %}</p>
<p> To see exactly how the cyclic identity enters, put {% raw %}<span class="math inline">\(a=C(X,Y,Z,W)\)</span>{% endraw %}, {% raw %}<span class="math inline">\(b=C(X,Z,Y,W)\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(c=C(X,W,Y,Z)\)</span>{% endraw %}. The first Bianchi identity and pair symmetry give {% raw %}<span class="math inline">\(a+c-b=0\)</span>{% endraw %}. Formula (5) and skew-symmetry in the last pair give</p>
<p> {% raw %}<div class="math display">\[D(X,Z;Y,W)=a-c,\qquad D(X,W;Y,Z)=-a-b.\tag{6}\]</div>{% endraw %}</p>
<p> Their difference is {% raw %}<span class="math inline">\(2a+b-c=3a\)</span>{% endraw %}, proving (3). Thus no mixed curvature entry remains undetermined. In particular, if all sectional curvatures at {% raw %}<span class="math inline">\(p\)</span>{% endraw %} equal {% raw %}<span class="math inline">\(f(p)\)</span>{% endraw %}, compare with the algebraic tensor {% raw %}<span class="math inline">\(R_0(X,Y)Z=f(p)(\langle X,Z\rangle Y-\langle Y,Z\rangle X)\)</span>{% endraw %}: it has the same {% raw %}<span class="math inline">\(Q\)</span>{% endraw %}, and polarization proves {% raw %}<span class="math inline">\(R=R_0\)</span>{% endraw %} at that point. ◻</p>
</div>
<p>Expanding the two polarizations gives an explicit formula involving only {% raw %}<span class="math inline">\(Q\)</span>{% endraw %}:</p>
{% raw %}<div class="math display">\[\begin{aligned}
6C(X,Y,Z,W)={}&amp;-Q(X+W,Y+Z)+Q(X,Y+Z)+Q(W,Y+Z)\\
&amp;+Q(X+W,Y)-Q(W,Y)+Q(X+W,Z)-Q(X,Z)\\
&amp;+Q(Y+W,Z+X)-Q(Y,Z+X)-Q(W,Z+X)\\
&amp;-Q(Y+W,Z)+Q(Y,Z)-Q(Y+W,X)+Q(W,X).
\end{aligned}\]</div>{% endraw %}
<p>For example, multilinearity first gives</p>
{% raw %}<div class="math display">\[Q(X+W,Y+Z)-Q(X,Y+Z)-Q(W,Y+Z)=2C(X,Y+Z,W,Y+Z).\]</div>{% endraw %}
<p>Expanding the remaining two slots and using Bianchi combines the mixed terms into {% raw %}<span class="math inline">\(6C(X,Y,Z,W)\)</span>{% endraw %} in the displayed formula. If one instead writes {% raw %}<span class="math inline">\(K(X,Y)=C(X,Y,Y,X)\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(K=-Q\)</span>{% endraw %} and every sign in the formula is reversed. This distinction is required by the curvature convention above.</p>
<div id="result-6" class="definition" data-note-number="6" data-note-kind="Definition">
<p><strong>Definition 6</strong>.  Let {% raw %}<span class="math inline">\(M\)</span>{% endraw %} be a differentiable manifold. {% raw %}<span class="math inline">\(M\)</span>{% endraw %} is called a <em>space form</em>, or a space of <em>constant sectional curvature</em>, if {% raw %}<span class="math inline">\(\kappa (X,Y) = K = \text{constant}\)</span>{% endraw %} for all linearly independent tangent vectors {% raw %}<span class="math inline">\(X,Y \in T_p M\)</span>{% endraw %}, where {% raw %}<span class="math inline">\(p \in M\)</span>{% endraw %}.</p>

</div>
<p>We will see some consequences of constant sectional curvature in the sequel. Note that some texts simply refer to these as “spaces of constant curvature”. For now, we note a significant consequence of <em>isotropy</em>.</p>

<div id="thm:schur" class="theorem" data-note-number="7" data-note-kind="Theorem">
<p><strong>Theorem 7 (Schur).</strong> Let {% raw %}<span class="math inline">\(M\)</span>{% endraw %} be a connected Riemannian manifold of dimension {% raw %}<span class="math inline">\(n\geq3\)</span>{% endraw %}. If every tangent two-plane at {% raw %}<span class="math inline">\(p\)</span>{% endraw %} has the same sectional curvature {% raw %}<span class="math inline">\(f(p)\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(f\)</span>{% endraw %} is constant on {% raw %}<span class="math inline">\(M\)</span>{% endraw %}. Without connectedness, it is constant on each component.</p>
</div>
<div class="proof">
<p><em>Proof.</em> By Lemma 5,</p>
<p> {% raw %}<div class="math display">\[R(X,Y)Z=f\bigl(\langle X,Z\rangle Y-\langle Y,Z\rangle X\bigr).\]</div>{% endraw %}</p>
<p> The function {% raw %}<span class="math inline">\(f\)</span>{% endraw %} is smooth: locally evaluate the smooth curvature tensor on a smooth orthonormal pair. Metric compatibility then gives</p>
<p> {% raw %}<div class="math display">\[(\nabla_UR)(X,Y)Z=(Uf)\bigl(\langle X,Z\rangle Y-\langle Y,Z\rangle X\bigr).\]</div>{% endraw %}</p>
<p> At any point choose three mutually orthonormal vectors {% raw %}<span class="math inline">\(U,X,Y\)</span>{% endraw %}, possible because {% raw %}<span class="math inline">\(n\geq3\)</span>{% endraw %}. In the second Bianchi identity</p>
<p> {% raw %}<div class="math display">\[(\nabla_UR)(X,Y)X+(\nabla_XR)(Y,U)X+(\nabla_YR)(U,X)X=0,\]</div>{% endraw %}</p>
<p> the three terms reduce to {% raw %}<span class="math inline">\((Uf)Y\)</span>{% endraw %}, zero, and {% raw %}<span class="math inline">\(-(Yf)U\)</span>{% endraw %}. Taking the inner product with {% raw %}<span class="math inline">\(Y\)</span>{% endraw %} gives {% raw %}<span class="math inline">\(Uf=0\)</span>{% endraw %}. For any chosen unit {% raw %}<span class="math inline">\(U\)</span>{% endraw %}, two perpendicular unit vectors can be selected, so {% raw %}<span class="math inline">\(df=0\)</span>{% endraw %} at every point. Connectedness makes {% raw %}<span class="math inline">\(f\)</span>{% endraw %} globally constant. In dimension two, there is only one tangent two-plane at each point and its curvature may vary, which explains the dimension hypothesis. ◻</p>
</div>
<div id="thm:schur-ricci" class="theorem" data-note-number="8" data-note-kind="Theorem">
<p><strong>Theorem 8 (Schur's lemma for Einstein metrics).</strong> Let {% raw %}<span class="math inline">\(M\)</span>{% endraw %} be a connected Riemannian manifold of dimension {% raw %}<span class="math inline">\(n\geq3\)</span>{% endraw %}. If {% raw %}<span class="math inline">\(\operatorname{Ric}=f g\)</span>{% endraw %} for a smooth function {% raw %}<span class="math inline">\(f\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(f\)</span>{% endraw %} is constant. Equivalently, if {% raw %}<span class="math inline">\(\operatorname{Ric}(X,X)=f(p)\)</span>{% endraw %} for every unit {% raw %}<span class="math inline">\(X\in T_pM\)</span>{% endraw %}, polarization gives the same hypothesis. Such a metric is Einstein.</p>
</div>
<div class="proof">
<p><em>Proof.</em> The contracted second Bianchi identity is</p>
<p> {% raw %}<div class="math display">\[\operatorname{div}\operatorname{Ric}=\frac12\,d\operatorname{Scal},\qquad \operatorname{Scal}=\operatorname{tr}_g\operatorname{Ric}.\]</div>{% endraw %}</p>
<p> Here is the contraction with our signs. At a point use a normal orthonormal frame and write {% raw %}<span class="math inline">\(C_{abcd}=\langle R(e_a,e_b)e_c,e_d\rangle\)</span>{% endraw %}, so {% raw %}<span class="math inline">\(\operatorname{Ric}_{bd}=\sum_a C_{abad}\)</span>{% endraw %}. Contracting the second Bianchi identity in its derivative index and the third curvature slot gives</p>
<p> {% raw %}<div class="math display">\[\sum_i\nabla_i C_{jk i m}-\nabla_j\operatorname{Ric}_{km}+\nabla_k\operatorname{Ric}_{jm}=0.\]</div>{% endraw %}</p>
<p> Now set {% raw %}<span class="math inline">\(m=k\)</span>{% endraw %} and sum over {% raw %}<span class="math inline">\(k\)</span>{% endraw %}. The first term is {% raw %}<span class="math inline">\(\sum_i\nabla_i\operatorname{Ric}_{ji}\)</span>{% endraw %}, the second is {% raw %}<span class="math inline">\(-\nabla_j\operatorname{Scal}\)</span>{% endraw %}, and the third is another copy of the first. This proves the contracted identity.</p>
<p>Under {% raw %}<span class="math inline">\(\operatorname{Ric}=fg\)</span>{% endraw %}, metric compatibility gives {% raw %}<span class="math inline">\(\operatorname{div}\operatorname{Ric}=df\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\operatorname{Scal}=nf\)</span>{% endraw %}. Hence {% raw %}<span class="math inline">\((n-2)df=0\)</span>{% endraw %}. Since {% raw %}<span class="math inline">\(n\geq3\)</span>{% endraw %}, {% raw %}<span class="math inline">\(df=0\)</span>{% endraw %}, and connectedness finishes the proof. A trace equation for Ricci cannot be “uncontracted” to specify the entire Riemann tensor; Einstein metrics need not have constant sectional curvature. ◻</p>
</div>
<div id="lem:ricci-averaged-sectional-curv" class="lemma" data-note-number="9" data-note-kind="Lemma">
<p><strong>Lemma 9 (Ricci as an average).</strong> If {% raw %}<span class="math inline">\(n\geq2\)</span>{% endraw %}, {% raw %}<span class="math inline">\(|X|=1\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(A\)</span>{% endraw %} is the uniform average of sectional curvatures of planes containing {% raw %}<span class="math inline">\(X\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(\operatorname{Ric}(X,X)=(n-1)A\)</span>{% endraw %}.</p>
</div>
<div class="proof">
<p><em>Proof.</em> Complete {% raw %}<span class="math inline">\(X=e_n\)</span>{% endraw %} to an orthonormal basis and let {% raw %}<span class="math inline">\(u=\sum_{j=1}^{n-1}\alpha_je_j\)</span>{% endraw %}, with {% raw %}<span class="math inline">\(\alpha\)</span>{% endraw %} uniformly distributed on {% raw %}<span class="math inline">\(S^{n-2}\)</span>{% endraw %}. Then {% raw %}<span class="math inline">\(X,u\)</span>{% endraw %} is an orthonormal pair. The vectors {% raw %}<span class="math inline">\(u\)</span>{% endraw %} and {% raw %}<span class="math inline">\(-u\)</span>{% endraw %} represent the same plane and give the same curvature, so averaging over this sphere gives the desired plane average.</p>
<p>Reflection of one coordinate makes {% raw %}<span class="math inline">\(\mathbb E\alpha_j\alpha_k=0\)</span>{% endraw %} for {% raw %}<span class="math inline">\(j\ne k\)</span>{% endraw %}. Permutation invariance makes all diagonal moments equal, and {% raw %}<span class="math inline">\(\sum_j\alpha_j^2=1\)</span>{% endraw %} gives {% raw %}<span class="math inline">\(\mathbb E\alpha_j^2=1/(n-1)\)</span>{% endraw %}. Therefore</p>
<p> {% raw %}<div class="math display">\[A=\mathbb E\langle R(X,u)X,u\rangle =\sum_{j,k}\mathbb E(\alpha_j\alpha_k)\langle R(X,e_j)X,e_k\rangle =\frac1{n-1}\sum_{j&lt;n}\langle R(X,e_j)X,e_j\rangle.\]</div>{% endraw %}</p>
<p> The omitted {% raw %}<span class="math inline">\(j=n\)</span>{% endraw %} term is zero, so the sum is {% raw %}<span class="math inline">\(\operatorname{Ric}(X,X)\)</span>{% endraw %}. For {% raw %}<span class="math inline">\(n=2\)</span>{% endraw %}, the sphere is {% raw %}<span class="math inline">\(S^0=\{-1,1\}\)</span>{% endraw %} with equal weights and the same calculation applies. No beta-integral normalization or curvature model is needed. ◻</p>
</div>
<h3 data-note-section="1" id="space-forms">1. Space Forms</h3>
<p>Spaces of constant sectional curvature provide explicit models for comparison geometry. The next theorem identifies their complete simply connected models. Passing to the universal cover separates the local curvature condition from the possible global identifications.</p>

<div id="thm:sectional-curvature-isometric" class="theorem" data-note-number="10" data-note-kind="Theorem">
<p><strong>Theorem 10 (Simply connected space-form models).</strong> Let {% raw %}<span class="math inline">\(M\)</span>{% endraw %} be a connected complete Riemannian manifold without boundary of dimension {% raw %}<span class="math inline">\(n\geq2\)</span>{% endraw %}, with constant sectional curvature {% raw %}<span class="math inline">\(K\)</span>{% endraw %}. Its universal cover with the lifted metric is isometric to the complete simply connected model: Euclidean {% raw %}<span class="math inline">\(\mathbb R^n\)</span>{% endraw %} for {% raw %}<span class="math inline">\(K=0\)</span>{% endraw %}, the sphere of radius {% raw %}<span class="math inline">\(K^{-1/2}\)</span>{% endraw %} for {% raw %}<span class="math inline">\(K&gt;0\)</span>{% endraw %}, or hyperbolic space with metric scaled to curvature {% raw %}<span class="math inline">\(K\)</span>{% endraw %} for {% raw %}<span class="math inline">\(K&lt;0\)</span>{% endraw %}. In particular the normalized cases {% raw %}<span class="math inline">\(K=-1,0,1\)</span>{% endraw %} give {% raw %}<span class="math inline">\(\mathbb H^n,\mathbb R^n,\mathbb S^n\)</span>{% endraw %}, respectively. In dimension one the complete simply connected model is the real line; sectional curvature is not defined on any tangent two-plane there.</p>
</div>
<p>We need a uniqueness fact for local isometries: their value and differential at one point determine them on a connected domain.</p>

<div id="lem:isometry-equivalence-by-differential" class="lemma" data-note-number="11" data-note-kind="Lemma">
<p><strong>Lemma 11</strong>.  Let {% raw %}<span class="math inline">\(M\)</span>{% endraw %} and {% raw %}<span class="math inline">\(N\)</span>{% endraw %} be connected, differentiable manifolds. Let {% raw %}<span class="math inline">\(f_i : M \to N\)</span>{% endraw %} be local isometries for {% raw %}<span class="math inline">\(i = 1,2\)</span>{% endraw %}. If there exists a {% raw %}<span class="math inline">\(p \in M\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(f_1 (p) = f_2 (p)\)</span>{% endraw %}, and {% raw %}<span class="math inline">\((\dif f_1)_p = (\dif f_2)_p\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(f_1 = f_2\)</span>{% endraw %} on {% raw %}<span class="math inline">\(M\)</span>{% endraw %}.</p>

</div>
<div class="proof">
<p><em>Proof.</em> A local isometry preserves the Levi–Civita connection, by uniqueness of the metric torsion-free connection, and therefore maps geodesics with their affine parameters to geodesics. Consequently, for sufficiently small {% raw %}<span class="math inline">\(v\in T_pM\)</span>{% endraw %},</p>
<p> {% raw %}<div class="math display">\[f_i(\exp_p^M v)=\exp_{f_i(p)}^N((df_i)_pv).\]</div>{% endraw %}</p>
<p> Equal values and differentials at {% raw %}<span class="math inline">\(p\)</span>{% endraw %} therefore imply equality on a normal neighbourhood of {% raw %}<span class="math inline">\(p\)</span>{% endraw %}, and then equality of their differentials on that neighbourhood.</p>
<p>Let {% raw %}<span class="math inline">\(A\)</span>{% endraw %} be the set of points where both their values and differentials agree. It is nonempty by hypothesis and open by the preceding argument applied at each point of {% raw %}<span class="math inline">\(A\)</span>{% endraw %}. It is closed: equality of values passes to limits by continuity, and in common coordinate charts around a limiting pair of image points, equality of the derivative matrices also passes to the limit. Connectedness of {% raw %}<span class="math inline">\(M\)</span>{% endraw %} gives {% raw %}<span class="math inline">\(A=M\)</span>{% endraw %}. The exponential on the right belongs to the target manifold and is based at the image point, not at {% raw %}<span class="math inline">\(p\)</span>{% endraw %}. ◻</p>
</div>
<div class="proof">
<p><em>Proof of Theorem 10.</em> The universal cover has the pulled-back metric, so its projection is a local isometry and its curvature is still {% raw %}<span class="math inline">\(K\)</span>{% endraw %}. It is complete: a geodesic upstairs projects to a geodesic downstairs, which exists for all time by Hopf–Rinow; the path-lifting property of a covering lifts this extension, and local isometry shows the lift continues the original geodesic. Thus the cover is geodesically complete and hence metrically complete. Denote it by {% raw %}<span class="math inline">\(\widetilde M\)</span>{% endraw %}.</p>
<p>We first justify the local isometries used in the construction. Put</p>
<p> {% raw %}<div class="math display">\[S_K(r)=\begin{cases}\sin(\sqrt K r)/\sqrt K,&amp;K&gt;0,\\r,&amp;K=0,\\\sinh(\sqrt{-K}r)/\sqrt{-K},&amp;K&lt;0.\end{cases}\]</div>{% endraw %}</p>
<p> Along a unit radial geodesic, an angular Jacobi field with initial data {% raw %}<span class="math inline">\(J(0)=0\)</span>{% endraw %}, {% raw %}<span class="math inline">\(D_rJ(0)=w\perp\dot\gamma(0)\)</span>{% endraw %} solves {% raw %}<span class="math inline">\(D_r^2J+KJ=0\)</span>{% endraw %}, because {% raw %}<span class="math inline">\(R(\dot\gamma,J)\dot\gamma=KJ\)</span>{% endraw %}. After parallel transport to the initial tangent space, ODE uniqueness gives {% raw %}<span class="math inline">\(J(r)=S_K(r)P_rw\)</span>{% endraw %}. The Gauss lemma makes radial and angular directions orthogonal. Therefore the exponential pullback metric is</p>
<p> {% raw %}<div class="math display">\[dr^2+S_K(r)^2g_{S^{n-1}}.\]</div>{% endraw %}</p>
<p> This holds wherever the radial exponential is a local diffeomorphism; the displayed differential shows that it is one for {% raw %}<span class="math inline">\(r&gt;0\)</span>{% endraw %} with {% raw %}<span class="math inline">\(S_K(r)\ne0\)</span>{% endraw %}, and at zero its derivative is the identity. This computation proves that radial maps between two curvature-{% raw %}<span class="math inline">\(K\)</span>{% endraw %} manifolds with an initial tangent-space isometry are local isometries on the indicated domains.</p>
<p>For {% raw %}<span class="math inline">\(K\leq0\)</span>{% endraw %}, let {% raw %}<span class="math inline">\(\Xi\)</span>{% endraw %} be the Euclidean or scaled hyperbolic model, choose {% raw %}<span class="math inline">\(p\in\Xi\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\widetilde p\in\widetilde M\)</span>{% endraw %}, and a linear isometry {% raw %}<span class="math inline">\(I:T_p\Xi\to T_{\widetilde p}\widetilde M\)</span>{% endraw %}. The model exponential is a global diffeomorphism (in hyperbolic polar coordinates its radial lines cover the model uniquely). Completeness defines {% raw %}<span class="math inline">\(\exp_{\widetilde p}\)</span>{% endraw %} on the entire tangent space. Hence</p>
<p> {% raw %}<div class="math display">\[F=\exp_{\widetilde p}\circ I\circ(\exp_p^\Xi)^{-1}:\Xi\to\widetilde M\]</div>{% endraw %}</p>
<p> is globally defined and is a local isometry by the pullback-metric calculation.</p>
<p>We use the following covering fact. A local isometry from a connected complete Riemannian manifold to a connected Riemannian manifold is a surjective covering map. To prove it, lift a piecewise smooth path starting at an image point by local inverses. If its maximal lift stops at a finite parameter, the remaining path lengths tend to zero, so the lift is Cauchy; completeness supplies a limiting point and a local inverse extends it. Every point of the connected target is reachable by such a path, proving surjectivity. Take a sufficiently small normal ball about any target point. For each point in its fibre, lift its radial geodesics to obtain an inverse sheet. The sheets are open by the local inverse theorem, disjoint by uniqueness of lifts (reverse the radial path), and cover the preimage by lifting the reverse radial paths. This is exactly an evenly covered neighbourhood. A connected covering of a simply connected space has one sheet, by lifting homotopies of paths. Applying this to {% raw %}<span class="math inline">\(F\)</span>{% endraw %} gives a diffeomorphism; a bijective local isometry is an isometry.</p>
<p>For {% raw %}<span class="math inline">\(K&gt;0\)</span>{% endraw %}, rescale to {% raw %}<span class="math inline">\(K=1\)</span>{% endraw %}. Let {% raw %}<span class="math inline">\(\Xi=S^n\)</span>{% endraw %} and let {% raw %}<span class="math inline">\(q\)</span>{% endraw %} be antipodal to {% raw %}<span class="math inline">\(p\)</span>{% endraw %}. The model exponential gives a diffeomorphism from the tangent ball of radius {% raw %}<span class="math inline">\(\pi\)</span>{% endraw %} onto {% raw %}<span class="math inline">\(S^n\setminus\{q\}\)</span>{% endraw %}. The same radial formula therefore gives a local isometry {% raw %}<span class="math inline">\(F\)</span>{% endraw %} on this punctured sphere, because {% raw %}<span class="math inline">\(\sin r&gt;0\)</span>{% endraw %} for {% raw %}<span class="math inline">\(0&lt;r&lt;\pi\)</span>{% endraw %}. Choose {% raw %}<span class="math inline">\(p'\ne p,q\)</span>{% endraw %}, put {% raw %}<span class="math inline">\(\widetilde p'=F(p')\)</span>{% endraw %}, and use {% raw %}<span class="math inline">\(I'=(dF)_{p'}\)</span>{% endraw %} to construct {% raw %}<span class="math inline">\(F'\)</span>{% endraw %} on the sphere minus the antipode {% raw %}<span class="math inline">\(q'\)</span>{% endraw %} of {% raw %}<span class="math inline">\(p'\)</span>{% endraw %}. The overlap {% raw %}<span class="math inline">\(S^n\setminus\{q,q'\}\)</span>{% endraw %} is connected for {% raw %}<span class="math inline">\(n\geq2\)</span>{% endraw %}. At {% raw %}<span class="math inline">\(p'\)</span>{% endraw %}, both maps have the same value and differential, so Lemma 11 makes them agree on the whole overlap. They patch to a local isometry {% raw %}<span class="math inline">\(G:S^n\to\widetilde M\)</span>{% endraw %}. The sphere is complete, so the covering fact applies again; simple connectivity of the target makes {% raw %}<span class="math inline">\(G\)</span>{% endraw %} a global isometry. Rescaling the metric gives radius {% raw %}<span class="math inline">\(K^{-1/2}\)</span>{% endraw %} and completes the positive-curvature case. ◻</p>
</div>
