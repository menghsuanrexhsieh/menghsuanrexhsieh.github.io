<h3 data-note-section="1" id="motivation-and-justifications-for-the-study-of-zeros-of-functions">1. Critical points and topology</h3>
<p>A smooth function filters a manifold by its sublevel sets. As the level rises through an interval without critical values, gradient flow can identify the levels under suitable compactness hypotheses. At a nondegenerate critical point, the Hessian describes the local change. Morse theory uses these local changes to study the topology of the manifold.</p>

<p>To motivate the study of connections between geometry and topology, let {% raw %}<span class="math inline">\(X\)</span>{% endraw %} be a complete differentiable manifold. Let {% raw %}<span class="math inline">\(f\)</span>{% endraw %} be a smooth real-valued function on {% raw %}<span class="math inline">\(X\)</span>{% endraw %}. The essential feature of this theory and its generalizations is the relationship between the structure of the <em>critical set of {% raw %}<span class="math inline">\(f\)</span>{% endraw %}</em>, </p>

{% raw %}<div class="math display">\[\begin{aligned}
    \operatorname{Crit}(f) \triangleq \left\{ x \in X : \dif f (x) = 0 \right\} ~,
\end{aligned}\]</div>{% endraw %}
<p> the space of trajectories for the gradient flow of {% raw %}<span class="math inline">\(f\)</span>{% endraw %}, and the topology of {% raw %}<span class="math inline">\(X\)</span>{% endraw %}. Informally, we can see the features of this theory in an example as follows. Let us consider a compact Riemannian manifold {% raw %}<span class="math inline">\(X\)</span>{% endraw %}, which is diffeomorphic to {% raw %}<span class="math inline">\(\mathbb S^2\)</span>{% endraw %}, and we study smooth functions on {% raw %}<span class="math inline">\(X\)</span>{% endraw %}. In this theory, we want to extract information about the global topology of {% raw %}<span class="math inline">\(X\)</span>{% endraw %} from the critical points of {% raw %}<span class="math inline">\(f\)</span>{% endraw %}. Clearly, this number is <em>not</em> a topological invariant. One way in which we can distinguish topological features is, to each critical point {% raw %}<span class="math inline">\(p\)</span>{% endraw %}, assign the number of linearly independent directions on which the second derivative {% raw %}<span class="math inline">\(\dif^{\:2}\! f(p)\)</span>{% endraw %} is negative definite. The study of Morse theory, therefore, immediately contains a series of local questions. We begin with the local behaviour of the gradient flow and then describe how crossing a critical value attaches a handle.</p>

<div id="def:morse-function" class="definition" data-note-number="1" data-note-kind="Definition">
<p><strong>Definition 1.</strong> A {% raw %}<span class="math inline">\(C^2\)</span>{% endraw %} function {% raw %}<span class="math inline">\(f\)</span>{% endraw %} on a finite-dimensional smooth manifold {% raw %}<span class="math inline">\(X\)</span>{% endraw %} is <em>Morse</em> if its Hessian is nondegenerate at every critical point. At a critical point {% raw %}<span class="math inline">\(p\)</span>{% endraw %}, the Hessian defines the linear isomorphism {% raw %}<span class="math inline">\(A:T_pX\to T_p^*X\)</span>{% endraw %}, {% raw %}<span class="math inline">\(A(u)(v)=d^2f_p(u,v)\)</span>{% endraw %}. Neither completeness nor a Riemannian metric is needed for this definition. Below, functions are smooth when smooth normal forms and flows are used.</p>
</div>
<div id="def:morse-index" class="definition" data-note-number="2" data-note-kind="Definition">
<p><strong>Definition 2.</strong> The Morse index {% raw %}<span class="math inline">\(\mu(p)\)</span>{% endraw %} is the largest dimension of a linear subspace on which {% raw %}<span class="math inline">\(d^2f_p\)</span>{% endraw %} is negative definite. After choosing an inner product, it is the number of negative eigenvalues of the associated self-adjoint operator, counted with multiplicity. Sylvester's law of inertia makes this number independent of that choice and of coordinates. Thus {% raw %}<span class="math inline">\(0\le\mu(p)\le\dim X\)</span>{% endraw %}, including index zero, and {% raw %}<span class="math inline">\(\operatorname{Crit}_k(f)\)</span>{% endraw %} denotes the critical points of index {% raw %}<span class="math inline">\(k\)</span>{% endraw %}.</p>
</div>

<p>After choosing a Riemannian metric, the negative gradient flow solves</p>
 {% raw %}<span id="eq:morse-ode-1"></span><span id="eq:morse-ode-2"></span>
<div class="math display">\[\partial_t\varphi(t,x)=-\nabla f(\varphi(t,x)),\qquad \varphi(0,x)=x.\tag{1}\]</div>{% endraw %}
<p> It is defined on an open maximal domain {% raw %}<span class="math inline">\(\mathcal D\subset\mathbb R\times X\)</span>{% endraw %}, not necessarily on all of {% raw %}<span class="math inline">\(\mathbb R\times X\)</span>{% endraw %}. Local ODE existence and uniqueness give the flow law whenever both sides are defined. The time-{% raw %}<span class="math inline">\(t\)</span>{% endraw %} map is a diffeomorphism between its open domain and the domain of the inverse time-{% raw %}<span class="math inline">\((-t)\)</span>{% endraw %} map. Along a trajectory,</p>
{% raw %}<div class="math display">\[\frac{d}{dt}f(\varphi(t,x))=-|\nabla f|^2.\]</div>{% endraw %}
<p> Compactness of {% raw %}<span class="math inline">\(X\)</span>{% endraw %} guarantees existence for all time. Completeness of the Riemannian metric alone does not: on complete {% raw %}<span class="math inline">\(\mathbb R\)</span>{% endraw %}, the function {% raw %}<span class="math inline">\(f(x)=-x^3/3\)</span>{% endraw %} has negative gradient {% raw %}<span class="math inline">\(x^2\)</span>{% endraw %}, whose solution from {% raw %}<span class="math inline">\(x&gt;0\)</span>{% endraw %} escapes in finite positive time.</p><p>With this in mind, we can then study the main features of Morse theory through a simple example: let {% raw %}<span class="math inline">\(X\)</span>{% endraw %} be a compact Riemannian manifold that is diffeomorphic to {% raw %}<span class="math inline">\(\mathbb S^2 \subset \mathbb R^3\)</span>{% endraw %}. The goal is to study all smooth functions defined on {% raw %}<span class="math inline">\(X\)</span>{% endraw %}. We seek information about the global topology of {% raw %}<span class="math inline">\(X\)</span>{% endraw %} from the critical points of smooth functions {% raw %}<span class="math inline">\(f\)</span>{% endraw %}. It is clear that the number of critical points is not an invariant: this is why we wanted to define the Morse index to begin with (Definition <a href="#def:morse-index" data-reference-type="ref" data-reference="def:morse-index">2</a>). The motivation is clear through the following functions {% raw %}<span class="math inline">\(f_1\)</span>{% endraw %} and {% raw %}<span class="math inline">\(f_2\)</span>{% endraw %}, illustrated in <a href="#fig:morse-example">the figure below</a>.</p>

<figure id="fig:morse-example">
<img src="{{ '/assets/images/notes/02/morse.png' | relative_url }}" style="width:70.0%" />
<figcaption>Real-valued smooth functions on a surface diffeomorphic to the sphere.</figcaption>
</figure>
<p>For the value {% raw %}<span class="math inline">\(p_1\)</span>{% endraw %}, the Morse index of {% raw %}<span class="math inline">\(p_1\)</span>{% endraw %} associated with the function {% raw %}<span class="math inline">\(f_1\)</span>{% endraw %} is {% raw %}<span class="math inline">\(\mu_{f_1} (p_1) = 2\)</span>{% endraw %}, because there are two linearly independent directions for which the negative gradient flow (flowing “downwards”) goes away from the critical point ({% raw %}<span class="math inline">\(p_1\)</span>{% endraw %} is the global maximum). Likewise, {% raw %}<span class="math inline">\(\mu_{f_2} (p_1) = \mu_{f_2} (p_2) = 2\)</span>{% endraw %}, while {% raw %}<span class="math inline">\(\mu_{f_1} (p_2) = \mu_{f_2} (p_4) = 0\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\mu_{f_2} (p_3) = 1\)</span>{% endraw %}. In light of this example, let us look at the following objects.</p>

<div id="def:stable-unstable-manifolds" class="definition" data-note-number="3" data-note-kind="Definition">
<p><strong>Definition 3</strong>.  The <em>stable</em> and <em>unstable manifolds at {% raw %}<span class="math inline">\(x_0 \in X\)</span>{% endraw %}</em> of the flow {% raw %}<span class="math inline">\(\varphi\)</span>{% endraw %} are defined as </p>

{% raw %}<span id="eq:stable-manifold"></span><span id="eq:unstable-manifold"></span><div class="math display">\[\begin{aligned}
         X^s (x_0) &amp;\triangleq \left\{ y \in X : \varphi(t,y) \xrightarrow{t\to\infty} x_0 \right\} \\
         X^u (x_0) &amp;\triangleq \left\{ y \in X : \varphi(t,y) \xrightarrow{t\to-\infty} x_0 \right\}
    
\end{aligned}\tag{2}\]</div>{% endraw %}
<p>Here {% raw %}<span class="math inline">\(x_0\)</span>{% endraw %} is a critical point, and the definition includes existence of the trajectory for all forward times in the stable case and all backward times in the unstable case. Initially these are sets; their manifold structure is a theorem, not a consequence of their definition.</p>
</div>
<p>For this topological conclusion, assume that {% raw %}<span class="math inline">\(X\)</span>{% endraw %} is compact without boundary and {% raw %}<span class="math inline">\(f\)</span>{% endraw %} is a smooth Morse function. Its critical points are isolated and form a closed set, hence there are finitely many. The Morse cell-attachment theorem gives a finite CW complex homotopy equivalent to {% raw %}<span class="math inline">\(X\)</span>{% endraw %}, with one cell of dimension {% raw %}<span class="math inline">\(\mu(p)\)</span>{% endraw %} for each critical point {% raw %}<span class="math inline">\(p\)</span>{% endraw %}. Write {% raw %}<span class="math inline">\(c_k(f)=\#\operatorname{Crit}_k(f)\)</span>{% endraw %}. Each {% raw %}<span class="math inline">\(k\)</span>{% endraw %}-cell contributes {% raw %}<span class="math inline">\((-1)^k\)</span>{% endraw %} to the Euler characteristic, so the contribution of a critical point is determined by the parity of its index:</p>

{% raw %}<div class="math display">\[\begin{aligned}
    \chi(X)=\sum_{k=0}^{\dim X}(-1)^k c_k(f)=\sum_{p\in\operatorname{Crit}(f)}(-1)^{\mu(p)} ~.
\end{aligned}\]</div>{% endraw %}
<p>The equality is the alternating sum of the numbers of critical points of each index. For example, a height function on {% raw %}<span class="math inline">\(\mathbb S^2\)</span>{% endraw %} has one minimum and one maximum, contributing {% raw %}<span class="math inline">\(1+1=2\)</span>{% endraw %}. This argument uses the cell-attachment theorem; see <a href="https://math.stanford.edu/~ralph/morsecourse/biglectures.pdf">Cohen, Iga and Norbury, <em>Topics in Morse Theory</em>, Introduction, Theorem 1</a>.</p>
<p>The finite CW model gives a precise chain complex over {% raw %}<span class="math inline">\(\mathbb Z_2\)</span>{% endraw %}. Its group {% raw %}<span class="math inline">\(C_k\)</span>{% endraw %} has one generator for each index-{% raw %}<span class="math inline">\(k\)</span>{% endraw %} critical point; the cellular attaching maps define {% raw %}<span class="math inline">\(\partial_k:C_k\to C_{k-1}\)</span>{% endraw %}, with {% raw %}<span class="math inline">\(\partial_{k-1}\partial_k=0\)</span>{% endraw %}. Consequently</p>
{% raw %}<div class="math display">\[H_k(X;\mathbb Z_2)\cong\ker\partial_k/\operatorname{im}\partial_{k+1}.\]</div>{% endraw %}
<p> The differential is not determined just by the list of critical points. Describing it by counting gradient trajectories requires a Morse–Smale transversality hypothesis and a separate compactness argument; the cellular definition suffices here.</p><p>The local stable-manifold argument explains the role of the Hessian. In coordinates centered at a nondegenerate critical point, with the metric Euclidean at that point, write the negative gradient vector field as</p>
{% raw %}<div class="math display">\[z'=Az+\eta(z),\qquad A=-\operatorname{Hess}_pf,\qquad \eta(0)=D\eta(0)=0.\]</div>{% endraw %}
<p> On a small convex ball the mean value estimate gives {% raw %}<span class="math inline">\(|\eta(x)-\eta(y)|\le\delta(\varepsilon)|x-y|\)</span>{% endraw %}, where {% raw %}<span class="math inline">\(\delta(\varepsilon)\to0\)</span>{% endraw %} as {% raw %}<span class="math inline">\(\varepsilon\to0\)</span>{% endraw %}. This is a local coordinate remainder, not a map {% raw %}<span class="math inline">\(X\to X\)</span>{% endraw %}. Split into the stable and unstable eigenspaces {% raw %}<span class="math inline">\(E_s,E_u\)</span>{% endraw %}, with {% raw %}<span class="math inline">\(A_s\le-aI\)</span>{% endraw %}, {% raw %}<span class="math inline">\(A_u\ge aI\)</span>{% endraw %}, {% raw %}<span class="math inline">\(a&gt;0\)</span>{% endraw %}. After a cutoff with sufficiently small Lipschitz norm, a bounded forward solution with stable initial coordinate {% raw %}<span class="math inline">\(s\)</span>{% endraw %} must satisfy</p>
{% raw %}<div class="math display">\[\begin{split} z_s(t)&amp;=e^{tA_s}s+\int_0^t e^{(t-r)A_s}\eta_s(z(r))\,dr,\\ z_u(t)&amp;=-\int_t^\infty e^{(t-r)A_u}\eta_u(z(r))\,dr. \end{split}\]</div>{% endraw %}
<p> The second formula follows from variation of constants and boundedness as {% raw %}<span class="math inline">\(t\to\infty\)</span>{% endraw %}. The right side is a contraction on bounded continuous paths when {% raw %}<span class="math inline">\(2\operatorname{Lip}(\eta)/a&lt;1\)</span>{% endraw %}. It is also a contraction in the weighted norm {% raw %}<span class="math inline">\(\sup_{t\ge0}e^{\beta t}|z(t)|\)</span>{% endraw %}, for {% raw %}<span class="math inline">\(0&lt;\beta&lt;a\)</span>{% endraw %} and sufficiently small remainder, because the integral bound is {% raw %}<span class="math inline">\(\operatorname{Lip}(\eta)((a-\beta)^{-1}+(a+\beta)^{-1})\)</span>{% endraw %}. The integral operator’s unique fixed point therefore decays exponentially. Smooth parameter dependence of this contraction gives a smooth graph {% raw %}<span class="math inline">\(z_u(0)=h(s)\)</span>{% endraw %}; differentiating at {% raw %}<span class="math inline">\(s=0\)</span>{% endraw %} gives {% raw %}<span class="math inline">\(Dh(0)=0\)</span>{% endraw %}. This proves that the local stable set is a disk tangent to {% raw %}<span class="math inline">\(E_s\)</span>{% endraw %}, of dimension {% raw %}<span class="math inline">\(\dim X-\mu(p)\)</span>{% endraw %}. Reversing time gives the unstable disk of dimension {% raw %}<span class="math inline">\(\mu(p)\)</span>{% endraw %}. The global stable and unstable sets acquire their immersed manifold structures by pulling back these disks along the flow. Local sets require trajectories to stay in the coordinate neighborhood; they are not identical to the global sets.</p>
<p>For a metric chosen Euclidean in Morse coordinates, the same conclusion is explicit: {% raw %}<span class="math inline">\(z_-(t)=e^{2t}z_-(0)\)</span>{% endraw %} and {% raw %}<span class="math inline">\(z_+(t)=e^{-2t}z_+(0)\)</span>{% endraw %}. The local stable disk is {% raw %}<span class="math inline">\(z_-=0\)</span>{% endraw %}, and the local unstable disk is {% raw %}<span class="math inline">\(z_+=0\)</span>{% endraw %}. This supplies the geometric interpretation of the indices in the figure.</p><h3 data-note-section="2" id="morse-functions">2. Morse Functions</h3>
<p>We next check which features of critical points are independent of coordinates for a function {% raw %}<span class="math inline">\(f\)</span>{% endraw %} on a manifold. These local results concern critical points of a function {% raw %}<span class="math inline">\(f\)</span>{% endraw %} on a manifold {% raw %}<span class="math inline">\(M\)</span>{% endraw %}.</p>

<div id="lem:crit-points-indep-chart" class="lemma" data-note-number="4" data-note-kind="Lemma">
<p><strong>Lemma 4</strong>.  Let {% raw %}<span class="math inline">\(f: M \to \mathbb R\)</span>{% endraw %} be a smooth function on a differentiable manifold {% raw %}<span class="math inline">\(M\)</span>{% endraw %}. The critical points of {% raw %}<span class="math inline">\(f\)</span>{% endraw %} are independent of the chart chosen for {% raw %}<span class="math inline">\(M\)</span>{% endraw %}.</p>

</div>
<div class="proof">
<p><em>Proof.</em> On the overlap of charts, put {% raw %}<span class="math inline">\(F=f\circ\varphi^{-1}\)</span>{% endraw %}, {% raw %}<span class="math inline">\(G=f\circ\psi^{-1}\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(h=\varphi\circ\psi^{-1}\)</span>{% endraw %}. These functions are defined on the chart images, and {% raw %}<span class="math inline">\(G=F\circ h\)</span>{% endraw %}. The chain rule gives {% raw %}<span class="math inline">\(dG_y=dF_{h(y)}\circ dh_y\)</span>{% endraw %}. Since the smooth transition map has invertible derivative, one differential vanishes if and only if the other does. At a critical point, the second derivative chain rule reduces to</p>
{% raw %}<div class="math display">\[D^2G_y(u,v)=D^2F_{h(y)}(dh_yu,dh_yv),\]</div>{% endraw %}
<p> since the term involving {% raw %}<span class="math inline">\(dF\)</span>{% endraw %} vanishes. Hence the critical Hessian is a coordinate-independent bilinear form, and its nondegeneracy and index are intrinsic. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>
</div>
<div id="lem:all-crit-points-are-isolated" class="lemma" data-note-number="5" data-note-kind="Lemma">
<p><strong>Lemma 5</strong>. Every nondegenerate critical point of a smooth function {% raw %}<span class="math inline">\(f:M\to\mathbb R\)</span>{% endraw %} is isolated. In particular, all critical points of a Morse function are isolated.</p>
</div>
<div class="proof">
<p><em>Proof.</em> Choose coordinates centred at a nondegenerate critical point {% raw %}<span class="math inline">\(p\)</span>{% endraw %}, and write {% raw %}<span class="math inline">\(F=f\circ\varphi^{-1}\)</span>{% endraw %}. Consider the coordinate derivative map {% raw %}<span class="math inline">\(G=(\partial_1F,\ldots,\partial_nF)\)</span>{% endraw %}. Then {% raw %}<span class="math inline">\(G(0)=0\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(DG(0)\)</span>{% endraw %} is the invertible Hessian matrix of {% raw %}<span class="math inline">\(F\)</span>{% endraw %} at {% raw %}<span class="math inline">\(0\)</span>{% endraw %}. The inverse function theorem makes {% raw %}<span class="math inline">\(G\)</span>{% endraw %} injective on a neighbourhood of {% raw %}<span class="math inline">\(0\)</span>{% endraw %}. Hence {% raw %}<span class="math inline">\(G(x)=0\)</span>{% endraw %} only at {% raw %}<span class="math inline">\(x=0\)</span>{% endraw %} in that neighbourhood, proving isolation. A nondegenerate critical point need not be a local extremum: {% raw %}<span class="math inline">\(F(x,y)=x^2-y^2\)</span>{% endraw %} has a nondegenerate saddle at the origin. ◻</p>

</div>
<p>A more general fact about <em>vanishing derivatives</em> is the following.</p>


<div id="lem:vanishing-derivatives-smooth-manifold" class="lemma" data-note-number="6" data-note-kind="Lemma">
<p><strong>Lemma 6.</strong> Let {% raw %}<span class="math inline">\(f\)</span>{% endraw %} be smooth and let {% raw %}<span class="math inline">\(\ell\ge0\)</span>{% endraw %} be an integer. If all partial derivatives of orders {% raw %}<span class="math inline">\(1,\ldots,\ell\)</span>{% endraw %} vanish at {% raw %}<span class="math inline">\(p\)</span>{% endraw %} in one chart, they vanish at {% raw %}<span class="math inline">\(p\)</span>{% endraw %} in every chart. For {% raw %}<span class="math inline">\(\ell=0\)</span>{% endraw %}, the assertion is vacuous.</p>
<p>In a chart {% raw %}<span class="math inline">\(\varphi\)</span>{% endraw %} centered at {% raw %}<span class="math inline">\(p\)</span>{% endraw %}, the hypothesis is</p>
 {% raw %}<span id="eq:vanishing-order-ell"></span>
<div class="math display">\[\partial_{i_1}\cdots\partial_{i_r}(f\circ\varphi^{-1})(\varphi(p))=0 \quad(1\leq r\leq\ell).\tag{3}\]</div>{% endraw %}
</div>
<div class="proof">
<p><em>Proof.</em> Write {% raw %}<span class="math inline">\(G=F\circ h\)</span>{% endraw %} for the coordinate transition. Repeated use of the product and chain rules shows inductively that every derivative of {% raw %}<span class="math inline">\(G\)</span>{% endraw %} of order {% raw %}<span class="math inline">\(r\ge1\)</span>{% endraw %} is a sum of terms, each containing a derivative {% raw %}<span class="math inline">\(D^sF\)</span>{% endraw %} with {% raw %}<span class="math inline">\(1\le s\le r\)</span>{% endraw %}, evaluated at {% raw %}<span class="math inline">\(h(y)\)</span>{% endraw %}, multiplied by derivatives of {% raw %}<span class="math inline">\(h\)</span>{% endraw %}. For {% raw %}<span class="math inline">\(r\le\ell\)</span>{% endraw %}, each such factor vanishes at {% raw %}<span class="math inline">\(p\)</span>{% endraw %}. The derivative expansion proves the coordinate invariance in <a href="#lem:vanishing-derivatives-smooth-manifold">Lemma 6</a> from the hypothesis in one chart; it does not assume it in both charts. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>
</div>
<div id="result-7" class="theorem" data-note-number="7" data-note-kind="Theorem">
<p><strong>Theorem 7 (Morse–Sard–Federer).</strong> Let {% raw %}<span class="math inline">\(f:M^m\to N^n\)</span>{% endraw %} be smooth, {% raw %}<span class="math inline">\(n\ge1\)</span>{% endraw %}, and let</p>
{% raw %}<div class="math display">\[\Delta_f=f(\{x:\operatorname{rank}df_x&lt;n\})\subset N\]</div>{% endraw %}
<p> be its set of <em>critical values</em>. Then {% raw %}<span class="math inline">\(\dim_H\Delta_f\le n-1\)</span>{% endraw %}, in particular {% raw %}<span class="math inline">\(\Delta_f\)</span>{% endraw %} has zero {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-dimensional measure in smooth charts. Regular values are dense in {% raw %}<span class="math inline">\(N\)</span>{% endraw %}, and regular values belonging to {% raw %}<span class="math inline">\(f(M)\)</span>{% endraw %} are dense in {% raw %}<span class="math inline">\(\operatorname{int}f(M)\)</span>{% endraw %}.</p>
<p>This is a theorem used here. To explain the dimension conclusion, if {% raw %}<span class="math inline">\(m\ge n\)</span>{% endraw %}, the finite-regularity bound gives {% raw %}<span class="math inline">\(\dim_H\Delta_f\le n-1+(m-n+1)/k\)</span>{% endraw %} for every {% raw %}<span class="math inline">\(k\)</span>{% endraw %}; smoothness lets {% raw %}<span class="math inline">\(k\to\infty\)</span>{% endraw %}. If {% raw %}<span class="math inline">\(m&lt;n\)</span>{% endraw %}, local Lipschitzness gives {% raw %}<span class="math inline">\(\dim_H f(M)\le m\le n-1\)</span>{% endraw %}. Countably many relatively compact charts pass these bounds to manifolds. See <a href="https://arxiv.org/pdf/1603.05858v2">Hajłasz, Korobkov and Kristensen, Theorem B, p.2</a>. A measure-zero subset cannot contain an open set, giving the density assertion. It does not imply density of regular values inside every lower-dimensional portion of the image.</p>
</div>
<p>On a compact manifold, Morse functions form an open dense subset of smooth functions in the {% raw %}<span class="math inline">\(C^2\)</span>{% endraw %} topology. On a noncompact manifold, openness requires an appropriate strong topology and does not follow in the compact-open topology. The parameter argument below proves that sufficiently large smooth families have Morse members for almost every parameter. To see this, for a smooth, connected {% raw %}<span class="math inline">\(n\)</span>{% endraw %}-dimensional manifold {% raw %}<span class="math inline">\(M\)</span>{% endraw %}, we will:</p>

<ol>
<li><p>describe families of smooth functions {% raw %}<span class="math inline">\(f: M \to \mathbb R\)</span>{% endraw %} such that they depend smoothly on {% raw %}<span class="math inline">\(\lambda \in \Lambda\)</span>{% endraw %} (where {% raw %}<span class="math inline">\(\Lambda\)</span>{% endraw %} is a smooth, finite-dimensional manifold);</p></li>
<li><p>determine smooth map {% raw %}<span class="math inline">\(\pi : Z \to \Lambda\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(f_\lambda\)</span>{% endraw %} is a Morse function for every regular value of {% raw %}<span class="math inline">\(\pi\)</span>{% endraw %};</p></li>
<li><p>apply Sard’s theorem to conclude that {% raw %}<span class="math inline">\(f_\lambda\)</span>{% endraw %} is “almost-everywhere” a Morse function.</p></li>
</ol>
<p>Embed {% raw %}<span class="math inline">\(M^m\)</span>{% endraw %} in a finite-dimensional Euclidean space {% raw %}<span class="math inline">\(E=\mathbb R^N\)</span>{% endraw %}; Whitney's embedding theorem supplies such an embedding. For a smooth family {% raw %}<span class="math inline">\(F:\Lambda\times E\to\mathbb R\)</span>{% endraw %}, set {% raw %}<span class="math inline">\(F_\lambda(x)=F(\lambda,x)\)</span>{% endraw %} and {% raw %}<span class="math inline">\(f_\lambda=F_\lambda|_M\)</span>{% endraw %}. Restriction of covectors is the surjective linear map {% raw %}<span class="math inline">\(P_x:E^*\to T_x^*M\)</span>{% endraw %}, and</p>
{% raw %}<div class="math display">\[df_\lambda(x)=P_x\,dF_\lambda(x),\qquad \partial^xf:\Lambda\to T_x^*M,\quad\lambda\mapsto df_\lambda(x).\]</div>{% endraw %}
<p> The family may also be specified intrinsically on {% raw %}<span class="math inline">\(\Lambda\times M\)</span>{% endraw %}; the proof below only uses this partial differential.</p><div id="result-8" class="definition" data-note-number="8" data-note-kind="Definition">
<p><strong>Definition 8</strong>.  The family of parametrized functions {% raw %}<span class="math inline">\(F: \Lambda \times E \to \mathbb R\)</span>{% endraw %} is <strong>sufficiently large relative to the submanifold {% raw %}<span class="math inline">\(M \hookrightarrow E\)</span>{% endraw %}</strong> if {% raw %}<span class="math inline">\(\dim \Lambda \geq \dim M\)</span>{% endraw %}, and for all {% raw %}<span class="math inline">\(x \in M\)</span>{% endraw %}, {% raw %}<span class="math inline">\(0 \in T_x^* M\)</span>{% endraw %} is a regular value for {% raw %}<span class="math inline">\(\partial^x f\)</span>{% endraw %}. Furthermore, {% raw %}<span class="math inline">\(F\)</span>{% endraw %} is <strong>large</strong> if for every {% raw %}<span class="math inline">\(x \in E\)</span>{% endraw %} the partial differential map {% raw %}<span class="math inline">\(\partial^x F : \Lambda \to E^* : \lambda \mapsto \dif F_\lambda (x)\)</span>{% endraw %} is a submersion (in other words, if the differential at any {% raw %}<span class="math inline">\(\lambda \in \Lambda\)</span>{% endraw %} is surjective).</p>

</div>
<div id="lem:large-implies-sufficiently-large" class="lemma" data-note-number="9" data-note-kind="Lemma">
<p><strong>Lemma 9</strong>.  If {% raw %}<span class="math inline">\(F : \Lambda \times E \to \mathbb R\)</span>{% endraw %} is large, then it is sufficiently large relative to any submanifold {% raw %}<span class="math inline">\(M \hookrightarrow E\)</span>{% endraw %}.</p>

</div>
<div class="proof">
<p><em>Proof.</em> By definition, since {% raw %}<span class="math inline">\(\partial^x F\)</span>{% endraw %} is a submersion, it follows that {% raw %}<span class="math inline">\(\partial^x f = P_x \dif F_\lambda (x)\)</span>{% endraw %} is a composition of two surjective differential maps (i.e. submersions), which is therefore a submersion. Therefore, {% raw %}<span class="math inline">\(\partial^x f\)</span>{% endraw %} has no critical values, therefore {% raw %}<span class="math inline">\(0\)</span>{% endraw %} has to be a regular value for {% raw %}<span class="math inline">\(\partial^x f\)</span>{% endraw %}. ◻</p>

</div>
<div id="result-10" class="example" data-note-number="10" data-note-kind="Example">
<p><strong>Example 10 (Large families).</strong> The family {% raw %}<span class="math inline">\(H(\lambda,x)=\lambda(x)\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\lambda\in E^*\)</span>{% endraw %}, has {% raw %}<span class="math inline">\(\partial^xH(\lambda)=\lambda\)</span>{% endraw %}. Its parameter derivative is the identity, so it is large.</p>
<p>Let {% raw %}<span class="math inline">\(\Lambda\)</span>{% endraw %} be the open cone of positive definite symmetric operators on {% raw %}<span class="math inline">\(E\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(F(D,x)=\frac12\langle Dx,x\rangle\)</span>{% endraw %}. At fixed {% raw %}<span class="math inline">\(x\ne0\)</span>{% endraw %}, the derivative of {% raw %}<span class="math inline">\(D\mapsto Dx\)</span>{% endraw %} is {% raw %}<span class="math inline">\(A\mapsto Ax\)</span>{% endraw %}, for arbitrary symmetric tangent operators {% raw %}<span class="math inline">\(A\)</span>{% endraw %}. This derivative is surjective: for any {% raw %}<span class="math inline">\(y\in E\)</span>{% endraw %}, the symmetric operator</p>
{% raw %}<div class="math display">\[A=\frac{y\otimes x+x\otimes y}{|x|^2}-\frac{\langle x,y\rangle}{|x|^4}x\otimes x\]</div>{% endraw %}
<p> satisfies {% raw %}<span class="math inline">\(Ax=y\)</span>{% endraw %}, where {% raw %}<span class="math inline">\((u\otimes v)w=u\langle v,w\rangle\)</span>{% endraw %}. Thus the family is sufficiently large on any submanifold avoiding {% raw %}<span class="math inline">\(0\)</span>{% endraw %}. The map {% raw %}<span class="math inline">\(D\mapsto Dx\)</span>{% endraw %} itself is not onto {% raw %}<span class="math inline">\(E\)</span>{% endraw %}, since {% raw %}<span class="math inline">\(\langle Dx,x\rangle&gt;0\)</span>{% endraw %}; it is its derivative that is onto. At {% raw %}<span class="math inline">\(x=0\)</span>{% endraw %}, that derivative is zero, so the family is not large on all of {% raw %}<span class="math inline">\(E\)</span>{% endraw %}.</p>
</div>
<p>The exceptional set in the next theorem is a set of parameters. Every resulting {% raw %}<span class="math inline">\(f_\lambda\)</span>{% endraw %} is defined on all of {% raw %}<span class="math inline">\(M\)</span>{% endraw %}.</p>

<div id="thm:sufficient-large-morse-existence" class="theorem" data-note-number="11" data-note-kind="Theorem">
<p><strong>Theorem 11</strong>.  If the family {% raw %}<span class="math inline">\(F:\Lambda \times E \to \mathbb R\)</span>{% endraw %} is sufficiently large relative to the submanifold {% raw %}<span class="math inline">\(M \hookrightarrow E\)</span>{% endraw %}, then there exists a negligible set {% raw %}<span class="math inline">\(\Lambda_0\)</span>{% endraw %} such that for all {% raw %}<span class="math inline">\(\lambda \in \Lambda \setminus \Lambda_0\)</span>{% endraw %}, the function {% raw %}<span class="math inline">\(f_\lambda : M \to \mathbb R\)</span>{% endraw %} is a Morse function.</p>

<p><em>Proof.</em> In local coordinates on {% raw %}<span class="math inline">\(M^m\)</span>{% endraw %}, form {% raw %}<span class="math inline">\(G(\lambda,x)=(\partial_{x^1}f_\lambda,\ldots,\partial_{x^m}f_\lambda)\)</span>{% endraw %}. At {% raw %}<span class="math inline">\(G=0\)</span>{% endraw %}, the parameter derivative {% raw %}<span class="math inline">\(D_\lambda G\)</span>{% endraw %} is onto by sufficient largeness. Thus the critical-pair set {% raw %}<span class="math inline">\(Z=\{(\lambda,x):df_\lambda(x)=0\}\)</span>{% endraw %} is a smooth submanifold of dimension {% raw %}<span class="math inline">\(\dim\Lambda\)</span>{% endraw %}, by the regular value theorem. This description is independent of the trivialization of {% raw %}<span class="math inline">\(T^*M\)</span>{% endraw %}.</p>
<p>Consider the projection {% raw %}<span class="math inline">\(\pi:Z\to\Lambda\)</span>{% endraw %}. A tangent pair {% raw %}<span class="math inline">\((a,v)\)</span>{% endraw %} belongs to {% raw %}<span class="math inline">\(T_{(\lambda,x)}Z\)</span>{% endraw %} exactly when</p>
{% raw %}<div class="math display">\[D_\lambda G\,a+\operatorname{Hess}_x(f_\lambda)v=0.\]</div>{% endraw %}
<p> Therefore {% raw %}<span class="math inline">\(d\pi\)</span>{% endraw %} is onto if the Hessian is invertible. Conversely, if {% raw %}<span class="math inline">\(d\pi\)</span>{% endraw %} is onto, every {% raw %}<span class="math inline">\(a\)</span>{% endraw %} can occur in such a tangent pair. Since {% raw %}<span class="math inline">\(D_\lambda G\)</span>{% endraw %} is onto, the Hessian must be onto, hence invertible. Thus {% raw %}<span class="math inline">\(\lambda\)</span>{% endraw %} is a regular value of {% raw %}<span class="math inline">\(\pi\)</span>{% endraw %} exactly when all critical points of {% raw %}<span class="math inline">\(f_\lambda\)</span>{% endraw %} are nondegenerate. Sard's theorem makes the set of nonregular values negligible in parameter charts, proving the claim. Empty critical fibers cause no problem.</p>
<p>For completeness, compact-manifold density follows by applying this to {% raw %}<span class="math inline">\(f_\lambda=f+\lambda\circ i\)</span>{% endraw %}, where {% raw %}<span class="math inline">\(i:M\hookrightarrow E\)</span>{% endraw %} is an embedding: parameter derivatives span every cotangent space, and arbitrarily small good {% raw %}<span class="math inline">\(\lambda\)</span>{% endraw %} give arbitrarily small {% raw %}<span class="math inline">\(C^2\)</span>{% endraw %} perturbations on compact {% raw %}<span class="math inline">\(M\)</span>{% endraw %}. Openness follows by taking small neighborhoods of the finitely many critical points where the Hessians remain nonsingular, and using a positive lower bound for {% raw %}<span class="math inline">\(|df|\)</span>{% endraw %} on their compact complement. Sufficiently small {% raw %}<span class="math inline">\(C^2\)</span>{% endraw %} perturbations preserve both properties. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>
</div>
<h3 data-note-section="3" id="morse-functions-and-their-topology">3. Morse Functions and Their Topology</h3>
<p>There are two steps in describing sublevel sets. First consider intervals without critical values; then examine the change across one critical value:</p>

<ol>
<li><p><em>“Weak” Morse principle:</em> if {% raw %}<span class="math inline">\(f^{-1}([a,b])\)</span>{% endraw %} is compact and contains no critical points, the sublevels {% raw %}<span class="math inline">\(M^t=\{f\leq t\}\)</span>{% endraw %}, {% raw %}<span class="math inline">\(a\leq t\leq b\)</span>{% endraw %}, are diffeomorphic by a suitably normalized gradient flow. Compactness prevents finite-time escape while traversing this strip.</p></li>
<li><p><em>“Strong” Morse principle:</em> crossing a nondegenerate critical point of index {% raw %}<span class="math inline">\(\lambda\)</span>{% endraw %}, isolated in a compact strip, attaches a {% raw %}<span class="math inline">\(\lambda\)</span>{% endraw %}-handle to the sublevel. Its boundary undergoes the corresponding surgery. These are assertions about {% raw %}<span class="math inline">\(\{f\leq t\}\)</span>{% endraw %}, with the handle dimension determined by the number of negative Hessian directions.</p></li>
</ol>
<p>We introduce the topological constructions needed to state the change across a critical value precisely.</p>

<p>A closed {% raw %}<span class="math inline">\(k\)</span>{% endraw %}-cell is a copy of {% raw %}<span class="math inline">\(\mathbb D^k\)</span>{% endraw %}, and attaching it to a space {% raw %}<span class="math inline">\(A\)</span>{% endraw %} along {% raw %}<span class="math inline">\(\phi:\mathbb S^{k-1}\to A\)</span>{% endraw %} forms the quotient {% raw %}<span class="math inline">\(A\cup_\phi\mathbb D^k\)</span>{% endraw %}. Finite CW complexes are built inductively in this way, attaching boundaries to lower-dimensional skeleta.</p>
<p>Surgery on a smooth {% raw %}<span class="math inline">\(m\)</span>{% endraw %}-manifold uses an embedded {% raw %}<span class="math inline">\(k\)</span>{% endraw %}-sphere, {% raw %}<span class="math inline">\(0\le k&lt;m\)</span>{% endraw %}, together with a framing of its rank-{% raw %}<span class="math inline">\((m-k)\)</span>{% endraw %} normal bundle. A tubular-neighborhood embedding {% raw %}<span class="math inline">\(\phi:\mathbb D^{m-k}\times\mathbb S^k\to M\)</span>{% endraw %} then specifies the replacement</p>
{% raw %}<div class="math display">\[M(S,\phi)=\left(M\setminus\phi(\operatorname{int}\mathbb D^{m-k}\times\mathbb S^k)\right)\cup_{\phi|\partial}\left(\mathbb S^{m-k-1}\times\mathbb D^{k+1}\right).\]</div>{% endraw %}
<p> Both boundaries are {% raw %}<span class="math inline">\(\mathbb S^{m-k-1}\times\mathbb S^k\)</span>{% endraw %}, of dimension {% raw %}<span class="math inline">\(m-1\)</span>{% endraw %}. Collars on the two sides identify a neighborhood of the seam with this boundary times an open interval, giving the glued smooth structure. Thus it is the disk of dimension {% raw %}<span class="math inline">\(k+1\)</span>{% endraw %}, not {% raw %}<span class="math inline">\(k-1\)</span>{% endraw %}, that fills each copy of the surgery sphere. Isotopic framed embeddings give diffeomorphic surgeries, by extending the isotopy to the tubular neighborhood.</p>
<p>For a manifold with boundary, a {% raw %}<span class="math inline">\(\lambda\)</span>{% endraw %}-handle of dimension {% raw %}<span class="math inline">\(m\)</span>{% endraw %} is {% raw %}<span class="math inline">\(\mathbb D^\lambda\times\mathbb D^{m-\lambda}\)</span>{% endraw %}, attached along {% raw %}<span class="math inline">\(\partial\mathbb D^\lambda\times\mathbb D^{m-\lambda}\)</span>{% endraw %} in the boundary. Corners can be rounded; the induced boundary change is surgery.</p>
<p>A smooth Morse function is <em>exhaustive</em> if every sublevel {% raw %}<span class="math inline">\(M^c=\{f\le c\}\)</span>{% endraw %} is compact. A vector field {% raw %}<span class="math inline">\(X\)</span>{% endraw %} is gradient-like in the increasing direction if {% raw %}<span class="math inline">\(df(X)&gt;0\)</span>{% endraw %} away from critical points and in Morse coordinates {% raw %}<span class="math inline">\(f=f(p)-|x_-|^2+|x_+|^2\)</span>{% endraw %} it equals</p>
{% raw %}<div class="math display">\[X=-2\sum_{i=1}^{\lambda}x^i\partial_{x^i}+2\sum_{j=\lambda+1}^m x^j\partial_{x^j}.\]</div>{% endraw %}
<p> Here {% raw %}<span class="math inline">\(0\le\lambda\le m\)</span>{% endraw %}; either sum may be empty.</p><div id="result-12" class="remark" data-note-number="12" data-note-kind="Remark">
<p><strong>Remark 12.</strong> Morse coordinates exist by the Morse lemma: a smooth function with a nondegenerate critical point of index {% raw %}<span class="math inline">\(\lambda\)</span>{% endraw %} has local form {% raw %}<span class="math inline">\(f(p)-|x_-|^2+|x_+|^2\)</span>{% endraw %}. The linear-algebra step is coordinate invariant by Lemma 4. One construction writes {% raw %}<span class="math inline">\(f-f(p)=\sum a_{ij}(x)x^ix^j\)</span>{% endraw %} using Taylor's integral remainder; the symmetric matrix {% raw %}<span class="math inline">\(a(0)\)</span>{% endraw %} is half the nonsingular Hessian. Successively completing squares with nonzero pivots, shrinking the neighborhood at each step, gives smooth coordinate changes with invertible derivative. Sylvester's law gives exactly {% raw %}<span class="math inline">\(\lambda\)</span>{% endraw %} negative squares. This is the Morse lemma used in the handle argument.</p>
<p>Choose a metric equal to the Euclidean metric in smaller Morse-coordinate neighborhoods. Such a metric exists: the critical set is closed and discrete, so choose disjoint locally finite coordinate neighborhoods, use cutoffs equal to one on smaller neighborhoods, and patch their Euclidean metrics to any initial metric by convex combinations. Positive definite forms remain positive definite under these combinations. In general coordinates,</p>
{% raw %}<div class="math display">\[\nabla^g f=\sum_{i,j}g^{ij}(\partial_j f)\,\partial_i.\]</div>{% endraw %}
<p> For the adapted metric this becomes the gradient-like field displayed above. Its negative flow in the coordinate neighborhood is</p>
{% raw %}<div class="math display">\[\Gamma_t(x_-,x_+)=(e^{2t}x_-,e^{-2t}x_+).\]</div>{% endraw %}
<p> This formula is valid while the trajectory remains in the coordinate neighborhood. It verifies directly the stable and unstable dimensions and the sign convention.</p>
</div>
<p>With these descriptions, and the regular-interval lemma (Lemma <a href="{% post_url 2023-07-06-the-isotopy-lemma-and-injectivity-radius %}#lem:proper-no-crit-point-deformation-retract" data-reference-type="ref" data-reference="lem:proper-no-crit-point-deformation-retract">10</a> of the isotopy-lemma note), we can state and prove the <em>fundamental structural theorem</em>.</p>

<div id="thm:structural-fundamental" class="theorem" data-note-number="13" data-note-kind="Theorem">
<p><strong>Theorem 13</strong> (Fundamental structural theorem).  Suppose {% raw %}<span class="math inline">\(c\)</span>{% endraw %} is a critical value of {% raw %}<span class="math inline">\(f\)</span>{% endraw %} containing a single critical point {% raw %}<span class="math inline">\(p\)</span>{% endraw %} of Morse index {% raw %}<span class="math inline">\(\lambda\)</span>{% endraw %}. Then, for every {% raw %}<span class="math inline">\(\varepsilon &gt; 0\)</span>{% endraw %} sufficiently small, the sublevel set {% raw %}<span class="math inline">\(\{f \leq c+\varepsilon\}\)</span>{% endraw %} is homeomorphic to {% raw %}<span class="math inline">\(\{f \leq c-\varepsilon\}\)</span>{% endraw %} with a {% raw %}<span class="math inline">\(\lambda\)</span>{% endraw %}-handle of dimension {% raw %}<span class="math inline">\(m\)</span>{% endraw %} attached. If {% raw %}<span class="math inline">\(x = (x_-,x_+)\)</span>{% endraw %} are coordinates adapted to the critical point, then the core of the handle is given by {% raw %}<span class="math inline">\(e_\lambda (p) \triangleq \{x_+ = 0 ~,~ |x_-|^2 \leq \varepsilon\}\)</span>{% endraw %}. In particular, {% raw %}<span class="math inline">\(\{f \leq c+\varepsilon\}\)</span>{% endraw %} is homotopy equivalent to {% raw %}<span class="math inline">\(\{f \leq c-\varepsilon\}\)</span>{% endraw %} with the {% raw %}<span class="math inline">\(\lambda\)</span>{% endraw %}-cell {% raw %}<span class="math inline">\(e_\lambda\)</span>{% endraw %} attached.</p>

<p>Assume here that {% raw %}<span class="math inline">\(f\)</span>{% endraw %} is smooth and exhaustive on a manifold without boundary. Equivalently for this local crossing argument, it suffices that a slightly larger strip around {% raw %}<span class="math inline">\(c\)</span>{% endraw %} be compact and contain no other critical points. The two endpoint levels are regular. The handle attachment is understood with corners rounded.</p>
</div>
<div class="proof">
<p><em>Proof.</em> Choose a Morse-coordinate neighborhood {% raw %}<span class="math inline">\(U\)</span>{% endraw %} of {% raw %}<span class="math inline">\(p\)</span>{% endraw %}. Compactness of a strip and isolation of critical points let us choose {% raw %}<span class="math inline">\(\varepsilon&gt;0\)</span>{% endraw %} so that {% raw %}<span class="math inline">\(p\)</span>{% endraw %} is the only critical point in the strip and the closed coordinate ball {% raw %}<span class="math inline">\(B\triangleq\{|x_-|^2+|x_+|^2\le2\varepsilon\}\)</span>{% endraw %} lies in {% raw %}<span class="math inline">\(U\)</span>{% endraw %}.</p>

<p>To apply the weak Morse principle across the critical level {% raw %}<span class="math inline">\(c\)</span>{% endraw %} without altering the topology of the upper sublevel set, we construct an auxiliary smooth function {% raw %}<span class="math inline">\(F : M \to \mathbb{R}\)</span>{% endraw %}. We want {% raw %}<span class="math inline">\(F\)</span>{% endraw %} to match {% raw %}<span class="math inline">\(f\)</span>{% endraw %} outside {% raw %}<span class="math inline">\(B\)</span>{% endraw %}, but strictly lower the critical value at {% raw %}<span class="math inline">\(p\)</span>{% endraw %} to push it below {% raw %}<span class="math inline">\(c-\varepsilon\)</span>{% endraw %}. Let {% raw %}<span class="math inline">\(\mu : [0, \infty) \to [0, \infty)\)</span>{% endraw %} be a smooth bump function satisfying the following criteria:</p>

<ol>
<li><p>{% raw %}<span class="math inline">\(\mu(0) &gt; \varepsilon\)</span>{% endraw %},</p></li>
<li><p>{% raw %}<span class="math inline">\(\mu(r) = 0\)</span>{% endraw %} for all {% raw %}<span class="math inline">\(r \geq 2\varepsilon\)</span>{% endraw %},</p></li>
<li><p>{% raw %}<span class="math inline">\(-1 &lt; \mu&#x27;(r) \leq 0\)</span>{% endraw %} for all {% raw %}<span class="math inline">\(r \geq 0\)</span>{% endraw %}.</p></li>
</ol>
<p>Such a bump exists: take a smooth {% raw %}<span class="math inline">\(h:[0,2\varepsilon]\to[0,1)\)</span>{% endraw %}, vanishing near {% raw %}<span class="math inline">\(2\varepsilon\)</span>{% endraw %}, whose integral exceeds {% raw %}<span class="math inline">\(\varepsilon\)</span>{% endraw %}, and let {% raw %}<span class="math inline">\(\mu(r)=\int_r^{2\varepsilon}h(s)\,ds\)</span>{% endraw %} for {% raw %}<span class="math inline">\(r&lt;2\varepsilon\)</span>{% endraw %}, extended by zero. Then {% raw %}<span class="math inline">\(\mu'=-h\)</span>{% endraw %} has the required bounds. Define {% raw %}<span class="math inline">\(F=f-\mu(|x_-|^2+2|x_+|^2)\)</span>{% endraw %} in {% raw %}<span class="math inline">\(U\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(F=f\)</span>{% endraw %} elsewhere.</p>

{% raw %}<div class="math display">\[\begin{aligned}
        F(x) = \begin{cases}
            f(x) - \mu(|x_-|^2 + 2|x_+|^2) &amp; \text{if } x \in U ~, \\
            f(x) &amp; \text{otherwise} ~.
        \end{cases}
    
\end{aligned}\]</div>{% endraw %}
<p> Because {% raw %}<span class="math inline">\(\mu(r) = 0\)</span>{% endraw %} for {% raw %}<span class="math inline">\(r \geq 2\varepsilon\)</span>{% endraw %}, {% raw %}<span class="math inline">\(F\)</span>{% endraw %} is a well-defined smooth function that transitions identically to {% raw %}<span class="math inline">\(f\)</span>{% endraw %} on and outside the boundary of {% raw %}<span class="math inline">\(B\)</span>{% endraw %}. Furthermore, since {% raw %}<span class="math inline">\(\mu \geq 0\)</span>{% endraw %}, we have {% raw %}<span class="math inline">\(F(x) \leq f(x)\)</span>{% endraw %} everywhere.</p>

<p>We first claim that {% raw %}<span class="math inline">\(\{f \leq c+\varepsilon\} = \{F \leq c+\varepsilon\}\)</span>{% endraw %}. The condition {% raw %}<span class="math inline">\(F \leq f\)</span>{% endraw %} trivially implies {% raw %}<span class="math inline">\(\{f \leq c+\varepsilon\} \subseteq \{F \leq c+\varepsilon\}\)</span>{% endraw %}. For the reverse inclusion, assume for the sake of contradiction there exists an {% raw %}<span class="math inline">\(x \in M\)</span>{% endraw %} such that {% raw %}<span class="math inline">\(F(x) \leq c+\varepsilon\)</span>{% endraw %} but {% raw %}<span class="math inline">\(f(x) &gt; c+\varepsilon\)</span>{% endraw %}. This discrepancy requires {% raw %}<span class="math inline">\(x \in B\)</span>{% endraw %} and the argument of {% raw %}<span class="math inline">\(\mu\)</span>{% endraw %} to be strictly less than {% raw %}<span class="math inline">\(2\varepsilon\)</span>{% endraw %}, meaning {% raw %}<span class="math inline">\(|x_-|^2 + 2|x_+|^2 &lt; 2\varepsilon\)</span>{% endraw %}. This enforces that {% raw %}<span class="math inline">\(2|x_+|^2 \leq |x_-|^2 + 2|x_+|^2 &lt; 2\varepsilon\)</span>{% endraw %}, and consequently {% raw %}<span class="math inline">\(|x_+|^2 &lt; \varepsilon\)</span>{% endraw %}. However, substituting this into the local form of {% raw %}<span class="math inline">\(f\)</span>{% endraw %} yields: </p>

{% raw %}<div class="math display">\[\begin{aligned}
        f(x) = c - |x_-|^2 + |x_+|^2 \leq c + |x_+|^2 &lt; c + \varepsilon ~,
    
\end{aligned}\]</div>{% endraw %}
<p> which contradicts {% raw %}<span class="math inline">\(f(x) &gt; c+\varepsilon\)</span>{% endraw %}. Thus, the sublevel sets are strictly identical: {% raw %}<span class="math inline">\(\{f \leq c+\varepsilon\} = \{F \leq c+\varepsilon\}\)</span>{% endraw %}.</p>

<p>Next, we verify that {% raw %}<span class="math inline">\(F\)</span>{% endraw %} has no critical values in the closed interval {% raw %}<span class="math inline">\([c-\varepsilon, c+\varepsilon]\)</span>{% endraw %}. Outside {% raw %}<span class="math inline">\(B\)</span>{% endraw %}, {% raw %}<span class="math inline">\(F = f\)</span>{% endraw %}, which has no critical points in this bounded range. Inside {% raw %}<span class="math inline">\(B\)</span>{% endraw %}, we compute the partial derivatives of {% raw %}<span class="math inline">\(F\)</span>{% endraw %}: </p>

{% raw %}<div class="math display">\[\begin{aligned}
        \frac{\partial F}{\partial x_-} &amp;= -2x_- - 2x_- \mu&#x27;(|x_-|^2 + 2|x_+|^2) = -2x_- \big(1 + \mu&#x27;(|x_-|^2 + 2|x_+|^2)\big) ~, \\
        \frac{\partial F}{\partial x_+} &amp;= 2x_+ - 4x_+ \mu&#x27;(|x_-|^2 + 2|x_+|^2) = 2x_+ \big(1 - 2\mu&#x27;(|x_-|^2 + 2|x_+|^2)\big) ~.
    
\end{aligned}\]</div>{% endraw %}
<p>Because {% raw %}<span class="math inline">\(-1&lt;\mu'\le0\)</span>{% endraw %}, both {% raw %}<span class="math inline">\(1+\mu'\)</span>{% endraw %} and {% raw %}<span class="math inline">\(1-2\mu'\)</span>{% endraw %} are positive, so the only critical point of {% raw %}<span class="math inline">\(F\)</span>{% endraw %} <em>in the coordinate ball</em> is {% raw %}<span class="math inline">\(p\)</span>{% endraw %}, with {% raw %}<span class="math inline">\(F(p)=c-\mu(0)&lt;c-\varepsilon\)</span>{% endraw %}. Outside the ball, {% raw %}<span class="math inline">\(F=f\)</span>{% endraw %}. Consequently the compact strip {% raw %}<span class="math inline">\(F^{-1}([c-\varepsilon,c+\varepsilon])\)</span>{% endraw %} has no critical points. The regular-interval lemma gives both a diffeomorphism of its endpoint sublevels and a strong deformation retraction of the upper sublevel onto the lower one. Since the upper {% raw %}<span class="math inline">\(F\)</span>{% endraw %}- and {% raw %}<span class="math inline">\(f\)</span>{% endraw %}-sublevels agree, it remains to identify the lower {% raw %}<span class="math inline">\(F\)</span>{% endraw %}-sublevel.</p>

<p>We now prove the cell conclusion without assuming a handle retracts onto its core while fixing its entire attaching region. Put {% raw %}<span class="math inline">\(A=\{f\le c-\varepsilon\}\)</span>{% endraw %}, {% raw %}<span class="math inline">\(u=x_-\)</span>{% endraw %}, {% raw %}<span class="math inline">\(v=x_+\)</span>{% endraw %}, {% raw %}<span class="math inline">\(a=|u|^2\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(b=|v|^2\)</span>{% endraw %}. On the new region {% raw %}<span class="math inline">\(\{F\le c-\varepsilon\}\setminus A\)</span>{% endraw %}, hold {% raw %}<span class="math inline">\(u\)</span>{% endraw %} fixed and shrink {% raw %}<span class="math inline">\(v\)</span>{% endraw %} until its squared norm is</p>
{% raw %}<div class="math display">\[b_*=\max(a-\varepsilon,0).\]</div>{% endraw %}
<p> More explicitly, for {% raw %}<span class="math inline">\(b&gt;0\)</span>{% endraw %} replace {% raw %}<span class="math inline">\(v\)</span>{% endraw %} by {% raw %}<span class="math inline">\(\bigl((1-t)+t\sqrt{b_*/b}\bigr)v\)</span>{% endraw %}, {% raw %}<span class="math inline">\(0\le t\le1\)</span>{% endraw %}. Fix {% raw %}<span class="math inline">\(A\)</span>{% endraw %} pointwise, and also fix {% raw %}<span class="math inline">\(v=0\)</span>{% endraw %}. On the new region {% raw %}<span class="math inline">\(b&gt;b_*\)</span>{% endraw %}, so this shrinks {% raw %}<span class="math inline">\(b\)</span>{% endraw %}; since {% raw %}<span class="math inline">\(\partial F/\partial b=1-2\mu'&gt;0\)</span>{% endraw %}, it stays in the sublevel. At the interface with {% raw %}<span class="math inline">\(A\)</span>{% endraw %}, the factor is {% raw %}<span class="math inline">\(1\)</span>{% endraw %}; at {% raw %}<span class="math inline">\(v=0\)</span>{% endraw %}, continuity follows because the displacement is bounded by {% raw %}<span class="math inline">\(|v|\)</span>{% endraw %}. The deformation is supported inside the coordinate ball and pastes continuously to the identity outside it.</p>
<p>At time one, if {% raw %}<span class="math inline">\(a&gt;\varepsilon\)</span>{% endraw %} the point lies on {% raw %}<span class="math inline">\(f=c-\varepsilon\)</span>{% endraw %}; if {% raw %}<span class="math inline">\(a\le\varepsilon\)</span>{% endraw %}, it lies on the core disk {% raw %}<span class="math inline">\(e_\lambda=\{v=0,\ |u|^2\le\varepsilon\}\)</span>{% endraw %}. The whole core lies in the {% raw %}<span class="math inline">\(F\)</span>{% endraw %}-sublevel because {% raw %}<span class="math inline">\(a+\mu(a)\ge\mu(0)&gt;\varepsilon\)</span>{% endraw %}, using {% raw %}<span class="math inline">\(1+\mu'&gt;0\)</span>{% endraw %}. This is a strong deformation retraction onto {% raw %}<span class="math inline">\(A\cup e_\lambda\)</span>{% endraw %}, fixing both {% raw %}<span class="math inline">\(A\)</span>{% endraw %} and the core. Composing with the regular-strip retraction proves the claimed cell attachment and its attaching sphere {% raw %}<span class="math inline">\(|u|^2=\varepsilon,\ v=0\)</span>{% endraw %}.</p>
<p>For the stronger handle description, choose {% raw %}<span class="math inline">\(0&lt;\delta&lt;\varepsilon\)</span>{% endraw %} small and use the actual product neighborhood</p>
{% raw %}<div class="math display">\[H_\delta=\{\,|v|^2\le\delta,\quad |u|^2\le\varepsilon+|v|^2\,\}.\]</div>{% endraw %}
<p> The map {% raw %}<span class="math inline">\((w,v)\mapsto(\sqrt{\varepsilon+|v|^2}\,w,v)\)</span>{% endraw %} identifies it with {% raw %}<span class="math inline">\(\mathbb D^\lambda\times\mathbb D_{\sqrt\delta}^{m-\lambda}\)</span>{% endraw %}. Its intersection with {% raw %}<span class="math inline">\(A\)</span>{% endraw %} is precisely {% raw %}<span class="math inline">\(|w|=1\)</span>{% endraw %}, so it is a handle attached along the required product of sphere and disk. Its core is {% raw %}<span class="math inline">\(e_\lambda\)</span>{% endraw %}. Choose the chart large enough to contain this small handle.</p>
<p>Outside {% raw %}<span class="math inline">\(A\cup H_\delta\)</span>{% endraw %}, the compact strip has no critical points. The negative adapted gradient decreases both {% raw %}<span class="math inline">\(f\)</span>{% endraw %} and {% raw %}<span class="math inline">\(|v|^2\)</span>{% endraw %} in the chart, with derivatives {% raw %}<span class="math inline">\(-4(|u|^2+|v|^2)\)</span>{% endraw %} and {% raw %}<span class="math inline">\(-4|v|^2\)</span>{% endraw %}. It therefore crosses inward through each exposed face of {% raw %}<span class="math inline">\(A\cup H_\delta\)</span>{% endraw %}, namely {% raw %}<span class="math inline">\(f=c-\varepsilon\)</span>{% endraw %} or {% raw %}<span class="math inline">\(|v|^2=\delta\)</span>{% endraw %}. Rounding their common corner preserves this transversality. Every descending trajectory from the upper level reaches this boundary in finite time: otherwise it would remain in a compact region where {% raw %}<span class="math inline">\(|\nabla f|\)</span>{% endraw %} has a positive lower bound while {% raw %}<span class="math inline">\(f\)</span>{% endraw %} decreases indefinitely. Conversely, the reversed flow reaches the upper level. Smooth dependence and the implicit function theorem for the transverse hitting time identify the region between the rounded boundary and the upper level with a product collar. Rescaling this collar and using the identity farther inside gives a diffeomorphism from the upper sublevel to {% raw %}<span class="math inline">\(A\)</span>{% endraw %} with this handle attached, after rounding corners. For {% raw %}<span class="math inline">\(\lambda=0\)</span>{% endraw %} the handle is a new disk with empty attaching region; for {% raw %}<span class="math inline">\(\lambda=m\)</span>{% endraw %} its entire boundary attaches. These endpoint cases follow from the same local quadratic model. {% raw %}<span class="math inline">\(\square\)</span>{% endraw %}</p>
