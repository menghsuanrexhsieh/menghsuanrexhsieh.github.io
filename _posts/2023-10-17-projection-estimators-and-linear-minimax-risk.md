<div class="note-content" markdown="0">
<p>Projection estimators retain finitely many coefficients in an orthogonal expansion. Omitted coefficients contribute approximation bias, while estimating retained coefficients contributes variance. We derive this risk decomposition, explain what a data-based tuning criterion does and does not guarantee, and solve the weighted Gaussian problem over an ellipsoid.</p>
<div id="projection-estimators"></div><p>Let {% raw %}<span class="math inline">\((\varphi_j)_{j\ge1}\)</span>{% endraw %} be an orthonormal basis of {% raw %}<span class="math inline">\(L^2[0,1]\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(\theta_j=\int_0^1f\varphi_j\)</span>{% endraw %}. Every {% raw %}<span class="math inline">\(f\in L^2\)</span>{% endraw %} has {% raw %}<span class="math inline">\(f=\sum_j\theta_j\varphi_j\)</span>{% endraw %} in {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %}; uniform convergence requires additional regularity and is not needed for Parseval risk calculations.</p>

<p>For fixed-design regression {% raw %}<span class="math inline">\(Y_i=f(X_i)+\xi_i\)</span>{% endraw %}, with independent centered errors, a coefficient estimate and its series estimator are</p>

{% raw %}<div class="math display">\[\widehat\theta_j=\frac1n\sum_iY_i\varphi_j(X_i),\qquad\widehat f_{nN}(x)=\sum_{j=1}^N\widehat\theta_j\varphi_j(x)=\sum_iY_iW_{ni}^{**}(x),\quad W_{ni}^{**}(x)=\frac1n\sum_{j=1}^N\varphi_j(X_i)\varphi_j(x).\]</div>{% endraw %}

<p>For arbitrary deterministic designs, {% raw %}<span class="math inline">\(\mathbb E\widehat\theta_j=n^{-1}\sum_if(X_i)\varphi_j(X_i)\)</span>{% endraw %} need not equal the integral {% raw %}<span class="math inline">\(\theta_j\)</span>{% endraw %}. If this quadrature bias is {% raw %}<span class="math inline">\(b_{j,n}\)</span>{% endraw %}, then orthogonality gives</p>

{% raw %}<div class="math display">\[\mathbb E\|\widehat f_{nN}-f\|_2^2=\sum_{j=1}^N\{b_{j,n}^2+\operatorname{Var}(\widehat\theta_j)\}+\sum_{j&gt;N}\theta_j^2,\qquad\operatorname{Var}(\widehat\theta_j)=\frac1{n^2}\sum_i\varphi_j(X_i)^2\operatorname{Var}(\xi_i).\]</div>{% endraw %}

<p>There are no integrated cross terms, even if the coefficient estimates are correlated. A continuous representative of {% raw %}<span class="math inline">\(f\)</span>{% endraw %}, or otherwise specified point values, is needed to define fixed-design regression on an {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %} class.</p>

<p>For iid observations from a density {% raw %}<span class="math inline">\(p\)</span>{% endraw %} on {% raw %}<span class="math inline">\([0,1]\)</span>{% endraw %}, instead define {% raw %}<span class="math inline">\(c_j=\int p\varphi_j\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\widehat c_j=n^{-1}\sum_i\varphi_j(X_i)\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(\widehat p_{nN}=\sum_{j=1}^N\widehat c_j\varphi_j\)</span>{% endraw %}. The truncation index is {% raw %}<span class="math inline">\(N\)</span>{% endraw %}, not the sample size {% raw %}<span class="math inline">\(n\)</span>{% endraw %}.</p>

<p>For integer {% raw %}<span class="math inline">\(\beta\ge1\)</span>{% endraw %}, the periodic Sobolev class has {% raw %}<span class="math inline">\(f^{(\beta-1)}\)</span>{% endraw %} absolutely continuous, {% raw %}<span class="math inline">\(\int_0^1|f^{(\beta)}|^2\le L^2\)</span>{% endraw %}, and matching endpoint derivatives {% raw %}<span class="math inline">\(f^{(j)}(0)=f^{(j)}(1)\)</span>{% endraw %}, {% raw %}<span class="math inline">\(0\le j&lt;\beta\)</span>{% endraw %}. Use {% raw %}<span class="math inline">\(\varphi_1=1\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\varphi_{2m}=\sqrt2\cos(2\pi mx)\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\varphi_{2m+1}=\sqrt2\sin(2\pi mx)\)</span>{% endraw %}. Integration by parts cancels the periodic boundary terms; differentiation rotates each sine/cosine pair and multiplies it by {% raw %}<span class="math inline">\(2\pi m\)</span>{% endraw %}. Parseval therefore gives</p>

{% raw %}<div class="math display">\[\|f^{(\beta)}\|_2^2=\pi^{2\beta}\sum_ja_j^2\theta_j^2,\qquad a_1=0,\quad a_{2m}=a_{2m+1}=(2m)^\beta.\]</div>{% endraw %}

<p>With {% raw %}<span class="math inline">\(Q=L^2/\pi^{2\beta}\)</span>{% endraw %}, let {% raw %}<span class="math inline">\(\Theta(\beta,Q)=\{\theta\in\ell^2:\sum_ja_j^2\theta_j^2\le Q\}\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\widetilde W(\beta,L)=\{f\in L^2:\theta\in\Theta(\beta,Q)\}\)</span>{% endraw %}. The ellipsoid definition also makes sense for every real {% raw %}<span class="math inline">\(\beta&gt;0\)</span>{% endraw %}, without requiring classical integer derivatives.</p>

<p>An oracle truncation {% raw %}<span class="math inline">\(N_n^*(f)\)</span>{% endraw %} minimizes the true expected risk over a specified candidate set, if the minimum is attained. Because it depends on unknown {% raw %}<span class="math inline">\(f\)</span>{% endraw %}, it is generally unavailable. More generally, for procedures {% raw %}<span class="math inline">\(\widehat\theta_\tau\)</span>{% endraw %} and loss {% raw %}<span class="math inline">\(\mathcal L\)</span>{% endraw %}, the oracle minimizes {% raw %}<span class="math inline">\(R_\theta(\tau)=\mathbb E_\theta\mathcal L(\widehat\theta_\tau,\theta)\)</span>{% endraw %}. Loss is a function of an estimate and parameter; risk is its expectation. Both the candidate class and the loss determine this benchmark.</p>
<div id="result-1" class="remark" data-note-kind="Remark" data-note-number="1"><p>Remark 1. For density estimation assume {% raw %}<span class="math inline">\(p\in L^2[0,1]\)</span>{% endraw %} and {% raw %}<span class="math inline">\(A_j=\int\varphi_j^2p&lt;\infty\)</span>{% endraw %} for the retained indices; the moment-finiteness condition is automatic for the trigonometric basis. Then {% raw %}<span class="math inline">\(\mathbb E\widehat c_j=c_j\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\operatorname{Var}(\widehat c_j)=(A_j-c_j^2)/n\)</span>{% endraw %}. Parseval, first for each realized coefficient vector and then in expectation, yields</p>

{% raw %}<div class="math display">\[\operatorname{MISE}(N)=\frac1n\sum_{j=1}^N(A_j-c_j^2)+\sum_{j&gt;N}c_j^2.\]</div>{% endraw %}

<p>For {% raw %}<span class="math inline">\(n\ge2\)</span>{% endraw %}, define</p>

{% raw %}<div class="math display">\[\widehat J(N)=\frac1{n-1}\sum_{j=1}^N\left\{\frac2n\sum_{i=1}^n\varphi_j(X_i)^2-(n+1)\widehat c_j^2\right\}.\]</div>{% endraw %}

<p>Since {% raw %}<span class="math inline">\(\mathbb E\widehat c_j^2=A_j/n+(n-1)c_j^2/n\)</span>{% endraw %}, each summand has expectation</p>

{% raw %}<div class="math display">\[\frac{2A_j-(n+1)[A_j/n+(n-1)c_j^2/n]}{n-1}=\frac{A_j}{n}-\frac{n+1}{n}c_j^2.\]</div>{% endraw %}

<p>Consequently {% raw %}<span class="math inline">\(\mathbb E\widehat J(N)=\operatorname{MISE}(N)-\|p\|_2^2\)</span>{% endraw %}. Minimizing {% raw %}<span class="math inline">\(\widehat J\)</span>{% endraw %} over a finite candidate set, with deterministic tie-breaking, defines a measurable data-based selector. Equality of the expected criteria does not imply that this random selector minimizes true risk, and a minimum over all integers need not exist without further control. Any oracle inequality for the selected estimate requires a separate argument.</p>

<p>For the trigonometric basis, {% raw %}<span class="math inline">\(A_1=1\)</span>{% endraw %}, {% raw %}<span class="math inline">\(A_{2m}=1+c_{4m}/\sqrt2\)</span>{% endraw %}, and {% raw %}<span class="math inline">\(A_{2m+1}=1-c_{4m}/\sqrt2\)</span>{% endraw %}, by the double-angle identities. Thus {% raw %}<span class="math inline">\(\sum_{j=1}^NA_j=N\)</span>{% endraw %} for odd {% raw %}<span class="math inline">\(N\)</span>{% endraw %}; for even {% raw %}<span class="math inline">\(N\)</span>{% endraw %} it equals {% raw %}<span class="math inline">\(N+c_{2N}/\sqrt2\)</span>{% endraw %}. Since {% raw %}<span class="math inline">\(|c_{2N}|\le\sqrt2\int p=\sqrt2\)</span>{% endraw %}, both cases give</p>

{% raw %}<div class="math display">\[\operatorname{MISE}(N)\le\frac{N+1}{n}+\sum_{j&gt;N}c_j^2\le\frac{N+1}{n}+QN^{-2\beta}\]</div>{% endraw %}

<p>for a density in the Sobolev ellipsoid, because {% raw %}<span class="math inline">\(a_{N+1}\ge N^\beta\)</span>{% endraw %}. Choosing {% raw %}<span class="math inline">\(N\)</span>{% endraw %} of order {% raw %}<span class="math inline">\(n^{1/(2\beta+1)}\)</span>{% endraw %} proves the rate {% raw %}<span class="math inline">\(n^{-2\beta/(2\beta+1)}\)</span>{% endraw %}.</p>
</div>
<div id="result-2" class="remark" data-note-kind="Remark" data-note-number="2"><p>Remark 2. Here is the complete density lower-bound construction underlying the corresponding rate. Let {% raw %}<span class="math inline">\(\mathcal P(\beta,L)\)</span>{% endraw %} be the Hölder densities on {% raw %}<span class="math inline">\(\mathbb R\)</span>{% endraw %} with degree {% raw %}<span class="math inline">\(\ell=\lceil\beta\rceil-1\)</span>{% endraw %} and seminorm bound {% raw %}<span class="math inline">\(L\)</span>{% endraw %}. There is a constant {% raw %}<span class="math inline">\(c&gt;0\)</span>{% endraw %} such that</p>

{% raw %}<div class="math display">\[\liminf_{n\to\infty}n^{2\beta/(2\beta+1)}\inf_{T_n}\sup_{p\in\mathcal P(\beta,L)}\mathbb E_p\|T_n-p\|_2^2\ge c.\]</div>{% endraw %}

<p>Choose a sufficiently spread-out Gaussian density {% raw %}<span class="math inline">\(p_0\)</span>{% endraw %} whose Hölder seminorm is at most {% raw %}<span class="math inline">\(L/2\)</span>{% endraw %}, and put {% raw %}<span class="math inline">\(b_0=\inf_{[0,1]}p_0&gt;0\)</span>{% endraw %}. Choose a fixed smooth nonzero {% raw %}<span class="math inline">\(g\)</span>{% endraw %}, supported inside {% raw %}<span class="math inline">\((0,1)\)</span>{% endraw %}, with {% raw %}<span class="math inline">\(\int g=0\)</span>{% endraw %}; the derivative of a smooth compactly supported bump provides one. Let {% raw %}<span class="math inline">\(h=1/m\)</span>{% endraw %} and {% raw %}<span class="math inline">\(g_k(x)=a h^\beta g((x-(k-1)h)/h)\)</span>{% endraw %}, {% raw %}<span class="math inline">\(1\le k\le m\)</span>{% endraw %}, for a sufficiently small constant {% raw %}<span class="math inline">\(a&gt;0\)</span>{% endraw %}. Define</p>

{% raw %}<div class="math display">\[p_\omega=p_0+\sum_{k=1}^m\omega_kg_k,\qquad\omega\in\{0,1\}^m.\]</div>{% endraw %}

<p>Each perturbation integrates to zero, so {% raw %}<span class="math inline">\(p_\omega\)</span>{% endraw %} integrates to one. The supports are disjoint and the pointwise perturbation is at most {% raw %}<span class="math inline">\(a h^\beta\|g\|_\infty\)</span>{% endraw %}, which is below {% raw %}<span class="math inline">\(b_0/2\)</span>{% endraw %} for large {% raw %}<span class="math inline">\(m\)</span>{% endraw %}; hence these are nonnegative densities. Scaling gives a Hölder seminorm bounded by {% raw %}<span class="math inline">\(C_ga\)</span>{% endraw %} for a bump. Across two different supports, compare each derivative value with its zero value at the intervening endpoint; the sum of the two powers is at most {% raw %}<span class="math inline">\(2|x-y|^{\beta-\ell}\)</span>{% endraw %}. Thus the bound remains {% raw %}<span class="math inline">\(2C_ga\)</span>{% endraw %}, independently of {% raw %}<span class="math inline">\(m\)</span>{% endraw %}. Choose {% raw %}<span class="math inline">\(a\)</span>{% endraw %} so it is at most {% raw %}<span class="math inline">\(L/2\)</span>{% endraw %}. This verifies membership of every perturbation in the stated class.</p>

<p>The Varshamov–Gilbert lemma supplies {% raw %}<span class="math inline">\(M+1\)</span>{% endraw %} binary vectors, including zero, with pairwise Hamming distances at least {% raw %}<span class="math inline">\(m/8\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\log(M+1)\ge c_0m\)</span>{% endraw %}, for all sufficiently large {% raw %}<span class="math inline">\(m\)</span>{% endraw %}. Disjoint supports give the squared distance</p>

{% raw %}<div class="math display">\[\|p_\omega-p_{\omega'}\|_2^2=a^2h^{2\beta+1}\|g\|_2^2H(\omega,\omega')\ge(a^2\|g\|_2^2/8)h^{2\beta}.\]</div>{% endraw %}

<p>Write {% raw %}<span class="math inline">\(v=p_\omega-p_0\)</span>{% endraw %}. Using {% raw %}<span class="math inline">\(\log(1+v/p_0)\le v/p_0\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\int v=0\)</span>{% endraw %},</p>

{% raw %}<div class="math display">\[D(p_\omega\|p_0)\le\int\frac{v^2}{p_0}\le b_0^{-1}a^2h^{2\beta+1}\|g\|_2^2m=Ch^{2\beta}.\]</div>{% endraw %}

<p>For {% raw %}<span class="math inline">\(n\)</span>{% endraw %} iid observations the divergence is multiplied by {% raw %}<span class="math inline">\(n\)</span>{% endraw %}, as follows by summing the log likelihood over observations. Choose {% raw %}<span class="math inline">\(m=\lceil A n^{1/(2\beta+1)}\rceil\)</span>{% endraw %}, with {% raw %}<span class="math inline">\(A\)</span>{% endraw %} sufficiently large; then {% raw %}<span class="math inline">\(nCh^{2\beta}/\log(M+1)\le C'n h^{2\beta+1}\)</span>{% endraw %} is at most {% raw %}<span class="math inline">\(1/4\)</span>{% endraw %}. The entropy testing bound proved in the preceding local-polynomial note gives average classification error at least {% raw %}<span class="math inline">\(1/2\)</span>{% endraw %} for large {% raw %}<span class="math inline">\(n\)</span>{% endraw %}. Selecting the nearest density to any proposed estimator converts squared {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %} error smaller than one quarter of the squared separation into correct classification. Its maximum risk is therefore at least a positive constant times {% raw %}<span class="math inline">\(h^{2\beta}\)</span>{% endraw %}, proving the claim. The packing lemma supplies separated alternatives; the divergence and testing steps, not the packing lemma alone, turn them into a minimax bound.</p>
</div>
<h3 id="adaptation-and-asymptotic-efficiency" data-note-section="1">1. Adaptation, and Asymptotic Efficiency</h3>
<p>For a squared semimetric loss let {% raw %}<span class="math inline">\(r(\widehat\theta_n)=\sup_{\theta\in\Theta}\mathbb E_\theta d^2(\widehat\theta_n,\theta)\)</span>{% endraw %} and {% raw %}<span class="math inline">\(\mathcal R_n^*=\inf_{\widehat\theta_n}r(\widehat\theta_n)\)</span>{% endraw %}. A rate {% raw %}<span class="math inline">\(\psi_n\)</span>{% endraw %} is minimax optimal if {% raw %}<span class="math inline">\(0&lt;c\le\liminf\psi_n^{-2}\mathcal R_n^*\le\limsup\psi_n^{-2}\mathcal R_n^*\le C&lt;\infty\)</span>{% endraw %}. An estimator is asymptotically efficient if {% raw %}<span class="math inline">\(r(\widehat\theta_n)/\mathcal R_n^*\to1\)</span>{% endraw %}. This is stronger than attaining only the rate. Adaptation asks whether one procedure can retain the desired performance over multiple smoothness classes without knowing which class contains the truth; nothing in the oracle definition itself proves adaptation.</p>

<p>In the white-noise model {% raw %}<span class="math inline">\(dY=fdt+\varepsilon dW\)</span>{% endraw %}, define the Pinsker estimator by {% raw %}<span class="math inline">\(\widehat f_\varepsilon=\sum_j(1-\kappa^*a_j)_+y_j\varphi_j\)</span>{% endraw %}, where {% raw %}<span class="math inline">\(y_j=\int\varphi_jdY\)</span>{% endraw %} and</p>

{% raw %}<div class="math display">\[\kappa^*=\left(\frac\beta{(2\beta+1)(\beta+1)Q}\right)^{\beta/(2\beta+1)}\varepsilon^{2\beta/(2\beta+1)}.\]</div>{% endraw %}
<div id="thm:pinsker" class="theorem" data-note-kind="Theorem" data-note-number="3"><p>Theorem 3. For every {% raw %}<span class="math inline">\(\beta,L&gt;0\)</span>{% endraw %}, using the ellipsoid definition of {% raw %}<span class="math inline">\(\widetilde W\)</span>{% endraw %},</p>

{% raw %}<div class="math display">\[\lim_{\varepsilon\downarrow0}\varepsilon^{-4\beta/(2\beta+1)}\sup_{f\in\widetilde W}\mathbb E_f\|\widehat f_\varepsilon-f\|_2^2=\lim_{\varepsilon\downarrow0}\varepsilon^{-4\beta/(2\beta+1)}\inf_{T_\varepsilon}\sup_{f\in\widetilde W}\mathbb E_f\|T_\varepsilon-f\|_2^2=C^*,\]</div>{% endraw %}

<p>where {% raw %}<span class="math inline">\(C^*=L^{2/(2\beta+1)}(2\beta+1)^{1/(2\beta+1)}[\beta/(\pi(\beta+1))]^{2\beta/(2\beta+1)}\)</span>{% endraw %}.</p>
</div>
<p>The full upper and Gaussian-prior lower bound are proved in <a href="{% post_url 2023-07-17-the-gaussian-sequence-model-and-pinskers-theorem %}#thm:pinsker">the Pinsker theorem note</a>. Its proof uses only the coefficient weights and works for all real positive {% raw %}<span class="math inline">\(\beta\)</span>{% endraw %}; the integer restriction there concerns the classical Sobolev interpretation. In particular, the theorem gives a risk ratio tending to one, rather than just matching exponents.</p>
<p>For equally spaced regression {% raw %}<span class="math inline">\(Y_i=f(i/n)+\xi_i\)</span>{% endraw %}, {% raw %}<span class="math inline">\(\xi_i\sim \mathcal{N}(0,\sigma^2)\)</span>{% endraw %}, the same sharp constant after replacing {% raw %}<span class="math inline">\(\varepsilon\)</span>{% endraw %} by {% raw %}<span class="math inline">\(\sigma/\sqrt n\)</span>{% endraw %} is valid for {% raw %}<span class="math inline">\(\beta&gt;1/2\)</span>{% endraw %}, with the continuous periodic representative. This needs a discretization argument; it is not a literal specialization of the white-noise observation.</p>

<p>Here is that argument. Write the complex Fourier coefficients as {% raw %}<span class="math inline">\(c_k\)</span>{% endraw %}, {% raw %}<span class="math inline">\(k\in\mathbb Z\)</span>{% endraw %}. The ellipsoid bound gives {% raw %}<span class="math inline">\(\sum_{k\ne0}|k|^{2\beta}|c_k|^2\le C L^2\)</span>{% endraw %}. For {% raw %}<span class="math inline">\(\beta&gt;1/2\)</span>{% endraw %}, Cauchy–Schwarz and {% raw %}<span class="math inline">\(\sum_{k\ne0}|k|^{-2\beta}&lt;\infty\)</span>{% endraw %} give absolute uniform convergence of the Fourier series. The discrete coefficient at frequency {% raw %}<span class="math inline">\(k\)</span>{% endraw %} therefore has mean {% raw %}<span class="math inline">\(\sum_{r\in\mathbb Z}c_{k+rn}\)</span>{% endraw %}. For {% raw %}<span class="math inline">\(|k|\le m&lt;n/4\)</span>{% endraw %}, its alias error {% raw %}<span class="math inline">\(d_k=\sum_{r\ne0}c_{k+rn}\)</span>{% endraw %} satisfies</p>

{% raw %}<div class="math display">\[|d_k|^2\le\left(\sum_{r\ne0}|k+rn|^{-2\beta}\right)\sum_{r\ne0}|k+rn|^{2\beta}|c_{k+rn}|^2\le C_\beta n^{-2\beta}\sum_{r\ne0}|k+rn|^{2\beta}|c_{k+rn}|^2.\]</div>{% endraw %}

<p>The residue classes for distinct {% raw %}<span class="math inline">\(|k|\le m\)</span>{% endraw %} are disjoint. Summing proves {% raw %}<span class="math inline">\(\sum_{|k|\le m}|d_k|^2\le C L^2n^{-2\beta}\)</span>{% endraw %}, also in the equivalent real basis. The real discrete trigonometric coefficients below frequency {% raw %}<span class="math inline">\(m\)</span>{% endraw %} have independent noise variance {% raw %}<span class="math inline">\(\sigma^2/n\)</span>{% endraw %}, by exact grid orthogonality and Gaussianity.</p>

<p>The Pinsker cutoff has {% raw %}<span class="math inline">\(m\asymp n^{1/(2\beta+1)}=o(n)\)</span>{% endraw %}; hence it lies in this range eventually. Its squared alias error is {% raw %}<span class="math inline">\(O(n^{-2\beta})=o(n^{-2\beta/(2\beta+1)})\)</span>{% endraw %}. By Cauchy–Schwarz, the cross term between this deterministic error and the ideal estimator error is also negligible relative to the ideal estimator’s risk: it is bounded by twice the product of their root mean squared errors. This proves the sharp upper bound. For the lower bound restrict to the finite Fourier submodel supported on the same active frequencies. There is no aliasing, and the remaining orthogonal coordinates are independent parameter-free Gaussian noise. The finite Gaussian prior and outside-mass argument in Pinsker's proof therefore apply unchanged. The regression minimax risk is consequently</p>

{% raw %}<div class="math display">\[C^*\sigma^{4\beta/(2\beta+1)}n^{-2\beta/(2\beta+1)}(1+o(1)).\]</div>{% endraw %}

<p>For {% raw %}<span class="math inline">\(\beta\le1/2\)</span>{% endraw %}, this argument fails and an {% raw %}<span class="math inline">\(L^2\)</span>{% endraw %} equivalence class does not itself specify values at the sampled points; the unrestricted discrete-regression assertion requires additional assumptions.</p>
<h3 id="reduction-to-linear-minimax-estimators" data-note-section="1.1">1.1. Reduction to Linear Minimax Estimators</h3>
<p>The sequence observations are {% raw %}<span class="math inline">\(y_j=\theta_j+\varepsilon\xi_j=\int\varphi_jdY\)</span>{% endraw %}, not the noiseless integrals {% raw %}<span class="math inline">\(\int\varphi_j f\)</span>{% endraw %}. For deterministic square-summable weights,</p>

{% raw %}<div class="math display">\[R(\lambda,\theta)=\sum_j\{(1-\lambda_j)^2\theta_j^2+\varepsilon^2\lambda_j^2\},\qquad R^L=\inf_\lambda\sup_{\theta\in\Theta}R(\lambda,\theta).\]</div>{% endraw %}

<p>Each coordinate is minimized separately: its derivative is {% raw %}<span class="math inline">\(2(\lambda_j-1)\theta_j^2+2\varepsilon^2\lambda_j\)</span>{% endraw %}, giving</p>

{% raw %}<div class="math display">\[\lambda_j^{\rm oracle}=\frac{\theta_j^2}{\varepsilon^2+\theta_j^2},\qquad\inf_\lambda R(\lambda,\theta)=\sum_j\frac{\varepsilon^2\theta_j^2}{\varepsilon^2+\theta_j^2}.\]</div>{% endraw %}

<p>The minimizing sequence is in {% raw %}<span class="math inline">\(\ell^2\)</span>{% endraw %}, since {% raw %}<span class="math inline">\(\sum_j(\lambda_j^{\rm oracle})^2\le\varepsilon^{-2}\|\theta\|_2^2\)</span>{% endraw %}. One summed first-order equation would not determine all the individual weights.</p>
<div id="lem:linear-minimax-first-step" class="lemma" data-note-kind="Lemma" data-note-number="4"><p>Lemma 4. Suppose {% raw %}<span class="math inline">\(a_j\ge0\)</span>{% endraw %} is nondecreasing and tends to infinity, and {% raw %}<span class="math inline">\(Q&gt;0\)</span>{% endraw %}. The auxiliary equation below has a unique solution {% raw %}<span class="math inline">\(\kappa&gt;0\)</span>{% endraw %}.</p>
</div>
<span id="eq:auxiliary-kappa-equation"></span>{% raw %}<div class="math display">\[\frac{\varepsilon^2}{\kappa}\sum_ja_j(1-\kappa a_j)_+=Q,\qquad\kappa=\frac{\varepsilon^2\sum_{j\le N}a_j}{Q+\varepsilon^2\sum_{j\le N}a_j^2},\quad N=\max\{j:\varepsilon^2\sum_{m\le j}a_m(a_j-a_m)&lt;Q\}.\tag{1}\]</div>{% endraw %}

<p>Proof. The left side as a function of {% raw %}<span class="math inline">\(\kappa\)</span>{% endraw %} is continuous, strictly decreasing while positive, tends to infinity at zero, and becomes zero at the reciprocal of the smallest positive {% raw %}<span class="math inline">\(a_j\)</span>{% endraw %}. Continuity follows from finite support of the summands on every compact subinterval of {% raw %}<span class="math inline">\((0,\infty)\)</span>{% endraw %}. This proves a unique root. The numbers {% raw %}<span class="math inline">\(S_j=\varepsilon^2\sum_{m\le j}a_m(a_j-a_m)\)</span>{% endraw %} increase to infinity. If {% raw %}<span class="math inline">\(A=\varepsilon^2\sum_{m\le N}a_m\)</span>{% endraw %}, {% raw %}<span class="math inline">\(B=\varepsilon^2\sum_{m\le N}a_m^2\)</span>{% endraw %}, then {% raw %}<span class="math inline">\(S_N=Aa_N-B&lt;Q\le Aa_{N+1}-B=S_{N+1}\)</span>{% endraw %}. Thus {% raw %}<span class="math inline">\(a_N&lt;1/\kappa\le a_{N+1}\)</span>{% endraw %} for the claimed formula, so precisely its first {% raw %}<span class="math inline">\(N\)</span>{% endraw %} terms are active; substitution proves (1). ◻</p>

<p>Define {% raw %}<span class="math inline">\(\ell_j=(1-\kappa a_j)_+\)</span>{% endraw %} and {% raw %}<span class="math inline">\(D^*=\varepsilon^2\sum_j\ell_j\)</span>{% endraw %}. The factor is {% raw %}<span class="math inline">\(\varepsilon^2\)</span>{% endraw %} throughout.</p>
<div id="lem:linear-minimax" class="lemma" data-note-kind="Lemma" data-note-number="5"><p>Lemma 5. For {% raw %}<span class="math inline">\(\Theta=\{\theta\in\ell^2:\sum_ja_j^2\theta_j^2\le Q\}\)</span>{% endraw %}, assume finitely many {% raw %}<span class="math inline">\(a_j=0\)</span>{% endraw %}, a positive solution of (1), and {% raw %}<span class="math inline">\(D^*&lt;\infty\)</span>{% endraw %}. Then</p>

{% raw %}<div class="math display">\[\sup_\theta\inf_\lambda R(\lambda,\theta)=\inf_\lambda\sup_\theta R(\lambda,\theta)=\sup_\theta R(\ell,\theta)=D^*.\]</div>{% endraw %}
</div>
<p>Proof. The general minimax inequality places {% raw %}<span class="math inline">\(\sup_\theta\inf_\lambda R\)</span>{% endraw %} below {% raw %}<span class="math inline">\(\inf_\lambda\sup_\theta R\)</span>{% endraw %}, which is no larger than {% raw %}<span class="math inline">\(\sup_\theta R(\ell,\theta)\)</span>{% endraw %}. It suffices to bound the two ends.</p>
<span id="eq:linear-minimax-first"></span><p>For the upper bound, zero-weight coordinates have {% raw %}<span class="math inline">\(\ell_j=1\)</span>{% endraw %} and no bias. On other coordinates {% raw %}<span class="math inline">\((1-\ell_j)/a_j\le\kappa\)</span>{% endraw %}, so</p>

{% raw %}<div class="math display">\[R(\ell,\theta)\le\varepsilon^2\sum_j\ell_j^2+Q\kappa^2=\varepsilon^2\sum_j\ell_j(\ell_j+\kappa a_j)=\varepsilon^2\sum_j\ell_j=D^*.\]</div>{% endraw %}

<p>We used (1) and {% raw %}<span class="math inline">\(\ell_j+\kappa a_j=1\)</span>{% endraw %} on active coordinates. The weights are admissible since {% raw %}<span class="math inline">\(\sum_j\ell_j^2\le\sum_j\ell_j&lt;\infty\)</span>{% endraw %}.</p>
<span id="eq:linear-minimax-second"></span><p>For the lower bound put {% raw %}<span class="math inline">\(v_j^2=\varepsilon^2\ell_j/(\kappa a_j)\)</span>{% endraw %} on any finite set of positive-weight coordinates, zero on the other positive-weight coordinates, and {% raw %}<span class="math inline">\(v_j=M\)</span>{% endraw %} on zero-weight coordinates. Equation (1) gives {% raw %}<span class="math inline">\(\sum_ja_j^2v_j^2\le Q\)</span>{% endraw %}, and the vector lies in {% raw %}<span class="math inline">\(\ell^2\)</span>{% endraw %}. Its oracle risk is</p>

{% raw %}<div class="math display">\[\sum_{a_j=0}\frac{\varepsilon^2M^2}{\varepsilon^2+M^2}+\varepsilon^2\sum_{j\text{ in the finite positive set}}\ell_j.\]</div>{% endraw %}

<p>Let the finite sets increase to all positive-weight coordinates and {% raw %}<span class="math inline">\(M\to\infty\)</span>{% endraw %}. The limit is {% raw %}<span class="math inline">\(D^*\)</span>{% endraw %}, giving the reverse bound without assuming that a least-favorable vector exists at the unbounded zero coordinates. ◻</p>
<div id="result-6" class="remark" data-note-kind="Remark" data-note-number="6"><p>Remark 6. The sequence {% raw %}<span class="math inline">\(\ell\)</span>{% endraw %} is the Pinsker weight and {% raw %}<span class="math inline">\(\widehat\theta_j=\ell_jy_j\)</span>{% endraw %} the Pinsker estimator. Lemma 5 solves the linear problem exactly; the Gaussian-prior lower bound in Theorem 3 is the additional step that establishes asymptotic optimality among all estimators.</p>
